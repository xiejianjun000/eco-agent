## 三、穿透式验证要点

1. **全栏目真实抓取**：主站 60+ 栏目逐一读取，全部返回有效 items（含 note 为空但 items>0），无空跑、无 404 幽灵栏目。
2. **文章正文穿透**：取真实文章 URL 读取正文，title/content 非空；政策全文、标准详情、实时空气质量、地表水、辐射剂量率均返回真实数据。
3. **搜索穿透**：政策/标准/危废/站内 4 类检索均返回真实条目。
4. **下载闭环**：栏目导出 CSV/JSON、空气质量 CSV、网页文件下载、下载目录列举全部真实落盘并可回读。
5. **RAG 闭环**：灌入→检索→命中（hits=1，2-gram 索引正常）。
6. **容错**：未知栏目/未知文种/未知报告/空关键词/超长 limit/非法 URL/外部 URL 全部优雅返回，无一崩溃。
7. **缓存压力**：同一栏目连续两次均 cache hit（首轮后全栏目命中），冷热两轮耗时 274s → 14s。
8. **并发压力**：12 线程并发 18 调用（栏目读取 + 导览 + 实时数据 + 检索 + RAG），0 错误，0.2s 完成，无线程安全问题。
