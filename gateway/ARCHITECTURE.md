# ECO AGENT Gateway 统一网关架构

> **多平台消息中间件 — 飞书 · 企业微信 · 钉钉 · 微信**
> 版本：v0.1.0 · 最后更新：2026-07-28

---

## 1. 架构概览

```
                    ┌──────────────────────────────┐
                    │       ECO AGENT Core          │
                    │  (Hermes AIAgent Loop)        │
                    └──────────┬───────────────────┘
                               │ Gateway API
                    ┌──────────▼───────────────────┐
                    │       Gateway Router           │
                    │  (platform dispatch + auth)    │
                    └──┬─────────┬─────────┬───────┘
                       │         │         │
              ┌────────▼──┐ ┌───▼────┐ ┌──▼───────┐
              │  飞书 Bot  │ │企业微信  │ │  钉钉 Bot │
              │ (WebSocket)│ │ (HTTP) │ │ (HTTP)   │
              └─────┬─────┘ └───┬────┘ └────┬─────┘
                    │           │           │
              ┌─────▼─────┐ ┌───▼────┐ ┌───▼──────┐
              │飞书审批收件箱│ │微信公号  │ │ 钉钉审批  │
              │           │ │(可选)   │ │          │
              └───────────┘ └────────┘ └──────────┘
```

## 2. 统一消息协议

所有平台统一使用以下消息格式进行内部路由：

```json
{
  "platform": "feishu | wecom | dingtalk | wechat",
  "event_type": "message | approval | callback",
  "event_id": "唯一事件 ID",
  "timestamp": "2026-07-28T12:00:00Z",
  "user": {
    "id": "用户 ID（平台原始）",
    "name": "用户姓名（可选）",
    "platform_id": "平台内唯一标识"
  },
  "conversation": {
    "id": "会话 ID",
    "type": "p2p | group | channel"
  },
  "message": {
    "type": "text | image | interactive | file",
    "content": "消息内容（文本）",
    "raw": {}  // 平台原始数据
  },
  "approval": {  // 审批事件时存在
    "id": "审批实例 ID",
    "status": "pending | approved | rejected",
    "risk_level": "low | medium | high",
    "operation": "操作描述"
  }
}
```

## 4. 安全策略

| 策略 | 说明 |
|:-----|:------|
| Token 验证 | 所有平台 Webhook 均需验证签名 |
| IP 白名单 | 仅允许平台官方 IP 段回调 |
| 消息去重 | 基于 event_id 去重（24h 窗口）|
| 频率限制 | 单用户 20 条/分钟，超限静默 |
| 敏感内容过滤 | 手机号/身份证号自动脱敏 |

## 5. 消息模板

所有平台共用一套消息模板，按平台能力自动适配：

| 模板 | 用途 | 适配方式 |
|:-----|:------|:---------|
| text_reply | 纯文本回复 | 所有平台直接支持 |
| card_reply | 富卡片消息 | 飞书 Interactive Card / 企微图文 / 钉钉 Card |
| approval_card | 审批通知 | 飞书审批卡片 / 企微审批 / 钉钉审批 |
| error_msg | 错误提示 | 各平台均适配为文本 |
| alert_msg | 风险预警 | 各平台红色提醒 |
