# 核心循环架构（The Eco Loops）—— 五重嵌套生命节律

> **Eco Agent 不做"一问一答"的提线木偶，而是拥有持续搏动的数字生命节律。**
> 版本：v1.0 · 建立：2026-07-29

---

## 总纲：五层循环的嵌套关系

```
                    时间尺度
                      │
       天/周  ◀───────┼─────────────────────▶  元认知进化循环
                      │                      (Evolve)
       小时   ◀───────┼───────────▶  后台心跳循环
                      │            (Pulse)
       分钟   ◀───────┼──▶  任务执行循环
                      │   (Task)
       秒     ◀───────┼─▶  微观行动循环
                      │  (ReAct++)
       实时   ◀───────┼▶  韧性自愈循环
                      │  (Self-Healing)
                      │
                      ▼
              Eco Agent 持续搏动
          （永不静止的数字生命体）
```

---

## 第一层：微观行动循环（Micro ReAct Loop）—— 节律：毫秒~秒级

**对标**：Claude 的推理-行动-观察（ReAct），但强化了"暂停-反思-重试"机制。

```
┌─────────────────────────────────────────────────────────────┐
│                    微观行动循环（ReAct++）                    │
├─────────────────────────────────────────────────────────────┤
│   ┌─────────┐    ┌─────────┐    ┌─────────┐               │
│   │ OBSERVE │───▶│  THINK  │───▶│  ACT    │               │
│   │  观察   │    │  推理   │    │  执行   │               │
│   └────┬────┘    └─────────┘    └────┬────┘               │
│        │                              │                     │
│        │     ┌─────────────────┐      │                     │
│        └─────│   PAUSE &       │◀─────┘                     │
│              │   REFLECT       │                            │
│              └─────────────────┘                            │
│                    │                                        │
│                    ▼                                        │
│         ┌─────────────────┐                                │
│         │  RETRY /        │                                │
│         │  ALTERNATIVE    │  ← 最多3次自修复尝试          │
│         │  PATH           │                                │
│         └─────────────────┘                                │
└─────────────────────────────────────────────────────────────┘
```

**Eco Agent 超越点**：
- **中断注入**：允许用户在循环任意节点打断并修正路径
- **置信度门控**：THINK 阶段输出置信度评分，低于阈值自动触发 PAUSE & REFLECT
- **工具调用链原子化**：每个工具调用视为原子操作，失败时可回滚到上一个观察点

## 第二层：任务执行循环（Task Execution Loop）—— 节律：秒~分钟级

**对标**：Codex 的多步骤架构设计 + Hermes 的任务验证机制。

```
┌─────────────────────────────────────────────────────────────────┐
│                    任务执行循环（Plan-Execute-Verify）           │
├─────────────────────────────────────────────────────────────────┤
│   ┌──────────────┐      ┌──────────────┐                      │
│   │  PLAN        │─────▶│  DECOMPOSE   │                      │
│   │  规划子目标   │      │  拆解为子任务 │                      │
│   └──────────────┘      └──────┬───────┘                      │
│                                 ▼                              │
│   ┌──────────────────────────────────────────┐                │
│   │          PARALLEL EXECUTION              │                │
│   │   ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐   │                │
│   │   │Agent│  │Agent│  │Agent│  │Agent│   │                │
│   │   │  A  │  │  B  │  │  C  │  │  D  │   │                │
│   │   └──┬──┘  └──┬──┘  └──┬──┘  └──┬──┘   │                │
│   └──────┼────────┼────────┼────────┼───────┘                │
│          └────────┴────┬───┴────────┘                          │
│                        ▼                                      │
│              ┌─────────────────┐                              │
│              │  AGGREGATE &    │                              │
│              │  VERIFY         │                              │
│              └────────┬────────┘                              │
│                       │                                       │
│            ┌──────────┴──────────┐                            │
│            │                     │                            │
│            ▼                     ▼                            │
│       ✅ PASS              ❌ FAIL                            │
│       ┌────────┐      ┌─────────────────┐                    │
│       │ DELIVER│      │  DIAGNOSE &     │                    │
│       │        │      │  REPLAN         │  ← 最多2轮重规划   │
│       └────────┘      └─────────────────┘                    │
└─────────────────────────────────────────────────────────────────┘
```

**Eco Agent 超越点**：
- **动态重规划**：失败后不简单重试，而是重新分解任务、换路径
- **子任务依赖图**：自动识别任务间的依赖关系（串行/并行/条件）
- **进度持久化**：长任务（跨小时）可中断恢复，保存执行快照

## 第三层：后台心跳循环（Heartbeat Background Loop）—— 节律：每5~20分钟

**对标**：OpenHuman 的"潜意识循环" + Codex 的"定时心跳自动化任务"。

```
┌─────────────────────────────────────────────────────────────────┐
│                  后台心跳循环（Autonomous Pulse）                │
├─────────────────────────────────────────────────────────────────┤
│   ⏰ 每5~20分钟（用户可配置间隔）自动唤醒                        │
│                                                                 │
│   ┌───────────────────────────────────────────────────────┐    │
│   │  STEP 1: 全平台数据同步                               │    │
│   └───────────────────────┬───────────────────────────────┘    │
│                           ▼                                    │
│   ┌───────────────────────────────────────────────────────┐    │
│   │  STEP 2: 差异检测（新邮件/新PR/新会议/新文档）       │    │
│   └───────────────────────┬───────────────────────────────┘    │
│                           ▼                                    │
│   ┌───────────────────────────────────────────────────────┐    │
│   │  STEP 3: 自动触发预定义规则（Rule Engine）           │    │
│   └───────────────────────┬───────────────────────────────┘    │
│                           ▼                                    │
│   ┌───────────────────────────────────────────────────────┐    │
│   │  STEP 4: 内存碎片整理（MemCron）                    │    │
│   └───────────────────────┬───────────────────────────────┘    │
│                           ▼                                    │
│   ┌───────────────────────────────────────────────────────┐    │
│   │  STEP 5: 主动建议生成（推送到用户通知中心）          │    │
│   └───────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────┘
```

**Eco Agent 超越点**：
- **渐进式唤醒**：根据电量/CPU负载动态调整心跳频率
- **静默执行**：绝大多数后台操作不打扰用户
- **睡眠期学习**：在设备空闲时进行离线推理

## 第四层：元认知进化循环（Meta-Cognition Evolution Loop）—— 节律：每次任务结束后 ~ 每日批次

**对标**：Hermes 的学习闭环，但扩展为多维度进化。

```
┌─────────────────────────────────────────────────────────────────┐
│                   元认知进化循环（Evolve Loop）                 │
├─────────────────────────────────────────────────────────────────┤
│   🧠 触发条件：任务完成 / 每日凌晨2:00 / 用户主动触发          │
│                                                                 │
│   ┌──────────────────────────────────────────────────────────┐ │
│   │  阶段1: 经验回放（Experience Replay）                   │ │
│   └──────────────────────┬───────────────────────────────────┘ │
│                          ▼                                     │
│   ┌──────────────────────────────────────────────────────────┐ │
│   │  阶段2: 差距分析（Gap Analysis）                       │ │
│   └──────────────────────┬───────────────────────────────────┘ │
│                          ▼                                     │
│   ┌──────────────────────────────────────────────────────────┐ │
│   │  阶段3: 技能生成/优化（Skill Gen/Update）              │ │
│   └──────────────────────┬───────────────────────────────────┘ │
│                          ▼                                     │
│   ┌──────────────────────────────────────────────────────────┐ │
│   │  阶段4: 记忆固化（Memory Consolidation）               │ │
│   └──────────────────────┬───────────────────────────────────┘ │
│                          ▼                                     │
│   ┌──────────────────────────────────────────────────────────┐ │
│   │  阶段5: 自我版本迭代（Self-Versioning）                │ │
│   └──────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
```

**Eco Agent 超越点**：
- **群体进化**：匿名化上传 Skill 摘要到社区市场
- **进化可解释性**：每次进化输出"我学会了什么"的明文报告
- **用户干预门**：高风险进化必须经过用户二次确认

## 第五层：韧性自愈循环（Resilience / Self-Healing Loop）—— 节律：实时（异常触发）

**此层为 Eco Agent 独创**，竞品均未系统化实现。

```
┌─────────────────────────────────────────────────────────────────┐
│                   韧性自愈循环（Self-Healing Loop）              │
├─────────────────────────────────────────────────────────────────┤
│   🚨 触发：工具崩溃 / API超时 / 上下文溢出 / 陷入死循环       │
│                                                                 │
│   ┌──────────────────────────────────────────────────────────┐ │
│   │  异常捕获 → 分类（瞬时/持久/环境/逻辑）                 │ │
│   └──────────────────────┬───────────────────────────────────┘ │
│                          ▼                                     │
│      ┌───────────────────┼───────────────────┐                 │
│      ▼                   ▼                   ▼                 │
│  ┌─────────┐      ┌─────────┐      ┌─────────┐              │
│  │瞬时故障  │      │持久故障  │      │逻辑死锁 │              │
│  │(超时/网络)│      │(API变更)│      │(循环依赖)│              │
│  └────┬────┘      └────┬────┘      └────┬────┘              │
│       ▼                ▼                ▼                     │
│  ┌─────────┐      ┌─────────┐      ┌─────────┐              │
│  │ 指数退避 │      │ 降级策略 │      │ 死锁检测 │              │
│  │ 重试     │      │ 换备用   │      │ 强制中断 │              │
│  │          │      │ 工具/API │      │ 回退到   │              │
│  │          │      │          │      │ 上次安全 │              │
│  │          │      │          │      │ 检查点   │              │
│  └──────────┘      └──────────┘      └──────────┘              │
│                                                                 │
│  所有异常及修复过程 → 写入"韧性日志" → 供进化循环学习          │
└─────────────────────────────────────────────────────────────────┘
```

**Eco Agent 超越点**：
- **检查点快照**：每个任务执行前保存完整状态
- **优雅降级**：云端不可用自动切换本地小模型
- **死循环熔断**：相同路径重复超5次自动熔断
