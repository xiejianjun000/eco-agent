# Eco Agent

> 让 AI 智能体像生命体一样持续进化、像蜂群一样协作、像原生应用一样融入数字世界。

Eco Agent 是一个开源自主 AI 智能体系统，内置五层嵌套循环，探索智能体的自我进化、多智能体协作和设备-云协同方向。

## 核心能力

| 能力 | 说明 |
|:-----|:------|
| **五层循环** | ReAct++ → Task → Pulse → Evolve → Heal，五重生命节律 |
| **自我进化** | 主动学习、技能自动生成、A-B 测试 |
| **多智能体协作** | 动态组队、并行执行、弹性伸缩、资源协商 |
| **统一网关** | 飞书 / 企微 / 钉钉 / Telegram / Discord / Slack / CLI / Web |
| **51 个连接器** | 12 类第三方服务统一接入 |
| **韧性自愈** | 熔断器、优雅降级、检查点快照 |

## 快速开始

```bash
git clone https://github.com/xiejianjun000/eco-agent.git
cd eco-agent
pip install -r requirements.txt
python gateway/daemon.py start
```
