# @eco-agent/node-addon-system-darwin-arm64

English | [中文](README.zh.md)

This platform package supplies `bin/system.node`, a stable Node-API v8 addon used by `@eco-agent/node-addon-system/flock`. It contains no Landlock executable, JavaScript loader, or installation build script. The native workflow builds it on macOS arm64 and owns its installed-artifact validation.
