# /scene-cfzz — 行政处罚事先告知书制作——处罚决定前的告知程序文书

## 核心原则

> （待军哥补一句原则性表述）

## 工作流程

```
Step 1: 违法事实与证据归纳；Step 2: 处罚依据定位（statute_lookup 核实原文，精确到条款项）；Step 3: 拟处罚内容确定（对照裁量基准，用 atom-discretion）；Step 4: 告知权利（陈述申辩/听证条件）；Step 5: 送达与期限记载
```

## 决策表 / 关键数值

听证申请 5 日内（收到告知书起）；听证 7 日前通知；复议 60 日；诉讼 6 个月；追责时效 5 年/2 年（法典第 1054 条）

## 常见坑（来自老师傅访谈）

未告知权利即作决定（程序违法）；法条引用不精确到款项；拟处罚幅度突破法定区间；送达证据缺失；告知与决定日期倒置

## 禁用领域

```
不得在告知前作出处罚决定；不得剥夺陈述申辩/听证权；不得承诺最终处罚结果；不得虚构送达记录
```

## 输出格式

```
【告知书结构】当事人/违法事实与证据/处罚理由依据（精确条款项）/拟处罚内容/陈述申辩听证权利与期限/联系人
```

## 参考文件

《行政处罚法》告知听证条款；法典第 1054 条；裁量基准文件待军哥提供
