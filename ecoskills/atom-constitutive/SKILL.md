# /atom-constitutive — 违法构成要件分析

## 核心原则

> 先定性后定量：要件不齐不认定违法，证据不足不定性。

```
四要件分析结构：
  要件1 行为主体 —— 排污单位/建设单位/个人，是否适格、是否持有许可
  要件2 客观行为 —— 实施了哪类行为（排放/倾倒/处置/未批先建/篡改数据）
  要件3 危害结果/状态 —— 超标倍数、违法持续时间、污染后果、风险状态
  要件4 主观状态 —— 故意/过失（生态环境领域多采客观归责+过错推定）
```

## 工作流程

```
Step 1: 提取事实要素（从笔录/监测数据/许可文件中逐项摘出）
Step 2: 逐要件比对（每个要件标注 证据来源 + 证据编号）
Step 3: 缺口清单（要件不齐 → 列出需补充的证据，不得强行定性）
Step 4: 行为定性（匹配法典条款的构成要件表述）
Step 5: 输出认定意见（含"待补证"项与证据清单）
```

## 常见案由构成要件速查

| 案由 | 核心要件提示 |
|------|------------|
| 超标排放 | 监测数据(在线/手工) + 排放标准限值 + 排污口归属 + 采样合规性 |
| 未批先建 | 项目开工时间 + 环评类别判定 + 是否取得批复 |
| 未验先投 | 建成投产时间 + 应验收类别 + 是否组织验收 |
| 暗管偷排 | 管道物理证据 + 排放行为记录 + 规避监管目的 |
| 篡改监测数据 | 设备异常记录 + 人为干预痕迹 + 数据突变比对 |
| 危废无证经营 | 危废属性鉴别 + 经营行为 + 许可证持有情况 |

## 禁用领域（严格限制）

```
⚠️ 不得仅凭单一要件推定违法——必须要件闭合且证据可溯
⚠️ 不得为凑结论放宽要件标准
⚠️ 主观要件存疑时按"疑点利益归于当事人"处理
⚠️ 涉及刑事移送的情形只做行政侧初核，罪与非罪由司法机关认定
```

## 输出格式

```
【认定意见】
行为定性：（构成/不构成/证据不足）……
四要件表：要件|事实|证据来源|是否闭合
缺口清单：（待补证项）
引用条款：（法典条号，需 statute_lookup 核实原文）
```
