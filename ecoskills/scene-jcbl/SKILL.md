# /scene-jcbl — 现场检查笔录制作——生态环境现场检查的规范笔录

## 核心原则

> （待军哥补一句原则性表述）

## 工作流程

```
Step 1: 检查准备（2人以上持证、执法记录仪、采样器具）；Step 2: 现场客观记录（时间地点天气、在场人员、治污设施运行、排污现状）；Step 3: 告知与陈述申辩（听取当事人意见并记录）；Step 4: 签认（当事人签认；拒签时见证人签字并注明）；Step 5: 证据固定（照片编号/样品封存/修改处捺印）
```

## 决策表 / 关键数值

检查人员 2 人以上持证；当事人拒签须见证人签字并注明事由；笔录修改处应捺印确认；采样执行 HJ 标准；法典第 51 条现场检查权

## 常见坑（来自老师傅访谈）

只记结论不记事实；漏记当事人陈述申辩；时间地点天气要素缺失；事后补记；修改处未确认；照片未编号未对应

## 禁用领域

```
不得虚构/推测现场情况；不得事后补造笔录；不得代当事人签认；不得只记录对己方有利内容
```

## 输出格式

```
【笔录结构】检查时间地点/检查人员与证件/当事人信息/现场情况客观描述/当事人陈述申辩/签认栏
```
