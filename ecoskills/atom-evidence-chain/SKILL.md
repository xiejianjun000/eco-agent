# /atom-evidence-chain — 证据链完整性核查

## 核心原则

> 孤证不定案，三性不齐不采信。

## 证据三性核查表

| 审查项 | 要点 |
|--------|------|
| 真实性 | 原件/复制件注明、电子数据哈希固化、监测数据来源可溯、有无篡改痕迹 |
| 合法性 | 取证主体适格（2 人以上持证）、程序合法（告知/回避/见证人）、超范围扣押、取样封存规范 |
| 关联性 | 与待证事实的因果关联、时间吻合、对象同一性（排污口/设备/批次） |

## 证据链闭环模型

```
行为证据（什么行为）→ 主体证据（谁干的）→ 结果证据（造成什么后果）
   ↑ 时间轴贯穿：每个环节标注时间戳，链上断裂点=待补证
```

## 典型孤证陷阱（必须识别）

| 陷阱 | 表现 |
|------|------|
| 单一口供 | 仅有当事人陈述，无书证/物证/电子数据印证 |
| 单次监测 | 仅一次手工采样，无在线数据/复测佐证（在线数据需设备验收+质控） |
| 无签认笔录 | 现场检查笔录无当事人签认又无见证人 |
| 复印件孤本 | 关键书证仅复印件且未注明出处、未签认 |
| 时间错位 | 证据时间与违法行为时间不吻合 |

## 工作流程

```
Step 1: 建立证据清单（编号/名称/来源/取证时间/三性初评）
Step 2: 逐份三性审查（不合格项标注理由）
Step 3: 链条拼接（行为→主体→结果 时间轴）
Step 4: 断裂点清单（列出需补证项与补证途径）
Step 5: 采信结论（可定案/需补证/建议退卷）
```

## 禁用领域

```
⚠️ 不得"用结论找证据"——先列证据后下结论
⚠️ 孤证不得作为唯一定案依据（行政拘留等重罚尤其严格）
⚠️ 非法证据排除提示必须给出（如程序违法取得的言词证据）
⚠️ 不得虚构/暗示不存在的证据来源
```

## 输出格式

```
【证据链核查结论】
证据清单表：编号|名称|三性结论|问题
链条状态：（闭环/断裂 N 处）
需补证项：……
采信建议：……
```
