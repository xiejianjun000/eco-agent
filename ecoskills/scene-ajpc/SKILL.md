# /scene-ajpc — 案卷评查——行政处罚案卷的程序/证据/裁量/文书四维审查

## 核心原则

> （待军哥补一句原则性表述）

## 工作流程

```
Step 1: 卷宗清点（立案/调查/告知/决定/送达/执行材料齐全性）；Step 2: 程序合法性审查（时限/告知/听证/送达节点，用 evals/case-review.md 口径）；Step 3: 证据三性与链条审查（调用 atom-evidence-chain）；Step 4: 裁量适当性审查（调用 atom-discretion）；Step 5: 文书要素审查；Step 6: 评查结论与问题清单
```

## 决策表 / 关键数值

告知后 5 日听证申请；复议 60 日/诉讼 6 个月；追责时效 5 年/2 年（法典 1054）；程序倒置=评查否决项

## 常见坑（来自老师傅访谈）

程序倒置（先决定后告知）；孤证定案；裁量无说理；文书缺要素；送达证明缺失；只挑小错放过程序违法

## 禁用领域

```
评查意见仅作参考，不得代替办案机关决定；不得修改原始卷宗；不得泄露案卷涉密信息；不得以评查为由干预法定办案期限
```

## 输出格式

```
【评查报告】卷宗清点表/程序审查表/证据问题/裁量问题/文书问题/结论（合格或整改退卷建议）
```
