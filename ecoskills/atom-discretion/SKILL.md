# /atom-discretion — 裁量幅度推算

## 核心原则

> 裁量有阶次，幅度有基准，情节必须写入文书。

## 裁量四阶模型

```
Step 1 基准确定 —— 依案由定位处罚条款的法定幅度（statute_lookup 核实原文）
Step 2 阶次定位 —— 对照裁量基准：轻微/一般/较重/严重（超标倍数、持续时间、后果）
Step 3 情节修正 —— 从轻（主动改正/首违不罚/配合调查）从重（拒不改正/伪造/阻挠）逐项加减
Step 4 复核边界 —— 最终幅度必须落在法定区间内，不得突破上下限
```

## 超标倍数→阶次 速查（以废水 COD 类为例，须以当地裁量基准文件为准）

| 超标倍数 | 通常阶次 |
|---------|---------|
| ≤0.5 倍 | 轻微（可首违不罚/警告） |
| 0.5–2 倍 | 一般 |
| 2–5 倍 | 较重 |
| >5 倍 | 严重 |

## 按日连续处罚计算

```
按日计罚 = 处罚决定送达后拒不改正 → 自责令改正之日的次日起，
按原处罚数额按日连续处罚。注意：起算日、改正核查日必须留痕。
```

## 从轻/从重情节清单（示例）

| 从轻情节 | 从重情节 |
|---------|---------|
| 主动消除危害后果 | 伪造/篡改监测数据 |
| 配合调查如实陈述 | 拒绝/阻挠执法检查 |
| 首次违法且及时改正 | 两年内同类再犯 |
| 积极履行生态损害赔偿 | 造成严重后果/敏感区域 |

## 禁用领域

```
⚠️ 不得承诺具体处罚结果（提示"以裁量基准和办案机关决定为准"）
⚠️ 不得突破法定上下限做"数学外推"
⚠️ 从轻/从重情节必须有证据支撑，不得臆断
⚠️ 裁量基准文件过期/缺失时必须标注[待确认]，不得编造阶次标准
```

## 输出格式

```
【裁量推算意见】
法定幅度：……（法条第 X 条，来源：statute_lookup）
建议阶次：轻微/一般/较重/严重（依据：超标倍数/情节）
从轻/从重：逐项列明+证据
建议区间：……（仅供办案参考，最终由办案人员依裁量基准确定）
```
