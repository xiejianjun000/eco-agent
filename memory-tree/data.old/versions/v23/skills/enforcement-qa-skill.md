# enforcement-qa-skill — 执法问答与裁量建议

## Meta

**用途**：回答执法相关问题，提供处罚幅度建议和裁量基准匹配
**调用条件**：用户询问执法操作、处罚标准、裁量建议时触发
**依赖**：query-skill（先检索法规）

---

## Instructions

### 1. 执法问答流程

```text
用户提问
  → query-skill 检索相关法规
  → 识别执法场景类型（处罚/强制/复议/诉讼）
  → 匹配适用的执法程序（普通/简易/听证）
  → 检索裁量基准
  → 生成回答（经 ACE 审查后交付）
```

### 2. 常见执法场景

| 场景 | 适用程序 | 关键要素 |
|:-----|:---------|:---------|
| 超标排放污染物 | 普通程序 / 简易程序 | 排放因子、超标倍数、时长 |
| 未批先建 | 普通程序 | 项目类别、投资额、环境影响 |
| 违反"三同时" | 普通程序 | 验收状态、投入运行时间 |
| 非法处置危废 | 普通程序（可能移送公安） | 危废类别、数量、处置方式 |
| 拒不改正 | 按日计罚程序 | 复查情况、原处罚决定 |
| 阻碍执法检查 | 普通程序 | 阻碍方式、情节严重程度 |

### 3. 裁量建议原则

```text
裁量因素分析：
  1. 违法事实（性质 + 情节 + 后果）
  2. 法律依据（适用法条 + 处罚幅度）
  3. 裁量基准（国家 + 各省）
  4. 从重/从轻/减轻/免予处罚情节
  5. 参考案例（相似案例的处罚结果）

输出格式：
  - 法定处罚幅度：[最低] ~ [最高]
  - 建议处罚金额：[具体金额]（参考基准 + 案例）
  - 裁量理由：[分析说明]
  - 风险提示：[可能的法律风险]
```

| 结果要件 | ... | 法典第Y条 |
| 因果关系 | ... | ... |

1. [法规名称] 第X条：[条文内容]
