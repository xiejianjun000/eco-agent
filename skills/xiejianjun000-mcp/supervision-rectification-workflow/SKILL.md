# 大气监督帮扶督办整改完整流程Skill

## 概述

本skill提供大气监督帮扶督办整改的完整工作流程，从问题交办开始，到整改销号结束。

**重要说明**：本skill内置规程标准，完整原文见 `docs/规程文档完整内容.md`。三份官方规程文档：
1. 《监督帮扶问题整改督办工作规程（试行）》（2024年7月修订）
2. 《问题认定情形及评分分值（试行）》（2025年6月）
3. 《重污染应急类问题认定及评分细则（试行）》（2026年1月）

| **粉尘无组织排放类** | 工业粉尘(1)、无组织管控(1)、工地六个百分百(1)、物料堆场(1) | 1分 |
| **其他环境管理问题** | 散乱污(10)、燃煤锅炉(5)、落后炉窑(5)、露天焚烧(1)、拒绝检查(0.5)、其他(0.5) | 0.5-10分 |

**重要**：具体问题认定和评分分值，请查阅《问题认定情形及评分分值（试行）》文档。

#### 2.3 分类处置

**处置分类原则**（基于评分分值和问题性质）：

| 分类 | 适用条件 | 典型问题 |
|------|---------|--------|
| **立行立改** | 分值较低（≤5分），能立即整改完成 | 运维不规范、台账不规范、现场交办类 |
| **跟踪督办** | 分值中等（5-10分），需限期整改 | 设施不正常运行、VOCs泄漏、粉尘无组织 |
| **重点查处** | 分值较高（≥10分）或涉及造假/偷排 | 弄虚作假(50)、偷排(15)、超标排污(20)、未落实应急管控(20) |

**必须移送的情形**：
- 自动监测数据弄虚作假（50分）→ 移送公安机关追究刑事责任
- 偷排偷放、逃避监管 → 移送公安机关行政拘留
- 监测报告弄虚作假 → 移送市场监管部门
- 第三方系统性造假（50分）→ 移送市场监管部门

> ⚠️ **例外**：地方出具不移交或立案说明并盖章的，可不再要求移交。

### 第三阶段：督促整改 → 材料提交

#### 3.1 整改要求（规程第二条）

**整改时限**：
- 问题认定后统一转入整改，整改工作应在**30日内完成**
- 预计30日内无法完成的，要制定整改方案（明确整改措施、时限、要求及责任人）
- **整改期限一般不超过3个月**

**问题移送**：
- 监测报告弄虚作假（不实）→ 移送市场监管部门
- 偷排偷放、逃避监管（适用行政拘留）→ 移送公安机关
- 自动监测数据弄虚作假（涉嫌环境犯罪）→ 移送公安机关追究刑事责任

**立案处罚**：
- 属地对查实的环境违法行为，依据相关法律法规，坚决予以立案查处

#### 3.2 提交整改材料（规程第三条第五款）

**市级操作**：

整改完成后，通过大气监督帮扶平台逐一填报问题整改情况：
1. 汇总形成报告（详见规程附件1模板），**盖章扫描版（PDF格式）和电子版（Word格式）一并上传**
2. 预计不能按期完成的，要上传整改方案或计划
3. 涉及立案处罚、移交相关部门的，要上传立案、移交材料、以及后续跟进办理情况

**系统操作**：
1. 点击记录的"提交审核"按钮
2. 上传附件材料
3. 填写整改完成情况描述
4. 提交省级审核

---

### 第四阶段：审核销号

#### 4.1 省级审核（规程第三条第六款）

**审核内容**：
- 对照《问题整改材料销号审核要求》（规程附件2）逐项审核
- 所有问题均满足整改、监测、处罚和移送等要求的，认定为予以销号
- 对逾期未上传或上传材料内容不符合要求的，要督促、提醒、指导各地市及时、规范上传整改材料

**审核方式**（规程第三条第七款）：
- 省级生态环境部门依托专项执法检查等方式，对问题整改情况进行现场核查

#### 4.2 部级审核（规程第三条第八款）

**审核方式**：
- 对省级审核销号的问题整改资料复审
- 组织专业组对突出问题整改情况进行现场抽查复核
- 重点核实：是否符合整改销号程序、问题整改完成情况（治污设施是否合规运行、旁路是否拆除封堵、是否存在整改弄虚作假）

**监督考核**（规程第五条）：
- 定期通报整改工作进度及成效
- 发现整改不严不实、逾期整改、敷衍整改、虚假整改的，印发督办函
- 纳入污染防治攻坚战考核，视情况扣分
- 拒不整改的采取约谈、公开曝光等措施

#### 4.3 销号条件判断（规程第四条）

> ⚠️ **核心概念：整改完成 ≠ 销号**
>
> 大气监督帮扶平台中，整改完成和销号是两个独立选项：
> - **"整改完成"**：问题已整改，移送类已移送，查处类已立案，生态环境部门基本已履职到位，其他正在走流程
> - **"销号"**：所有问题均满足《问题整改材料销号审核要求》中整改、监测、处罚和移送等要求

**未完成整改情形**：
1. 移送移交类问题尚未完成移交（特殊：地方出具不移交说明并盖章的，可按完成整改、予以销号审核）
2. 查处类问题尚未立案，也未提交不予立案说明材料

**完成整改，但不销号**：
1. 重点查处类已立案，案件正在办理中，尚未提交处罚决定书
2. 移送移交类已移送，尚未反馈调查处理结果（移送后被退回的需自行处罚或再次移送）

**完成整改，销号**：
1. 重点查处类提交**不予立案说明、不予处罚说明（需盖章）**，系统选择"已上传不予处罚/立案说明（销号）"
2. 企业停产6个月以上（上传说明材料或承诺书，属地或企业盖章）

```javascript
// 递归访问iframe
function accessIframe(doc, depth) {
  if (depth > 3) return null;
  const iframes = doc.querySelectorAll('iframe');
  for (let iframe of iframes) {
    try {
      const innerDoc = iframe.contentDocument || iframe.contentWindow.document;
      // 查找目标元素
      const target = innerDoc.querySelector(selector);
      if (target) return target;
      // 递归查找
      const result = accessIframe(innerDoc, depth + 1);
      if (result) return result;
    } catch (e) {
      console.log('Cannot access iframe:', e);
    }
  }
  return null;
}
```

## 智能判断

### 销号条件判断（基于规程标准）

```python
def check_xiaohao_status(record):
    """
    判断是否可销号
    必须同时满足（规程文档1第四条第3点、第七条第2-3点）
    """
    # 基础条件（必须全部满足）
    basic_conditions = {
        "市级确认整改完成": record.get("是否完成整改") == "完成整改",
        "省级审核通过": record.get("省级审核") == "已通过",
        "省级建议销号": record.get("是否建议销号") == "是",
        "部级审核通过": record.get("部级审核") == "已通过"
    }
    
    # 材料完整性检查
    material_check = check_materials_complete(record)
    
    # 综合判断
    all_passed = all(basic_conditions.values()) and material_check["完整"]
    
    if all_passed:
        return {
            "状态": "可销号 ✅",
            "条件": basic_conditions,
            "材料": "完整",
            "操作": "可以执行销号"
        }
    else:
        failed = [k for k, v in basic_conditions.items() if not v]
        if not material_check["完整"]:
            failed.append(f"材料缺失：{', '.join(material_check['缺失材料'])}")
        return {
            "状态": "不可销号 ❌",
            "未满足条件": failed,
            "材料": "完整" if material_check["完整"] else f"缺失{material_check['缺失材料']}",
            "操作": "需要补充满足条件后再申请销号"
        }
```

> **关键纠正**（规程文档1第四条第3点）：
> - **整改完成** ≠ **销号**
> - 整改完成：问题已整改、移送类已移送、查处类已立案查处
> - 销号：必须省级审核通过 + 部级审核通过，才能销号

## 自动化功能

### 5.1 自动化导出

**功能**：自动点击导出按钮，下载Excel/PDF文件

**实现方法**：
```javascript
// 方法1：点击导出按钮
var exportBtn = innerDoc.querySelector('button:contains("导出")');
if(exportBtn) exportBtn.click();

// 方法2：调用导出函数（如果存在）
if(typeof innerWin.exportData === 'function'){
  innerWin.exportData();
}

// 方法3：模拟表单提交导出
var exportForm = innerDoc.createElement('form');
exportForm.action = 'exportExcel.jsp';
exportForm.method = 'POST';
innerDoc.body.appendChild(exportForm);
exportForm.submit();
```

**下载处理**：
- OpenClaw浏览器自动化会自动处理文件下载
- 下载的文件保存在默认下载目录
- 可以使用`browser`工具的`download` action管理下载

### 5.2 批量采集

**功能**：遍历所有县市区，批量采集数据

**实现流程**：
```javascript
// 1. 获取所有区县列表
var counties = ['431381', '431302', ...]; // 冷水江市、娄星区...

// 2. 循环采集每个区县
for(var i=0; i<counties.length; i++){
  // 设置SSQX
  ssqx.value = counties[i];
  
  // 执行查询
  innerWin.searchQhdcRecord();
  
  // 等待加载
  await page.waitForTimeout(3000);
  
  // 提取数据
  var data = extractData();
  
  // 保存到文件
  saveToFile(data, `督办整改_${counties[i]}.json`);
}
```

**注意事项**：
- 每次查询后等待页面加载完成
- 处理分页（如果有多个页面）
- 添加延时避免被封IP

### 5.3 数据分析

**功能**：统计各维度数据，生成图表

**统计维度**：
1. **地区维度**：各市/县问题数量、整改率、销号率
2. **问题类别维度**：六大类问题分布、平均评分
3. **时间维度**：月度趋势、季节性分析
4. **审核状态维度**：省级审核通过率、部级审核通过率

**实现方法**：
```python
import pandas as pd
import matplotlib.pyplot as plt

# 读取数据
df = pd.read_json('督办整改_冷水江市.json')

# 统计问题类别分布
problem_dist = df['问题类别'].value_counts()

# 绘制图表
plt.figure(figsize=(10, 6))
problem_dist.plot(kind='bar')
plt.title('问题类别分布')
plt.savefig('问题类别分布.png')
```

### 5.4 定时任务

**功能**：定期采集数据，定期提醒审核

**实现方法**：
```javascript
// 使用OpenClaw的cron功能
const cron = require('openclaw/cron');

// 每周一上午9:00采集数据
cron.add({  schedule: { kind: 'cron', expr: '0 9 * * 1' },
  payload: { kind: 'agentTurn', message: '采集本周督办整改数据' },
  sessionTarget: 'isolated'
});

// 每天上午10:00提醒审核
cron.add({  schedule: { kind: 'cron', expr: '0 10 * * *' },
  payload: { kind: 'agentTurn', message: '提醒：有3条记录待省级审核' },
  sessionTarget: 'isolated'
});
```
