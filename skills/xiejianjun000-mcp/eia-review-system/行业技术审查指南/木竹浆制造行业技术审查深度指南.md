## 一、行业概述与技术路线

### 1.1 行业定义

木竹浆制造（C2211）指以木材、竹材为原料，经化学、机械或化学机械方法制浆的生产活动。

**主要产品类别**：
1. **化学浆**：硫酸盐法（碱法）、亚硫酸盐法（酸法）
2. **机械浆**：磨石磨木浆、盘磨机械浆
3. **化学机械浆**：化学预处理+机械磨浆

**特别提醒**：
- 木竹浆制造属于**造纸行业上游**，执行GB 3544-2008《制浆造纸工业水污染物排放标准》
- **化学浆（尤其是漂白化学浆）**需特别关注AOX、色度因子

### 1.2 典型生产工艺

#### 工艺路线一：化学浆（硫酸盐法）

```
原料堆场 → 备料 → 蒸煮 → 洗涤 → 筛选 → 漂白 → 抄浆 → 成品浆
                ↓
            黑液提取
                ↓
            碱回收系统（回收化学品和能量）
```

**产污环节**：
- 蒸煮：废气（H₂S、CH₃SH等恶臭气体）
- 洗涤、筛选：废水（高COD、高SS、高色度）
- 漂白：废水（AOX、可吸附有机卤化物）
- 碱回收炉：废气（SO₂、NOx、颗粒物、TRS）
- 石灰窑：废气（SO₂、NOx、颗粒物）

#### 工艺路线二：机械浆

```
原料堆场 → 备料 → 磨浆 → 筛选 → 浓缩 → 成品浆
```

**产污环节**：
- 磨浆：废水（较高COD、SS，但无AOX）
- 筛选：废水（纤维、SS）

#### 工艺路线三：化学机械浆

```
原料堆场 → 备料 → 化学预处理 → 磨浆 → 筛选 → 漂白（可选） → 成品浆
```

**产污环节**：
- 化学预处理：废水（COD、SS）
- 磨浆：废水（COD、SS）
- 漂白（如采用）：废水（AOX，如采用含氯漂白）

## 二、行业特征因子核对表

### 2.1 废水排放因子

#### 制浆系统排放口（TW001）

| 工艺类型 | 必填因子 | 特别提示 |
|---------|---------|---------|
| 化学浆（漂白） | pH、COD、BOD₅、SS、氨氮、总氮、总磷、AOX、色度、二噁英 | **AOX、色度必填** |
| 化学浆（未漂白） | pH、COD、BOD₅、SS、氨氮、总氮、总磷、色度 | 色度必填，AOX可不填 |
| 机械浆 | pH、COD、BOD₅、SS、氨氮、总氮、总磷 | 无AOX、色度可不填 |
| 化学机械浆 | pH、COD、BOD₅、SS、氨氮、总氮、总磷、色度 | 如漂白采用含氯工艺，需填AOX |

**重点提示**：
- **AOX（可吸附有机卤化物）**：漂白化学浆采用含氯漂白工艺时**必填**
- **色度**：所有制浆工艺**必填**（GB 3544-2008表1有要求）
- **二噁英**：如采用元素氯漂白（ECF/TCF除外），需填报二噁英

#### 碱回收系统排放口（TW002）

| 必填因子 | 备注 |
|---------|------|
| pH、COD、SS | 碱回收系统排水通常回用，如排放需填报 |

#### 生活污水排放口（TW003）

| 必填因子 | 备注 |
|---------|------|
| pH、COD、BOD₅、NH₃-N、SS、TN、TP | 生活污水处理设施排口 |

### 2.2 废气排放因子

#### 有组织废气

| 排放源 | 必填因子 | 可选因子 | 适用标准 |
|-------|---------|---------|---------|
| 碱回收炉 | SO₂、NOx、颗粒物、TRS（总还原硫） | 汞及其化合物 | GB 3544-2008 |
| 石灰窑 | SO₂、NOx、颗粒物 | - | GB 3544-2008 |
| 燃煤锅炉 | SO₂、NOx、颗粒物、汞及其化合物 | 氟化物 | GB 13271-2014 |
| 燃气锅炉 | SO₂、NOx、颗粒物 | - | GB 13271-2014 |
| 恶臭气体（蒸煮） | H₂S、甲硫醇、臭气浓度 | - | GB 14554-93 |
| 无元素氯漂白（ECF）排气 | ClO₂ | - | 地标或环评批复 |

#### 无组织废气

| 排放源 | 必填因子 | 监测点位 |
|-------|---------|---------|
| 厂界无组织 | H₂S、甲硫醇、臭气浓度、颗粒物 | 厂界上、下风向 |
| 原料堆场 | 颗粒物 | 厂界 |

**重点提示**：
- **TRS（总还原硫）**：碱回收炉**必填**，这是制浆企业特征因子
- **恶臭气体**：蒸煮工序产生H₂S、甲硫醇等，需填报

### 2.3 噪声排放因子

| 噪声源 | 必填因子 |
|-------|---------|
| 厂界噪声 | 昼间Leq、夜间Leq |

### 2.4 固体废物

| 废物类别 | 必填信息 | 备注 |
|---------|---------|------|
| 危险废物 | 废物代码、产生量、处置方式 | HW21（黑液）、HW08（废矿物油）等 |
| 一般工业固体废物 | 种类、产生量、利用处置方式 | 绿泥、白泥、石灰渣、生物质燃料残渣 |

**重点提示**：
- **白泥**：碱回收系统产生，属于一般工业固体废物，但需综合利用或处置
- **绿泥**：澄清器产生，属于一般工业固体废物

### 3.1 废水监测频次决策树

```
开始
  ↓
是重点管理？
  ├─ 是 → 制浆系统排放口：COD、氨氮优先自动监测
  │        （或日测，重点管理）
  │        其他因子：月度手工监测
  └─ 否 ↓
        制浆系统排放口：季度手工监测（简化管理）
```

**特别提示**：
- **AOX**：重点管理月度或季度手工监测（依据GB 3544-2008表4）
- **色度**：重点管理月度手工监测
- **二噁英**：年度手工监测（如适用）

### 3.2 废气监测频次决策树

```
开始
  ↓
是重点管理？
  ├─ 是 → 碱回收炉：SO₂、NOx、颗粒物优先自动监测
  │        其他因子：季度手工监测
  │        恶臭气体：季度手工监测
  └─ 否 ↓
        碱回收炉：季度手工监测（简化管理）
        恶臭气体：半年手工监测
```

**依据**：HJ 819-2017《排污单位自行监测技术指南 总则》、HJ 852-2017《排污许可证申请与核发技术规范 造纸行业》、GB 3544-2008表4

| 污染物 | 限值（mg/L） | 备注 |
|--------|-------------|------|
| pH | 6-9 | - |
| COD | 90（现有）/ 80（新建） | 制浆企业 |
| BOD₅ | 20 | - |
| SS | 30 | - |
| 氨氮 | 8 | - |
| 总氮 | 12 | - |

## 五、常见错误TOP 10

### 错误1：AOX因子遗漏

**表现**：漂白化学浆企业未填报AOX因子。

**正确做法**：采用含氯漂白工艺的漂白化学浆企业，**必须填报AOX因子**。

### 错误2：色度因子遗漏

**表现**：制浆企业未填报色度因子。

**正确做法**：GB 3544-2008表1有色度要求，**所有制浆企业必填色度因子**。

### 错误3：TRS因子遗漏

**表现**：碱回收炉未填报TRS因子。

**正确做法**：TRS是碱回收炉特征因子，**必填**。

### 错误4：排放标准适用错误

**表现**：制浆企业执行GB 8978-1996。

**正确做法**：制浆企业执行GB 3544-2008，不适用GB 8978-1996。

### 错误5：监测频次填报错误

**表现**：重点管理企业制浆系统排放口COD、氨氮未填报自动监测。

**正确做法**：重点管理企业制浆系统排放口COD、氨氮**优先自动监测**。

### 错误6：许可排放量核算错误

**表现**：AOX许可排放量未核算或核算错误。

**正确做法**：AOX许可排放量按GB 3544-2008表1限值核算。

### 错误7：碱回收系统信息不全

**表现**：未填报碱回收系统排放口信息。

**正确做法**：有碱回收系统的企业，需填报碱回收系统排放口信息。

### 错误8：恶臭气体遗漏

**表现**：蒸煮工序未填报恶臭气体（H₂S、甲硫醇）。

**正确做法**：蒸煮工序产生恶臭气体，需填报H₂S、甲硫醇、臭气浓度。

### 错误9：白泥、绿泥信息不全

**表现**：未填报白泥、绿泥的产生量、处置方式。

**正确做法**：白泥、绿泥属于一般工业固体废物，需填报产生量、处置方式。

### 错误10：二噁英遗漏

**表现**：采用元素氯漂白的企业未填报二噁英。

**正确做法**：采用元素氯漂白的企业，需填报二噁英，并执行年度监测。

## 六、省份差异要求

### 6.1 江苏省

**特别要求**：
1. **太湖流域**：执行《太湖流域管理条例》，COD、NH₃-N、TP执行更严标准，禁止新建制浆项目
2. **AOX排放控制**：漂白化学浆企业需安装AOX在线监测设备（重点区域）
3. **废水排入太湖流域**：COD≤50 mg/L、NH₃-N≤5 mg/L、TP≤0.5 mg/L
4. **碱回收炉NOx**：执行DB32/4042-2021，NOx≤100 mg/m³
5. **危险废物申报**：需通过江苏省固体废物管理信息系统申报

**审查要点**：
- 位于太湖流域的企业，排放标准需按地方要求执行，且禁止新建制浆项目
- 漂白化学浆企业需核查AOX排放控制设施

### 6.2 浙江省

**特别要求**：
1. **钱塘江流域**：执行《浙江省钱塘江流域水环境保护条例》，排放标准加严
2. **AOX排放控制**：漂白化学浆企业需执行AOX总量控制
3. **废水排入钱塘江流域**：COD≤50 mg/L、NH₃-N≤2.5 mg/L、TP≤0.3 mg/L
4. **碱回收炉NOx**：执行DB33/2147-2018，NOx≤100 mg/m³
5. **"亩均论英雄"改革**：排污许可证需与"亩均论英雄"综合评价结果关联

**审查要点**：
- 位于钱塘江流域的企业，排放标准需按地方要求执行
- 核查企业"亩均论英雄"评价结果

### 6.3 广东省

**特别要求**：
1. **北江、东江、西江流域**：执行流域水污染物排放标准，排放标准加严
2. **AOX排放控制**：漂白化学浆企业需执行AOX特别排放限值
3. **废水排入流域**：COD≤50 mg/L、NH₃-N≤5 mg/L、TP≤0.5 mg/L
4. **碱回收炉NOx**：执行DB44/816-2010，NOx≤150 mg/m³
5. **茅洲河、淡水河等重污染河流**：执行更严标准，COD≤40 mg/L、NH₃-N≤2 mg/L

**审查要点**：
- 位于重点流域的企业，排放标准需按流域标准执行
- 漂白化学浆企业需核查AOX排放控制设施

### 6.4 山东省

**特别要求**：
1. **海河流域**：执行DB37/3416-2018《海河流域水污染物综合排放标准》
2. **AOX排放控制**：漂白化学浆企业需执行AOX总量控制
3. **废水排入海河流域**：COD≤50 mg/L、NH₃-N≤5 mg/L、TP≤0.5 mg/L
4. **碱回收炉NOx**：执行DB37/2374-2018，NOx≤100 mg/m³（重点区域）
5. **重点区域（京津冀及周边地区）**：排放标准全面加严

**审查要点**：
- 位于重点区域的企业，排放标准全面加严
- 核查碱回收炉NOx排放控制设施

### 6.5 河北省

**特别要求**：
1. **白洋淀流域**：执行《白洋淀生态环境治理和保护条例》，排放标准加严

3. **废水排入白洋淀流域**：COD≤30 mg/L、NH₃-N≤1.5 mg/L、TP≤0.3 mg/L
4. **碱回收炉NOx**：执行DB13/2161-2018，NOx≤100 mg/m³（重点区域）
5. **雄安新区**：执行《雄安新区生态环境保护条例》，排放标准全面加严

**审查要点**：
- 位于雄安新区的企业，排放标准全面加严，需单独核查
- 漂白化学浆企业需核查AOX排放控制设施

### 6.6 北京市

**特别要求**：

**审查要点**：
- 北京市原则上不再新建造纸企业，需核查存量企业合规性

### 6.7 上海市

2. **AOX排放控制**：漂白化学浆企业需执行AOX特别排放限值
3. **废水排入流域**：COD≤50 mg/L、NH₃-N≤5 mg/L、TP≤0.5 mg/L
4. **碱回收炉NOx**：执行DB31/387-2018，NOx≤50 mg/m³（现有企业）、30 mg/m³（新建企业）

**审查要点**：
- 位于上海市的企业，碱回收炉NOx执行严标准
- 漂白化学浆企业需核查AOX排放控制设施

### 6.8 福建省

**特别要求**：
1. **闽江、九龙江流域**：执行流域水污染物排放标准，排放标准加严
2. **AOX排放控制**：漂白化学浆企业需执行AOX总量控制
3. **废水排入流域**：COD≤50 mg/L、NH₃-N≤5 mg/L、TP≤0.5 mg/L
4. **碱回收炉NOx**：执行DB35/1513-2015，NOx≤150 mg/m³

## 七、多工序企业标准适用指南

### 7.1 典型多工序组合

木竹浆制造企业可能涉及的多工序组合：
1. **木竹浆制造 + 造纸**：浆纸联合企业
2. **木竹浆制造 + 生物质发电**：利用生物质燃料发电
3. **木竹浆制造 + 造纸 + 生物质发电**：全流程企业

### 7.2 标准适用原则

**原则**：制浆工序执行GB 3544-2008，造纸工序执行GB 3544-2008，发电工序执行GB 13223-2011（火电）。

### 7.3 多工序企业排放标准体系

| 工序 | 废水排放标准 | 废气排放标准 |
|-----|------------|------------|
| 制浆 | GB 3544-2008 | GB 3544-2008 |
| 造纸 | GB 3544-2008 | GB 3544-2008 |
| 生物质发电 | - | GB 13223-2011 |

**示例**：
- 某浆纸联合企业：
  - 制浆废水：执行GB 3544-2008表1
  - 造纸废水：执行GB 3544-2008表1
  - 生物质发电废气：执行GB 13223-2011

## 八、真实审批拒绝案例

### 案例1：AOX因子遗漏导致退回

**企业基本情况**：
- 企业名称：某纸浆有限公司
- 行业：木竹浆制造（C2211）
- 管理类别：重点管理
- 主要工序：硫酸盐法漂白化学浆

**拒绝原因**：
许可证申请材料中，制浆系统排放口未填报AOX因子。

**审查发现**：
1. 企业采用硫酸盐法漂白化学浆，使用含氯漂白工艺
2. AOX是特征因子，必须填报
3. 申请材料未填报AOX因子，属于特征因子遗漏

**整改要求**：
补充AOX因子，并提供AOX监测方案。

**经验总结**：
漂白化学浆企业必须填报AOX因子，审查时需核对漂白工艺。

### 案例2：色度因子遗漏导致退回

**企业基本情况**：
- 企业名称：某纸业有限公司
- 行业：木竹浆制造（C2211）
- 管理类别：重点管理
- 主要工序：化学机械浆

**拒绝原因**：
许可证申请材料中，制浆系统排放口未填报色度因子。

**审查发现**：
1. GB 3544-2008表1有色度要求
2. 所有制浆企业必填色度因子
3. 申请材料未填报色度因子，属于特征因子遗漏

**整改要求**：
补充色度因子，并提供色度监测方案。

**经验总结**：
所有制浆企业必填色度因子，审查时需核对GB 3544-2008表1。

## 十一、边缘情况处理指南

### 11.1 未漂白化学浆

**情况描述**：企业采用化学浆工艺，但未漂白。

**处理方案**：
1. AOX因子可不填（未漂白无AOX产生）
2. 色度因子仍需填报
3. 在"其他信息"中说明：未漂白化学浆，无AOX产生

### 11.2 无元素氯漂白（ECF）

**情况描述**：企业采用ECF漂白（二氧化氯漂白），AOX产生量较低。

**处理方案**：
1. AOX因子仍需填报（ECF仍有少量AOX产生）
2. 提供漂白工艺说明，证明采用ECF漂白
3. AOX排放浓度通常较低，但需监测

### 11.3 全无氯漂白（TCF）

**情况描述**：企业采用TCF漂白（臭氧、过氧化氢漂白），无AOX产生。

**处理方案**：
1. AOX因子可填"0"
2. 在"其他信息"中说明：采用TCF漂白，无AOX产生
3. 提供漂白工艺说明，证明采用TCF漂白

### 11.4 机械浆无碱回收系统

**情况描述**：企业仅生产机械浆，无碱回收系统。

**处理方案**：
1. 无需填报碱回收炉排放口
2. 无需填报TRS因子
3. 在"其他信息"中说明：仅生产机械浆，无碱回收系统

### 11.5 碱回收系统排水回用

**情况描述**：碱回收系统排水全部回用，无排放口。

**处理方案**：
1. 无需填报碱回收系统排放口
2. 在"其他信息"中说明：碱回收系统排水全部回用，无排放口
3. 提供水平衡图，证明排水全部回用
