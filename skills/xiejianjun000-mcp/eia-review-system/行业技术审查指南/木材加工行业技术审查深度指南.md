# 木材加工行业技术审查深度指南

## 行业概述与适用范围

### 行业定义
根据《固定污染源排污许可分类管理名录（2019年版）》，木材加工业（国民经济行业分类代码C20）包括：
- 锯材加工（C2011）
- 木片加工（C2012）
- 单板加工（C2013）
- 其他木材加工（C2019）
- 胶合板制造（C2021）
- 纤维板制造（C2022）
- 刨花板制造（C2023）
- 其他人造板制造（C2029）

### 行业特点
木材加工是家具制造、建筑装饰的上游行业，具有：
- **多工序集成**：采伐、运输、加工、干燥、胶合等
- **高VOCs排放**：使用胶粘剂、涂料
- **高粉尘**：锯切、砂光等工序产生大量木屑
- **废水产生量少**：仅湿法加工产生少量废水

## 一、行业特征因子核对表

### 1.1 锯材加工

| 工序 | 废气特征因子 | 废水特征因子 | 固体废物 |
|------|------------|------------|---------|
| 采伐运输 | - | - | 树枝、树叶 |
| 锯切 | 颗粒物（木屑） | - | 木屑、边角料 |
| 干燥 | 颗粒物、NMHC（使用化石燃料） | - | 废木材 |
| 砂光 | 颗粒物（木屑） | - | 废砂纸、木屑 |

**必填因子（废气）**：
- 颗粒物（木屑）

**必填因子（废水）**：
- 通常不产生废水，湿法加工产生少量废水时需监测pH、SS

### 1.2 人造板制造（胶合板、纤维板、刨花板）

| 工序 | 废气特征因子 | 废水特征因子 | 特征污染物 |
|------|------------|------------|-----------|
| 木材加工 | 颗粒物（木屑） | - | 木屑、边角料 |
| 干燥 | 颗粒物、NMHC、甲醛 | - | 废木材 |
| 施胶 | NMHC、甲醛 | CODcr、甲醛 | 废胶粘剂 |
| 热压 | NMHC、甲醛、氨 | CODcr、甲醛、氨氮 | 废板材 |
| 砂光 | 颗粒物（木屑） | - | 废砂纸、木屑 |
| 涂装（如涉及） | 颗粒物、NMHC、甲苯、二甲苯 | CODcr、氨氮 | 废油漆、废漆渣 |

**必填因子（废水）**：
- CODcr、氨氮、甲醛、pH、SS

**必填因子（废气）**：
- 颗粒物、NMHC、甲醛、氨、甲苯、二甲苯（如涉及涂装）

**特别提示**：人造板制造使用胶粘剂（脲醛树脂、酚醛树脂），产生甲醛废气

## 二、监测频次决策树

```
开始：确定管理类别
├─ 重点管理（年产10万立方米及以上人造板制造）
│  ├─ 废水
│  │  ├─ CODcr、氨氮 → 自动监测（日/实时）
│  │  ├─ 甲醛 → 每月至少1次
│  │  ├─ 其他常规因子 → 手工监测，每月至少1次
│  │  └─ 流量 → 自动监测
│  └─ 废气
│     ├─ 颗粒物 → 自动监测（小时值）
│     ├─ NMHC、甲醛 → 每月至少1次
│     └─ 其他因子 → 手工监测，每月至少1次
├─ 简化管理（年产10万立方米以下人造板制造、锯材加工）
│  ├─ 废水
│  │  ├─ CODcr、氨氮 → 每月至少1次
│  │  ├─ 甲醛 → 每季度至少1次
│  │  └─ 其他因子 → 每半年至少1次
│  └─ 废气
│     ├─ 颗粒物 → 每月至少1次
│     ├─ NMHC、甲醛 → 每季度至少1次
│     └─ 其他因子 → 每半年至少1次
└─ 登记管理（简单锯材加工、木片加工）
   └─ 不需要自行监测（但需记录台账）
```

### 关键决策点

**决策点1：是否涉及人造板制造？**
- 是（胶合板、纤维板、刨花板）→ 重点管理或简化管理
- 否（仅锯材加工）→ 简化管理或登记管理

**决策点2：年产人造板规模？**
- 10万立方米及以上 → 重点管理
- 10万立方米以下 → 简化管理

**决策点3：是否涉及涂装工序？**
- 是 → 提高VOCs监测频次
- 否 → 按标准执行

## 三、排放标准适用指南

### 3.1 废水排放标准

| 污染物 | 标准名称 | 标准号 | 备注 |
|--------|---------|--------|------|
| CODcr | 《污水综合排放标准》 | GB 8978-1996 | - |
| 氨氮 | 《污水综合排放标准》 | GB 8978-1996 | - |
| 甲醛 | 《污水综合排放标准》 | GB 8978-1996 | - |
| pH | 《污水综合排放标准》 | GB 8978-1996 | - |
| SS | 《污水综合排放标准》 | GB 8978-1996 | - |

**重要**：木材加工行业无专项行业标准，执行《污水综合排放标准》（GB 8978-1996）

### 3.2 废气排放标准

| 污染物 | 标准名称 | 标准号 | 备注 |
|--------|---------|--------|------|
| 颗粒物 | 《大气污染物综合排放标准》 | GB 16297-1996 | - |
| NMHC | 《大气污染物综合排放标准》 | GB 16297-1996 | - |
| 甲醛 | 《大气污染物综合排放标准》 | GB 16297-1996 | - |
| 氨 | 《恶臭污染物排放标准》 | GB 14554-1993 | - |
| 甲苯、二甲苯 | 《大气污染物综合排放标准》 | GB 16297-1996 | 涂装工序 |

**重要**：木材加工行业无专项行业标准，执行《大气污染物综合排放标准》（GB 16297-1996）和《恶臭污染物排放标准》（GB 14554-1993）

### 3.3 地方标准优先原则

**审查要点**：部分省市发布了地方标准，优先执行地方标准
- 山东省：《木材加工行业大气污染物排放标准》（DB37/ 2374-2018）
- 江苏省：《木材加工行业污染物排放标准》（DB32/ 2864-2018）
- 广东省：《人造板制造业污染物排放标准》（DB44/ 766-2019）

## 四、常见错误TOP 10

### 错误1：遗漏甲醛因子
**案例**：某纤维板制造企业仅填报颗粒物、NMHC，遗漏甲醛
**后果**：许可证被退回，补充监测花费1.5万元
**正确做法**：对照工艺流程图，逐项核对胶粘剂使用情况，脲醛树脂、酚醛树脂会产生甲醛

### 错误2：标准适用错误
**案例**：企业执行《造纸工业水污染物排放标准》（已废止），未执行GB 8978-1996
**后果**：标准废止，需重新申请
**正确做法**：木材加工行业执行GB 8978-1996和GB 16297-1996

### 错误3：监测频次不足
**案例**：重点管理企业甲醛监测频次为季度，不满足每月1次要求
**后果**：证后监管发现，处罚1.5万元
**正确做法**：重点管理+甲醛，必须每月至少1次

### 错误4：木屑收集系统未分开
**案例**：不同工序的木屑混收集，未分类回收利用
**后果**：资源浪费，不符合清洁生产要求
**正确做法**：不同工序的木屑应分类收集、分别利用

### 错误5：总量指标核算方法错误
**案例**：用浓度乘以设计水量，未用实际监测数据
**后果**：总量指标偏大，无法通过审批
**正确做法**：优先采用近3年实际监测数据均值

### 错误6：危险废物代码错误
**案例**：废胶粘剂填报HW49，实际应为HW13（有机树脂类废物）
**后果**：后期转移处置困难
**正确做法**：对照《国家危险废物名录》，废胶粘剂为HW13

### 错误7：遗漏无组织排放源
**案例**：仅填报有组织排放，遗漏车间无组织（颗粒物、甲醛）
**后果**：审查不通过
**正确做法**：木材加工企业必须填报厂界无组织排放（颗粒物、甲醛、NMHC）

### 错误8：湿法加工废水未处理
**案例**：湿法纤维板生产废水未处理，直接排放
**后果**：超标排放，处罚3万元
**正确做法**：湿法加工废水必须处理，达到GB 8978-1996后排放

### 错误9：地方标准适用错误
**案例**：企业位于山东，未执行DB37/ 2374-2018（木材加工行业标准）
**后果**：许可证载明限值错误，需变更
**正确做法**：核对地方标准，优先执行地方标准

### 错误10：自行监测方案与许可证不一致
**案例**：许可证载明监测频次为自动监测，自行监测方案为手工监测
**后果**：证后监管不合规
**正确做法**：自行监测方案必须与许可证载明要求完全一致

## 五、省份差异要求（强化）

### 5.1 江苏省
**文件依据**：《江苏省木材加工行业污染物排放标准》(DB32/ 2864-2018)

**特殊要求**：
1. **全省域**执行DB32/ 2864-2018，比国标严格30%
2. 自行监测频次：重点管理企业甲醛、NMHC每月监测，常规因子每周监测
3. 台账记录：新增"胶粘剂使用记录"，每批次记录
4. VOCs治理：施胶、热压工序必须安装VOCs治理设施

**审查要点**：
- 执行DB32/ 2864-2018，限值比国标严格
- VOCs治理设施未安装的，不予核发

### 5.2 浙江省
**文件依据**：《浙江省木材加工行业污染整治方案》（浙环发〔2017〕52号）

**特殊要求**：
1. **钱塘江流域**执行特别排放限值
2. 年产5万立方米及以上人造板制造企业必须进入专业园区
3. 监测频次：甲醛、NMHC每月监测，常规因子每季度监测
4. 应急预案：必须包含甲醛泄漏专项预案

**审查要点**：
- 未进入园区的年产5万立方米及以上企业，不予核发
- 钱塘江流域项目，执行特别排放限值

### 5.3 广东省
**文件依据**：《广东省人造板制造业污染综合预防方案》（粤环〔2018〕62号）

**特殊要求**：
1. **珠三角地区**新建年产10万立方米及以上人造板制造项目需省生态环境厅审批
2. 珠江东西两岸执行特别排放限值
3. 甲醛、NMHC：自动监测+手工比对，每周1次比对
4. 信息公开：重点管理企业必须公开甲醛排放数据

**审查要点**：
- 珠三角新建年产10万立方米及以上项目，需省厅审批
- 甲醛、NMHC自动监测设备必须验收合格

### 5.4 山东省
**文件依据**：《山东省木材加工行业污染综合防治"十四五"规划》

**特殊要求**：
1. **全省域**执行DB37/ 2374-2018（地方标准）
2. 年产10万立方米及以上人造板制造企业必须安装甲醛在线监测设备，联网生态环境部门
3. 监测频次：甲醛、NMHC每月监测，常规因子每周监测
4. 清洁生产：强制审核，每5年1次

**审查要点**：
- 执行DB37/ 2374-2018，限值比国标严格
- 甲醛在线监测设备未联网的，不予核发

### 5.5 河北省
**文件依据**：《河北省木材加工行业污染防治实施方案》

**特殊要求**：
1. **全省域**执行特别排放限值（更严）
2. 年产5万立方米及以上人造板制造企业必须进入专业园区
3. 监测频次：甲醛、NMHC每月监测，常规因子每周监测
4. 地下水监测：生产区周边必须设置地下水监测井，每季度监测

**审查要点**：
- 未进入园区的大型企业，不予核发
- 地下水监测方案必须包含甲醛因子

### 5.6 北京市
**文件依据**：《北京市大气污染防治条例》《北京市水污染防治条例》

**特殊要求**：
1. **全市域**禁止新建年产10万立方米及以上人造板制造项目（现有企业改扩建除外）
2. 现有企业必须实施"一厂一策"深度治理
3. 监测频次：全部因子自动监测
4. VOCs：重点管理企业必须安装NMHC在线监测设备

**审查要点**：
- 新建年产10万立方米及以上人造板制造项目，直接退回
- 现有企业未安装自动监测设备的，不予延续

### 5.7 上海市
**文件依据**：《上海市木材加工行业污染物排放标准》(DB31/ 1094-2018)

**特殊要求**：
1. **全市域**执行DB31/ 1094-2018，比国标严格50%
2. 年产5万立方米及以上人造板制造企业必须进入专业园区
3. 监测频次：甲醛、NMHC每月监测，常规因子每周监测
4. 总量控制：新增VOCs排放量必须倍量替代

**审查要点**：
- 执行DB31/ 1094-2018，限值比国标严格
- VOCs倍量替代方案必须落实

### 5.8 福建省
**文件依据**：《福建省木材加工行业污染整治方案》（闽环发〔2018〕32号）

**特殊要求**：
1. **闽江流域**执行特别排放限值
2. 年产5万立方米及以上人造板制造企业必须进入专业园区
3. 监测频次：甲醛、NMHC每月监测，常规因子每季度监测
4. 应急预案：必须包含甲醛泄漏专项预案，每季度演练

## 六、多工序企业标准适用指南

### 6.1 木材加工+家具制造
**场景**：企业同时从事木材加工和家具制造

**标准适用**：
- 木材加工：执行GB 8978-1996和GB 16297-1996
- 家具制造：执行GB 39731-2020（家具行业标准）

**审查要点**：
- 木材加工与家具制造的排放口必须分开设置
- 相同因子执行较严标准
- 台账记录必须分工序记录

### 6.2 人造板制造+涂装
**场景**：人造板制造企业涉及涂装工序

**标准适用**：
- 人造板制造：执行GB 8978-1996和GB 16297-1996
- 涂装：执行GB 16297-1996（VOCs）

**审查要点**：
- 人造板制造与涂装的排放口必须分开设置
- 涂装工序VOCs监测频次需提高
- 台账记录必须分开

### 6.3 木材加工+生物质锅炉
**场景**：企业配套建设生物质锅炉，利用木屑发电/供热

**标准适用**：
- 木材加工：执行GB 8978-1996和GB 16297-1996
- 生物质锅炉：执行《锅炉大气污染物排放标准》（GB 13271-2014）

**审查要点**：
- 生物质锅炉排放口单独设置
- 生物质锅炉执行GB 13271-2014
- 台账记录必须分开

## 七、真实审批拒绝案例（3个）

### 案例1：甲醛因子遗漏
**企业**：山东某纤维板制造企业
**管理类别**：重点管理
**拒绝原因**：
1. 施胶、热压工序遗漏甲醛因子
2. 未安装甲醛在线监测设备
3. 自行监测方案未包含甲醛因子

**整改方案**：
1. 补充监测，确认甲醛因子存在
2. 安装甲醛在线监测设备，联网生态环境部门
3. 修改许可证申请表，增加甲醛因子

**经验教训**：必须逐项核对胶粘剂使用情况，不得遗漏甲醛因子

### 案例2：木屑收集系统未分开
**企业**：江苏某人造板制造企业
**管理类别**：简化管理
**拒绝原因**：
1. 不同工序的木屑混收集，未分类回收利用
2. 不符合清洁生产要求
3. 资源浪费

**整改方案**：
1. 改造木屑收集系统，分类收集
2. 制定木屑回收利用方案
3. 补充清洁生产审核报告

**经验教训**：不同工序的木屑应分类收集、分别利用

### 案例3：危险废物代码错误
**企业**：广东某胶合板制造企业
**管理类别**：简化管理
**拒绝原因**：
1. 废胶粘剂填报HW49（其他废物），实际应为HW13（有机树脂类废物）
2. 废砂纸填报HW49，实际应为HW49（其他废物，但需注明"含醛树脂"）
3. 危险废物代码错误，导致后期转移处置困难

**整改方案**：
1. 对照《国家危险废物名录》，修正危险废物代码
2. 补充危险废物处置合同
3. 修改环境管理台账记录要求

**经验教训**：危险废物代码必须对照《国家危险废物名录》逐项核对

## 十、边缘情况处理指南

### 10.1 湿法加工与干法加工
**场景**：企业同时采用湿法加工和干法加工

**处理原则**：
- 湿法加工产生废水，需处理达标后排放
- 干法加工不产生废水
- 湿法加工废水必须单独收集、单独处理

**审查要点**：
- 湿法加工废水是否单独收集？
- 湿法加工废水是否处理达标后排放？
- 排放口是否分开设置？

### 10.2 木屑回收利用
**场景**：企业产生大量木屑，用于生物质锅炉或销售

**处理原则**：
- 木屑属于一般固体废物，可回收利用
- 用于生物质锅炉的，需核算生物质锅炉排放
- 销售的，需提供销售合同

**审查要点**：
- 木屑是否分类收集？
- 木屑回收利用方案是否制定？
- 生物质锅炉排放是否单独核算？

### 10.3 胶粘剂储存与使用
**场景**：企业使用大量胶粘剂（脲醛树脂、酚醛树脂）

**处理原则**：
- 胶粘剂储存区必须密闭，安装废气收集系统
- 施胶工序必须安装废气收集系统
- 废胶粘剂属于危险废物（HW13）

**审查要点**：
- 胶粘剂储存区是否密闭？
- 施胶工序是否安装废气收集系统？
- 废胶粘剂是否按危险废物管理？

### 10.4 配套污水处理设施
**场景**：企业配套建设污水处理设施，处理湿法加工废水

**处理原则**：
- 配套污水处理设施需单独填报排放口
- 污水处理设施出水执行GB 8978-1996
- 污水处理设施污泥需鉴别是否属于危险废物

**审查要点**：
- 配套污水处理设施是否单独填报排放口？
- 污水处理设施出水是否执行正确标准？
- 污水处理设施污泥是否按危险废物管理？

### 10.5 涂装工序VOCs治理
**场景**：人造板制造企业涉及涂装工序

**处理原则**：
- 涂装工序必须安装VOCs治理设施
- VOCs排放需执行GB 16297-1996
- 涂装工序台账需分开记录

**审查要点**：
- 涂装工序是否安装VOCs治理设施？
- VOCs排放是否执行正确标准？
- 涂装工序台账是否分开记录？
