## 一、行业特征因子核对表

### 1.1 合成树脂制造（C2651）

#### 1.1.1 聚乙烯（PE）制造
**生产工艺**: 乙烯聚合（高压法、低压法）

**废气特征因子**:
- **有组织排放**: 非甲烷总烃、乙烯、颗粒物
- **关键装置**: 聚合反应釜、造粒机、干燥机
- **特别因子**: 非甲烷总烃、乙烯

**废水特征因子**:
- **生产废水**: pH、SS、COD、BOD₅、石油类
- **冷却水**: 温排水（温度）
- **设备清洗水**: SS、COD

**土壤特征因子**:
- 乙烯、非甲烷总烃

#### 1.1.2 聚丙烯（PP）制造
**生产工艺**: 丙烯聚合

**废气特征因子**:

**废水特征因子**:

**土壤特征因子**:
- 丙烯、非甲烷总烃

**土壤特征因子**:

## 二、监测频次决策树

### 2.1 废气监测频次决策

```
开始：确定排放口类型
│
├─ 主要排放口
│  ├─ 有组织排放
│  │  ├─ 连续自动监测（如适用）
│  │  │  ├─ 非甲烷总烃（必装，如VOCs排放量≥10t/a）
│  │  │  ├─ 特征因子（如氯乙烯、丙烯腈、TDI等，建议安装）
│  │  │  └─ 颗粒物（如涉及）
│  │  │
│  │  └─ 手工监测
│  │     ├─ 重点管理：每月至少1次
│  │     ├─ 简化管理：每季度至少1次
│  │     └─ 特征因子：每月至少1次（重点管理）、每季度至少1次（简化管理）
│  │
│  └─ 无组织排放
│     ├─ 厂界监测：每季度至少1次
│     └─ 厂区内部监测：每月至少1次
│
└─ 一般排放口
   ├─ 有组织排放：每季度至少1次
   └─ 无组织排放：每半年至少1次
```

### 2.2 废水监测频次决策

```
开始：确定排放类型
│
├─ 重点管理单位
│  ├─ 直接排放
│  │  ├─ 日排放水量≥100m³：每日采样至少1次
│  │  ├─ 日排放水量<100m³：每周采样至少1次
│  │  └─ 自动监测：COD、氨氮（必装，如排放量大）
│  │
│  └─ 间接排放
│     ├─ 必测因子：每周至少1次
│     └─ 选测因子：每月至少1次
│
├─ 简化管理单位
│  ├─ 直接排放：每周至少1次
│  └─ 间接排放：每月至少1次
│
└─ 特别要求
   ├─ 特征有机物（氯乙烯、丙烯腈、TDI等）：每月至少1次
   ├─ 重金属因子：每月至少1次（如涉及）
   └─ 第一类污染物：在车间处理设施排放口采样，每周至少1次
```

### 2.3 土壤监测频次决策

```
开始：确定监测类型
│
├─ 重点管理单位
│  ├─ 基本监测：每年至少1次
│  ├─ 特征因子监测：每3年至少1次
│  └─ 周边敏感点：每年至少1次
│
└─ 简化管理单位
   ├─ 基本监测：每3年至少1次
   └─ 特征因子监测：每5年至少1次
```

## 三、排放标准适用指南

### 3.1 大气污染物排放标准

#### 3.1.1 国家标准

**《大气污染物综合排放标准》（GB 16297-1996）**
- 适用：未制定专项标准的污染物
- 关键限值：
  - 颗粒物：最高允许排放浓度18-120mg/m³
  - 非甲烷总烃：最高允许排放浓度120mg/m³
  - 苯：最高允许排放浓度12mg/m³
  - 甲苯：最高允许排放浓度40mg/m³
  - 二甲苯：最高允许排放浓度70mg/m³
  - 苯乙烯：最高允许排放浓度80mg/m³

**《合成树脂工业污染物排放标准》（GB 31572-2015）**
- 适用：合成树脂制造企业
- 关键限值：
  - SO₂：100-400mg/m³
  - NOx：100-150mg/m³
  - 颗粒物：10-30mg/m³
  - 非甲烷总烃：去除效率≥95% 或 排放浓度≤80mg/m³
  - 苯乙烯：20mg/m³
  - 丙烯腈：0.5mg/m³（极严）
  - 氯乙烯：1mg/m³（严）

**《石油化学工业污染物排放标准》（GB 31571-2015）**
- 适用：石油化学工业企业（部分合成材料制造适用）
- 关键限值：参照标准具体内容

#### 3.1.2 地方标准（重点省份）

**江苏省**：《大气污染物综合排放标准》（DB32/4041-2021）
- 特别排放限值：
  - 非甲烷总烃：50mg/m³
  - 苯乙烯：15mg/m³

**浙江省**：《化学工业大气污染物排放标准》（DB33/2368-2021）
- 特别排放限值：
  - 非甲烷总烃：60mg/m³

**广东省**：《大气污染物排放限值》（DB44/27-2001）
- 关键限值：
  - 非甲烷总烃：120mg/m³（第二时段）

**山东省**：《区域性大气污染物综合排放标准》（DB37/2376-2019）
- 核心控制区限值：
  - 非甲烷总烃：50mg/m³

#### 3.2.2 地方标准（重点省份）

**江苏省**：《化学工业水污染物排放标准》（DB32/939-2021）

## 四、常见错误TOP 10

### 错误1：特征因子严重遗漏
**问题描述**: 未填报剧毒或持久性有机污染物特征因子。

**典型案例**: 
- 某PVC制造企业未填报"氯乙烯"、"二噁英"
- 某ABS树脂制造企业未填报"丙烯腈"

**正确做法**:
1. 识别所有原料、辅料、单体、聚合物的化学物质
2. 重点识别剧毒物质（氯乙烯、丙烯腈、TDI、MDI、光气等）
3. 重点识别持久性有机污染物（二噁英、PFOA、PFOS等）
4. 对照技术规范附录，逐项核对特征因子

### 错误2：监测频次不满足规范要求
**问题描述**: VOCs和特征因子监测频次不足。

**正确做法**:
1. 按技术规范确定监测频次
2. 重点管理+主要排放口：VOCs每月至少1次
3. 特征因子（剧毒物质）：每月至少1次（重点管理）
4. 无组织排放：厂界监测每季度至少1次

### 错误3：排放标准引用错误
**问题描述**: 未执行合成树脂工业专项标准（GB 31572-2015）。

**正确做法**:
1. 合成树脂制造必须执行GB 31572-2015
2. 优先执行地方标准（如有，且严于国家标准）
3. 标准更新后及时更新许可证载明标准

### 错误4：排放口信息不完整
**问题描述**: 排放口信息描述不完整或与实际不符。

**正确做法**:
1. 使用GPS定位仪现场测定排放口坐标
2. 核实现场实际情况与申报材料一致性
3. 上传排放口照片

### 错误5：总量指标核算方法错误
**问题描述**: 总量指标核算方法不符合技术规范。

**正确做法**:
1. 按产污系数法、物料衡算法、实际监测法核算
2. 优先使用实际监测数据核算
3. 多种方法核算结果差异较大时，取严值

### 错误6：无组织排放控制措施缺失
**问题描述**: 未填报无组织排放源或未制定控制措施。

**正确做法**:
1. 识别所有无组织排放源
2. 制定无组织排放控制措施
3. 制定LDAR方案（如涉及VOCs）

### 错误7：自动监测设备安装要求不明确
**问题描述**: 未明确自动监测设备安装要求。

**正确做法**:
1. 按技术规范明确自动监测设备安装要求
2. 明确安装时限、调试期、验收、联网要求

### 错误8：环境管理台账记录要求不明确
**问题描述**: 台账记录要求不明确。

**正确做法**:
1. 按HJ 944-2018明确台账记录要求
2. 明确记录内容、频次、保存期限

### 错误9：执行报告填报要求不明确
**问题描述**: 执行报告填报要求不明确。

**正确做法**:

## 六、多工序企业标准适用指南

### 6.1 多工序企业定义
**典型情形**:
- 合成材料制造企业同时从事基础化学原料制造
- 合成材料制造企业同时从事专用化学品制造
- 合成材料制造企业同时从事危险化学品生产

### 6.2 标准适用原则
1. **一厂一证**: 同一个排污单位，核发一个排污许可证
2. **分类管理**: 按主要生产工序的管理类别确定整体管理类别
3. **标准分别适用**: 不同工序分别适用对应的技术规范和排放标准
4. **从严要求**: 当多个标准对同一污染物有不同要求时，取最严值

### 6.3 不同工序标准适用指南

#### 6.3.1 合成树脂制造 + 基础化学原料制造
**技术规范适用**:
- 合成树脂制造工序：适用GB 31572-2015对应技术规范
- 基础化学原料制造工序：适用HJ 853-2017

**排放标准适用**:
- 合成树脂制造工序：适用GB 31572-2015
- 基础化学原料制造工序：适用GB 31571-2015

#### 6.3.2 合成橡胶制造 + 合成树脂制造
**技术规范适用**:
- 分别适用对应技术规范

**排放标准适用**:
- 如执行同一排放标准（如GB 31572-2015），统一执行
- 如执行不同排放标准，分别执行并取严值

#### 6.3.3 合成材料制造 + 危险化学品生产
**技术规范适用**:
- 合成材料制造工序：适用对应技术规范
- 危险化学品生产工序：适用对应技术规范

**排放标准适用**:
- 分别适用对应行业标准

**特别注意**:
- 危险化学品生产需额外关注环境风险防范
- 需制定环境应急预案

## 七、真实审批拒绝案例（3个）

### 案例1：特征因子严重遗漏（剧毒物质），许可证被退回

**企业基本情况**:
- 企业名称：某PVC制造企业
- 行业：合成材料制造（C2651）
- 产品：聚氯乙烯
- 管理类别：重点管理

**拒绝原因**:
- 特征因子严重遗漏
- 未填报"氯乙烯"、"二噁英"

**整改要求**:
- 补充填报"氯乙烯"、"二噁英"
- 补充制定监测方案

**整改结果**:
- 许可证通过审批

### 案例2：监测频次不满足规范要求，许可证被退回

**企业基本情况**:
- 企业名称：某ABS树脂制造企业
- 行业：合成材料制造（C2651）
- 产品：ABS树脂
- 管理类别：重点管理

**拒绝原因**:
- 监测频次不满足规范要求
- 丙烯腈监测频次填报为"每季度1次"，实际应为"每月1次"

**整改要求**:
- 修正监测频次（丙烯腈：每月至少1次）

**整改结果**:
- 许可证通过审批

### 案例3：剧毒物质环境风险防范要求缺失，许可证被退回

**企业基本情况**:
- 企业名称：某聚氨酯制造企业
- 行业：合成材料制造（C2659）
- 产品：聚氨酯
- 管理类别：重点管理

**拒绝原因**:
- 剧毒物质环境风险防范要求缺失
- 未制定TDI、MDI环境风险防范方案

**整改要求**:
- 制定TDI、MDI环境风险防范方案
- 制定环境应急预案

**整改结果**:
- 许可证通过审批

## 十、边缘情况处理指南

### 10.1 涉及剧毒物质的合成材料制造
**处理方法**:
- 识别剧毒物质
- 制定环境风险防范方案
- 制定环境应急预案
- 配备环境应急物资
- 设置泄漏检测与报警装置

### 10.2 涉及持久性有机污染物的合成材料制造
**处理方法**:
- 识别持久性有机污染物
- 制定减排方案
- 禁止新建、扩建排放持久性有机污染物的生产装置
- 现有生产装置应逐步淘汰或改造

### 10.3 合成材料制造涉及VOCs
**处理方法**:
- 识别VOCs排放源
- 制定VOCs减排方案
- 设置VOCs收集处理设施
- 开展LDAR（如适用）

### 10.4 合成材料制造涉及重金属
**处理方法**:
- 识别重金属污染物
- 制定重金属污染物削减方案
- 定期开展土壤污染状况调查

### 10.5 合成材料制造涉及环境风险
**处理方法**:
- 识别环境风险源
- 制定环境风险防范方案
- 制定环境应急预案
- 定期开展环境应急演练
