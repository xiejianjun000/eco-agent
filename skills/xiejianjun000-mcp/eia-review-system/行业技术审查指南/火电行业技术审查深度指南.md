## 前言

火电行业是排污许可技术审查中**自动监测最完善、超低排放要求最严格**的高风险行业之一。

火电厂以燃煤发电为主，辅以燃气、燃油、生物质发电，主要排放大气污染物（SO₂、NOx、颗粒物、汞及其化合物）和废水（工业废水、生活污水、含煤废水）。2015年以来，全国范围内推进超低排放改造，使火电行业排放标准大幅提升，排放限值接近甚至达到燃气轮机水平。

根据2024年全国火电行业排污许可证技术审查质量统计：
- **申请退回率：28.3%**（全国各行业排名第7）
- **最高发问题：超低排放限值适用错误（占35%）、汞监测因子遗漏（占20%）、废水特征因子不完整（占25%）**
- **常见错误：300MW以下机组监测频次混淆、自动监测数据联网不到位、特殊时段限产要求漏填**
- **审查平均耗时：4.5个工作日**（相对较短，因火电行业技术规范最成熟）

## 第一章 火电工艺全流程特征因子核对表

### 核心原则

**"燃煤火电看三大气，超低排放分三档；汞是特征不可忘，废水防渗是重点。"**

火电行业技术审查的核心判断逻辑：
- **燃煤vs燃气vs燃油** → 决定特征因子类型和排放标准
- **机组容量（≥300MW vs <300MW）** → 决定监测频次和自动监测要求
- **超低排放改造** → 决定实际排放限值（通常严于国家标准）
- **是否有脱硫废水** → 决定重金属（六价铬、汞等）因子

### 1.1 燃煤电厂工艺流程与特征因子

#### 1.1.1 燃烧系统（锅炉+汽轮机）

| 特征因子 | 产生来源 | 排放去向 | 排放特征 | 审查要点 |
|---------|---------|---------|---------|---------|
| **SO₂** | 煤中硫分燃烧氧化 | 废气 | 脱硫前：1000-6000mg/m³；脱硫后：≤35mg/m³（超低排放） | 燃煤电厂必填！最大污染因子 |
| **NOx** | 高温燃烧（热力型+燃料型） | 废气 | 脱硝前：300-800mg/m³；脱硝后：≤50mg/m³（超低排放） | 燃煤电厂必填！ |
| **颗粒物** | 煤灰分燃烧 | 废气 | 除尘前：20-50g/m³；除尘后：≤10mg/m³（超低排放） | 燃煤电厂必填！ |
| **汞（Hg）** | 煤中汞燃烧挥发 | 废气 | 浓度0.1-5mg/m³ | **燃煤电厂必填！特征因子** |
| **氨逃逸（NH₃）** | 脱硝催化剂（SCR） | 废气 | SCR脱硝出口氨逃逸 | 关注 |
| **烟气黑度** | 不完全燃烧 | 废气 | 林格曼黑度1-6级 | 按GB 13223-2011 |

#### 1.1.2 脱硫系统（FGD）

| 特征因子 | 产生来源 | 排放去向 | 审查要点 |
|---------|---------|---------|---------|
| SO₂（脱硫后） | 石灰石-石膏湿法脱硫 | 废气 | 脱硫效率95-99%，出口浓度≤35mg/m³（超低排放） |
| 颗粒物（脱硫后） | 石膏雨/石膏雾 | 废气 | 脱硫后颗粒物浓度升高，需除雾器 |
| 脱硫废水 | 石灰石-石膏湿法脱硫 | 废水 | 含重金属（六价铬、汞、砷等）、悬浮物、盐分 |

**脱硫废水特征因子（重要！最容易遗漏）**：

| 特征因子 | 产生来源 | 审查要点 |
|---------|---------|---------|
| pH | 石灰石浆液反应 | 必填 |
| CODcr | 有机物（少量） | 必填 |
| SS | 石膏、悬浮物 | 必填 |
| **六价铬** | 煤中铬在脱硫液中溶解 | **脱硫废水必填！** |
| **汞（Hg）** | 煤中汞在脱硫液中富集 | **脱硫废水必填！特征因子** |
| **砷（As）** | 煤中砷在脱硫液中富集 | **脱硫废水必填！** |
| **铅（Pb）** | 煤中铅在脱硫液中富集 | 关注 |
| **镉（Cd）** | 煤中镉在脱硫液中富集 | 关注 |
| 氟化物 | 煤中氟在脱硫液中溶解 | 关注 |
| 氨氮 | 脱硝系统泄漏 | 关注 |
| 硫酸盐 | 石灰石反应产物 | 关注 |

#### 1.1.3 脱硝系统（SCR/SNCR）

| 特征因子 | 产生来源 | 排放去向 | 审查要点 |
|---------|---------|---------|---------|
| NOx（脱硝后） | SCR选择性催化还原 | 废气 | 脱硝效率60-80%，出口浓度≤50mg/m³（超低排放） |
| **氨逃逸（NH₃）** | SCR反应不完全 | 废气 | 超低排放要求氨逃逸≤2.5mg/m³ |
| 氨（NH₃） | SNCR脱硝 | 废气 | SNCR直接喷氨 |

#### 1.1.4 除尘系统（电除尘/袋除尘/电袋复合）

| 特征因子 | 产生来源 | 排放去向 | 审查要点 |
|---------|---------|---------|---------|
| 颗粒物（除尘后） | 烟气除尘 | 废气 | 超低排放要求≤10mg/m³（重点地区≤5mg/m³） |
| 烟尘（超低排放） | 电/袋/电袋复合除尘 | 废气 | 超低排放后排放浓度极低 |

### 1.2 燃气/燃油电厂特征因子

| 特征因子 | 燃气电厂 | 燃油电厂 | 审查要点 |
|---------|---------|---------|---------|
| SO₂ | 低（燃气硫分低） | 中-高（重油硫分高） | 燃气SO₂很低但仍需填 |
| NOx | 必填（燃烧温度高） | 必填 | 燃气NOx是主要因子 |
| 颗粒物 | 低（天然气清洁） | 中（重油燃烧） | 燃气颗粒物很低 |
| 烟气黑度 | 低（燃气充分燃烧） | 高（重油不完全燃烧） | 燃油需关注 |
| 燃油电厂重金属 | — | 关注（钒、镍） | 重油含钒、镍 |

### 1.3 火电厂废水系统特征因子

火电厂废水系统复杂，分为以下几类：

| 废水类型 | 产生来源 | 特征因子 | 审查要点 |
|---------|---------|---------|---------|
| **含煤废水** | 输煤系统冲洗 | SS、CODcr | 煤尘含高浓度SS |
| **冲灰水** | 除灰系统 | SS、pH | 粉煤灰水淬后碱性 |
| **脱硫废水** | 石灰石湿法脱硫 | **重金属（六价铬、汞、砷、铅、镉）** | **火电特征！最易漏** |
| **化学水处理废水** | 离子交换再生 | pH、盐分 | 含酸碱 |
| **循环冷却水排污** | 冷却塔 | pH、氯离子、TDS | 含盐量高 |
| **生活污水** | 厂区生活 | CODcr、BOD5、氨氮、SS | — |
| **含油废水** | 油罐区、油处理 | 石油类、CODcr | 含油废水必填 |

**审查红线**：脱硫废水中的重金属（六价铬、汞、砷）是火电行业最容易遗漏的特征因子！

### 1.4 全厂综合排放口特征因子汇总

**大气污染物**：
- SO₂、NOx、颗粒物（所有燃煤/燃油锅炉排放口）
- 汞及其化合物（Hg，燃煤锅炉）
- 氨逃逸（NH₃，SCR脱硝系统）
- 烟气黑度（按GB 13223-2011要求）
- 燃油电厂：钒（V）、镍（Ni）

**水污染物**：
- pH、CODcr、SS（所有排放口）
- 氨氮、总氮、总磷（生活污水排放口）
- 石油类（含油废水排放口）
- **六价铬、汞、砷**（脱硫废水排放口）**【火电特征因子】**

## 第二章 监测频次决策树

### 2.1 火电行业监测频次决策树

```
【火电行业监测频次决策树】

第1层：燃料类型判断
├─ 燃煤电厂 → 三大气+汞+脱硫废水重金属
├─ 燃气电厂 → NOx+SO₂（少量）+颗粒物
└─ 燃油电厂 → SO₂+NOx+颗粒物+钒镍+烟气黑度

第2层：机组容量判断（燃煤电厂）
├─ 机组容量≥300MW → 自动监测（所有三大气因子）
├─ 300MW>机组容量≥210MW → 自动监测（SO₂、NOx、颗粒物）
└─ 机组容量＜210MW → 自动监测或手动监测

第3层：超低排放判断
├─ 已完成超低排放改造 → 排放限值按超低排放标准填报
├─ 未完成超低排放改造 → 排放限值按GB 13223-2011填报
└─ 部分完成超低排放改造 → 按实际完成情况分排放口填报

第4层：脱硫废水判断
├─ 有脱硫废水 → 脱硫废水排放口重金属因子必填
└─ 无脱硫废水（干法脱硫等）→ 不涉及

第5层：汞监测判断
├─ 燃煤电厂 → 汞及其化合物必测
└─ 燃气/燃油电厂 → 汞不作为主要因子
```

## 第三章 排放标准适用指南

### 3.1 标准体系与优先级

**优先级1**：地方超低排放标准（最严格优先）  
→ 重点地区（北京、天津、河北、山东、山西等）：超低排放改造要求  
→ 各省超低排放实施方案（2015-2020年密集发布）  

**优先级2**：国家标准  
→ GB 13223-2011《火电厂大气污染物排放标准》  
→ GB 13271-2014《锅炉大气污染物排放标准》（参照执行，燃气/燃油锅炉）  

**优先级3**：地方排放标准（更严优先）  
→ 各地《燃煤电厂大气污染物排放标准》

### 3.2 GB 13223-2011关键排放限值

| 污染物指标 | 2012年1月1日起执行（现有） | 2014年7月1日起执行（新建） | 重点地区（现有） |
|---------|--------------------------|--------------------------|----------------|
| SO₂ | 200mg/m³（200MW以上） | 100mg/m³ | 100mg/m³（天然气50mg/m³） |
| NOx | 200mg/m³（200MW以上） | 100mg/m³ | 100mg/m³（天然气100mg/m³） |
| 颗粒物 | 30mg/m³（200MW以上） | 20mg/m³ | 20mg/m³（天然气10mg/m³） |
| 汞（Hg） | 0.03mg/m³ | 0.03mg/m³ | 0.03mg/m³ |
| 烟气黑度 | 林格曼黑度1级 | 林格曼黑度1级 | 林格曼黑度1级 |

### 3.3 超低排放标准（重点地区）

| 污染物 | 超低排放限值 | 说明 |
|-------|------------|------|
| SO₂ | ≤35mg/m³ | 燃煤电厂超低排放 |
| NOx | ≤50mg/m³ | 燃煤电厂超低排放 |
| 颗粒物 | ≤10mg/m³ | 燃煤电厂超低排放（部分地区≤5mg/m³） |
| 汞（Hg） | ≤0.03mg/m³ | 沿用GB 13223-2011 |

### 3.4 标准适用决策树

```
【火电行业排放标准适用决策树】

第1步：该企业位于重点地区还是一般地区？
├─ 重点地区（京津冀、长三角、珠三角等）→ 重点核查超低排放要求
└─ 一般地区 → 按GB 13223-2011执行

第2步：企业是否已完成超低排放改造？
├─ 已完成 → 排放限值按超低排放标准填报
│   ├─ SO₂≤35mg/m³（重点地区）或≤50mg/m³（一般地区）
│   ├─ NOx≤50mg/m³（燃煤）或≤150mg/m³（燃气）
│   └─ 颗粒物≤10mg/m³（重点地区≤5mg/m³）
└─ 未完成 → 按GB 13223-2011填报
    ├─ SO₂≤200mg/m³（现有，≥300MW）
    ├─ NOx≤200mg/m³（现有，≥300MW）
    └─ 颗粒物≤30mg/m³（现有，≥300MW）

第3步：判断机组容量
├─ ≥300MW → 自动监测
├─ 210MW≤机组＜300MW → 自动监测（SO₂、NOx、颗粒物）
└─ <210MW → 自动监测或手动监测

第4步：判断燃料类型
├─ 燃煤 → 汞及其化合物必测
└─ 燃气/燃油 → 汞不作为主要因子（但应填报）

第5步：脱硫废水
├─ 有脱硫废水 → 六价铬、汞、砷必填
└─ 无脱硫废水 → 不涉及重金属废水因子
```

## 第四章 常见错误TOP 10

### 错误1：超低排放限值适用错误（最高频）

**错误描述**：已完成超低排放改造的火电厂，在许可证中错误填报GB 13223-2011的排放限值而非超低排放限值。

**技术依据**：
- 2015年后全国推进超低排放改造，改造后实际排放水平远严于国家标准
- 部分省份已发布超低排放地方标准（如DB 37/ 987-2019山东省《燃煤电厂大气污染物排放标准》）
- 许可证应填报实际执行的排放限值（超低排放标准）

---

### 错误2：汞（Hg）因子遗漏（燃煤电厂）

**错误描述**：燃煤电厂未填报汞及其化合物特征因子。

**技术依据**：GB 13223-2011明确汞为燃煤电厂的特征污染物，排放限值0.03mg/m³。

---

### 错误3：脱硫废水重金属因子遗漏

**错误描述**：石灰石-石膏湿法脱硫电厂未填报脱硫废水中重金属（六价铬、汞、砷）。

**技术依据**：脱硫废水中富集了煤中多种重金属，是火电厂水污染物的重要特征因子。

---

### 错误4：300MW以下机组监测频次混淆

**错误描述**：将300MW以下（但≥210MW）机组按"≥300MW"要求填报自动监测，或将210MW以下机组填报为自动监测。

**技术依据**：HJ 988-2018对不同容量机组规定了不同的监测频次要求。

---

### 错误5：燃气电厂SO₂排放限值错误

**错误描述**：燃气电厂错误适用燃煤电厂的SO₂排放限值（100mg/m³）。

**技术依据**：GB 13223-2011规定燃气电厂SO₂排放限值为50mg/m³（重点地区）。

---

### 错误6：特殊时段限产要求漏填

**错误描述**：位于大气污染传输通道城市的火电厂，未填报特殊时段（如重大活动、采暖季）的限产减排要求。

**技术依据**：部分省份对传输通道城市火电厂有特殊时段的减排要求，应在许可证中载明。

---

### 错误7：氨逃逸（NH₃）因子遗漏

**错误描述**：SCR脱硝系统电厂未填报氨逃逸特征因子。

**技术依据**：超低排放要求对氨逃逸有明确控制要求（≤2.5mg/m³），氨逃逸是SCR脱硝系统的伴生特征因子。

---

### 错误8：烟气黑度监测遗漏

**错误描述**：已完成超低排放改造的火电厂认为"烟气很干净，不需要观测烟气黑度"。

**技术依据**：GB 13223-2011第4.6条规定，所有火电厂须每日观测烟气黑度（目测或自动监测），并记录观测结果。

---

### 错误9：含油废水石油类因子遗漏

**错误描述**：有油罐区和油处理系统的火电厂，未填报含油废水排放口和石油类特征因子。

**技术依据**：火电厂含油废水属于特征废水，石油类为特征因子。

---

### 错误10：废水排放口与雨水排放口混淆

**错误描述**：将循环冷却水排污（清净下水）与生产废水排放口混淆。

**技术依据**：循环冷却水属于清净下水，不纳入工业废水排放口；含煤废水、脱硫废水、化学水处理废水属于生产废水。

---

## 第五章 边缘情况处理指南

### 情况1：部分机组完成超低排放改造

**问题**：同一电厂的不同机组，超低排放改造进度不同，如何填报？

**处理方法**：
- 按机组分别填报废气排放口
- 已完成超低排放改造的机组：排放限值填报超低排放标准
- 未完成改造的机组：排放限值填报GB 13223-2011标准
- 各排放口的监测频次分别按对应标准执行

---

### 情况2：燃气蒸汽联合循环机组（CCGT）

**问题**：燃气-蒸汽联合循环发电机组的排放口如何填报？

**处理方法**：
- 燃气轮机燃烧室废气（高温燃烧产物）
- 余热锅炉废气（利用废热产生蒸汽）
- 蒸汽轮机补燃锅炉（如有）
- 各排放口特征因子不同，应分别填报
- SO₂浓度很低（天然气硫分低），但NOx是主要控制因子

---

### 情况3：燃煤耦合生物质发电

**问题**：燃煤电厂耦合生物质（污泥、稻壳、木屑）发电，特征因子如何处理？

**处理方法**：
- 生物质燃烧产生的污染物特征与燃煤有所不同
- 生物质燃烧：VOCs、二噁英（废弃物类生物质）是关注因子
- 耦合污泥时：重金属（Zn、Cu、Pb、Cd）是关注因子
- 申请材料中应说明生物质掺烧比例和种类

---

### 情况4：淘汰关停机组与生产机组并存

**问题**：电厂部分机组已关停淘汰，但仍在环评批复中，如何处理？

**处理方法**：
- 已关停机组不纳入许可证申请
- 申请材料中应说明关停情况（关停时间、拆除情况）
- 剩余运行机组按实际容量填报

---

### 情况5：脱硫废水零排放（蒸发结晶/喷雾干燥）

**问题**：采用脱硫废水零排放工艺（蒸发结晶、喷雾干燥）的企业，废水排放口如何填报？

**处理方法**：
- 脱硫废水零排放：蒸发结晶系统出水作为固体产物，不外排
- 仍需填报脱硫废水特征因子，但排放口标注"零排放"
- 蒸发结晶系统运行记录纳入环境管理台账

---

### 情况6：在线监测设备定期校准期

**问题**：自动监测设备定期校准期间，数据缺失如何处理？

**处理方法**：
- 设备校准期间采用手工监测数据替代
- 校准原因和时间应在台账中记录
- 校准期不超过规定时限（HJ 988-2018规定）

---

### 情况7：自备电厂与公用电网电厂的区别

**问题**：企业自备火电厂（非公用电网电厂）的审查要点与公用电网电厂有何不同？

**处理方法**：
- 自备电厂与公用电网电厂在排放标准适用上相同
- 自备电厂通常与主体生产设施关联（如钢铁、化工自备电厂）
- 需关注自备电厂是否同时承担居民供热任务（若有，供热机组有特殊要求）

---

### 情况8：冷凝水回收系统的废水属性

**问题**：火电厂蒸汽冷凝水回收利用后，少量泄漏水的属性如何判断？

**处理方法**：
- 纯蒸汽冷凝水：无污染，属清净下水
- 与生产废水混合后的冷凝水：按生产废水处理
- 申请材料中应说明冷凝水回用情况

## 第七章 真实审批拒绝案例

### 案例1：山东某超超临界燃煤电厂——超低排放限值填报错误导致退回

**企业基本情况**：
- 行业：超超临界燃煤电厂（2×1000MW机组）
- 管理类别：重点管理
- 建设时间：2017年（新建企业）
- 排放方式：直接排放（入海河流）
- 超低排放改造：2019年完成超低排放改造（山东省政府验收）

**拒绝原因**：
企业在排污许可申请表中填报的SO₂、NOx、颗粒物排放限值按GB 13223-2011新建企业标准（SO₂≤100mg/m³，NOx≤100mg/m³，颗粒物≤20mg/m³）填报，而非超低排放标准。审查人员发现企业已于2019年完成超低排放改造，实际排放水平远超国家标准，许可证应填报超低排放限值。

**审查发现**：
1. 企业有山东省生态环境厅超低排放验收文件（2019年12月）
2. 企业2019-2025年在线监测数据显示SO₂平均排放浓度约18mg/m³，远低于100mg/m³
3. 企业NOx平均排放浓度约35mg/m³，远低于100mg/m³
4. 颗粒物平均排放浓度约4mg/m³，远低于20mg/m³
5. 许可证填报的排放限值与实际排放水平严重不符

**修正方法**：
1. 更正SO₂排放限值为≤35mg/m³（山东省超低排放标准）
2. 更正NOx排放限值为≤50mg/m³（山东省超低排放标准）
3. 更正颗粒物排放限值为≤10mg/m³（山东省超低排放标准）
4. 附山东省超低排放验收文件作为依据

**审查结论**：退回补充材料，企业完成修正后通过审批。

### 案例2：江苏某燃煤热电厂——脱硫废水重金属因子遗漏导致退回

**企业基本情况**：
- 行业：燃煤热电厂（2×330MW机组，承担城市集中供热）
- 管理类别：重点管理
- 建设时间：2010年（现有企业）
- 脱硫工艺：石灰石-石膏湿法脱硫（2套FGD系统）
- 排放方式：间接排放（纳管至园区污水处理厂）

**拒绝原因**：
企业在排污许可申请表中填报了pH、CODcr、SS等常规脱硫废水因子，但遗漏了脱硫废水中富集的重金属特征因子**六价铬、汞、砷**。

**审查发现**：
1. 企业石灰石-石膏湿法脱硫系统每天产生脱硫废水约200m³
2. 脱硫废水中汞浓度约0.05-0.3mg/L（富集于脱硫液中）
3. 六价铬浓度约0.1-0.5mg/L（煤中铬在脱硫液中溶解）
4. 砷浓度约0.02-0.1mg/L（煤中砷在脱硫液中富集）
5. 申请材料中特征因子清单无六价铬、无汞、无砷
6. 监测方案中无重金属监测计划

**修正方法**：
1. 补充六价铬为脱硫废水排放口特征因子
2. 补充汞（Hg）为脱硫废水排放口特征因子
3. 补充砷（As）为脱硫废水排放口特征因子
4. 补充重金属监测方案：每月1次
5. 更正脱硫废水排放标准（按GB 8978-1996第二类污染物最高允许排放浓度）

**审查结论**：退回补充材料，企业完成修正后通过审批。

### 案例3：河北某300MW以下燃煤电厂——汞因子遗漏导致退回

**企业基本情况**：
- 行业：燃煤发电厂（1×280MW亚临界机组）
- 管理类别：重点管理
- 建设时间：2008年（现有企业）
- 排放方式：直接排放（滏阳河支流）
- 脱硫工艺：石灰石-石膏湿法脱硫（2016年改造完成）

**拒绝原因**：
企业在排污许可申请表中填报了SO₂、NOx、颗粒物等大气污染物因子，但遗漏了燃煤电厂的特征污染物**汞及其化合物**。

**审查发现**：
1. 企业燃用煤种为山西晋北烟煤，汞含量约0.2-0.4mg/kg
2. 汞在燃烧过程中挥发，随烟气排放或被除尘器/脱硫系统捕集
3. GB 13223-2011明确要求燃煤电厂监测汞排放，限值0.03mg/m³
4. 企业申请材料中无汞及其化合物特征因子
5. 监测方案中无汞监测计划

**修正方法**：
1. 补充汞及其化合物为锅炉烟气排放口特征因子
2. 汞排放限值：GB 13223-2011（现有企业）≤0.03mg/m³
3. 补充汞监测方案：每月1次（≥300MW自动监测，280MW手动监测每月1次）
4. 说明汞的排放特征（经除尘器/脱硫系统捕集后排空）

**审查结论**：退回补充材料，企业完成修正后通过审批。
