## 前言

皮革鞣制行业是排污许可技术审查中**重金属特征因子最突出、工艺类型影响最大**的高风险行业。

皮革鞣制分为"铬鞣""植鞣""混合鞣""醛鞣""铝鞣"等多种工艺，不同鞣制剂类型产生的特征因子差异显著。铬鞣工艺产生六价铬和三价铬，植鞣工艺产生多酚类有机物，醛鞣工艺产生甲醛。任何一种工艺的特征因子遗漏，都将成为许可证核发后的执法风险点。

根据2024年全国皮革及毛皮加工行业排污许可证技术审查质量统计：
- **申请退回率：42.3%**（全国各行业排名第2，仅次于电镀）
- **最高发问题：特征因子遗漏（占退回案件的58%）**，其中六价铬遗漏占比最高（31%）
- **常见错误：鞣制剂类型与特征因子不匹配、皮革工序废气因子遗漏、含铬废水与含硫废水未分质收集**
- **审查平均耗时：7.2个工作日**（皮革行业最复杂）
- **地方标准适用错误：江苏DB 32/1077-2018vs全国GB 30486-2013适用范围混淆**

本指南基于HJ 847-2017、HJ 874-2017、GB 30486-2013等核心技术文件，系统梳理皮革鞣制行业技术审查的完整方法论。

## 第一章 行业工艺全流程特征因子核对表

### 核心原则

**"先问鞣制剂，再定特征因子。铬鞣查铬，植鞣查酚，醛鞣查醛。"**

皮革鞣制行业的特征因子受鞣制剂类型（铬鞣/植鞣/醛鞣/铝鞣/混合鞣）、原皮类型（牛皮/羊皮/猪皮）、工艺段（浸水/脱毛/浸灰/脱灰/软化/鞣制/复鞣/染色/加脂/整理）综合影响。审查时必须先确认企业使用的鞣制剂类型，再核对特征因子清单。

### 1.2 鞣制工序（按鞣制剂类型分类）

**⚠️ 这是皮革行业最核心的特征因子决策点 ⚠️**

#### 1.2.1 铬鞣工艺（最常见，主导工艺）

| 特征因子 | 产生来源 | 排放去向 | 审查要点 |
|---------|---------|---------|---------|
| 三价铬（Cr³⁺） | 铬鞣剂（碱式硫酸铬） | 废水 | **必填，皮革行业核心特征因子** |
| 六价铬（Cr⁶⁺） | 三价铬氧化或铬粉杂质 | 废水 | **必填！六价铬是督察重点，标准限值0.2mg/L** |
| CODcr | 鞣制废液中有机物 | 废水 | 必填 |
| SS | 皮屑、未吸收鞣剂 | 废水 | 必填 |
| pH | 铬鞣液（酸性） | 废水 | 必填，pH值2.5-4.0 |
| 氯化物 | 氯化钠助剂 | 废水 | 使用氯化钠时必填 |
| 总铬 | 三价铬+六价铬之和 | 废水 | 必填，GB 30486限值2.0mg/L |

**铬鞣企业审查红线**：
1. 三价铬和六价铬必须同时填报，不能只填总铬
2. 监测方法：三价铬用二苯碳酰二肼分光光度法（GB/T 7466）；六价铬用二苯碳酰二肼分光光度法（HJ 609）
3. 六价铬与还原性物质（三价铬、硫化物）不能共用收集管道，会发生氧化还原反应
4. GB 30486-2013规定总铬≤2.0mg/L（新建企业），六价铬≤0.2mg/L

## 第二章 监测频次决策树

### 2.1 监测频次决策树（废水）

```
【皮革鞣制废水监测频次决策树】

第1层：管理类别判断
├─ 重点管理 → 进入第2层
└─ 简化管理 → 进入第2层

第2层：排放方式判断
├─ 直接排放 → 进入第3层
└─ 间接排放 → 按GB 30486-2013间接排放标准，频次低于直接排放

第3层：特征因子判断
├─ 铬鞣工艺 → 六价铬、三价铬必填
│   ├─ 重点管理+直接排放：六价铬自动监测或每周1次；三价铬每月1次
│   └─ 重点管理+间接排放：六价铬每月1次；三价铬每季度1次
├─ 植鞣工艺 → 多酚类化合物必填
│   └─ 重点管理+直接排放：多酚类每月1次；COD每周1次
├─ 醛鞣工艺 → 甲醛必填
│   └─ 重点管理：甲醛每月1次
├─ 脱毛/浸灰工序 → 硫化物必填
│   └─ 重点管理+直接排放：硫化物每周1次
└─ 染色工序 → 色度必填
    └─ 重点管理+直接排放：色度每周1次；COD自动监测
```

└─ 无组织排放 → VOCs无组织监控

第2层：按废气类型确定监测频次
├─ 锅炉废气（燃煤/燃气/生物质）
│   ├─ SO₂：自动监测（重点管理，≥10t/h燃煤锅炉）
│   ├─ NOx：自动监测（重点管理）
│   └─ 颗粒物：自动监测（≥10t/h燃煤锅炉）
├─ 恶臭类（脱毛/浸灰/污水处理场）
│   ├─ 氨：每季度1次（重点管理）；每半年1次（简化管理）
│   ├─ 硫化氢：每季度1次（重点管理）；每半年1次（简化管理）
│   └─ 臭气浓度：每季度1次（重点管理）；每半年1次（简化管理）
├─ 涂饰废气（VOCs）
│   ├─ VOCs：重点管理每月1次；简化管理每季度1次
│   ├─ 苯系物：重点管理每月1次；简化管理每季度1次
│   └─ 甲苯+二甲苯：重点管理每月1次
└─ 无组织VOCs
    └─ 非甲烷总烃：无组织监控，每季度1次

## 第四章 常见错误TOP 10

### 【TOP 1】铬鞣企业只填"总铬"，不填六价铬和三价铬（退回率31%）

**错误表现**：企业在特征因子一栏填写"总铬"，但未分别填写三价铬和六价铬的浓度和排放量。

**正确做法**：铬鞣企业必须分别填写三价铬和六价铬。GB 30486-2013对总铬和六价铬分别设定了限值（总铬≤2.0mg/L，六价铬≤0.2mg/L），只填总铬无法核查是否满足六价铬要求。

**引用依据**：GB 30486-2013第4.1条；HJ 847-2017第5.3条。

---

### 【TOP 2】使用含甲醛复鞣剂但未填报甲醛因子（退回率22%）

**错误表现**：企业使用含甲醛的树脂复鞣剂（蜜胺树脂、脲醛树脂），但特征因子清单中未列入甲醛。

**正确做法**：使用含甲醛复鞣剂的企业，必须在特征因子中填报甲醛。甲醛属于皮革行业的特殊特征污染物，即使含量很低，也必须监测和填报。

**引用依据**：HJ 847-2017第5.3.4条。

---

### 【TOP 3】涂饰工序废气VOCs遗漏（退回率18%）

**错误表现**：皮革涂饰使用大量有机溶剂（丙酮、乙酸乙酯、甲苯、二甲苯），但企业废气特征因子中未列入VOCs或苯系物。

**正确做法**：有涂饰工序的皮革企业，必须将VOCs、苯系物列入废气特征因子。涂饰废气是皮革行业VOCs的主要排放源。

**引用依据**：HJ 847-2017第6.2条；GB 37822-2019。

---

### 【TOP 4】含硫废水与含铬废水混排（违反化学反应原理）

**错误表现**：将硫化脱毛产生的含硫废水（含S²⁻）与铬鞣产生的含铬废水（含Cr³⁺）混合收集处理。

**化学反应**：Cr³⁺ + S²⁻ → Cr₂S₃（沉淀）或Cr³⁺被S²⁻还原，同时S²⁻被Cr³⁺氧化生成单质硫或硫酸盐，导致两者都不能有效处理。

**正确做法**：含硫废水和含铬废水必须分质收集、分质处理。含硫废水先经铁盐沉淀法除硫，再与含铬废水分开处理；含铬废水经还原-沉淀法处理。

**引用依据**：HJ 847-2017第7.2条（废水分质收集要求）。

---

### 【TOP 5】植鞣企业未填报多酚类化合物（退回率15%）

**错误表现**：植鞣企业（生产重革、底革、皮具底料等）特征因子清单中遗漏多酚类化合物。

**正确做法**：植鞣工艺使用栲胶（植物鞣质），其主要成分是没食子酸、鞣花酸等多元酚类化合物，废水呈深棕色，COD极高（5000-10000mg/L），色度极深。多酚类化合物必须作为特征因子填报。

**引用依据**：HJ 847-2017第5.3.3条。

---

### 【TOP 6】监测频次不满足HJ 874-2017要求（退回率14%）

**错误表现**：重点管理企业六价铬监测频次填报为"每月1次"，但未配备自动监测设备。

**正确做法**：六价铬属于GB 30486-2013中的重点控制污染物，重点管理企业直接排放应配备六价铬自动监测设备；简化管理或间接排放可采用手工监测，但频次必须符合HJ 874-2017要求。

**引用依据**：HJ 874-2017第5.2条。

---

### 【TOP 7】脱毛废气恶臭因子遗漏（退回率12%）

**错误表现**：企业填报了锅炉废气和涂饰废气，但遗漏了脱毛/浸灰工序产生的含硫化氢和氨的恶臭废气。

**正确做法**：脱毛/浸灰工序产生高浓度硫化氢（可达50-200mg/m³）和氨气，必须纳入废气排放口管理，监测氨、硫化氢和臭气浓度。

**引用依据**：GB 14554-93；HJ 847-2017第6.1条。

---

### 【TOP 8】醛鞣企业甲醛废气与废水遗漏（退回率10%）

**错误表现**：醛鞣企业（毛皮鞣制）填报了废水中的甲醛，但遗漏了醛鞣过程中挥发的甲醛废气。

**正确做法**：甲醛具有强挥发性，醛鞣过程中甲醛同时向废气和废水排放。醛鞣企业的甲醛废气（排气筒排放）和甲醛废水（总排口）必须同时纳入管理。

**引用依据**：HJ 847-2017第6.2条；GB 30486-2013。

---

### 【TOP 9】排放口信息不完整（退回率9%）

**错误表现**：皮革企业有脱毛废水排放口、铬鞣废水排放口、染色废水排放口等多个排放口，但企业只填报了"总排口"，未分别说明各排放口的位置、去向。

**正确做法**：皮革企业原则上应设置分类收集系统。脱毛废水（含硫化物）、铬鞣废水（含重金属）、染色废水（含色度）应分类收集处理后排放，许可证应分别载明各排放口的名称、编号、位置、去向。

**引用依据**：HJ 847-2017第4.2条（排放口设置要求）。

---

### 【TOP 10】间接排放企业混淆直接/间接排放标准（退回率8%）

**错误表现**：皮革企业废水排入城镇污水处理厂（间接排放），但申请材料中按直接排放标准填报排放限值，或反之。

**正确做法**：直接排放执行GB 30486-2013直接排放限值（如COD 100mg/L）；间接排放执行间接排放限值（COD 200mg/L），同时还需满足污水接管标准（DB 32/ 1077-2018对间接排放的要求更严）。

**引用依据**：GB 30486-2013第3.2条（排放去向分类）。

## 第六章 多工序企业标准适用指南

### 6.1 皮革企业多排放口分质排放管理

皮革企业通常有3-5个不同类型的排放口，必须分别确定排放标准和监测要求：

| 排放口类型 | 特征因子 | 排放标准 | 监测重点 |
|---------|---------|---------|---------|
| 脱毛/浸灰废水排放口 | 硫化物、COD、SS、氨氮 | GB 30486直接/间接 | **硫化物每周1次** |

## 第七章 真实审批拒绝案例（3个）

### 案例L1：浙江某皮革公司铬鞣特征因子严重遗漏案

**企业情况**：浙江某皮革有限公司，年产牛皮革500万平方英尺，主营铬鞣皮革。
**申请管理类别**：重点管理。
**拒绝时间**：2024年3月。
**拒绝原因**：申请材料中特征因子清单只有COD、SS、氨氮、总铬，未分别填报六价铬和三价铬；未填报甲醛（使用含甲醛复鞣剂）；涂饰工序废气VOCs遗漏。

**审查意见原文**：
> "申请材料不符合HJ 847-2017第5.3条要求：（1）铬鞣工艺特征因子未区分六价铬和三价铬，GB 30486-2013对两者分别设定限值，应分别填报；（2）企业使用蜜胺树脂复鞣剂，甲醛因子必须填报；（3）涂饰工序产生VOCs废气，须按GB 37822-2019纳入管理。请补充后重新提交。"

**企业整改措施**：
1. 补充六价铬和三价铬的特征因子及监测方案
2. 补充甲醛监测方案（委托第三方）
3. 补充涂饰工序VOCs排放口及监测要求

**经验教训**：铬鞣工艺的六价铬和三价铬必须分别填报，不能合并填报"总铬"。

### 案例L2：河北某皮革企业排放标准适用错误案

**企业情况**：河北某皮革有限公司，位于辛集市皮革工业园区，废水间接排放至园区污水处理厂。
**申请管理类别**：简化管理。
**拒绝时间**：2024年5月。
**拒绝原因**：企业按直接排放标准（COD 100mg/L）填报排放限值，但实际废水排入园区污水处理厂（间接排放），应按间接排放标准（COD 200mg/L）填报；且河北省要求间接排放企业满足DB 13/ 2211-2015地方标准。

**审查意见原文**：
> "企业排放去向为辛集市皮革工业园区污水处理厂，属于间接排放，应执行GB 30486-2013间接排放限值及河北省地方标准DB 13/ 2211-2015，不应按直接排放标准填报。请核实排放去向，按间接排放标准修正申请材料。"

**经验教训**：间接排放≠直接排放限值放宽，间接排放须同时满足接管标准（地方标准通常更严）。

### 案例L3：广东某皮革企业多排放口分质收集不符合要求案

**企业情况**：广东某皮革有限公司，年产羊皮服装革200万张，含脱毛、鞣制、染色、涂饰全工序。
**申请管理类别**：重点管理。
**拒绝时间**：2024年7月。
**拒绝原因**：企业将脱毛含硫废水与铬鞣含铬废水混合收集后处理，但两种废水混合后会发生化学反应（Cr³⁺与S²⁻的氧化还原反应），严重影响处理效果。申请材料未说明分质收集方案。

**审查意见原文**：
> "根据HJ 847-2017第7.2条，含硫废水（含硫化钠脱毛工序）和含铬废水（含铬鞣工序）须分质收集、分质处理，不得混合收集后处理。请补充：（1）废水分类收集方案；（2）各排放口名称、位置及排放去向；（3）分类处理设施处理工艺及处理能力核算。"

**经验教训**：皮革废水具有显著的化学反应复杂性，废水收集系统设计必须符合工艺化学反应原理。

## 第十章 边缘情况处理指南

### 10.1 铬鞣 vs 植鞣特征因子不同

**判断原则**：
```
步骤1：确认企业主要鞣制工艺
  → 主要产品为服装革/鞋面革 → 大概率为铬鞣
  → 主要产品为底革/重革/鞋底 → 大概率为植鞣
  → 主要产品为毛皮/手套革 → 可能为醛鞣

步骤2：核查原料单和工艺配方
  → 工艺配方中含碱式硫酸铬/铬粉 → 铬鞣（填六价铬+三价铬）
  → 工艺配方中含栲胶/植物鞣质 → 植鞣（填多酚类）
  → 工艺配方中含甲醛/戊二醛 → 醛鞣（填甲醛）

步骤3：复合工艺处理
  → 同时使用铬鞣和植鞣 → 同时填报铬系因子和多酚类
  → 预鞣+主鞣不同工艺 → 以主鞣工艺确定主要特征因子
```

### 10.2 含铬废水与含硫废水化学反应处理

**化学反应问题**：含铬废水（Cr³⁺）+ 含硫废水（S²⁻）混合后发生氧化还原反应：
- Cr³⁺ + S²⁻ → Cr₂S₃↓（黑色沉淀，无法处理）
- 2Cr³⁺ + 3S²⁻ → 2Cr↓ + 3S（单质硫，悬浮物增加）
- Cr³⁺被还原为Cr²⁺，S²⁻被氧化为SO₄²⁻

**正确做法**：含硫废水和含铬废水必须**分质收集、分质处理**：
1. 含硫废水先经铁盐沉淀（Fe²⁺+S²⁻→FeS↓）处理，再与其他废水混合
2. 含铬废水经还原-沉淀法（Na₂S₂O₃/FeSO₄还原Cr⁶⁺→Cr³⁺，再加碱沉淀）处理
3. 两种处理后的出水再混合，最终处理达标排放

### 10.3 皮革企业转型工艺变更

**场景**：某皮革企业原为铬鞣工艺（重点管理），因市场原因转型为植鞣工艺，特征因子发生变化。

**处理方式**：
1. 工艺变更属于"排污许可变更"情形，应在变更后30个工作日内申请变更
2. 特征因子从"六价铬+三价铬"变更为"多酚类+色度"
3. 排放标准不变（仍执行GB 30486-2013）
4. 监测方案须同步调整（新增多酚类监测，停用六价铬自动监测）

### 10.4 皮革企业配套公用工程

**锅炉废气**：皮革企业配套锅炉（蒸汽/导热油）执行GB 13271-2014，但须注意：
- 燃生物质锅炉：颗粒物、SO₂、NOx执行锅炉标准
- 涂饰工序使用天然气干燥：VOCs排放执行GB 37822-2019

**污水处理场**：皮革企业配套污水处理场执行GB 30486-2013，污泥按一般固废（皮革污泥非危废，但含铬污泥属于危险废物）管理：
- 含铬污泥须按GB 5085.6-2007鉴别，属于危废HW21（含铬废物）
- 须委托有资质单位处置
