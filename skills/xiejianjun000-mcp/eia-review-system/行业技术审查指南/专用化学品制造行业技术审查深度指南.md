## 一、行业特征因子核对表

### 1.1 农药制造（C2631）- 本指南不涉及，见农药制造专项指南

### 1.2 染料、颜料制造（C2643、C2644）

#### 1.2.1 染料制造
**生产工艺**: 重氮化、偶合、过滤、干燥、粉碎

**废气特征因子**:
- **有组织排放**: 非甲烷总烃、苯、甲苯、二甲苯、H₂S、NH₃、SO₂、NOx、颗粒物
- **关键装置**: 重氮化反应釜、偶合反应釜、过滤机、干燥机
- **特别因子**: 苯系物、H₂S（臭气）、NH₃（臭气）

**废水特征因子**:
- **生产废水**: pH、SS、COD、BOD₅、石油类、苯、甲苯、二甲苯、总盐量、色度
- **特征污染物**: 苯胺类、硝基苯类（如涉及）
- **高盐废水**: 总盐量、氯化物、硫酸盐

**土壤特征因子**:
- 苯、甲苯、二甲苯、苯胺类、硝基苯类、重金属（如涉及）

#### 1.2.2 颜料制造
**生产工艺**: 合成、过滤、洗涤、干燥、粉碎

**废气特征因子**:
- **有组织排放**: 非甲烷总烃、SO₂、NOx、颗粒物、重金属（如涉及铅铬黄、镉红等）
- **关键装置**: 反应釜、过滤机、干燥机、煅烧炉
- **特别因子**: 重金属（铅、铬、镉等，如涉及）

**废水特征因子**:
- **生产废水**: pH、SS、COD、BOD₅、石油类、色度、重金属（铅、铬、镉等，如涉及）
- **洗涤废水**: SS、COD、重金属

**土壤特征因子**:
- 重金属（铅、铬、镉、汞等，如涉及）

## 二、监测频次决策树

### 2.1 废气监测频次决策

```
开始：确定排放口类型
│
├─ 主要排放口
│  ├─ 有组织排放
│  │  ├─ 连续自动监测（如适用）
│  │  │  ├─ 非甲烷总烃（必装，如VOCs排放量≥10t/a）
│  │  │  ├─ SO₂、NOx、颗粒物（如涉及燃烧装置）
│  │  │  └─ 特征因子（如苯、H₂S等，建议安装）
│  │  │
│  │  └─ 手工监测
│  │     ├─ 重点管理：每月至少1次
│  │     ├─ 简化管理：每季度至少1次
│  │     └─ 特征因子：每月至少1次（重点管理）、每季度至少1次（简化管理）
│  │
│  └─ 无组织排放
│     ├─ 厂界监测：每季度至少1次
│     ├─ 厂区内部监测：每月至少1次
│     └─ 臭气污染物：每月至少1次（如涉及H₂S、NH₃）
│
└─ 一般排放口
   ├─ 有组织排放：每季度至少1次
   └─ 无组织排放：每半年至少1次
```

### 2.2 废水监测频次决策

```
开始：确定排放类型
│
├─ 重点管理单位
│  ├─ 直接排放
│  │  ├─ 日排放水量≥100m³：每日采样至少1次
│  │  ├─ 日排放水量<100m³：每周采样至少1次
│  │  └─ 自动监测：COD、氨氮（必装，如排放量大）
│  │
│  └─ 间接排放
│     ├─ 必测因子：每周至少1次
│     └─ 选测因子：每月至少1次
│
├─ 简化管理单位
│  ├─ 直接排放：每周至少1次
│  └─ 间接排放：每月至少1次
│
└─ 特别要求
   ├─ 特征污染物（苯胺类、硝基苯类、重金属等）：每月至少1次
   ├─ 色度：每周至少1次（染料、颜料制造）
   ├─ 总盐量：每周至少1次（高盐废水）
   └─ 第一类污染物：在车间处理设施排放口采样，每周至少1次
```

### 2.3 土壤监测频次决策

```
开始：确定监测类型
│
├─ 重点管理单位
│  ├─ 基本监测：每年至少1次
│  ├─ 特征因子监测：每3年至少1次
│  └─ 周边敏感点：每年至少1次
│
└─ 简化管理单位
   ├─ 基本监测：每3年至少1次
   └─ 特征因子监测：每5年至少1次
```

## 三、排放标准适用指南

### 3.1 大气污染物排放标准

#### 3.1.1 国家标准

**《大气污染物综合排放标准》（GB 16297-1996）**
- 适用：未制定专项标准的污染物
- 关键限值：
  - 颗粒物：最高允许排放浓度18-120mg/m³
  - SO₂：最高允许排放浓度550-960mg/m³
  - NOx：最高允许排放浓度240-420mg/m³
  - 苯：最高允许排放浓度12mg/m³
  - 甲苯：最高允许排放浓度40mg/m³
  - 二甲苯：最高允许排放浓度70mg/m³
  - 非甲烷总烃：最高允许排放浓度120mg/m³
  - H₂S：无专项标准，参考地方标准
  - NH₃：无专项标准，参考地方标准

**《工业炉窑大气污染物排放标准》（GB 9078-1996）**
- 适用：工业炉窑（如干燥炉、煅烧炉）
- 关键限值：
  - SO₂：850mg/m³
  - 颗粒物：100-200mg/m³

**《恶臭污染物排放标准》（GB 14554-1993）**
- 适用：涉及恶臭污染物的专用化学品制造（如皮革化学品、农药制剂等）
- 关键限值：
  - NH₃：1.5mg/m³（厂界）
  - H₂S：0.06mg/m³（厂界）
  - 臭气浓度：20（厂界）

**《涂料、油墨及胶粘剂工业大气污染物排放标准》（GB 37824-2019）**
- 适用：涂料、油墨制造（如涉及）
- 关键限值：
  - 非甲烷总烃：去除效率≥95% 或 排放浓度≤80mg/m³
  - 苯：1mg/m³
  - 甲苯：15mg/m³
  - 二甲苯：20mg/m³

#### 3.1.2 地方标准（重点省份）

**江苏省**：《大气污染物综合排放标准》（DB32/4041-2021）
- 特别排放限值：
  - 颗粒物：10mg/m³
  - SO₂：50mg/m³
  - NOx：100mg/m³
  - 非甲烷总烃：50mg/m³
  - 苯：1mg/m³

**浙江省**：《化学工业大气污染物排放标准》（DB33/2368-2021）
- 特别排放限值：
  - 颗粒物：10mg/m³
  - 非甲烷总烃：60mg/m³

**广东省**：《大气污染物排放限值》（DB44/27-2001）
- 关键限值：
  - 颗粒物：120mg/m³（第二时段）
  - SO₂：500mg/m³（第二时段）

**山东省**：《区域性大气污染物综合排放标准》（DB37/2376-2019）
- 核心控制区限值：
  - 颗粒物：10mg/m³
  - SO₂：50mg/m³
  - NOx：100mg/m³

### 3.2 水污染物排放标准

#### 3.2.1 国家标准

**《污水综合排放标准》（GB 8978-1996）**
- 分一级、二级、三级标准
- 关键限值（一级标准）：
  - pH：6-9
  - COD：100mg/L
  - BOD₅：30mg/L
  - SS：70mg/L
  - 石油类：10mg/L
  - 氨氮：15mg/L
  - 总磷：0.5mg/L（敏感区域）
  - 苯：0.1mg/L
  - 甲苯：0.1mg/L
  - 二甲苯：0.4mg/L
  - 苯胺类：1.0mg/L
  - 硝基苯类：2.0mg/L
  - 总铬：0.5mg/L（车间排放口）
  - 六价铬：0.5mg/L（车间排放口）
  - 总镉：0.1mg/L（车间排放口）
  - 总铅：0.5mg/L（车间排放口）

**《合成树脂工业水污染物排放标准》（GB 31572-2015）**
- 适用：部分专用化学品制造（如合成型专用化学品）
- 关键限值：参照标准具体内容

**《染料工业水污染物排放标准》（GB 4287-2012）**

  - COD：50mg/L
  - 氨氮：5mg/L
  - 总磷：0.5mg/L
  - 总氮：10mg/L
  - 色度：20倍

**浙江省**：《化学工业水污染物排放标准》（DB33/2015-2016）
- 特别排放限值：
  - COD：50mg/L
  - 氨氮：5mg/L

**广东省**：《水污染物排放限值》（DB44/26-2001）
- 第二时段限值：
  - COD：90mg/L（一级）
  - 氨氮：10mg/L

**山东省**：《流域水污染物综合排放标准》（DB37/3416-2018）

  - COD：50mg/L

## 四、常见错误TOP 10

### 错误1：特征因子严重遗漏
**问题描述**: 未填报所有特征污染物，特别是苯胺类、硝基苯类、重金属等。

**典型案例**: 
- 某染料制造企业未填报"苯胺类"、"硝基苯类"
- 某颜料制造企业未填报"总铅"、"总铬"

**正确做法**:
1. 对照原料MSDS，列出所有原料中的有害成分
2. 对照产品成分，列出所有特征污染物
3. 对照适用排放标准，核对所有限值涉及的污染物
4. 重点填报苯胺类、硝基苯类、重金属等特征因子

### 错误2：监测频次不满足规范要求
**问题描述**: 特征污染物监测频次不足。

**正确做法**:
1. 按技术规范确定监测频次
2. 重点管理+主要排放口：特征污染物每月至少1次
3. 色度：每周至少1次（染料、颜料制造）
4. 重金属：每月至少1次（如涉及）

### 错误3：排放标准引用错误
**问题描述**: 未执行专项排放标准（如GB 4287-2012）。

**正确做法**:
1. 染料、颜料制造必须执行GB 4287-2012
2. 优先执行地方标准（如有，且严于国家标准）
3. 标准更新后及时更新许可证载明标准

### 错误4：排放口信息不完整
**问题描述**: 排放口信息描述不完整或与实际不符。

**正确做法**:
1. 使用GPS定位仪现场测定排放口坐标
2. 核实现场实际情况与申报材料一致性
3. 上传排放口照片

### 错误5：总量指标核算方法错误
**问题描述**: 总量指标核算方法不符合技术规范。

**正确做法**:
1. 按产污系数法、物料衡算法、实际监测法核算
2. 优先使用实际监测数据核算

### 错误6：无组织排放控制措施缺失
**问题描述**: 未填报无组织排放源或未制定控制措施。

**正确做法**:
1. 识别所有无组织排放源
2. 制定无组织排放控制措施
3. 制定LDAR方案（如涉及VOCs）

### 错误7：自动监测设备安装要求不明确
**问题描述**: 未明确自动监测设备安装要求。

**正确做法**:
1. 按技术规范明确自动监测设备安装要求
2. 明确安装时限、调试期、验收、联网要求

### 错误8：环境管理台账记录要求不明确
**问题描述**: 台账记录要求不明确。

**正确做法**:
1. 按HJ 944-2018明确台账记录要求
2. 明确记录内容、频次、保存期限

### 错误9：执行报告填报要求不明确
**问题描述**: 执行报告填报要求不明确。

**正确做法**:
1. 明确执行报告类型、提交时限、填报内容
2. 提供执行报告填报模板

### 错误10：重金属污染物控制要求缺失
**问题描述**: 涉及重金属污染物的企业未制定重金属污染物削减方案。

**正确做法**:
1. 识别重金属污染物
2. 制定重金属污染物削减方案
3. 设置重金属污染物在线监测设备（如适用）
4. 定期开展土壤污染状况调查

## 六、多工序企业标准适用指南

### 6.1 多工序企业定义
**典型情形**:
- 专用化学品制造企业同时从事基础化学原料制造
- 专用化学品制造企业同时从事合成材料制造
- 专用化学品制造企业同时从事危险化学品生产

### 6.2 标准适用原则
1. **一厂一证**: 同一个排污单位，核发一个排污许可证
2. **分类管理**: 按主要生产工序的管理类别确定整体管理类别
3. **标准分别适用**: 不同工序分别适用对应的技术规范和排放标准
4. **从严要求**: 当多个标准对同一污染物有不同要求时，取最严值

### 6.3 不同工序标准适用指南

#### 6.3.1 专用化学品制造 + 基础化学原料制造
**技术规范适用**:
- 专用化学品制造工序：适用对应技术规范
- 基础化学原料制造工序：适用HJ 853-2017

**排放标准适用**:
- 分别适用对应行业标准

#### 6.3.2 专用化学品制造 + 合成材料制造
**技术规范适用**:
- 分别适用对应技术规范

**排放标准适用**:
- 分别适用对应行业标准
- 如执行同一排放标准，统一执行并取严值

#### 6.3.3 专用化学品制造 + 危险化学品生产
**技术规范适用**:
- 专用化学品制造工序：适用对应技术规范
- 危险化学品生产工序：适用对应技术规范

**排放标准适用**:
- 分别适用对应行业标准

**特别注意**:
- 危险化学品生产需额外关注环境风险防范
- 需制定环境应急预案

## 七、真实审批拒绝案例（3个）

### 案例1：特征因子严重遗漏（重金属），许可证被退回

**企业基本情况**:
- 企业名称：某颜料制造企业
- 行业：专用化学品制造（C2644）
- 产品：铅铬黄颜料
- 管理类别：重点管理

**拒绝原因**:
- 特征因子严重遗漏
- 未填报"总铅"、"总铬"

**整改要求**:
- 补充填报"总铅"、"总铬"
- 补充制定重金属污染物监测方案

**整改结果**:
- 许可证通过审批

### 案例2：监测频次不满足规范要求，许可证被退回

**企业基本情况**:
- 企业名称：某染料制造企业
- 行业：专用化学品制造（C2643）
- 产品：活性染料
- 管理类别：重点管理

**拒绝原因**:
- 监测频次不满足规范要求
- 色度监测频次填报为"每月1次"，实际应为"每周1次"

**整改要求**:
- 修正监测频次（色度：每周至少1次）

**整改结果**:
- 许可证通过审批

### 案例3：重金属污染物控制要求缺失，许可证被退回

**企业基本情况**:
- 企业名称：某颜料制造企业
- 行业：专用化学品制造（C2644）
- 产品：镉红颜料
- 管理类别：重点管理

**拒绝原因**:
- 重金属污染物控制要求缺失
- 未制定重金属污染物削减方案
- 未开展土壤污染隐患排查

**整改要求**:
- 制定重金属污染物削减方案
- 开展土壤污染隐患排查
- 定期开展土壤污染状况调查

**整改结果**:
- 许可证通过审批

## 十、边缘情况处理指南

### 10.1 涉及重金属的专用化学品制造
**处理方法**:
- 识别重金属污染物
- 制定重金属污染物削减方案
- 设置重金属污染物在线监测设备（如适用）
- 定期开展土壤污染状况调查
- 建立重金属污染物管理台账

### 10.2 涉及臭气污染物的专用化学品制造
**处理方法**:
- 识别臭气污染物（H₂S、NH₃、臭气浓度）
- 制定臭气污染物控制方案
- 设置臭气收集处理设施
- 定期开展臭气监测

### 10.3 涉及高盐废水的专用化学品制造
**处理方法**:
- 识别高盐废水
- 制定高盐废水处理方案
- 总盐量、氯化物、硫酸盐必须监测
- 高盐废水应优先考虑蒸发结晶等处理工艺

### 10.4 涉及危险化学品的专用化学品制造
**处理方法**:
- 识别危险化学品
- 制定环境风险防范方案
- 制定环境应急预案
- 配备环境应急物资

### 10.5 涉及环境风险的专用化学品制造
**处理方法**:
- 识别环境风险源
- 制定环境风险防范方案
- 制定环境应急预案
- 定期开展环境应急演练
