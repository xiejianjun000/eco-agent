# 医院行业排污许可技术审查深度指南

> **版本**: V1.0  
> **适用行业**: 综合医院、专科医院、卫生院、疗养院等医疗机构  
> **核心标准**: GB 18466-2005《医疗机构水污染物排放标准》  
> **技术规范**: HJ 1105-2020《排污许可证申请与核发技术规范 医疗机构》

## 一、行业特征因子核对表

### 1.1 按机构类型必填因子清单

#### 综合医院（所有科室）
| 污染因子类别 | 必填因子 | 适用排放口 | 备注 |
|------------|---------|----------|------|
| **常规污染物** | COD、BOD5、SS、氨氮、总氮、总磷、动植物油、石油类 | 废水总排口 | 所有医院必填 |
| **病原微生物** | 粪大肠菌群、肠道致病菌、肠道病毒 | 废水总排口 | GB 18466-2005要求 |
| **消毒因子** | 总余氯（采用含氯消毒工艺时） | 废水总排口 | 每日监测 |
| **重金属因子** | 汞、银、铬、镉、铅、砷 | 废水总排口 | 口腔科、检验科排水 |
| **特殊药剂因子** | 六价铬、总铬 | 废水总排口 | 病理科、检验科 |
| **放射性因子** | 总α、总β（开展放射治疗时） | 专用排放口 | 需专项评价 |

#### 专科医院补充因子
| 专科医院类型 | 补充特征因子 | 来源科室 |
|------------|------------|---------|
| 传染病医院 | 肠道致病菌、肠道病毒、结核杆菌 | 传染科、隔离病房 |
| 结核病专科医院 | 结核杆菌 | 全院的含菌废水 |
| 精神病专科医院 | 药物残留因子（锂等） | 药房、治疗室 |
| 肿瘤医院 | 总α、总β、放射性同位素 | 放疗科、核医学科 |
| 口腔医院 | 汞、银、铬 | 口腔科 |
| 妇幼保健院 | 总余氯（婴儿洗涤水） | 产科、婴儿洗浴 |

### 1.2 特别注意事项

#### 重金属因子（汞、银）识别要点
1. **汞的来源**：
   - 口腔科：银汞合金充填材料
   - 检验科：含汞试剂、体温计、血压计
   - 病理科：固定液、染色剂
   
2. **银的来源**：
   - 医学影像科：传统胶片冲洗液
   - 检验科：某些免疫检测试剂
   
3. **审查要点**：
   - 500张床位以上医院必须填报汞、银
   - 有口腔科的专科医院必须填报汞、银
   - 医学影像科使用传统胶片必须填报银

#### 消毒因子（氯）识别要点
1. **总余氯监测条件**：
   - 采用含氯消毒剂（次氯酸钠、二氧化氯等）
   - 每天监测2次（GB 18466-2005表1要求）
   
2. **不测总余氯的情形**：
   - 采用臭氧消毒
   - 采用紫外线消毒
   - 采用膜过滤消毒
   
3. **审查要点**：
   - 许可证需注明消毒工艺类型
   - 含氯消毒工艺必须载明总余氯限值（0.5mg/L）

#### 药剂因子识别要点
1. **六价铬/总铬来源**：
   - 病理科：组织固定液（含铬酸盐）
   - 检验科：某些生化试剂
   
2. **审查要点**：
   - 有病理科的医院必须填报六价铬、总铬
   - 参考限值：六价铬≤0.05mg/L（GB 18466-2005表1）

## 二、监测频次决策树

### 2.1 废水排放口监测频次

```
开始
 │
 ├─ 废水总排口（综合/传染病/结核病医院）
 │   │
 │   ├─ 采用含氯消毒工艺
 │   │   └─ 总余氯：每日2次（GB 18466-2005表1）
 │   │
 │   ├─ COD、BOD5、SS、氨氮、动植物油
 │   │   ├─ 20张床位及以上：每月1次
 │   │   └─ 20张床位以下：每季度1次
 │   │
 │   ├─ 粪大肠菌群
 │   │   ├─ 综合/传染病/结核病医院：每周1次
 │   │   └─ 其他医疗机构：每月1次
 │   │
 │   ├─ 肠道致病菌/肠道病毒/结核杆菌
 │   │   └─ 传染病/结核病医院：每月1次
 │   │
 │   └─ 重金属（汞、银、铬等）
 │       └─ 有相关科室时：每季度1次
 │
 └─ 生活污水排放口（预处理后排入市政管网）
     └─ COD、氨氮：每月1次（参照HJ 819-2017）
```

### 2.2 废气排放口监测频次

| 排放口类型 | 监测因子 | 监测频次 | 依据 |
|----------|---------|---------|------|
| 锅炉废气 | SO2、NOx、颗粒物、烟气黑度 | 季度（有自动监测除外） | GB 18483-2001 |
| 污水处理站恶臭 | 氨、硫化氢、臭气浓度 | 每半年1次 | GB 14554-93 |
| 医疗废物贮存间 | 氨、硫化氢 | 每年1次 | 地方要求 |

### 2.3 决策树关键节点说明

1. **床位数的判定**：
   - 以《医疗机构执业许可证》核准的床位数为准
   - 包含正式床位和观察床位
   
2. **监测频次的调整**：
   - 排放不稳定时，加密监测
   - 地方有更严要求的，从其规定

### 3.3 标准适用常见错误

1. **错误**：所有医院都执行排放标准（严格限值）  
   **正确**：排入城镇污水处理厂的，可执行预处理标准

2. **错误**：总余氯限值为接触池出口瞬时值  
   **正确**：总余氯为接触30分钟后的测定值

3. **错误**：粪大肠菌群按月监测  
   **正确**：综合/传染病/结核病医院应每周监测

## 四、常见错误TOP 10

### 错误1：重金属因子遗漏
- **表现**：有口腔科但未填报汞、银；有病理科但未填报六价铬
- **后果**：许可证质量不合格，需重新填报
- **审查要点**：查科室设置，核对特征因子

### 错误2：总余氯监测频次错误
- **表现**：填报为每月1次或每季度1次
- **正确要求**：采用含氯消毒工艺的，每日监测2次
- **依据**：GB 18466-2005表1 footnote

### 错误3：粪大肠菌群监测频次不足
- **表现**：综合/传染病/结核病医院填报为每月1次
- **正确要求**：每周1次
- **依据**：GB 18466-2005表1

### 错误4：排放标准选择错误
- **表现**：直接排放但执行预处理标准
- **正确**：直接排入水体执行排放标准（严格限值）
- **审查**：查清排水去向（排水许可证）

### 错误5：消毒工艺与因子不匹配
- **表现**：采用紫外线消毒但填报了总余氯
- **正确**：只有含氯消毒工艺才需监测总余氯
- **审查**：核对污染治理设施填报内容

### 错误6：床位数量填报错误
- **表现**：填报床位数与实际不符，影响管理类别判定
- **后果**：管理类别判定错误，许可证效力问题
- **审查**：核对《医疗机构执业许可证》

### 错误7： infectious废水未单独处理
- **表现**：传染病区废水未单独消毒处理
- **要求**：传染病区应单独收集、单独消毒
- **依据**：GB 18466-2005第4.1.3条

### 错误8：监测方案未覆盖所有排放口
- **表现**：只填报了废水总排口，遗漏了生活污水口、锅炉废气口
- **要求**：所有许可排放口都应有监测方案
- **审查**：对照排放口信息逐一核对

### 错误9：医疗废物焚烧炉标准适用错误
- **表现**：执行了错误的大气排放标准
- **正确**：执行GB 18485-2014《生活垃圾焚烧污染控制标准》（医疗废物专用焚烧炉执行GB 19218-2012）
- **注意**：医废焚烧有专门标准

### 错误10：总量指标核算方法错误
- **表现**：废水排放量×浓度限值，而非实际排放量×实际浓度
- **正确**：按实际监测数据核算，无监测数据的按产排污系数法
- **依据**：HJ 1105-2020附录B

## 六、多工序企业标准适用指南

### 6.1 典型多工序场景

#### 场景1：医院同时有生活污水、医疗废物焚烧、洗衣房废水

**问题**：不同工序的废水可以合并排放吗？执行什么标准？

**分析**：
1. **生活污水的性质**：
   - 来自办公楼、食堂、宿舍等非医疗区域
   - 污染物浓度较低，主要是COD、氨氮、SS
   
2. **洗衣房废水的性质**：
   - 来自被服洗涤
   - 含有洗涤剂、悬浮物，可能含有病菌
   
3. **医疗废物焚烧炉废水的性质**：
   - 来自焚烧炉冷却系统、烟气净化系统
   - 含有重金属、酸性物质
   
4. **排放标准适用原则**：
   - **原则1**：不同性质的废水应分类收集、分别处理
   - **原则2**：确需合并排放的，执行最严标准
   - **原则3**：有关规定允许混合，且不对监测造成干扰的，可合并排放

**具体适用**：
- 生活污水经化粪池预处理后，可排入医疗废水处理站合并处理
- 洗衣房废水应消毒处理后排放（含病菌）
- 医废焚烧废水应经专用设施处理后排放（含重金属）
- 若合并排放，执行GB 18466-2005（最严标准）

### 6.2 标准适用决策树

```
开始
 │
 ├─ 废水是否可以分类收集？
 │   │
 │   ├─ 可以分类 → 分别处理，分别执行标准
 │   │   ├─ 生活污水：执行GB 8978-1996（排入污水处理厂）
 │   │   ├─ 医疗废水：执行GB 18466-2005
 │   │   └─ 焚烧废水：执行GB 18485-2014相关标准
 │   │
 │   └─ 无法分类（合并排放）
 │       └─ 执行最严标准（GB 18466-2005）
 │
 └─ 废气排放
     ├─ 锅炉废气：执行GB 13271-2014
     ├─ 焚烧废气：执行GB 18485-2014
     └─ 污水处理站恶臭：执行GB 14554-93
```

### 6.3 审查要点

1. **查水平衡**：各工序用水量、排水量是否匹配
2. **查排放口设置**：是否按工序分别设置排放口
3. **查监测方案**：是否对所有排放口都制定了监测方案
4. **查标准适用**：合并排放的，是否执行了最严标准

## 七、真实审批拒绝案例

### 案例1：重金属因子遗漏（江苏省南京市）

**企业信息**：
- 名称：南京市某口腔专科医院
- 床位数：80张
- 科室设置：口腔科、内科、外科、检验科

**拒绝原因**：
- 许可证申请材料中未填报汞、银等重金属因子
- 口腔科使用银汞合金，废水中含汞、银
- 检验科使用含汞试剂

**审查发现**：
- 特征因子遗漏2项（汞、银）
- 监测方案不完整

**整改要求**：
- 补充填报汞、银等重金属因子
- 补充重金属监测方案（每季度1次）
- 重新提交申请材料

**处理结果**：补正后通过审批。

### 案例2：总余氯监测频次错误（浙江省杭州市）

**企业信息**：
- 名称：杭州市某综合医院
- 床位数：500张
- 消毒工艺：次氯酸钠消毒

**拒绝原因**：
- 自行监测方案中总余氯监测频次填报为"每月1次"
- GB 18466-2005要求总余氯每日监测2次

**审查发现**：
- 监测频次不满足标准要求
- 可能导致消毒效果无法保证

**整改要求**：
- 修改监测方案，总余氯监测频次改为"每日2次"
- 提供消毒接触池设计参数（确保接触时间≥30分钟）

**处理结果**：修改后通过审批。

### 案例3：排放标准适用错误（广东省广州市）

**企业信息**：
- 名称：广州市某肿瘤医院
- 床位数：300张
- 排水去向：直接排入珠江

**拒绝原因**：
- 许可证中执行了预处理标准（COD≤250mg/L）
- 实际为直接排放，应执行排放标准（COD≤60mg/L）

**审查发现**：
- 排水去向填报错误
- 排放标准适用错误

**整改要求**：
- 查清排水去向（查阅排水许可证）
- 修改为直接排放，执行GB 18466-2005排放标准
- 重新核算许可排放量

**处理结果**：修改后通过审批。

## 十、边缘情况处理指南

### 10.1 边缘情况1：医院床位数在临界点

**情形**：床位数刚好19张或20张

**影响**：
- 19张床位：可能为登记管理
- 20张床位：重点或简化管理

**处理原则**：
- 以《医疗机构执业许可证》核准的床位数为准
- 包含正式床位和观察床位
- 不计入临时加床

**审查要点**：
- 核对执业许可证
- 现场核查实际床位数

### 10.2 边缘情况2：医院内设养老院

**情形**：医院内设有养老院，废水合并排放

**问题**：养老院的废水是否执行GB 18466-2005？

**处理原则**：
- 养老院废水如含有医疗废水，应执行GB 18466-2005
- 如养老院独立设置、废水独立收集，可执行生活污水标准

**审查要点**：
- 查清废水是否混合
- 混合的执行最严标准

### 10.3 边缘情况3：医院部分科室外包

**情形**：检验科、病理科外包给第三方

**问题**：外包科室的污染物是否纳入许可证管理？

**处理原则**：
- 外包科室仍在医院内部的，应纳入
- 污染物由医院总排口排放的，应纳入

**审查要点**：
- 查清外包合同的权责划分
- 查清废水排放路径

### 10.4 边缘情况4：医院迁建过渡期

**情形**：医院正在迁建，旧院仍在运行

**问题**：许可证如何管理？

**处理原则**：
- 旧院：原许可证继续有效，直至关闭
- 新院：需重新申请排污许可证
- 过渡期：两个许可证同时有效

**审查要点**：
- 查清迁建进度
- 查清旧院关闭时间

### 10.5 边缘情况5：传染病医院同时接收非传染病患者

**情形**：传染病医院也设有普通门诊

**问题**：是否全部废水都按传染病医院要求管理？

**处理原则**：
- 全部废水按传染病医院要求管理（最严标准）
- 不必区分传染病区和非传染病区

**审查要点**：
- 查清废水是否合并处理
- 合并的执行最严标准

### 10.6 边缘情况6：医院使用电子胶片（无银污染源）

**情形**：医学影像科使用数字影像，无传统胶片冲洗

**问题**：是否还需填报银因子？

**处理原则**：
- 无传统胶片冲洗的，可不填报银因子
- 需在许可证中注明"不使用传统胶片"

**审查要点**：
- 现场核查医学影像科
- 查清是否还有传统胶片
