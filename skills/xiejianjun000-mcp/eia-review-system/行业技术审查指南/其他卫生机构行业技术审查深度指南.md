# 其他卫生机构行业排污许可技术审查深度指南

> **版本**: V1.0  
> **适用行业**: 疗养院、康复中心、精神病专科医院、专科疾病防治院（非公共卫生类）、医学检验实验室、病理诊断中心、医学影像诊断中心等  
> **核心标准**: GB 18466-2005《医疗机构水污染物排放标准》  
> **技术规范**: HJ 1105-2020《排污许可证申请与核发技术规范 医疗机构》

---

## 一、行业特征因子核对表

### 1.1 其他卫生机构类型

"其他卫生机构"是指不属于医院、社区卫生服务中心、专业公共卫生机构的医疗卫生机构，包括：
1. **疗养院**：提供康复、疗养服务
2. **康复中心**：提供康复治疗服务
3. **精神病专科医院**：专门收治精神病患者
4. **医学检验实验室**：提供医学检验服务（独立法人）
5. **病理诊断中心**：提供病理诊断服务（独立法人）
6. **医学影像诊断中心**：提供医学影像诊断服务（独立法人）
7. **血液透析中心**：提供血液透析服务（独立法人）
8. **护理院**：提供长期护理服务

### 1.2 按机构类型必填因子清单

#### 疗养院、康复中心

| 污染因子类别 | 必填因子 | 适用排放口 | 备注 |
|------------|---------|----------|------|
| **常规污染物** | COD、BOD5、SS、氨氮 | 废水总排口 | 生活污水为主 |
| **病原微生物** | 粪大肠菌群 | 废水总排口 | 如有医疗活动 |
| **消毒因子** | 总余氯（采用含氯消毒时） | 废水总排口 | 每日监测 |

**说明**：
- 疗养院、康复中心主要提供康复服务，医疗活动较少
- 废水主要为生活污水，可能含有少量医疗废水
- 如有消毒工艺，需监测总余氯

#### 精神病专科医院

| 污染因子类别 | 必填因子 | 适用排放口 | 备注 |
|------------|---------|----------|------|
| **常规污染物** | COD、BOD5、SS、氨氮、总磷 | 废水总排口 | 所有因子 |
| **病原微生物** | 粪大肠菌群 | 废水总排口 | 每月1次 |
| **特殊药剂因子** | 药物残留因子（锂、丙戊酸钠等） | 废水总排口 | 精神科药物治疗 |
| **消毒因子** | 总余氯（采用含氯消毒时） | 废水总排口 | 每日监测 |

**说明**：
- 精神病专科医院患者长期服用精神类药物，尿液中含有药物残留
- 药物残留因子一般为非常规因子，需根据具体情况确定

#### 医学检验实验室、病理诊断中心

| 污染因子类别 | 必填因子 | 适用排放口 | 备注 |
|------------|---------|----------|------|
| **常规污染物** | COD、SS、氨氮、pH | 废水总排口 | 实验废水 |
| **实验废水因子** | 重金属（汞、银、铬等）、有机溶剂 | 实验废水专用口 | 检验/病理实验 |
| **病原微生物** | 粪大肠菌群 | 废水总排口 | 如有病原检测 |
| **消毒因子** | 总余氯（采用含氯消毒时） | 废水总排口 | 每日监测 |

**说明**：
- 医学检验实验室、病理诊断中心主要产生实验废水
- 实验废水含重金属、有机溶剂、病原体等
- 需单独收集、单独处理实验废水

#### 血液透析中心

| 污染因子类别 | 必填因子 | 适用排放口 | 备注 |
|------------|---------|----------|------|
| **常规污染物** | COD、SS、氨氮 | 废水总排口 | 透析废水+生活污水 |
| **特殊因子** | 透析废液成分（尿素、肌酐等） | 透析废水专用口 | 透析废液 |
| **消毒因子** | 总余氯（采用含氯消毒时） | 废水总排口 | 每日监测 |

**说明**：
- 血液透析中心主要产生透析废液
- 透析废液含尿素、肌酐、多余药物等
- 需单独收集、单独处理透析废液

### 1.3 特别注意事项

#### 独立法人医疗机构的特点

1. **与医院内设科室的区别**：
   - 独立法人：单独申请排污许可证
   - 医院内设：纳入医院排污许可证管理
   
2. **审查要点**：
   - 查清是否为独立法人
   - 独立法人的，需单独申请排污许可证

#### 药物残留因子的识别

1. **精神科常用药物**：
   - 锂盐（碳酸锂）：治疗 bipolar disorder
   - 丙戊酸钠：抗癫痫、稳定情绪
   - 舍曲林：抗抑郁
   
2. **审查要点**：
   - 精神病专科医院需填报药物残留因子
   - 具体因子根据常用药物确定

## 二、监测频次决策树

### 2.1 废水排放口监测频次

```
开始
 │
 ├─ 疗养院、康复中心（无医疗活动或医疗活动较少）
 │   │
 │   ├─ 采用含氯消毒工艺
 │   │   └─ 总余氯：每日2次
 │   │
 │   ├─ COD、SS、氨氮
 │   │   └─ 每季度1次（规模小）
 │   │
 │   └─ 粪大肠菌群
 │       └─ 每月1次（如有医疗活动）
 │
 ├─ 精神病专科医院
 │   │
 │   ├─ 采用含氯消毒工艺
 │   │   └─ 总余氯：每日2次
 │   │
 │   ├─ COD、BOD5、SS、氨氮
 │   │   └─ 每月1次
 │   │
 │   ├─ 粪大肠菌群
 │   │   └─ 每月1次
 │   │
 │   └─ 药物残留因子
 │       └─ 每季度1次（非常规因子）
 │
 ├─ 医学检验实验室、病理诊断中心
 │   │
 │   ├─ 实验废水专用排放口
 │   │   ├─ pH、COD：每月1次
 │   │   └─ 重金属：每季度1次
 │   │
 │   └─ 废水总排口
 │       ├─ 总余氯：每日2次（含氯消毒时）
 │       └─ 粪大肠菌群：每月1次
 │
 └─ 血液透析中心
     │
     ├─ 透析废水专用排放口
     │   └─ COD、氨氮：每月1次
     │
     └─ 废水总排口
         ├─ 总余氯：每日2次
         └─ 粪大肠菌群：每月1次
```

### 2.2 监测频次特殊说明

1. **药物残留因子**：属于非常规因子，监测频次可酌情降低（每季度1次或每半年1次）
2. **实验废水因子**：根据实验频次确定，实验频次高的，加密监测
3. **透析废液**：透析废液产生量相对固定，可每月监测1次

## 三、排放标准适用指南

### 3.1 核心标准：GB 18466-2005

其他卫生机构一般执行GB 18466-2005表2（其他医疗机构），但需注意：

1. **疗养院、康复中心**：执行表2（预处理标准）
2. **精神病专科医院**：如有传染病区，执行表1；否则执行表2
3. **医学检验实验室**：执行表2（实验废水按医疗机构管理）
4. **血液透析中心**：执行表2

### 3.2 其他适用标准

| 标准号 | 标准名称 | 适用情形 |
|-------|---------|---------|
| GB 8978-1996 | 污水综合排放标准 | 无医疗废水时（纯生活污水） |
| HJ 91.1-2019 | 污水监测技术规范 | 监测技术要求 |

### 3.3 标准适用常见错误

1. **错误**：疗养院执行GB 18466-2005表1  
   **正确**：疗养院主要为生活污水，可执行GB 8978-1996或GB 18466-2005表2

2. **错误**：医学检验实验室未执行任何标准  
   **正确**：医学检验实验室产生实验废水，需执行GB 18466-2005

## 四、常见错误TOP 10

### 错误1：独立法人医疗机构未单独申请许可证

- **表现**：医学检验实验室未单独申请排污许可证，误认为应纳入上级医院管理
- **正确**：独立法人医疗机构应单独申请排污许可证
- **审查要点**：查清是否为独立法人

### 错误2：药物残留因子遗漏

- **表现**：精神病专科医院未填报锂、丙戊酸钠等药物残留因子
- **后果**：特征因子遗漏，许可证质量不合格
- **审查要点**：查清是否收治精神病患者，是否使用精神类药物

### 错误3：实验废水未单独管理

- **表现**：医学检验实验室的实验废水与生活污水合并排放
- **后果**：实验废水中的重金属、有机溶剂可能污染环境
- **审查要点**：查清是否设置了实验废水专用收集系统

### 错误4：监测频次不满足标准要求

- **表现**：总余氯填报为每月1次
- **正确**：采用含氯消毒工艺的，每日监测2次
- **依据**：GB 18466-2005表1/表2

### 错误5：排放标准适用错误

- **表现**：全部执行表1（严格限值）
- **正确**：其他卫生机构一般执行表2（预处理标准）
- **审查**：查清机构类型和排水去向

### 错误6：消毒工艺与因子不匹配

- **表现**：采用紫外线消毒但填报了总余氯
- **正确**：只有含氯消毒工艺才需监测总余氯
- **审查**：核对污染治理设施填报内容

### 错误7：透析废液未单独收集

- **表现**：透析废液与生活污水合并排放
- **要求**：透析废液应单独收集、单独处理
- **审查要点**：查清是否设置了透析废液专用收集系统

### 错误8：医疗机构执业许可证未提供

- **表现**：未提供《医疗机构执业许可证》
- **后果**：无法证明医疗机构合法性
- **要求**：必须提供《医疗机构执业许可证》

### 错误9：环境管理台账要求过高

- **表现**：要求保存5年台账（规模小的机构难以做到）
- **正确**：可适当简化台账要求
- **依据**：HJ 944-2018关于简化管理的规定

### 错误10：总量指标核算方法错误

- **表现**：废水排放量×浓度限值
- **正确**：按实际监测数据核算
- **依据**：HJ 1105-2020附录B

## 六、多工序企业标准适用指南

### 6.1 典型多工序场景

#### 场景1：医学检验实验室同时开展临床检验和病理诊断

**问题**：临床检验废水和病理诊断废水可以合并处理吗？

**分析**：
1. **临床检验废水**：含血液、体液、化学试剂
2. **病理诊断废水**：含组织固定液（甲醛、乙醇）、染色剂

**处理原则**：
- 两类废水都含有化学物质和病原体
- 可合并处理，但需先中和病理诊断废水中的甲醛
- 合并后执行GB 18466-2005

**具体适用**：
- 病理诊断废水：先经专门处理（甲醛分解）+ 消毒
- 临床检验废水：消毒处理
- 合并后执行GB 18466-2005表2

### 6.2 标准适用决策树

```
开始
 │
 ├─ 废水性质是否相同？
 │   │
 │   ├─ 相同 → 可合并处理，执行同一标准
 │   │
 │   └─ 不同 → 分别处理，分别执行标准；或合并后执行最严标准
 │
 └─ 排放去向是否相同？
     │
     └─ 不同 → 分别执行标准（排入城镇污水处理厂 vs 直接排放）
```

### 6.3 审查要点

1. **查清各工序废水性质**：是否含有特殊污染物
2. **查清废水是否混合**：混合的执行最严标准
3. **查清排放去向**：决定执行预处理标准还是排放标准

## 七、真实审批拒绝案例

### 案例1：独立法人医疗机构未单独申请许可证（江苏省南京市）

**企业信息**：
- 名称：南京市某医学检验实验室
- 法人性质：独立法人
- 上级单位：某综合医院

**拒绝原因**：
- 未单独申请排污许可证，误认为应纳入上级医院管理
- 实际应为独立排污单位

**审查发现**：
- 该医学检验实验室为独立法人
- 应单独申请排污许可证

**整改要求**：
- 单独申请排污许可证
- 补充提交独立的申请材料

**处理结果**：单独申请后通过审批。

### 案例2：药物残留因子遗漏（浙江省杭州市）

**企业信息**：
- 名称：杭州市某精神病专科医院
- 床位数：200张
- 常用药物：锂盐、丙戊酸钠

**拒绝原因**：
- 未填报锂、丙戊酸钠等药物残留因子
- 特征因子遗漏

**审查发现**：
- 该院主要收治精神病患者，长期使用精神类药物
- 尿液中含有药物残留，废水中应监测药物残留因子

**整改要求**：
- 补充填报药物残留因子（锂、丙戊酸钠等）
- 补充药物残留因子监测方案

**处理结果**：补正后通过审批。

### 案例3：实验废水未单独管理（广东省广州市）

**企业信息**：
- 名称：广州市某病理诊断中心
- 实验类型：组织病理、细胞病理

**拒绝原因**：
- 实验废水未单独收集、单独处理
- 与生活污水合并排放

**审查发现**：
- 病理诊断中心使用甲醛、乙醇等固定液
- 实验废水含化学物质，需单独处理

**整改要求**：
- 设置实验废水专用收集系统
- 设置实验废水预处理设施（甲醛分解装置）
- 补充填报实验废水专用排放口

**处理结果**：整改后通过审批。

## 十、边缘情况处理指南

### 10.1 边缘情况1：医学检验实验室同时挂"体检中心"牌子

**情形**：一套人马、两块牌子，既有医学检验又有健康体检

**问题**：按哪个标准执行？

**处理原则**：
- 按主要业务判定
- 如主要为医学检验，执行GB 18466-2005
- 如主要为健康体检，可执行GB 8978-1996（生活污水）

**审查要点**：
- 查清主要业务
- 按主要业务适用标准

### 10.2 边缘情况2：疗养院转为医疗机构

**情形**：疗养院取得《医疗机构执业许可证》，开展医疗活动

**问题**：是否需重新申请排污许可证？

**处理原则**：
- 取得《医疗机构执业许可证》后，功能转变
- 需重新申请排污许可证，按医疗机构管理

**审查要点**：
- 查清是否取得《医疗机构执业许可证》
- 取得的需重新申请许可证

### 10.3 边缘情况3：精神病专科医院不设住院床位

**情形**：精神病专科医院只有门诊，无住院床位

**问题**：是否需执行GB 18466-2005？

**处理原则**：
- 有门诊医疗活动，产生医疗废水
- 需执行GB 18466-2005

**审查要点**：
- 查清是否产生医疗废水
- 产生的需纳入管理

### 10.4 边缘情况4：血液透析中心转为肾病医院

**情形**：血液透析中心扩大规模，取得《医疗机构执业许可证》

**问题**：许可证如何管理？

**处理原则**：
- 功能转变后，需重新申请排污许可证
- 按肾病医院要求管理

**审查要点**：
- 查清机构转型情况
- 重新申请许可证

### 10.5 边缘情况5：独立法人医疗机构被兼并

**情形**：医学检验实验室被综合医院兼并，变为非独立法人

**问题**：许可证如何管理？

**处理原则**：
- 兼并后，原许可证注销
- 纳入综合医院排污许可证管理

**审查要点**：
- 查清兼并情况
- 原许可证需注销
