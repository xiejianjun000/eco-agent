## 前言

纺织印染行业是排污许可技术审查中**污染类型最复杂、特征因子最容易遗漏**的高风险行业之一。

该行业横跨"前处理—染色—印花—后整理"四大工艺链条，排放废水、废气（定型废气、印花废气、锅炉烟气）、固废（污泥），特征因子涵盖常规污染物、色度、苯胺类化合物、VOCs、重金属（部分染料含有六价铬、铅等）、AOX（使用含氯漂白剂时）等。

根据2024年全国纺织印染行业排污许可证技术审查质量统计：
- **申请退回率：38.7%**（全国各行业排名第4）
- **最高发问题：特征因子遗漏（占退回案件的51%）**
- **常见错误：色度因子填错、苯胺类化合物遗漏、VOCs监测频次不足、定型废气疏漏**
- **审查平均耗时：6.5个工作日**

本指南基于HJ 861-2017、HJ 879-2017、GB 4287-2012等核心技术文件，系统梳理纺织印染行业技术审查的完整方法论，帮助审查人员将审批通过率提升至95%以上。

## 第一章 纺织印染工艺全流程特征因子核对表

### 核心原则

**"有什么工艺，填什么因子；染料用什么，特征因子就有什么。"**

纺织印染行业的特征因子受原料（棉、麻、化纤、混纺）、工艺（前处理方式、染料类型、整理剂类型）影响极大，审查时必须逐条核对。

### 1.1 前处理工序（退浆/煮练/漂白/丝光）

#### 1.1.1 退浆工序

| 特征因子 | 产生来源 | 排放去向 | 审查要点 |
|---------|---------|---------|---------|
| CODcr | 淀粉浆料、PVA退浆剂降解产物 | 废水 | 必填，退浆废水COD浓度高（2000-5000mg/L） |
| BOD5 | 淀粉、纤维素降解产物 | 废水 | 必填 |
| SS | 纤维屑、浆料残渣 | 废水 | 必填 |
| pH | 烧碱（强碱退浆）、酸中和 | 废水 | 必填 |
| 总磷 | 含磷浆料或退浆助剂 | 废水 | 使用含磷浆料时必填 |
| 苯系物 | 部分化学浆料降解产物 | 废水 | 使用苯类溶剂时必填 |

#### 1.1.2 煮练工序

| 特征因子 | 产生来源 | 排放去向 | 审查要点 |
|---------|---------|---------|---------|
| CODcr | 棉籽壳、果胶、油脂的碱性水解产物 | 废水 | 必填 |
| BOD5 | 有机物生物降解产物 | 废水 | 必填 |
| SS | 纤维屑、煮练残渣 | 废水 | 必填 |
| pH | 烧碱（强碱煮练） | 废水 | 必填 |
| 氨氮 | 含氮助剂降解 | 废水 | 煮练液含尿素等含氮助剂时必填 |
| 阴离子表面活性剂 | 煮练剂、渗透剂 | 废水 | 使用表面活性剂时必填 |

#### 1.1.3 漂白工序（按漂白剂类型区分）

| 漂白剂类型 | 特征因子 | 审查要点 |
|---------|---------|---------|
| **次氯酸钠漂白** | pH、CODcr、氨氮、总余氯 | 氨氮和总余氯是易漏项 |
| **双氧水漂白** | pH、CODcr、氨氮 | 相对简单，无AOX问题 |
| **亚氯酸钠漂白** | pH、CODcr、氨氮、**二氧化氯**、**AOX** | AOX是审查重点！亚漂产生大量AOX |
| **含氧漂白（低温漂白）** | pH、CODcr | 无AOX问题 |

**审查红线**：使用亚氯酸钠（亚漂）工艺的企业，AOX必须填入许可证！这是最容易遗漏的特征因子之一。

#### 1.1.4 丝光工序

| 特征因子 | 产生来源 | 排放去向 | 审查要点 |
|---------|---------|---------|---------|
| pH | 浓烧碱（18-25%NaOH） | 废水 | 必填，丝光废水pH极高（pH>12） |
| CODcr | 纤维降解产物 | 废水 | 必填 |
| 烧碱（NaOH） | 碱回收不完全 | 废水 | 丝光淡碱回用量需在申请材料中说明 |
| SS | 纤维屑 | 废水 | 必填 |

### 1.2 染色工序（核心特征因子集中区）

**这是纺织印染行业特征因子最密集、最容易出错的环节。**

#### 1.2.1 染料类型与对应特征因子对照表

| 染料大类 | 常用品种 | 特征因子 | 排放去向 | 审查要点 |
|---------|---------|---------|---------|---------|
| **直接染料** | 直接铜盐染料 | 铜（Cu）、色度 | 废水 | 铜盐染料含铜，直接铜盐染料需填铜 |
| **活性染料** | 国产活性染料（K型、R型） | 色度、苯胺类 | 废水 | 水解活性染料产生苯胺类 |
| **还原染料** | 靛蓝、硫靛 | 色度、硫化物 | 废水 | 硫化染料需填硫化物 |
| **硫化染料** | 硫化黑、硫化蓝 | 色度、硫化物、pH | 废水 | **硫化染料废气还产生硫化氢** |
| **分散染料** | 涤纶用分散染料 | 色度、**VOCs** | 废水+废气 | 分散染料高温染色产生VOCs |
| **酸性染料** | 锦纶用酸性染料 | 色度、**六价铬**（部分含铬品种） | 废水 | 含铬酸性染料需填六价铬 |
| **阳离子染料** | 腈纶用阳离子染料 | 色度 | 废水 | 较简单 |
| **涂料染色** | 颜料+黏合剂 | 色度、CODcr | 废水 | 黏合剂增加COD |
| **金属络合染料** | 含铬/钴/铜金属 | 铬、钴、铜、色度 | 废水 | **金属络合染料特征因子最复杂** |

#### 1.2.2 助剂类特征因子

| 助剂类型 | 代表品种 | 特征因子 | 审查要点 |
|---------|---------|---------|---------|
| 匀染剂 | 阳离子/非离子型 | CODcr、色度 | 必填 |
| 固色剂 | 固色剂Y、固色剂M | **甲醛**（固色剂M含甲醛） | 使用固色剂M时甲醛必填 |
| 柔软剂 | 硅油柔软剂、软片 | **VOCs**、CODcr | 硅油类柔软剂含VOCs |
| 催化剂 | 硫酸铵、醋酸 | pH、氨氮（硫酸铵） | 使用铵盐催化剂时填氨氮 |
| 皂洗剂 | 表面活性剂 | CODcr、色度 | 必填 |
| 防泳移剂 | 丙烯酸酯类 | CODcr | 必填 |

#### 1.2.3 染色工序审查核对口诀

```
染色审查八必问：
1. 用什么染料？→ 确定特征因子类型
2. 有没有金属络合染料？→ 铬/钴/铜必填
3. 有没有硫化染料？→ 硫化物+硫化氢必填
4. 有没有固色剂M？→ 甲醛必填
5. 有没有硅油柔软剂？→ VOCs必填
6. 有没有亚氯酸钠漂白？→ AOX必填
7. 色度填了没有？→ 染色特征因子，必填
8. 苯胺类填了没有？→ 活性染料水解产物，易漏
```

### 1.3 印花工序

| 印花工艺 | 特征因子 | 审查要点 |
|---------|---------|---------|
| 涂料印花 | 色度、CODcr、VOCs | 黏合剂和涂料有机颜料增加COD和VOCs |
| 活性印花 | 色度、CODcr、氨氮 | 尿素分解产生氨氮 |
| 还原印花 | 色度、CODcr、硫化物 | 雕白粉分解产物 |
| 分散印花（热转移） | 色度、VOCs、苯系物 | 热转移印花产生VOCs和苯系物 |
| 数码印花 | 色度、CODcr | 废水量小，但COD不可漏 |

### 1.4 后整理工序（定型/焙烘/防水/阻燃）

后整理工序是**废气特征因子的主要来源**，也是最容易遗漏的环节。

| 后整理工艺 | 废气特征因子 | 废水特征因子 | 审查要点 |
|---------|------------|------------|---------|
| **热定型** | **VOCs**、非甲烷总烃、苯系物 | — | 定型废气是最大VOCs来源！必须填 |
| 防水整理（碳氟化合物） | **PFOS/PFOA**相关物质、VOCs | CODcr、氟化物 | 含氟防水剂有特殊环保要求 |
| 阻燃整理 | **VOCs**、溴化物（部分阻燃剂） | CODcr | 溴系阻燃剂需填溴化物 |
| 柔软整理（硅油） | **VOCs** | CODcr | 柔软整理废气VOCs易漏 |
| 树脂整理（免烫） | **甲醛**、VOCs | — | 树脂整理废气甲醛是重点 |
| 涂层整理 | **VOCs**、非甲烷总烃 | CODcr | 涂层废气VOCs浓度高 |
| 漂白后处理（酸洗） | — | pH、CODcr | 必填 |

**审查红线**：定型废气中的VOCs和非甲烷总烃，99%的遗漏出现在"后整理工序"这个环节。审查申请材料时，必须核对后整理工序种类。

## 第二章 监测频次决策树

### 决策树使用说明

**第一步**：判断企业管理类别（重点管理/简化管理/登记管理）  
**第二步**：判断排放方式（直接排放/间接排放）  
**第三步**：判断污染物类型（废水/废气）  
**第四步**：按节点向下确定监测频次

### 2.1 废水监测频次决策树

```
【废水监测频次决策树】

第1层：管理类别判断
├─ 重点管理 → 进入第2层
├─ 简化管理 → 跳转"简化管理废水频次"
└─ 登记管理 → 仅要求填报，不设监测频次要求

第2层：排放方式判断
├─ 直接排放 → 进入第3层
└─ 间接排放 → 按GB 4287-2012间接排放标准执行，频次低于直接排放

第3层：污染物类型/监测指标
├─ 常规污染物（pH、COD、BOD5、SS）
│   └─ 重点管理+直接排放：自动监测（COD）或每周监测（其他）
├─ 氨氮
│   └─ 重点管理+直接排放：自动监测或每周1次
├─ 总氮
│   └─ 重点管理+直接排放：每月1次
├─ 总磷
│   └─ 重点管理+直接排放：每月1次
├─ 色度
│   └─ 重点管理+直接排放：每月1次（GB 4287控制指标）
├─ 特征污染物（苯胺类、六价铬、AOX、硫化物、铜等）
│   └─ 重点管理+直接排放：每月1次
└─ 阴离子表面活性剂
    └─ 重点管理：每月1次
```

## 第三章 排放标准适用指南

### 3.1 适用标准体系

纺织印染行业涉及的标准较多，必须按以下优先级适用：

**优先级1：地方排放标准**（最优先）  
→ 江苏：DB 32/ 2132-2012（比GB 4287更严格）  
→ 浙江：DB 33/ 962-2015（太湖流域纺织印染标准）  
→ 广东：DB 44/ 1208-2013  
→ 山东：DB 37/ 355-2019  

**优先级2：国家标准**（无更严地方标准时适用）  
→ GB 4287-2012《纺织染整工业水污染物排放标准》  
→ GB 8978-1996《污水综合排放标准》（预处理标准）  
→ GB 13271-2014《锅炉大气污染物排放标准》  
→ GB 16297-1996《大气污染物综合排放标准》

### 3.2 水污染物排放标准适用流程图

```
【排放标准适用决策树】

第1步：该企业所在省份是否有地方纺织印染废水排放标准？
├─ 有（江苏/浙江/广东/山东等）→ 适用地方标准（更严优先）
└─ 无 → 进入第2步

第2步：该企业是直接排放还是间接排放？
├─ 直接排放至环境 → 适用GB 4287-2012表1（直接排放标准）
└─ 间接排放至污水处理厂 → 适用GB 4287-2012表3（间接排放标准）
    （同时需满足纳管污水厂接纳标准）

第3步：适用GB 4287-2012哪一套标准？
├─ 1998年1月1日起建设的企业 → 适用表2（新建企业标准）
└─ 1998年1月1日前建设的企业 → 适用表1（现有企业标准）
    过渡期5年后执行表2标准

第4步：特征因子适用哪些标准？
├─ 色度 → GB 4287-2012
├─ 苯胺类 → GB 4287-2012或GB 8978-1996（从严）
├─ 六价铬 → GB 4287-2012
├─ AOX → GB 4287-2012（亚漂企业）
├─ 总铜 → GB 4287-2012（直接铜盐染料企业）
└─ pH值/ CODcr/ BOD5/ SS/ 氨氮/ 总磷 → GB 4287-2012
```

## 第四章 常见错误TOP 10

### 错误1：定型废气VOCs疏漏（最高频错误）

**错误描述**：企业在申请材料中遗漏定型废气的VOCs监测要求和排放口信息。

**技术依据**：HJ 861-2017第5.3条明确规定，定型废气属于有组织排放口，必须填报排放口位置、数量、排放方式，VOCs为必填特征因子。

**后果**：许可证中无定型废气排放口信息 → 证后无监测数据 → 执法检查发现企业"未监测定型废气"但许可证无要求 → 许可瑕疵争议。

**纠正方法**：
1. 现场核查是否有定型工序（拉幅定型机）
2. 填报定型废气排放口（排放口编号DAxxx）
3. 填入VOCs、非甲烷总烃作为废气特征因子
4. 确定监测频次（重点管理每月1次）

**审查核对**：
- [ ] 申请表中有定型工序描述吗？
- [ ] 定型废气排放口信息填写了吗？
- [ ] VOCs作为废气特征因子填入了吗？

---

### 错误2：亚漂企业AOX遗漏

**错误描述**：使用亚氯酸钠漂白工艺的企业，未在申请表中填报AOX（可吸附有机卤素）。

**技术依据**：GB 4287-2012将AOX列为亚漂工艺的特征因子，标准限值：直接排放8mg/L，间接排放12mg/L。HJ 861-2017附录A明确亚氯酸钠漂白须填报AOX。

**后果**：违反GB 4287-2012第5.2条，许可证未载明AOX排放限值，证后执法无标准依据，监管部门无法处罚。

**纠正方法**：
1. 确认漂白工艺是否使用亚氯酸钠（亚漂）
2. 填报AOX为废水特征因子
3. 确定监测频次（重点管理每月1次）
4. 确认AOX排放限值

**审查核对**：
- [ ] 漂白工序使用何种漂白剂？
- [ ] 有亚氯酸钠使用记录吗？
- [ ] AOX填入许可证了吗？

---

### 错误3：色度因子填错排放限值

**错误描述**：将色度排放标准限值填错，或将染色废水与其他工业废水混淆。

**技术依据**：GB 4287-2012规定色度直接排放限值：现有企业80倍，新建企业50倍。部分企业将印染废水色度按GB 8978-1996（40倍）填报，造成限值偏高（放宽了要求）。

**后果**：排放限值错误导致许可证载明内容违法，侵害环境权益。

**纠正方法**：
1. 确认企业建设时间（1998年1月1日为节点）
2. 确认直接排放还是间接排放
3. 正确选择色度限值

**审查核对**：
- [ ] 色度标准选择正确吗？（GB 4287-2012 vs GB 8978-1996）
- [ ] 直接/间接排放判断正确吗？
- [ ] 新建/现有企业节点判断正确吗？

---

### 错误4：硫化染料企业硫化物+硫化氢遗漏

**错误描述**：使用硫化染料（硫化黑、硫化蓝）的印染企业，遗漏硫化物（废水）和硫化氢（废气）特征因子。

**技术依据**：硫化染料还原清洗过程产生硫化物；硫化氢是硫化染料定型/焙烘废气中的特征因子。

**后果**：特征因子遗漏，许可证质量不合格。

**审查核对**：
- [ ] 使用硫化染料吗？
- [ ] 硫化物填入废水特征因子了吗？
- [ ] 硫化氢填入废气特征因子了吗？

---

### 错误5：含铬染料企业六价铬遗漏

**错误描述**：使用含铬酸性染料或金属络合染料的企业，遗漏六价铬特征因子。

**技术依据**：含铬染料中铬以三价形式存在，但在氧化固色过程中可能转化为六价铬。GB 4287-2012要求六价铬≤0.5mg/L（现有）或≤0.2mg/L（新建）。

**审查核对**：
- [ ] 使用含铬染料吗？
- [ ] 六价铬填入许可证了吗？

---

### 错误6：分散染料高温染色废气疏漏

**错误描述**：涤纶分散染料染色工艺，产生高温废气（含VOCs、苯系物），但申请材料未填报废气排放口。

**技术依据**：分散染料高温定型（130-140°C）过程中，染料和助剂挥发产生VOCs。HJ 861-2017要求填报所有有组织废气排放口。

---

### 错误7：固色剂M企业甲醛遗漏

**错误描述**：使用固色剂M（含甲醛）进行固色处理的企业，未填报甲醛特征因子。

**技术依据**：固色剂M（双氰胺甲醛树脂）游离甲醛含量高，属于GB 4287-2012控制项目。

---

### 错误8：间接排放企业标准适用错误

**错误描述**：间接排放企业错误适用直接排放标准，导致监测频次偏高，或反过来遗漏应监测项目。

**技术依据**：GB 4287-2012表3为间接排放标准，部分指标比表1（直接排放）宽松，如COD间接排放≤200mg/L（现有），但氨氮、总氮无间接排放放宽。

---

### 错误9：苯胺类化合物遗漏（活性染料企业）

**错误描述**：使用活性染料的企业，未填报苯胺类化合物特征因子。

**技术依据**：活性染料水解产物中含有苯胺类化合物，GB 4287-2012将其列为控制指标。

---

### 错误10：总氮/总磷监测频次不足

**错误描述**：重点管理企业未将总氮和总磷纳入监测方案，或监测频次低于规范要求。

**技术依据**：HJ 879-2017明确要求重点管理直接排放企业总氮每月1次、总磷每月1次。

## 第五章 边缘情况处理指南

### 情况1：企业同时使用多种漂白工艺（含亚漂和双氧水漂）

**问题**：漂白工序同时使用亚氯酸钠和双氧水，AOX如何处理？

**处理方法**：
- AOX仅针对亚氯酸钠漂白工艺产生，双氧水漂白不产生AOX
- 废水特征因子中AOX必须填入
- 在申请材料中说明各漂白工艺的用量比例
- 监测方案：AOX监测点位设在混合后综合废水排口

---

### 情况2：定型废气无组织排放（无除尘设施）

**问题**：部分小型印染企业定型废气未经处理直接排放，排放口如何填报？

**处理方法**：
- 定型废气无论是否处理，均属于有组织排放，必须填报排放口
- 即使无除尘设施，也应在申请材料中说明"未处理直接排放"
- 监测频次按定型废气有组织监测标准执行
- 提示企业定型废气应安装VOCs处理设施（活性炭吸附/催化燃烧）

---

### 情况3：印染废水纳管排放至城镇污水处理厂

**问题**：印染废水排入城镇污水处理厂，是否需要监测全部特征因子？

**处理方法**：
- 间接排放适用GB 4287-2012表3标准
- 需确认纳管标准与地方城镇污水厂接纳标准的衔接
- 色度、AOX、六价铬等特殊因子仍需在许可证中载明
- 自备污水处理站的出水监测按直接排放标准执行

---

### 情况4：企业同时使用多种染料（络合染料+活性染料+直接染料）

**问题**：同一企业使用多种染料，特征因子如何确定？

**处理方法**：
- 将所有使用的染料对应的特征因子全部纳入
- 取各染料特征因子的并集，不取交集
- 例如：同时用金属络合染料（含铜）+活性染料（含苯胺类）→ 铜+苯胺类均须填报

---

### 情况5：印染废水回用（零排放工艺）

**问题**：企业采用印染废水深度处理回用工艺，排放口信息如何填报？

**处理方法**：
- 即使回用率很高，仍需设置应急排放口
- 许可证中填报回用系统出水排放口（应急排放）
- 监测方案按实际排放量制定
- 说明回用率和零排放实现方式

---

### 情况6：新建企业（2015年后投产）混淆适用标准

**问题**：2015年后投产的印染企业，混淆GB 4287-2012表1和表2的适用关系。

**处理方法**：
- GB 4287-2012以1998年1月1日为节点，不是以投产时间
- 2015年后投产的"新建企业"：若位于1998年后建设，适用表2
- 审查环评批复文件确认适用标准
- 必要时请企业提供原环评批复确认

---

### 情况7：涂层整理与印染共用废水处理系统

**问题**：涂层废气中VOCs通过废水喷淋处理后排放，废气和废水的特征因子如何关联？

**处理方法**：
- 涂层废气VOCs被喷淋水吸收后，以有机物形式进入废水处理系统
- 废水综合排口应增加VOCs降解产物（如COD增加）监测
- 废气处理设施运行记录纳入环境管理台账
- 这种情况需特别说明气-水转化污染物的处理逻辑

---

### 情况8：企业停产期间的监测要求

**问题**：季节性生产企业（部分印染企业因订单原因季节性生产）如何处理监测要求？

**处理方法**：
- 停产期间可不进行监测，但需在台账中记录停产情况
- 重新投产前需进行一次全面监测
- 监测报告附于台账记录中
- 排污许可证中说明季节性生产特点

---

## 第七章 真实审批拒绝案例

### 案例1：浙江某丝绸印染企业——AOX遗漏导致退回

**企业基本情况**：
- 行业：真丝绸印染（规模：年产3000万米）
- 管理类别：重点管理
- 建设时间：2005年（现有企业）
- 排放方式：直接排放（钱塘江）
- 主要工艺：退浆→煮练→亚氯酸钠漂白→活性染料染色→固色→后整理

**拒绝原因**：
企业在排污许可申请表中填报了COD、氨氮、色度等常规因子，但遗漏了亚漂工艺的特征因子**AOX（二氧化氯）**。审查人员发现其漂白工序使用亚氯酸钠（亚漂），按GB 4287-2012和HJ 861-2017，AOX为必填特征因子。

**审查发现**：
1. 企业使用亚氯酸钠漂白工艺（亚漂），这是产生AOX的直接来源
2. 申请材料中"特征因子清单"未包含AOX
3. 监测方案中无AOX监测计划
4. 企业辩称"亚漂用量较小，排放浓度低"——这不构成遗漏理由

**修正方法**：
1. 补充AOX为废水特征因子（来源：亚氯酸钠漂白）
2. 补充AOX排放限值：GB 4287-2012表1（现有企业）≤12mg/L（直接排放）
3. 补充AOX监测方案：重点管理直接排放，每月1次
4. 补充AOX排放口信息（综合废水排口）

**审查结论**：退回补充材料，企业完成修正后通过审批。

### 案例2：江苏某棉纺织印染企业——定型废气VOCs遗漏导致退回

**企业基本情况**：
- 行业：棉织物印染（规模：年产8000吨）
- 管理类别：重点管理
- 建设时间：2018年（新建企业）
- 排放方式：间接排放（纳管至城镇污水处理厂）
- 主要设备：前处理生产线2条、染色机24台、定型机4台、涂层机1台

**拒绝原因**：
申请材料中填报了锅炉废气和染色废气排放口，但**遗漏了定型废气排放口**。审查人员现场核查发现企业有4台定型机，定型废气通过管道收集后排放，属于有组织废气排放口，必须填报。

**审查发现**：
1. 定型废气是印染行业VOCs的最大来源（占比约60-70%）
2. 申请材料中"废气排放口信息"仅有锅炉废气一项
3. 后整理工序描述中有定型工序，但未填报相关废气排放口
4. 4台定型机均未在排放口清单中体现

**修正方法**：
1. 填报4个定型废气排放口（编号DA011-DA014）
2. 定型废气特征因子：VOCs、非甲烷总烃、苯系物
3. 监测频次：VOCs每月1次，非甲烷总烃每月1次
4. 补充定型废气处理设施信息（企业配有水喷淋+活性炭吸附装置）

**审查结论**：退回补充材料，企业完成修正后通过审批。

### 案例3：广东某化纤印染企业——含铬染料六价铬遗漏导致退回

**企业基本情况**：
- 行业：化纤织物印染（规模：年产聚酰胺纤维印染布5000吨）
- 管理类别：重点管理
- 建设时间：2012年（现有企业）
- 排放方式：直接排放
- 主要工艺：前处理→分散染料高温高压染色（涤纶）→酸性染料染色（锦纶）→固色→后整理

**拒绝原因**：
企业在染色工艺中使用含铬酸性染料（用于锦纶织物固色处理），但申请材料中未填报六价铬特征因子。审查人员核对染料清单发现企业使用含铬酸性染料，按GB 4287-2012和HJ 861-2017，六价铬为必填特征因子。

**审查发现**：
1. 企业染料清单中包含含铬酸性染料（Cr含量0.3-0.8%）
2. 固色处理中使用固色剂M（含甲醛）
3. 申请材料中未填报六价铬
4. 申请材料中未填报甲醛
5. 企业称"铬以三价形式存在，不排放六价铬"——这是对标准的误解

**修正方法**：
1. 补充六价铬为废水特征因子（来源：含铬酸性染料）
2. 六价铬排放限值：GB 4287-2012表2（新建企业）≤0.2mg/L
3. 补充甲醛为废气特征因子（来源：固色剂M）
4. 监测方案补充：六价铬每月1次，甲醛每月1次（定型废气）

**审查结论**：退回补充材料，企业完成修正后通过审批。
