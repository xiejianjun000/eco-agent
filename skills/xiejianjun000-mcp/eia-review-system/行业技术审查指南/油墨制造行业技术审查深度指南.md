# 油墨制造行业排污许可技术审查深度指南

> **适用范围**：本标准适用于GB/T 4754—2017中行业代码2642的油墨制造企业排污许可证申请与核发，包括印刷油墨、书写油墨、墨水等制造。
> **核心技术规范**：HJ 1107-2020《排污许可证申请与核发技术规范 涂料制造》（油墨制造参照执行）

## 一、行业特征因子核对表

### 1.1 有组织排放口因子核对表

| 油墨类型 | 污染物类型 | 必填因子 | 备注 |
|---------|---------|---------|------|
| 溶剂型凹印油墨 | 挥发性有机物 | VOCs、甲苯、乙酸乙酯、丙二醇甲醚 | 凹印油墨VOCs最高 |
| 溶剂型柔印油墨 | 挥发性有机物 | VOCs、乙醇、乙酸乙酯、丁酮 | 柔印油墨VOCs中等 |
| 溶剂型丝印油墨 | 挥发性有机物 | VOCs、甲苯、二甲苯、乙酸丁酯 | 丝印油墨VOCs较高 |
| 水性油墨 | 挥发性有机物 | VOCs（少量）、醇醚类（如乙二醇丁醚） | 水性油墨VOCs很低 |
| UV固化油墨 | 挥发性有机物 | VOCs（很低，固化后无） | UV油墨基本无VOCs |
| 平版印刷油墨（胶印墨） | 挥发性有机物 | VOCs、矿物油（植物油基油墨VOCs较低） | 胶印墨VOCs较低 |
| 书写墨水 | 挥发性有机物 | VOCs（如含溶剂） | 水性墨水VOCs很低 |
| 树脂连接料合成 | 挥发性有机物 | VOCs、苯乙烯（丙烯酸树脂） | 有树脂合成时 |
| 配料/分散/研磨工序 | 挥发性有机物 | VOCs、特征溶剂 | 各工序溶剂挥发 |
| 锅炉/热风系统 | 燃烧废气 | SO₂、NOx、颗粒物、烟气黑度 | 使用化石燃料时 |

### 1.2 VOCs特征因子识别（核心重点）

油墨制造行业VOCs因子填报复杂，不同油墨产品的VOCs成分差异极大。

**第一步：识别油墨产品类型**

| 油墨类型 | VOCs含量 | 主要VOCs成分 |
|---------|---------|------------|
| 溶剂型凹印油墨 | ≥70% | 甲苯（30-50%）、乙酸乙酯（20-40%）、丙二醇甲醚（10-20%） |
| 溶剂型柔印油墨 | 50-70% | 乙醇（40-60%）、乙酸乙酯（20-30%）、丁酮（10-20%） |
| 溶剂型丝印油墨 | 60-80% | 甲苯（30-40%）、二甲苯（20-30%）、乙酸丁酯（15-25%） |
| 水性油墨 | ≤10% | 少量醇醚类（如乙二醇丁醚≤5%） |
| UV固化油墨 | ≤5% | 丙烯酸酯类（固化后无VOCs） |
| 平版印刷油墨 | 20-40% | 矿物油（高沸点，VOCs较低） |
| 书写墨水（水性） | ≤5% | 少量醇类（防腐剂） |

**第二步：识别各产品所用原料**

| 原料类别 | 典型物质 | VOCs特征 |
|---------|---------|---------|
| 连接料（树脂） | 丙烯酸树脂、醇酸树脂、聚氨酯 | 溶液型树脂含溶剂 |
| 溶剂 | 甲苯、乙酸乙酯、乙醇、二甲苯 | 主要VOCs来源 |
| 颜料 | 有机颜料、无机颜料 | 无VOCs |
| 助剂 | 分散剂、流平剂、消泡剂 | 可能含少量VOCs |

**第三步：按产品分别确定特征因子**

| 油墨产品 | 主要原料 | 必填VOCs特征因子 |
|---------|---------|----------------|
| 溶剂型凹印油墨 | 甲苯（40%）、乙酸乙酯（30%） | VOCs、甲苯、乙酸乙酯 |
| 溶剂型柔印油墨 | 乙醇（50%）、乙酸乙酯（25%） | VOCs、乙醇、乙酸乙酯、丁酮 |
| 溶剂型丝印油墨 | 甲苯（35%）、二甲苯（25%）、乙酸丁酯（20%） | VOCs、甲苯、二甲苯、乙酸丁酯 |
| 水性柔印油墨 | 少量乙二醇丁醚（≤5%） | VOCs（可仅填总量） |
| UV固化油墨 | 丙烯酸酯类（固化后无VOCs） | VOCs（很低，按实测） |
| 平版印刷油墨 | 矿物油（20-40%） | VOCs（可仅填总量） |

### 1.3 树脂连接料合成工序特征因子（有树脂合成的企业）

| 树脂类型 | 反应过程产生污染物 | 必填因子 |
|---------|-----------------|---------|
| 丙烯酸树脂 | 聚合反应 | VOCs（未反应单体）、苯乙烯（如使用苯乙烯单体） |
| 醇酸树脂 | 酯化反应 | VOCs（溶剂）、甲醛（如使用甲醛） |
| 聚氨酯树脂 | 预聚反应 | VOCs（溶剂）、TDI（如未完全反应） |

### 1.4 无组织排放因子核对表

| 无组织排放源 | 必填因子 | 监测方式 |
|-----------|---------|---------|
| 配料车间（门窗/缝隙） | VOCs | 厂界监控点 |

## 二、监测频次决策树

### 2.1 决策树逻辑

```
开始
│
├─ 企业是否有树脂连接料合成工序？
│  ├─ 是 → 按化工行业要求，监测频次从严
│  │  ├─ 重点管理？→ VOCs：月度监测
│  │  └─ 简化管理？→ VOCs：季度监测
│  └─ 否 → 按油墨制造行业要求
│
├─ 油墨产品类型？
│  ├─ 溶剂型凹印油墨（VOCs≥70%）？→ 监测频次从严
│  ├─ 溶剂型柔印/丝印油墨（VOCs 50-80%）？→ 监测频次从严
│  └─ 水性/UV固化油墨（VOCs≤10%）？→ 监测频次可适当放宽
│
├─ 排放口类型？
│  ├─ 主要排放口？
│  │  ├─ 重点管理？→ VOCs：季度监测（非焚烧类）
│  │  └─ 简化管理？→ VOCs：半年1次
│  ├─ 一般排放口？
│  │  ├─ 重点管理？→ VOCs：季度监测
│  │  └─ 简化管理？→ VOCs：半年1次
│  └─ 无组织监控点？
│     ├─ 重点管理？→ VOCs：季度监测
│     └─ 简化管理？→ VOCs：半年1次
│
└─ 省份差异
   ├─ 江苏省：所有VOCs排放口自动监测
   ├─ 广东省：无组织VOCs重点管理每月监测
   └─ 山东省：必须有高效治理设施
```

### 2.2 监测频次依据表

| 管理类别 | 产品类型 | 排放口类型 | 监测频次 | 依据 |
|---------|---------|---------|---------|------|
| 重点管理 | 溶剂型凹印油墨 | 主要排放口 | 每月1次（建议） | VOCs产生量大 |
| 重点管理 | 其他溶剂型油墨 | 主要排放口 | 每季度1次 | HJ 1107-2020参照 |
| 重点管理 | 水性/UV油墨 | 主要排放口 | 每季度1次 | VOCs产生量小 |
| 简化管理 | 所有类型 | 所有排放口 | 每半年1次 | HJ 1107-2020参照 |
| 有树脂合成 | 所有类型 | 所有排放口 | 每月1次（建议） | 化工行业从严 |

## 三、排放标准适用指南

### 3.1 VOCs排放标准选择

油墨制造企业VOCs排放，优先执行以下标准（按优先级排序）：

1. **所在地地标**（如江苏DB 32/4041、浙江DB 33/2146等）
2. **GB 31572-2015**《合成树脂工业污染物排放标准》（有树脂合成时）
3. **GB 16297-1996**《大气污染物综合排放标准》（无地标、无树脂合成时）

### 3.2 常用排放标准对照表

| 标准名称 | 标准号 | 适用范围 | VOCs限值（排气筒） | VOCs无组织限值 |
|---------|-------|---------|-------------------|--------------|
| 大气污染物综合排放标准 | GB 16297-1996 | 全国（无地标时） | 120mg/m³ | 5.0mg/m³（厂界） |
| 合成树脂工业污染物排放标准 | GB 31572-2015 | 有树脂合成的企业 | 60mg/m³（现有企业） | 4.0mg/m³（厂界） |
| 江苏省表面涂装挥发性有机物排放标准 | DB 32/4041-2021 | 江苏省 | 50mg/m³ | 2.0mg/m³（厂界） |
| 浙江省工业涂装工序大气污染物排放标准 | DB 33/2146-2018 | 浙江省 | 50mg/m³ | 2.0mg/m³（厂界） |
| 广东省大气污染物排放限值 | DB 44/27-2001 | 广东省 | 120mg/m³（第II时段） | 5.0mg/m³（厂界） |
| 山东省挥发性有机物排放标准 第6部分：有机化工 | DB 37/2801.6-2018 | 山东省 | 50mg/m³ | 2.0mg/m³（厂界） |

## 四、常见错误TOP 10

### 错误1：溶剂型凹印油墨特征因子严重遗漏（出现频率：★★★★★）

**表现**：企业生产溶剂型凹印油墨（含甲苯30-50%），但许可证仅填了"VOCs"一个因子。

**后果**：凹印油墨中甲苯占比很高，不单独管控甲苯，企业可能甲苯超标排放而未被发现。

**审查要点**：
- 溶剂型凹印油墨必须填报：VOCs、甲苯、乙酸乙酯
- 如油墨含丙二醇甲醚、丁酮等，也需填报

### 错误2：有树脂合成但未执行GB 31572（出现频率：★★★★☆）

**表现**：企业有丙烯酸树脂连接料合成工序，但许可证执行GB 16297-1996（120mg/m³），未执行GB 31572-2015（60mg/m³）。

**审查要点**：
- 审查时先问企业是否有树脂连接料合成工序
- 有树脂合成，必须执行GB 31572-2015

### 错误3：水性油墨误按溶剂型填报（出现频率：★★★★☆）

**表现**：企业生产水性油墨（VOCs含量≤10%），但许可证按溶剂型填报，因子填了一大堆（甲苯、二甲苯等）。

**后果**：水性油墨不含甲苯、二甲苯，填报后企业无法执行自行监测。

**审查要点**：
- 水性油墨VOCs含量很低（≤10%），可仅填"VOCs"总量
- 无需单独填报苯系物

### 错误4：监测频次不足（出现频率：★★★☆☆）

**表现**：重点管理企业（生产溶剂型凹印油墨），VOCs监测频次填报为"每季度1次"。

**后果**：溶剂型凹印油墨VOCs产生量很大，季度监测频次不足。

**审查要点**：
- 生产溶剂型凹印油墨的重点管理企业，VOCs监测频次建议按月度

### 错误5：地方标准未执行（出现频率：★★★☆☆）

**表现**：企业位于浙江省，但许可证执行GB 16297-1996，未执行DB 33/2146-2018。

**审查要点**：
- 审查时先查企业所在地是否有地标
- 油墨制造企业参照涂料制造地标执行

### 错误6：无组织排放因子遗漏（出现频率：★★★☆☆）

**表现**：许可证只填报了有组织排放口，未填报原料储罐呼吸废气无组织排放。

**审查要点**：
- 油墨制造企业必须有原料储罐呼吸废气收集系统
- 大型储罐（≥10m³）必须设置呼吸阀+废气收集

### 错误7：UV固化油墨VOCs填报错误（出现频率：★★☆☆☆）

**表现**：企业生产UV固化油墨，但许可证填报VOCs限值为50mg/m³（按常规油墨）。

**后果**：UV固化油墨固化后无VOCs，限值50mg/m³过严，企业无法达标。

**审查要点**：
- UV固化油墨VOCs含量极低，可执行GB 16297或地标中"其他"类限值

### 错误8：平版印刷油墨（胶印墨）VOCs因子填报错误（出现频率：★★☆☆☆）

**表现**：企业生产平版印刷油墨（植物油基，VOCs含量20-40%），但许可证按溶剂型油墨填报（甲苯、二甲苯等）。

**后果**：平版印刷油墨不含甲苯、二甲苯，填报后企业无法执行自行监测。

**审查要点**：
- 平版印刷油墨（胶印墨）VOCs主要来自矿物油/植物油，可仅填"VOCs"总量
- 无需填报苯系物

### 错误9：排放口编号不规范（出现频率：★★☆☆☆）

**表现**：排放口编号随意编写，未按要求编码。

**审查要点**：
- 排放口编号格式：FQ-XXXXXXXX（废气）+ 序号

### 错误10：原料MSDS不全，特征因子无法确定（出现频率：★★★☆☆）

**表现**：企业无法提供溶剂原料的MSDS，或MSDS未标明各成分占比。

**审查要点**：
- 要求企业向原料供应商索取完整MSDS
- 如无法提供，要求委托第三方检测

## 六、多工序企业标准适用指南

### 6.1 典型多工序油墨制造企业

```
某油墨制造企业工艺流程：
1. 树脂连接料合成工序（丙烯酸树脂）→ VOCs+酸性废气
2. 配料工序 → VOCs
3. 分散/研磨工序 → VOCs
4. 调墨工序 → VOCs
5. 过滤/包装工序 → VOCs
```

### 6.2 多工序企业标准适用原则

**原则：按工序分别适用标准**

| 工序 | 适用标准 | 限值 |
|-----|---------|------|
| 树脂连接料合成 | GB 31572-2015 | VOCs：60mg/m³ |
| 配料/分散/调墨/包装 | 地标（如DB 32/4041） | VOCs：50mg/m³ |

## 七、真实审批拒绝案例（3个）

### 案例1：溶剂型凹印油墨特征因子遗漏

**企业基本情况**：
- 名称：温州市XX油墨有限公司
- 行业：油墨制造
- 管理类别：重点管理
- 主要产品：溶剂型凹印油墨

**拒绝原因**：
许可证申请材料中，VOCs特征因子仅填报了"VOCs"总量，未填报甲苯、乙酸乙酯等特征因子。

经审查发现：
- 企业使用甲苯（40%）、乙酸乙酯（30%）等溶剂
- 甲苯占比40%，必须单独填报

**整改要求**：
补充填报甲苯、乙酸乙酯等特征因子。

### 案例2：有树脂合成但未执行GB 31572

**企业基本情况**：

## 十、边缘情况处理指南

### 边缘情况1：企业同时生产多种油墨，如何填报VOCs特征因子？

**情况描述**：企业同时生产溶剂型凹印油墨、水性油墨、UV固化油墨，VOCs特征差异大。

**处理方法**：
1. 按产品类型分别识别VOCs特征因子
2. 各产品特征因子合并去重，全部填报
3. 但需在许可证中注明"不同产品生产线分别按其特征因子进行自行监测"

### 边缘情况2：原料MSDS不全，如何确定特征因子？

**情况描述**：企业无法提供溶剂原料MSDS，或MSDS未标明各成分占比。

**处理方法**：
1. 要求企业向供应商索取完整MSDS
2. 如无法提供，要求委托第三方检测
3. 审查时暂按"VOCs总量+苯+甲苯+二甲苯"填报，备注"待检测后补充"

### 边缘情况3：有树脂合成但产量很小，是否执行GB 31572？

**情况描述**：企业树脂合成产量很小（每年50吨），认为无需执行GB 31572。

**处理方法**：
1. 只要有树脂合成工序，无论产量大小，都必须执行GB 31572-2015

### 边缘情况4：UV固化油墨生产企业，VOCs排放量极少，如何执行标准？

**情况描述**：企业全部生产UV固化油墨，VOCs排放量极少（≤0.01t/a）。

**处理方法**：
1. UV固化油墨VOCs含量极低，可执行GB 16297或地标中"其他"类限值
2. 监测频次可适当放宽（简化管理：年1次），但必须在许可证中载明

### 边缘情况5：企业位于两省交界处，执行哪个省的地标？

**情况描述**：企业注册地在安徽省，但生产厂址在江苏省苏州市（化工园区）。

**处理方法**：
1. 按生产厂址所在地（江苏省）的地标执行
2. 且必须在化工园区内，否则不予核发许可证
