# 金属表面处理及热处理加工行业排污许可证技术审查深度指南

> **适用对象**：技术评估机构、审批部门、执法人员
> **行业代码**：C336（金属表面处理及热处理加工）
> **管理类别判断依据**：《固定污染源排污许可分类管理名录（2019年版）》第73项
> **核心规范**：《排污许可证申请与核发技术规范 电镀工业》（HJ 855-2017）
> **自行监测规范**：《排污单位自行监测技术指南 电镀工业》（HJ 985-2018）
> **排放标准**：GB 21900-2008《电镀污染物排放标准》、GB 8978-1996《污水综合排放标准》

## 一、行业概述与工艺特征

### 1.1 行业分类

金属表面处理及热处理加工行业涵盖面极广，按工艺分为：

| 类别 | 主要工艺 | 典型产品/服务 |
|-----|---------|-------------|
| 电镀 | 镀锌/镀镍/镀铬/镀铜/镀锡/贵金属电镀等 | 镀锌板、镀镍件、装饰镀铬 |
| 化学镀 | 化学镀镍/化学镀铜 | PCB板、塑料电镀 |
| 阳极氧化 | 铝阳极氧化/镁阳极氧化 | 铝型材阳极氧化件 |
| 金属转化膜 | 磷化/钝化/发黑/磷皂化 | 钢铁磷化件 |
| 金属精饰 | 电泳/喷漆/喷粉/喷塑/电泳涂装 | 汽车零部件涂装 |
| 热处理 | 渗碳/渗氮/碳氮共渗/淬火/回火/正火/退火 | 齿轮渗碳件 |
| 表面改性 | 喷砂/抛丸/喷丸/抛光/研磨 | 表面预处理 |
| 印刷电路板 | PCB制造（电镀/蚀刻） | 线路板 |
| 阳极保护 | 阳极保护（酸洗钝化） | 设备防护 |

### 1.2 典型工艺流程

#### 电镀工艺：

```
前处理（除油→酸洗→水洗）→ 电镀（主镀→水洗）→ 后处理（钝化→干燥）→ 成品
```

#### 阳极氧化工艺（铝）：

```
脱脂→碱蚀→水洗→酸中和→阳极氧化→水洗→染色/封孔→干燥→成品
```

#### 热处理工艺（渗碳）：

```
零件清洗→渗碳炉（碳势控制）→淬火→清洗→回火→检验→成品
```

### 1.3 行业特征

- **行业覆盖面极广**：几乎涉及所有制造业的表面处理工序
- **重金属污染突出**：电镀是典型的重金属污染行业
- **六价铬问题**：镀铬（尤其是装饰铬、硬铬）是六价铬主要来源
- **氰化物使用**：镀锌/镀铜/镀金等工艺使用氰化物氰根
- **酸碱用量大**：大量使用硫酸、盐酸、硝酸、氢氟酸、氢氧化钠
- **工序多、产污环节多**：每个工序均有废水废气排放
- **小微企业多**：大量电镀小作坊散布于工业园区

## 二、管理类别判断

### 2.1 管理类别划分

根据《名录》第73项：

| 生产类型 | 规模条件 | 管理类别 |
|---------|---------|---------|
| 金属表面处理及热处理加工 | 使用溶剂型涂料的喷涂工艺 | **重点管理** |
| 金属表面处理及热处理加工 | 使用有机溶剂的清洗工艺 | **重点管理** |
| 金属表面处理及热处理加工 | 电镀工艺 | **重点管理** |
| 金属表面处理及热处理加工 | 其他（无上述工艺） | **简化管理** |

### 2.2 重点说明

**"重点管理"的三种触发情形**：
1. **电镀工艺**（含镀锌、镀镍、镀铬、镀铜、镀锡等所有电镀工序）→ 重点管理
2. **使用有机溶剂的清洗工艺**（如三氯乙烯脱脂、煤油清洗等）→ 重点管理
3. **使用溶剂型涂料的喷涂工艺**（如喷漆、喷粉不属于此——粉末涂料VOCs少）→ 重点管理

**"简化管理"的情形**：
- 仅有物理除油（不含溶剂）
- 仅有磷化/钝化（无电镀）
- 仅有喷砂/抛丸等物理预处理
- 仅有热处理（无清洗/喷涂）
- 仅有电泳（但电泳通常使用有机溶剂，需重点管理）

**"使用有机溶剂的清洗"判断标准**：
- 三氯乙烯（TCE）、四氯乙烯（全氯乙烯）、丙酮、甲苯、二甲苯等有机溶剂清洗
- 水基清洗剂（含少量表面活性剂）不属于"使用有机溶剂的清洗"

### 2.3 电镀工艺的广义理解

根据HJ 855-2017，电镀工艺的"电镀"包括：
- **金属电沉积**（电镀）：镀锌、镀镍、镀铬、镀铜、镀锡等
- **化学镀**（自催化镀）：化学镀镍、化学镀铜
- **阳极氧化**：铝阳极氧化、镁阳极氧化
- **电解加工**：电解抛光、电解去毛刺
- **电泳涂装**：电泳漆涂装（槽液含溶剂）

### 4.4 自动监测设备安装要求

**必须安装自动监测的排放口**：
1. 电镀废水直接排放总排口（pH、COD、流量——六价铬/总镍/总铜等至少1项重金属自动监测）
2. 国家或省级明确要求自动监测的其他排放口
3. 重点管理企业废水总排口（六价铬自动监测设备是重点）

**注意**：重金属自动监测设备（特别是六价铬在线监测仪）价格昂贵，部分中小企业难以承担，可申请以手工监测替代（需说明原因并经批准）

## 六、常见错误TOP 10

### 错误1：六价铬因子遗漏（最常见最严重）

**错误表现**：
- 镀铬企业遗漏六价铬监测
- 将装饰铬（高浓度六价铬）误认为"普通镀锌"
- 六价铬钝化企业未监测六价铬

**正确做法**：
- **所有镀铬工艺必测六价铬**
- 装饰镀铬：六价铬浓度高（CrO₃ 200-300 g/L）
- 硬铬：六价铬浓度极高（CrO₃ 150-250 g/L）
- 钝化液（含六价铬钝化）同样需要监测六价铬

### 错误2：氰化物因子遗漏

**错误表现**：
- 氰化镀锌/氰化镀铜企业遗漏氰化物监测
- 将"氰化"误写为"碱性"（氰化镀锌溶液是碱性的，容易混淆）
- 氰化物超标危害极大

**正确做法**：
- 氰化镀锌、氰化镀铜、氰化镀金等工艺使用氰化物
- 槽液含氰根，废水含氰化物
- 监测频次：每月1次（重点管理）
- 超标氰化物废水需用次氯酸钠破氰处理后才能排放

### 错误3：简化管理误用于有电镀工序企业

**错误表现**：
- 有电镀工序的企业错误申请简化管理
- 企图降低监测频次和许可要求
- 遗漏重金属因子

**正确做法**：
- **只要涉及电镀工序（镀锌/镀镍/镀铬等）即为重点管理**
- 不论电镀规模大小，一律为重点管理
- 不能因为"产量小"而申请简化管理

### 错误4：热处理油烟/废气未纳入许可

**错误表现**：
- 热处理企业遗漏淬火油烟监测
- 渗碳/渗氮废气（氨气/CO/氰化氢）未纳入许可
- 将热处理视为"简单加工"忽视废气污染

**正确做法**：
- 淬火热处理：监测油烟（颗粒物/非甲烷总烃）
- 渗氮：监测氨气（NH₃）
- 氰化物法渗碳：监测氰化氢（HCN）
- 淬火废液属于危险废物HW09，需单独收集处置

### 错误5：阳极氧化六价铬与总铬混淆

**错误表现**：
- 铝阳极氧化企业不区分钝化类型
- 三价铬钝化误报为"无铬钝化"
- 实际使用六价铬钝化的企业遗漏六价铬监测

**正确做法**：
- 硫酸阳极氧化：主要监测总铝，钝化后测六价铬（若使用六价铬钝化）
- 三价铬钝化：总铬有检出，六价铬含量低（但仍有）
- 无铬钝化（锆盐/硅烷）：无重金属铬检出
- 需实地核实钝化液类型，不能仅凭企业申报

### 错误6：多镀种企业特征因子遗漏

**错误表现**：
- 多镀种（镀锌+镀镍+镀铬+镀铜）企业仅填报主要镀种因子
- 遗漏了某些镀种的特征重金属
- PCB企业遗漏镍/金/锡等因子

**正确做法**：
- 按镀种逐项核查特征因子（锌/镍/铬/铜/锡/金等）
- 每个镀种对应一种或多种特征重金属
- PCB企业还需关注镍、金、钯等贵金属

### 错误7：废酸液/废钝化液定性错误

**错误表现**：
- 镀铬废液、钝化废液定性为一般废水
- 将废电镀液直接排放至废水处理系统
- 镀铬废液（高浓度六价铬）直接进入废水站

**正确做法**：
- 废电镀液属于危险废物HW34（废酸）
- 废钝化液（含六价铬）属于危险废物HW21（表面处理废物）
- 废氰化液属于危险废物HW29（含氰废物）
- **各类废槽液必须单独收集，委托有资质单位处置**

### 错误8：喷漆废气VOCs因子遗漏

**错误表现**：
- 使用溶剂型涂料的喷涂企业遗漏VOCs监测
- 粉末喷涂误报为溶剂型喷涂
- 仅监测粉尘，遗漏VOCs

**正确做法**：
- 溶剂型涂料：主要污染物为VOCs（甲苯、二甲苯、乙酸乙酯等）
- 粉末涂料：主要污染物为粉尘（VOCs很少）
- 需核实企业实际使用的涂料类型
- VOCs监测频次：每月1次（重点管理）

### 错误9：废水处理站管理不规范

**错误表现**：
- 六价铬废水与含氰废水混合（导致剧毒气体释放）
- 废水处理站缺乏六价铬还原和氰化物破氰工序
- pH调节池未安装搅拌设备，处理效果差

**正确做法**：
- **六价铬还原（亚硫酸氢钠/焦亚硫酸钠）和氰化物破氰（次氯酸钠）是两个必须分开的处理工序**
- 六价铬还原在酸性条件下进行，pH=2-3
- 氰化物破氰在碱性条件下进行，pH=10-11
- 两个工序不能混合，否则产生剧毒氰化氢气体

### 错误10：槽液更换台账缺失

**错误表现**：
- 电镀槽液更换频率高，但无台账记录
- 废槽液产生量无法核算
- 危险废物申报数量与实际不符

**正确做法**：
- 建立电镀槽液管理台账（添加/更换记录）
- 废槽液按批次委托处置
- 废槽液产生量=槽液体积×浓度系数
- 年度危险废物申报需与台账一致

## 九、真实审批拒绝案例

### 案例1：六价铬和氰化物双遗漏（广东某电镀企业）

**基本信息**：
- 行业：电镀+阳极氧化（年产镀锌件5000吨、铝阳极氧化2000吨）
- 管理类别：重点管理
- 审批结果：不予核发，退回修改

**拒绝原因**：
1. 遗漏六价铬因子（企业有装饰镀铬工序）
2. 遗漏氰化物因子（企业有氰化镀锌工序）
3. 错误认为"碱性镀锌不含氰化物"（混淆了碱性无氰和氰化镀锌）
4. 铝阳极氧化钝化液使用六价铬钝化但未监测

**整改要求**：
- 补充六价铬监测方案（废气+废水，每月1次）
- 补充氰化物监测方案（废水每月1次）
- 核实钝化液类型（若为六价铬钝化需监测）
- 建设氰化物破氰处理设施

**经验教训**：氰化镀锌和碱性无氰镀锌是两种完全不同的工艺，必须区分。"氰化"≠"碱性"

### 案例2：简化管理误用于电镀企业（浙江某小微电镀企业）

**基本信息**：
- 行业：单一镀锌加工（年产500吨）
- 管理类别：重点管理（误报简化管理）
- 审批结果：不予核发

**拒绝原因**：
1. 企业有氰化镀锌工艺，属于电镀工序
2. 错误申请简化管理（误认为规模小可以简化）
3. 电镀工序企业无论规模大小均为重点管理

**整改要求**：
- 按重点管理重新填报申请材料
- 补充氰化物、六价铬因子监测方案
- 建设氰化物破氰处理设施

**经验教训**：电镀工序是管理类别判断的核心依据，与规模无关

### 案例3：热处理油烟因子遗漏（山东某齿轮热处理企业）

**基本信息**：
- 行业：热处理加工（渗碳+淬火+回火，服务于汽车零部件）
- 管理类别：重点管理（误以为热处理不属于电镀）
- 审批结果：补充材料后通过

**拒绝原因**：
1. 遗漏淬火热处理油烟因子（矿物油挥发）
2. 遗漏渗碳废气（氨气/氰化氢）
3. 遗漏淬火废液（矿物油，危险废物HW09）管理方案
4. 仅关注了清洗工序的有机溶剂

**整改要求**：
- 补充淬火油烟监测方案
- 补充渗氮废气（氨气）监测方案
- 补充淬火废液危险废物管理方案
- 淬火废液需委托有资质单位处置

**经验教训**：热处理行业虽非典型电镀，但淬火油烟和氰化物法渗碳的氰化氢是重要废气因子

## 十、边缘情况处理指南

### 10.1 不同涂料类型的VOCs因子识别

| 涂料类型 | VOCs含量 | 主要溶剂 | 监测因子 |
|---------|---------|---------|---------|
| 溶剂型涂料 | 30%-60% | 甲苯、二甲苯、乙酸乙酯 | VOCs、甲苯、二甲苯 |
| 水性涂料 | 5%-15% | 醇醚类溶剂 | VOCs（含量较低） |
| 粉末涂料 | <2% | 无溶剂 | 粉尘（主要），VOCs极少 |
| 紫外光固化涂料 | 10%-30% | 丙烯酸单体 | VOCs（活性稀释剂） |
| 电泳涂料 | 5%-15% | 醇醚类溶剂 | VOCs |

### 10.2 "无氰电镀"的认定

**问题**：企业声称"无氰电镀"，是否需要监测氰化物？

**判断方法**：
1. 查阅工艺配方（槽液组分）
2. 检测槽液中氰根浓度（检出限以下可认为无氰）
3. 现场核查是否使用氰化物化学品

**结论**：
- 槽液中不含氰根（检出限以下）→ 不测氰化物
- 槽液中含氰根（检出限以上）→ 监测氰化物

### 10.3 六价铬钝化的"三价铬化"趋势

**行业趋势**：传统六价铬钝化正逐步被三价铬钝化替代

**处理方法**：
1. 实地核实钝化液组分（检测Cr⁶⁺浓度）
2. 三价铬钝化：六价铬检出值很低（<0.1 mg/L），但仍需监测
3. 无铬钝化（锆盐/硅烷）：无需监测铬因子
4. 鼓励企业使用无铬钝化工艺

### 10.4 小微电镀企业的许可简化

**问题**：小微企业（年产<100吨电镀件）如何处理？

**处理方法**：
1. **管理类别不变**：只要有电镀工序仍为重点管理
2. **许可内容可简化**：排放口可合并，监测频次可申请适当降低
3. **申请降低监测频次**：需满足连续2年稳定达标、无超标记录等条件
4. **政策支持**：部分地区对小微企业提供简化许可服务

### 10.5 氰化物与六价铬的协同处理

**废水处理工艺设计**：

```
电镀废水（混合）→ 格栅隔油 → 调节池 → 六价铬还原池（pH=2-3，焦亚硫酸钠）→ 中间池 → 氰化物破氰池（pH=10-11，次氯酸钠）→ 综合废水处理池（pH调节+絮凝沉淀）→ 排放
```

**注意**：六价铬还原和氰化物破氰必须分开两个独立池子，不能混用
