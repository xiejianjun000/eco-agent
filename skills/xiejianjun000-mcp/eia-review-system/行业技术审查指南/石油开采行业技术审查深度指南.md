# 石油开采行业技术审查深度指南

## 适用范围
本指南适用于《固定污染源排污许可分类管理名录（2019年版）》中规定的石油开采行业排污许可证技术审查工作。

## 行业代码与分类
- **行业代码**：B0711（陆地石油开采）
- **管理类别**：重点管理/简化管理
- **技术规范**：HJ 947-2018《排污许可证申请与核发技术规范 石油开采》

## 二、监测频次决策树

```
开始
│
├─ 管理类别判断
│   ├─ 重点管理企业
│   │   ├─ 主要排放口（采出水排放口）
│   │   │   ├─ 自动监测：石油类（日排放≥500吨）
│   │   │   ├─ 手工监测
│   │   │   │   ├─ 每月：pH、SS、COD、氨氮、石油类
│   │   │   │   └─ 每季：挥发酚、硫化物、总盐
│   │   │   └─ 对照 HJ 819-2017 调整
│   │   └─ 一般排放口
│   │       └─ 每半年或每年手工监测
│   └─ 简化管理企业
│       └─ 所有排放口：每年手工监测
│
├─ 废气排放口
│   ├─ 加热炉/锅炉（≥20t/h 或 14MW）
│   │   └─ 自动监测：颗粒物、SO₂、NOx
│   ├─ 加热炉/锅炉（<20t/h 或 <14MW）
│   │   └─ 手工监测：每季度或每半年
│   └─ 无组织排放（储罐呼吸、装卸）
│       └─ 每季度或每半年监测
│
├─ 地下水监测
│   └─ 重点管理企业：每半年监测一次
│
└─ 特殊情形
    ├─ 高含硫油田：增加硫化氢监测
    ├─ 入海排污口：执行海洋环境保护要求
    └─ 地方有更严要求的：执行地方要求
```

## 四、常见错误TOP 10

### 错误1：采出水特征因子遗漏
**问题描述**：许可证中遗漏了采出水的特征因子，如挥发酚、硫化物、总盐等。
**正确做法**：对照 HJ 947-2018 表3，完整填报采出水污染物因子。

### 错误2：石油类因子未填报或限值错误
**问题描述**：采出水排放口中漏报石油类，或排放限值未按 GB 39727-2020 填报。
**正确做法**：石油类是油田采出水的核心控制因子，必填；限值按 GB 39727-2020 执行。

### 错误3：含油污泥类别判断错误
**问题描述**：将含油污泥填报为一般工业固体废物，实际应为危险废物（HW08）。
**正确做法**：含油污泥属于危险废物，应按危险废物管理要求填报。

### 错误4：地下水监测要求遗漏
**问题描述**：石油开采企业未填报地下水监测要求。
**正确做法**：石油开采企业可能发生地下水污染，应按 HJ 947-2018 要求填报地下水监测。

### 错误5：储罐呼吸废气未填报
**问题描述**：原油储罐呼吸阀产生的无组织废气（NMHC）未填报。
**正确做法**：原油储罐呼吸阀是无组织排放重要来源，应填报 NMHC 等因子。

### 错误6：钻井临时排放口处理不当
**问题描述**：钻井废水作为永久排放口填报，实际应为临时排放口。
**正确做法**：钻井废水排放口为临时排放口，应标注"临时"属性。

### 错误7：排放标准引用错误
**问题描述**：采出水排放执行《污水综合排放标准》GB 8978-1996，而非《陆上石油天然气开采工业水污染物排放标准》GB 39727-2020。
**正确做法**：石油开采行业废水应优先执行行业标准。

### 错误8：总量指标核算方法错误
**问题描述**：石油类总量指标核算时，未按采出水产生量、回注量、排放量分别核算。
**正确做法**：石油类总量应按实际排放量核算，回注部分不计入排放总量。

### 错误9：回注井信息未填报
**问题描述**：采出水回注井的位置、数量、回注层位等信息未填报。
**正确做法**：采出水回注是石油开采行业重要特征，回注井信息应完整填报。

### 错误10：地方特殊要求未落实
**问题描述**：位于敏感区域（如水源保护区、自然保护区）的油田，未执行更严的排放要求。
**正确做法**：审查时注意企业是否位于特殊保护区，执行相应特别排放限值或禁止排放要求。

## 五、省份差异要求

### 5.1 新疆（石油/天然气主产区）

**特殊要求**：
1. **干旱区地下水保护**：新疆干旱半干旱区，地下水是重要饮用水源，要求加强地下水监测，防止石油类污染。
2. **沙漠生态保护区**：位于沙漠自然保护区的油井，要求采用"丛式井"工艺，减少地表占用。
3. **冬季排放要求**：新疆冬季寒冷，要求确保污水处理设施正常运行，防止冻裂泄漏。

**审查要点**：
- 核查油田地理位置，是否在沙漠自然保护区、饮用水源保护区内
- 检查地下水监测方案是否满足 HJ 947-2018 要求
- 检查冬季防冻措施

### 5.2 陕西（长庆油田等）

**特殊要求**：
1. **黄河流域保护要求**：位于黄河干支流岸线1公里范围内的油田，执行更严格的排放管控。
2. **陕北生态保护**：陕北地区生态脆弱，要求采出水全部回注，禁止外排。
3. **油气泄漏防控**：要求建立油气泄漏监测预警系统。

**审查要点**：
- 核对油田与黄河干支流的距离
- 检查采出水回注方案，陕北地区原则上不允许外排

### 5.3 黑龙江（大庆油田）

**特殊要求**：
1. **松嫩平原地下水保护**：松嫩平原是重要农产品基地，要求加强地下水监测和保护。
2. **湿地保护**：位于湿地自然保护区的油井，要求逐步退出或执行最严格的环保措施。

**审查要点**：
- 核查油田是否位于湿地保护区内
- 检查地下水监测方案

### 5.4 山东（胜利油田）

**特殊要求**：
1. **黄河流域保护要求**：位于黄河三角洲的油田，执行严格的环保要求。
2. **海洋环境保护**：位于渤海湾的海上油田（陆上部分），执行海洋环境保护要求。

**审查要点**：
- 核查油田是否位于黄河三角洲湿地保护区
- 检查入海排污口设置是否合法

### 5.5 河北

**特殊要求**：
1. **京津冀协同保护要求**：位于京津冀生态保护区的油田，执行更严的排放限值。
2. **雄安新区周边保护**：位于雄安新区周边的油田，要求采用最先进的环保工艺。

### 5.6 辽宁（辽河油田）

**特殊要求**：
1. **辽河流域保护**：位于辽河流域的油田，执行辽河流域特别排放限值。
2. **盘锦湿地保护**：位于盘锦湿地的油井，要求加强溢油风险防控。

### 5.7 甘肃（玉门油田等）

**特殊要求**：
1. **祁连山生态保护**：位于祁连山自然保护区的油井，要求关闭或逐步退出。
2. **干旱区地下水保护**：要求加强地下水监测。

### 5.8 广东、福建、浙江、江苏、上海、北京

**特殊要求**：
- 这些省市石油开采活动较少（主要为炼化），如有石油开采活动，参照各省地方标准执行。

## 六、多工序企业标准适用指南

### 6.1 典型多工序石油开采企业

一个石油开采企业可能同时具有以下工序：
1. **石油开采工序**（主体工程）
2. **原油集输工序**（配套工程）
3. **原油储存工序**（配套工程）
4. **燃煤/燃气锅炉工序**（供热）
5. **油田伴生天然气利用工序**（综合利用）
6. **石油炼制工序**（如有炼厂，独立法人）

### 6.2 标准适用原则

| 工序 | 适用技术规范 | 标准号 |
|-----|------------|-------|
| 石油开采 | 《排污许可证申请与核发技术规范 石油开采》 | HJ 947-2018 |
| 原油集输 | 同上 | HJ 947-2018 |
| 原油储存 | 同上 | HJ 947-2018 |
| 锅炉 | 《排污许可证申请与核发技术规范 锅炉》 | HJ 953-2018 |
| 天然气利用 | 《排污许可证申请与核发技术规范 天然气开采》 | HJ 948-2018 |

### 6.3 审查要点

1. **完整识别所有工序**：审查时确保企业所有产排污工序均在许可证中体现。
2. **集输管线信息**：原油集输管线可能产生跑冒滴漏，应在许可证中说明防控措施。
3. **储罐信息**：原油储罐的数量、容量、呼吸阀类型等应完整填报。
4. **停产井信息**：长期停产的油井，也应在许可证中说明。

## 七、真实审批拒绝案例

### 案例1：含油污泥类别判断错误案

**基本情况**：
- 企业：新疆某石油开采企业
- 管理类别：重点管理
- 拒绝原因：含油污泥填报为一般工业固体废物，实际应为危险废物

**审查发现**：
该企业钻井和采油过程中产生的含油污泥，主要成分为石油类污染物，属于《国家危险废物名录》中的HW08类危险废物。但企业许可证申请材料中，将含油污泥填报为一般工业固体废物，未按危险废物管理要求填报贮存、处置、利用信息。

**整改措施**：
将含油污泥更正为危险废物（HW08），补充填报危险废物贮存场信息、委托处置单位信息等。

**教训**：
审查时应注意识别危险废物，对照《国家危险废物名录》逐一核对。

### 案例2：采出水石油类限值错误案

**基本情况**：
- 企业：陕西某石油开采企业
- 管理类别：重点管理
- 拒绝原因：采出水石油类排放限值未按 GB 39727-2020 执行

**审查发现**：
该企业采出水外排口石油类排放限值填报为10mg/L（引用GB 8978-1996三级标准），但 GB 39727-2020《陆上石油天然气开采工业水污染物排放标准》规定，直接排放限值为石油类 5mg/L（现有企业）、3mg/L（新建企业）。该企业属于现有企业，应执行 5mg/L 限值。

**整改措施**：
按 GB 39727-2020 重新核定石油类排放限值。

**教训**：
行业标准发布后，应优先执行行业标准，而非国家标准中的通用规定。

### 案例3：地下水监测遗漏案

**基本情况**：
- 企业：黑龙江某石油开采企业
- 管理类别：重点管理
- 拒绝原因：未填报地下水监测要求

**审查发现**：
该企业位于松嫩平原，地下水是当地重要饮用水源。对照 HJ 947-2018，石油开采企业应填报地下水监测要求，包括监测点位、监测因子、监测频次等。但企业许可证申请材料中未填报任何地下水监测信息。

**整改措施**：
补充填报地下水监测方案，设置不少于3个地下水监测井，监测因子包括pH、总硬度、溶解性总固体、氯化物、石油类、挥发性酚类等，监测频次为每半年1次。

**教训**：
石油开采企业可能发生地下水污染，地下水监测是许可证必备内容。

## 十、边缘情况处理指南

### 边缘情况1：采出水全部回注

**情形描述**：油田采出水全部回注地下，无外排口。

**处理原则**：
- 无外排口时，废水排放口可不填报，但应在许可证中说明采出水回注方案
- 回注井信息应完整填报（位置、数量、回注层位、回注压力等）
- 审查时注意核实回注层的适宜性，避免污染地下水

### 边缘情况2：老油田增产措施

**情形描述**：老油田进行压裂、酸化等增产措施，产生增产作业废水。

**处理原则**：
- 增产作业废水应作为临时排放口管理
- 压裂返排液应妥善处理处置，优先回用
- 审查时注意增产作业废水的产生量、处置方式

### 边缘情况3：海上油田陆上终端

**情形描述**：海上油田的陆上终端（处理厂）位于陆域。

**处理原则**：
- 陆上终端按石油开采行业管理
- 适用技术规范和排放标准与陆上油田相同
- 审查时注意与海上部分的衔接

### 边缘情况4：油田与炼厂一体化

**情形描述**：企业既有石油开采，又有石油炼制。

**处理原则**：
- 石油开采和石油炼制分别适用不同的技术规范
- 应分别填报产排污信息
- 审查时注意两个工序的排放标准衔接

### 边缘情况5：位于饮用水水源保护区

**情形描述**：油田井场位于饮用水水源保护区内。

**处理原则**：
- 位于一级保护区内：禁止新建油井，现有油井应关闭
- 位于二级保护区内：现有油井应执行最严格的防控措施，逐步退出
- 审查时发现此类情况，应告知生态环境部门处理
