# 手工纸制造行业技术审查深度指南

> **行业代码**：C2233（归入纸制品制造）  
> **技术规范**：HJ 852-2017《排污许可证申请与核发技术规范 造纸行业》  
> **适用行业**：手工纸制造 — 宣纸、书画纸、皮纸、麻纸等传统手工纸  
> **版本**：v1.0  
> **发布日期**：2026年

---

## 一、行业概述与技术路线

### 1.1 行业定义

手工纸制造指采用传统手工工艺，以植物纤维为原料，经浸泡、蒸煮、捣碓、抄造等工序制成纸张的生产活动。

**主要产品类别**：
1. **宣纸**：安徽泾县特产，以青檀皮和沙田稻草为原料
2. **书画纸**：以竹、麻、草类纤维为原料
3. **皮纸**：以树皮纤维为原料（如构树皮、桑树皮）
4. **麻纸**：以麻类纤维为原料
5. **其他传统手工纸**：如云南东巴纸、四川竹纸等

**行业特点**：
- 生产规模小，通常为作坊式生产
- 污染负荷相对较轻，但蒸煮工序仍产生废水
- 部分企业位于环境敏感区（如风景名胜区、水源保护区）

### 1.2 典型生产工艺

#### 工艺路线：传统宣纸制造

```
原料准备（青檀皮、稻草） → 浸泡 → 蒸煮 → 天然漂白（日晒雨淋） → 捣碓 → 打浆 → 抄纸 → 晾晒 → 整理 → 成品
```

**产污环节**：
- 蒸煮：废气（H₂S、NH₃等）、废水（COD、SS、色度）
- 天然漂白：无化学品，污染轻
- 抄纸：废水（白水，含SS）
- 晾晒：无污染

**重点提示**：
- 传统手工纸制造**无漂白工序**（采用天然漂白），不产生AOX
- 蒸煮废水量小，但通常未经处理直接排放（需重点审查）

## 二、行业特征因子核对表

### 2.1 废水排放因子

| 排放环节 | 必填因子 | 可选因子 | 备注 |
|---------|---------|---------|------|
| 蒸煮废水 | pH、COD、BOD₅、SS、色度 | 氨氮 | 排放量小，但浓度高 |
| 抄纸白水 | pH、COD、SS | - | 可循环利用 |
| 生活污水 | pH、COD、BOD₅、NH₃-N、SS | TN、TP | 生活污水处理设施排口 |

**重点提示**：
- 手工纸制造**无漂白工序**，不产生AOX，无需填报AOX因子
- 天然漂白（日晒雨淋）不产生废水

### 2.2 废气排放因子

| 排放源 | 必填因子 | 可选因子 | 适用标准 |
|-------|---------|---------|---------|
| 蒸煮废气 | H₂S、NH₃、臭气浓度 | - | GB 14554-93 |
| 锅炉（如有） | SO₂、NOx、颗粒物 | - | GB 13271-2014 |
| 厂界无组织 | H₂S、NH₃、臭气浓度 | - | GB 14554-93 |

**重点提示**：
- 蒸煮废气以恶臭气体为主，需填报H₂S、NH₃、臭气浓度
- 小规模企业可能无锅炉，采用自然晾晒

### 2.3 噪声排放因子

| 噪声源 | 必填因子 |
|-------|---------|
| 厂界噪声 | 昼间Leq、夜间Leq |

### 2.4 固体废物

| 废物类别 | 必填信息 | 备注 |
|---------|---------|------|
| 一般工业固体废物 | 种类、产生量、利用处置方式 | 废纤维、废纸边角料 |

**重点提示**：
- 手工纸制造不产生危险废物（无油墨、无化学品）
- 废纤维可综合利用

## 三、监测频次决策树

### 3.1 废水监测频次决策树

```
开始
  ↓
有废水排放口？
  ├─ 否 → 无需填报废水监测要求
  └─ 是 ↓
      排水量是否小于100 t/d？
        ├─ 是 → 简化管理：季度手工监测
        └─ 否 → 重点管理：月度手工监测
```

**重点提示**：
- 手工纸制造企业规模小，通常排水量小于100 t/d，可按简化管理
- 如位于环境敏感区，需提高监测频次

### 3.2 废气监测频次决策树

```
开始
  ↓
有废气排放口？
  ├─ 否 → 无需填报废气监测要求
  └─ 是 ↓
      是锅炉废气？
        ├─ 是 → 季度手工监测（简化管理）
        └─ 否 ↓
            是蒸煮废气？
              ├─ 是 → 半年手工监测（恶臭气体）
              └─ 否 → 无组织废气：半年手工监测
```

## 四、排放标准适用指南

### 4.1 废水排放标准

**适用标准**：
- 如企业有制浆工序（蒸煮），执行GB 3544-2008《制浆造纸工业水污染物排放标准》
- 如企业仅抄纸（无制浆），执行GB 8978-1996《污水综合排放标准》

**重点提示**：
- 手工纸制造企业通常有蒸煮工序（制浆），应执行GB 3544-2008
- 但排水量小，可与地方生态环境部门沟通，执行GB 8978-1996或地方标准

### 4.2 废气排放标准

**蒸煮废气**：
- 执行GB 14554-1993《恶臭污染物排放标准》
- H₂S：0.06 mg/m³（厂界）
- NH₃：1.5 mg/m³（厂界）
- 臭气浓度：20（无量纲，厂界）

**锅炉废气**：
- 执行GB 13271-2014《锅炉大气污染物排放标准》

## 五、常见错误TOP 10

### 错误1：错误适用GB 3544-2008

**表现**：小规模手工纸制造企业（排水量<100 t/d）执行GB 3544-2008，限值过严。

**正确做法**：可与地方生态环境部门沟通，执行GB 8978-1996或地方标准。

### 错误2：AOX因子误填

**表现**：手工纸制造企业填报AOX因子。

**正确做法**：手工纸制造无漂白工序，不产生AOX，无需填报AOX因子。

### 错误3：监测频次填报过高

**表现**：小规模手工纸制造企业填报月度监测。

**正确做法**：排水量小、污染轻的企业，可按简化管理填报季度监测。

### 错误4：蒸煮废水未处理直接排放

**表现**：企业蒸煮废水未处理直接排放，不符合环保要求。

**正确做法**：蒸煮废水需处理达标后排放，或回用。

### 错误5：恶臭气体遗漏

**表现**：蒸煮工序未填报H₂S、NH₃、臭气浓度。

**正确做法**：蒸煮工序产生恶臭气体，需填报H₂S、NH₃、臭气浓度。

### 错误6：天然漂白未说明

**表现**：企业采用天然漂白（日晒雨淋），但未在许可证中说明。

**正确做法**：在"其他信息"中说明采用天然漂白，无化学品使用。

### 错误7：抄纸白水未说明回用

**表现**：企业抄纸白水未回用，直接排放。

**正确做法**：抄纸白水应回用，在许可证中载明回用率。

### 错误8：位于环境敏感区但未特别说明

**表现**：企业位于风景名胜区、水源保护区等环境敏感区，但未在许可证中特别说明。

**正确做法**：在"其他信息"中说明企业位于环境敏感区，执行更严排放标准。

### 错误9：固体废物信息填报不全

**表现**：未填报废纤维、废纸边角料的产生量、处置方式。

**正确做法**：废纤维、废纸边角料属于一般工业固体废物，需填报。

### 错误10：许可证副本附件不全

**表现**：未附平面布置图、工艺流程图（尤其是蒸煮、抄纸工序）。

**正确做法**：许可证副本必须附相关图纸，缺一不可。

## 六、省份差异要求

### 6.1 安徽省（宣纸主产区）

**特别要求**：
1. **泾县**：宣纸传统产地，企业需执行《宣纸传统制作技艺保护条例》
2. **排放标准**：可与地方生态环境部门沟通，执行较宽松标准（考虑传统工艺保护）
3. **废水治理**：鼓励采用生物处理工艺，保护青弋江水质
4. **固体废物**：废纤维需综合利用，不得焚烧
5. **文化遗产保护**：排污许可证需与传统制作技艺保护相协调

**审查要点**：
- 核查企业是否位于泾县传统产区
- 排放标准是否与传统工艺保护相协调

### 6.2 浙江省（书画纸主产区）

**特别要求**：
1. **富阳**：书画纸主产区，企业需执行《富阳市书画纸行业环境污染整治方案》
2. **废水治理**：蒸煮废水需处理达标后排放
3. **锅炉废气**：执行DB33/2147-2018，NOx≤100 mg/m³
4. **固体废物**：废纤维需综合利用

**审查要点**：
- 核查企业废水治理设施运行情况
- 锅炉废气是否达标

## 七、多工序企业标准适用指南

### 7.1 典型多工序组合

手工纸制造企业通常涉及的多工序：
1. **手工纸制造 + 书画创作**：部分企业兼营书画创作
2. **手工纸制造 + 旅游观光**：部分企业位于风景名胜区，兼营旅游观光

### 7.2 标准适用原则

**原则**：手工纸制造执行GB 3544-2008或GB 8978-1996，旅游观光无污染物排放无需执行排放标准。

## 八、真实审批拒绝案例

### 案例1：蒸煮废水未处理导致退回

**企业基本情况**：
- 企业名称：某宣纸厂
- 行业：手工纸制造
- 管理类别：简化管理
- 主要工序：蒸煮、抄纸

**拒绝原因**：
蒸煮废水未处理直接排放，不符合环保要求。

**审查发现**：
1. 企业有蒸煮工序，产生蒸煮废水
2. 蒸煮废水未处理直接排放入附近溪流
3. 不符合GB 3544-2008要求

**整改要求**：
安装蒸煮废水治理设施，确保达标排放。

**经验总结**：
手工纸制造企业蒸煮废水需处理达标后排放，审查时需重点核查治理设施。

### 案例2：AOX因子误填导致退回

**企业基本情况**：
- 企业名称：某书画纸厂
- 行业：手工纸制造
- 管理类别：简化管理
- 主要工序：蒸煮、抄纸

**拒绝原因**：
许可证申请材料中填报了AOX因子，不适用。

**审查发现**：
1. 企业采用天然漂白，无化学品漂白工序
2. 不产生AOX，无需填报AOX因子
3. 申请材料误填AOX因子

**整改要求**：
删除AOX因子。

**经验总结**：
手工纸制造无漂白工序，不产生AOX，审查时需核对生产工艺。

### 案例3：恶臭气体遗漏导致退回

**企业基本情况**：
- 企业名称：某皮纸厂
- 行业：手工纸制造
- 管理类别：简化管理
- 主要工序：蒸煮、抄纸

**拒绝原因**：
蒸煮工序未填报恶臭气体（H₂S、NH₃、臭气浓度）。

**审查发现**：
1. 企业有蒸煮工序，使用石灰蒸煮
2. 蒸煮废气含H₂S、NH₃等恶臭气体
3. 申请材料未填报恶臭气体因子

**整改要求**：
补充恶臭气体因子（H₂S、NH₃、臭气浓度）。

**经验总结**：
蒸煮工序产生恶臭气体，需填报H₂S、NH₃、臭气浓度，审查时需核对产污环节。

## 十一、边缘情况处理指南

### 11.1 天然漂白（日晒雨淋）

**情况描述**：企业采用天然漂白，无化学品使用。

**处理方案**：
1. 在"其他信息"中说明采用天然漂白
2. 无需填报AOX因子
3. 天然漂白场地需防雨淋径流污染

### 11.2 蒸煮废水回用

**情况描述**：企业蒸煮废水回用，无排放口。

**处理方案**：
1. 无需填报蒸煮废水排放口
2. 在"其他信息"中说明：蒸煮废水全部回用，无排放口
3. 提供水平衡图，证明废水全部回用

### 11.3 位于环境敏感区

**情况描述**：企业位于风景名胜区、水源保护区等环境敏感区。

**处理方案**：
1. 在"其他信息"中说明企业位于环境敏感区
2. 执行更严排放标准（如地方标准）
3. 提高监测频次

### 11.4 小规模企业无监测能力

**情况描述**：企业规模极小，无监测能力。

**处理方案**：
1. 按简化管理填报
2. 监测可委托第三方监测机构
3. 自行监测方案需明确委托监测机构名称和资质

### 11.5 传统工艺保护与环境监管协调

**情况描述**：传统手工纸制造工艺需保护，但需符合环保要求。

**处理方案**：
1. 与地方生态环境部门沟通，执行较宽松标准
2. 在许可证中载明传统工艺保护要求
3. 鼓励企业采用清洁生产工艺
