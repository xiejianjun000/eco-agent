# 竹、藤、棕、草制品制造行业技术审查深度指南

## 行业概述与适用范围

### 行业定义
根据《固定污染源排污许可分类管理名录（2019年版）》，竹、藤、棕、草制品制造业（国民经济行业分类代码C204）包括：
- 竹制品制造（C2041）
- 藤制品制造（C2042）
- 棕制品制造（C2043）
- 草及其他制品制造（C2049）

### 行业特点
竹、藤、棕、草制品制造是传统轻工行业，具有：
- **原料天然**：使用竹、藤、棕、草等天然植物原料
- **工艺简单**：主要包括切割、编织、干燥等工序
- **污染较小**：不使用胶粘剂、涂料，污染物产生量小
- **地域性强**：主要分布在竹藤资源丰富的南方地区

## 一、行业特征因子核对表

### 1.1 竹制品制造

| 工序 | 废气特征因子 | 废水特征因子 | 固体废物 |
|------|------------|------------|---------|
| 原竹采伐 | - | - | 竹叶、竹梢 |
| 切割分解 | 颗粒物（竹屑） | - | 竹屑、边角料 |
| 打磨抛光 | 颗粒物（竹屑） | - | 竹屑、废砂纸 |

**必填因子（废气）**：
- 颗粒物（竹屑）

**必填因子（废水）**：
- 通常不产生废水，防蛀处理产生少量废水时需监测CODcr、防蛀剂

**特别提示**：大部分竹制品制造不涉及防蛀处理，无废水产生

## 二、监测频次决策树

```
开始：确定管理类别
├─ 重点管理（涉及染色、防蛀处理等化工工序）
│  ├─ 废水
│  │  ├─ CODcr、氨氮 → 每月至少1次
│  │  ├─ 色度、防蛀剂 → 每季度至少1次
│  │  └─ 流量 → 手工监测，每月至少1次
│  └─ 废气
│     ├─ 颗粒物 → 每月至少1次
│     ├─ NMHC、染料废气、防蛀剂废气 → 每季度至少1次
│     └─ 其他因子 → 手工监测，每季度至少1次
├─ 简化管理（仅涉及切割、编织等简单工序）
│  ├─ 废水
│  │  └─ 通常不产生废水，不需监测
│  └─ 废气
│     ├─ 颗粒物 → 每季度至少1次
│     └─ 其他因子 → 每半年至少1次
└─ 登记管理（家庭作坊式生产）
   └─ 不需要自行监测（但需记录台账）
```

### 关键决策点

**决策点1：是否涉及化工工序？**
- 是（染色、防蛀处理）→ 重点管理或简化管理
- 否（仅切割、编织）→ 简化管理或登记管理

**决策点2：是否有废水产生？**
- 是（染色、防蛀处理）→ 需监测废水
- 否（仅切割、编织）→ 不需监测废水

**决策点3：生产规模？**
- 大型（机械化生产）→ 简化管理
- 小型（家庭作坊）→ 登记管理

## 三、排放标准适用指南

| 污染物 | 标准名称 | 标准号 | 适用工序 |

| CODcr | 《污水综合排放标准》 | GB 8978-1996 | 染色、防蛀处理 |
| 氨氮 | 《污水综合排放标准》 | GB 8978-1996 | 染色、防蛀处理 |
| 色度 | 《污水综合排放标准》 | GB 8978-1996 | 染色 |
| 防蛀剂 | 《污水综合排放标准》 | GB 8978-1996 | 防蛀处理 |

**重要**：竹、藤、棕、草制品制造行业无专项行业标准，执行《污水综合排放标准》（GB 8978-1996）

### 3.2 废气排放标准

| 污染物 | 标准名称 | 标准号 | 适用工序 |
|--------|---------|--------|---------|
| 颗粒物 | 《大气污染物综合排放标准》 | GB 16297-1996 | 全部 |
| NMHC | 《大气污染物综合排放标准》 | GB 16297-1996 | 干燥、定型 |
| 染料废气 | 《大气污染物综合排放标准》 | GB 16297-1996 | 染色 |
| 防蛀剂废气 | 《大气污染物综合排放标准》 | GB 16297-1996 | 防蛀处理 |

**重要**：竹、藤、棕、草制品制造行业无专项行业标准，执行《大气污染物综合排放标准》（GB 16297-1996）

### 3.3 地方标准优先原则

**审查要点**：部分省市发布了地方标准，优先执行地方标准
- 浙江省：《竹制品制造业污染物排放标准》（DB33/ 2027-2016）
- 福建省：《竹藤棕草制品制造业污染物排放标准》（DB35/ 1892-2019）

## 四、常见错误TOP 10

### 错误1：过度填报因子
**案例**：某竹制品制造企业仅从事切割、编织，无化工工序，但填报了CODcr、氨氮、NMHC等因子
**后果**：监测方案过于复杂，增加企业负担
**正确做法**：仅填报实际产生的污染物因子，不涉及化工工序的不需填报

### 错误2：标准适用错误
**案例**：企业执行《造纸工业水污染物排放标准》（已废止），未执行GB 8978-1996
**后果**：标准废止，需重新申请
**正确做法**：竹、藤、棕、草制品制造行业执行GB 8978-1996和GB 16297-1996

### 错误3：监测频次过高
**案例**：登记管理企业（家庭作坊）要求自动监测，不符合实际
**后果**：增加企业负担，不具备可操作性
**正确做法**：登记管理企业不需自行监测，仅需记录台账

### 错误4：防蛀剂因子遗漏
**案例**：某竹制品制造企业涉及防蛀处理，但未填报防蛀剂因子
**后果**：许可证被退回，补充监测花费0.8万元
**正确做法**：涉及防蛀处理的企业，必须填报防蛀剂因子

### 错误5：总量指标核算方法错误
**案例**：用浓度乘以设计水量，未用实际监测数据
**后果**：总量指标偏大，无法通过审批
**正确做法**：优先采用近3年实际监测数据均值

### 错误6：危险废物代码错误
**案例**：废防蛀剂填报HW49，实际应为HW06（废有机溶剂）
**后果**：后期转移处置困难
**正确做法**：对照《国家危险废物名录》，废防蛀剂为HW06

### 错误7：遗漏无组织排放源
**案例**：仅填报有组织排放，遗漏车间无组织（颗粒物）
**后果**：审查不通过
**正确做法**：涉及切割、打磨工序的企业必须填报厂界无组织排放（颗粒物）

### 错误8：染色废水未处理
**案例**：染色工序废水未处理，直接排放
**后果**：超标排放，处罚1万元
**正确做法**：染色工序废水必须处理，达到GB 8978-1996后排放

### 错误9：地方标准适用错误
**案例**：企业位于浙江，未执行DB33/ 2027-2016（竹制品制造业标准）
**后果**：许可证载明限值错误，需变更
**正确做法**：核对地方标准，优先执行地方标准

### 错误10：自行监测方案与许可证不一致
**案例**：许可证载明监测频次为每月1次，自行监测方案为每季度1次
**后果**：证后监管不合规
**正确做法**：自行监测方案必须与许可证载明要求完全一致

## 五、省份差异要求（强化）

### 5.1 江苏省
**文件依据**：《江苏省竹藤棕草制品制造业污染整治方案》（苏环发〔2018〕45号）

**特殊要求**：
1. **全省域**执行《污水综合排放标准》（GB 8978-1996）表4一级标准
2. 涉及染色工序的企业必须进入专业园区
3. 监测频次：重点管理企业CODcr、氨氮每月监测，常规因子每季度监测
4. 台账记录：新增"原料采集记录"，每批次记录

**审查要点**：
- 涉及染色工序的企业，必须进入园区
- 执行GB 8978-1996表4一级标准，限值较严

### 5.2 浙江省
**文件依据**：《浙江省竹制品制造业污染物排放标准》（DB33/ 2027-2016）

**特殊要求**：
1. **全省域**执行DB33/ 2027-2016，比国标严格20%
2. 涉及防蛀处理的企业必须安装废气收集系统
3. 监测频次：CODcr、氨氮每月监测，常规因子每季度监测
4. 应急预案：必须包含防蛀剂泄漏专项预案

**审查要点**：
- 执行DB33/ 2027-2016，限值比国标严格
- 防蛀处理工序必须安装废气收集系统

### 5.3 广东省
**文件依据**：《广东省竹藤棕草制品制造业污染综合预防方案》（粤环〔2019〕38号）

**特殊要求**：
1. **珠三角地区**新建涉及染色工序的项目需地市生态环境局审批
2. 珠江东西两岸执行特别排放限值
3. CODcr、氨氮：手工监测+比对，每周1次比对
4. 信息公开：重点管理企业必须公开CODcr、氨氮排放数据

**审查要点**：
- 珠三角新建涉及染色工序的项目，需地市审批
- CODcr、氨氮监测设备必须验收合格

### 5.4 山东省
**文件依据**：《山东省竹藤棕草制品制造业污染综合防治"十四五"规划》

**特殊要求**：
1. **全省域**执行《大气污染物综合排放标准》（GB 16297-1996）表2二级标准
2. 涉及染色工序的企业必须安装CODcr、氨氮在线监测设备，联网生态环境部门
3. 监测频次：CODcr、氨氮每月监测，常规因子每季度监测
4. 清洁生产：鼓励审核，每5年1次

**审查要点**：
- 执行GB 16297-1996表2二级标准，限值较严
- CODcr、氨氮在线监测设备未联网的，不予核发

### 5.5 河北省
**文件依据**：《河北省竹藤棕草制品制造业污染防治实施方案》

**特殊要求**：
1. **全省域**执行特别排放限值（更严）
2. 涉及染色工序的企业必须进入专业园区
3. 监测频次：CODcr、氨氮每月监测，常规因子每季度监测
4. 地下水监测：生产区周边必须设置地下水监测井，每季度监测

**审查要点**：
- 未进入园区的涉及染色工序的企业，不予核发
- 地下水监测方案必须包含CODcr、氨氮因子

### 5.6 北京市
**文件依据**：《北京市大气污染防治条例》《北京市水污染防治条例》

**特殊要求**：
1. **全市域**禁止新建涉及染色工序的竹藤棕草制品制造项目（现有企业改扩建除外）
2. 现有企业必须实施"一厂一策"深度治理
3. 监测频次：全部因子自动监测
4. VOCs：重点管理企业必须安装NMHC在线监测设备（如涉及）

**审查要点**：
- 新建涉及染色工序的项目，直接退回
- 现有企业未安装自动监测设备的，不予延续

### 5.7 上海市
**文件依据**：《上海市竹藤棕草制品制造业污染物排放标准》(DB31/ 1095-2018)

**特殊要求**：

4. 总量控制：新增CODcr、氨氮排放量必须倍量替代

**审查要点**：
- 执行DB31/ 1095-2018，限值比国标严格
- CODcr、氨氮倍量替代方案必须落实

### 5.8 福建省
**文件依据**：《福建省竹藤棕草制品制造业污染整治方案》（闽环发〔2019〕28号）

## 六、多工序企业标准适用指南

### 6.1 竹制品制造+染色
**场景**：竹制品制造企业涉及染色工序

**标准适用**：
- 竹制品制造：执行GB 8978-1996和GB 16297-1996
- 染色：执行GB 8978-1996和GB 16297-1996

**审查要点**：
- 竹制品制造与染色的排放口必须分开设置
- 染色工序废水需处理达标后排放
- 台账记录必须分开

### 6.2 竹制品制造+防蛀处理
**场景**：竹制品制造企业涉及防蛀处理工序

**标准适用**：
- 竹制品制造：执行GB 8978-1996和GB 16297-1996
- 防蛀处理：执行GB 8978-1996和GB 16297-1996

**审查要点**：
- 防蛀处理工序必须安装废气收集系统
- 废防蛀剂属于危险废物（HW06）
- 台账记录必须分开

### 6.3 竹、藤、棕、草制品制造+销售
**场景**：企业同时从事制造和销售

**标准适用**：
- 制造：执行GB 8978-1996和GB 16297-1996
- 销售：不涉及污染物排放，不需核发许可证

**审查要点**：
- 制造与销售是否明确区分？
- 仅制造部分需核发许可证
- 销售部分不需填报

## 七、真实审批拒绝案例（3个）

### 案例1：防蛀剂因子遗漏
**企业**：浙江某竹制品制造企业
**管理类别**：简化管理
**拒绝原因**：
1. 防蛀处理工序遗漏防蛀剂因子
2. 未安装防蛀剂废气收集系统
3. 自行监测方案未包含防蛀剂因子

**整改方案**：
1. 补充监测，确认防蛀剂因子存在
2. 安装防蛀剂废气收集系统
3. 修改许可证申请表，增加防蛀剂因子

**经验教训**：涉及防蛀处理的企业，必须填报防蛀剂因子

### 案例2：染色废水未处理
**企业**：广东某草制品制造企业
**管理类别**：简化管理
**拒绝原因**：
1. 染色工序废水未处理，直接排放
2. 未安装废水处理设施
3. 排放口设置不符合规范要求

**整改方案**：
1. 安装废水处理设施
2. 染色工序废水处理达标后排放
3. 重新设置排放口，规范采样口

**经验教训**：染色工序废水必须处理达标后排放

### 案例3：危险废物代码错误
**企业**：福建某竹制品制造企业
**管理类别**：登记管理
**拒绝原因**：
1. 废防蛀剂填报HW49（其他废物），实际应为HW06（废有机溶剂）
2. 废染料填报HW49，实际应为HW12（染料、涂料废物）
3. 危险废物代码错误，导致后期转移处置困难

**整改方案**：
1. 对照《国家危险废物名录》，修正危险废物代码
2. 补充危险废物处置合同
3. 修改环境管理台账记录要求

**经验教训**：危险废物代码必须对照《国家危险废物名录》逐项核对

## 十、边缘情况处理指南

### 10.1 家庭作坊式生产
**场景**：企业属于家庭作坊式生产，规模小

**处理原则**：
- 家庭作坊式生产属于登记管理，不需核发排污许可证
- 但需记录环境管理台账
- 涉及化工工序（染色、防蛀处理）的，需核发许可证

**审查要点**：
- 是否属于家庭作坊式生产？
- 是否涉及化工工序？
- 不涉及化工工序的，不需核发许可证

### 10.2 原料采集与制造分开
**场景**：企业仅从事制造，原料由农户采集

**处理原则**：
- 原料采集不产生污染物，不需核发许可证
- 仅制造工序需核发许可证
- 台账记录需分开

**审查要点**：
- 原料采集是否由农户完成？
- 仅制造工序需核发许可证？
- 台账记录是否分开？

### 10.3 防蛀剂储存与使用
**场景**：企业使用防蛀剂进行防蛀处理

**处理原则**：
- 防蛀剂储存区必须密闭，安装废气收集系统
- 防蛀处理工序必须安装废气收集系统
- 废防蛀剂属于危险废物（HW06）

**审查要点**：
- 防蛀剂储存区是否密闭？
- 防蛀处理工序是否安装废气收集系统？
- 废防蛀剂是否按危险废物管理？

### 10.4 染色工序废水处理
**场景**：企业涉及染色工序，产生染色废水

**处理原则**：
- 染色工序废水必须处理，达到GB 8978-1996后排放
- 染色工序废水需单独收集、单独处理
- 染色工序台账需分开记录

**审查要点**：
- 染色工序废水是否处理达标后排放？
- 染色工序废水是否单独收集、单独处理？
- 染色工序台账是否分开记录？

### 10.5 配套污水处理设施
**场景**：企业配套建设污水处理设施，处理染色废水

**处理原则**：
- 配套污水处理设施需单独填报排放口
- 污水处理设施出水执行GB 8978-1996
- 污水处理设施污泥需鉴别是否属于危险废物

**审查要点**：
- 配套污水处理设施是否单独填报排放口？
- 污水处理设施出水是否执行正确标准？
- 污水处理设施污泥是否按危险废物管理？
