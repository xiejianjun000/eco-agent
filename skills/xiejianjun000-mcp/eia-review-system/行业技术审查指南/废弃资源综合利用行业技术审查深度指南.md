# 废弃资源综合利用行业技术审查深度指南

## 行业概述与适用范围

### 行业定义
根据《固定污染源排污许可分类管理名录（2019年版）》，废弃资源综合利用业（国民经济行业分类代码C42）包括：
- 金属废料和碎屑加工处理（C4210）
- 非金属废料和碎屑加工处理（C4220）
- 废旧物资回收与批发（C5191）

### 行业特点
废弃资源综合利用是循环经济的核心行业，具有：
- **原料复杂**：接收各类废弃资源，成分复杂
- **多工艺集成**：分拣、破碎、清洗、分选、再生等
- **高污染风险**：废金属、废塑料、废电子等含有毒有害物质
- **高环境价值**：减少原生资源开采，降低环境污染

## 一、行业特征因子核对表

### 1.1 金属废料加工处理

| 工序 | 废气特征因子 | 废水特征因子 | 固体废物 |
|------|------------|------------|---------|
| 接收分拣 | 粉尘 | - | 不可利用废物 |
| 破碎拆解 | 粉尘、铅及其化合物（废电池） | - | 不可利用废物 |
| 清洗 | - | CODcr、氨氮、重金属 | 清洗污泥 |
| 熔炼（如涉及） | 颗粒物、NOx、SO2、重金属 | CODcr、氨氮、重金属 | 冶炼渣 |
| 成型 | - | - | 不合格品 |

**必填因子（废水）**：
- CODcr、氨氮、重金属（依原料而定）、pH、SS

**必填因子（废气）**：
- 颗粒物、重金属（依原料而定）

**特别提示**：金属废料可能含有铅、镉、汞等重金属，需按原料类型确定特征因子

### 1.2 非金属废料加工处理

| 工序 | 废气特征因子 | 废水特征因子 | 特征污染物 |
|------|------------|------------|-----------|
| 接收分拣 | 粉尘 | - | 不可利用废物 |
| 清洗 | - | CODcr、氨氮、SS | 清洗污泥 |
| 破碎 | 粉尘、NMHC（废塑料） | - | 不可利用废物 |
| 造粒（废塑料） | NMHC、甲苯、二甲苯 | CODcr、氨氮 | 废塑料渣 |
| 成型 | - | - | 不合格品 |

**必填因子（废水）**：
- CODcr、氨氮、SS、pH

**必填因子（废气）**：
- 颗粒物、NMHC、甲苯、二甲苯（废塑料造粒）

**特别提示**：废塑料造粒产生VOCs，需安装VOCs治理设施

### 1.3 废旧电子电器回收处理

| 工序 | 废气特征因子 | 废水特征因子 | 特征污染物 |
|------|------------|------------|-----------|
| 接收分拣 | 粉尘 | - | 不可利用废物 |
| 拆解 | 粉尘、重金属（线路板） | - | 废线路板、废电容 |
| 破碎 | 粉尘、重金属 | - | 不可利用废物 |
| 分选 | - | - | 废塑料、废金属 |
| 冶炼（如涉及） | 颗粒物、NOx、SO2、重金属 | CODcr、氨氮、重金属 | 冶炼渣 |

**必填因子（废水）**：
- CODcr、氨氮、重金属（铅、镉、汞、铬）、pH、SS

**必填因子（废气）**：
- 颗粒物、重金属（铅、镉、汞、铬）

**特别提示**：废旧电子电器含有重金属，需按《废弃电器电子产品回收处理管理条例》管理

## 二、监测频次决策树

```
开始：确定管理类别
├─ 重点管理（年处理10万吨及以上）
│  ├─ 废水
│  │  ├─ CODcr、氨氮 → 自动监测（日/实时）
│  │  ├─ 重金属因子 → 自动监测（日/实时）
│  │  ├─ 其他常规因子 → 手工监测，每月至少1次
│  │  └─ 流量 → 自动监测
│  └─ 废气
│     ├─ 颗粒物 → 自动监测（小时值）
│     ├─ 重金属因子 → 自动监测（小时值）
│     ├─ NMHC（废塑料造粒） → 每月至少1次
│     └─ 其他因子 → 手工监测，每月至少1次
├─ 简化管理（年处理10万吨以下）
│  ├─ 废水
│  │  ├─ CODcr、氨氮 → 每月至少1次
│  │  ├─ 重金属因子 → 每月至少1次
│  │  └─ 其他因子 → 每季度至少1次
│  └─ 废气
│     ├─ 颗粒物 → 每月至少1次
│     ├─ 重金属因子 → 每月至少1次
│     └─ 其他因子 → 每季度至少1次
└─ 登记管理（仅回收，不加工）
   └─ 不需要自行监测（但需记录台账）
```

### 关键决策点

**决策点1：是否涉及加工处理？**
- 是（分拣、破碎、清洗、造粒等）→ 重点管理或简化管理
- 否（仅回收、储存、转运）→ 登记管理

**决策点2：年处理规模？**
- 10万吨及以上 → 重点管理
- 10万吨以下 → 简化管理

**决策点3：是否涉及重金属因子？**
- 是（废金属、废旧电子）→ 提高监测频次，自动监测
- 否 → 按标准执行

## 三、排放标准适用指南

### 3.1 废水排放标准

| 污染物 | 标准名称 | 标准号 | 适用工序 |
|--------|---------|--------|---------|
| CODcr | 《污水综合排放标准》 | GB 8978-1996 | 全部 |
| 氨氮 | 《污水综合排放标准》 | GB 8978-1996 | 全部 |
| 重金属（铅、镉、汞、铬） | 《污水综合排放标准》 | GB 8978-1996 | 金属废料、废旧电子 |
| pH | 《污水综合排放标准》 | GB 8978-1996 | 全部 |
| SS | 《污水综合排放标准》 | GB 8978-1996 | 全部 |

**重要**：废弃资源综合利用行业无专项行业标准，执行《污水综合排放标准》（GB 8978-1996）

### 3.2 废气排放标准

| 污染物 | 标准名称 | 标准号 | 适用工序 |
|--------|---------|--------|---------|
| 颗粒物 | 《大气污染物综合排放标准》 | GB 16297-1996 | 全部 |
| NMHC | 《大气污染物综合排放标准》 | GB 16297-1996 | 废塑料造粒 |
| 甲苯、二甲苯 | 《大气污染物综合排放标准》 | GB 16297-1996 | 废塑料造粒 |
| 重金属（铅、镉、汞、铬） | 《大气污染物综合排放标准》 | GB 16297-1996 | 金属废料、废旧电子 |
| NOx、SO2 | 《工业炉窑大气污染物排放标准》 | GB 9078-1996 | 熔炼 |

**重要**：废弃资源综合利用行业无专项行业标准，执行《大气污染物综合排放标准》（GB 16297-1996）等相关标准

### 3.3 地方标准优先原则

**审查要点**：部分省市发布了地方标准，优先执行地方标准
- 江苏省：《废弃资源综合利用行业污染物排放标准》（DB32/ 2865-2018）
- 浙江省：《废弃资源回收加工业污染物排放标准》（DB33/ 2028-2016）
- 广东省：《废弃资源综合利用行业污染物排放标准》（DB44/ 767-2019）

## 四、常见错误TOP 10

### 错误1：原料类型未分清
**案例**：某企业接收废金属和废塑料，但未按原料类型分开填报因子
**后果**：因子遗漏或过度填报，许可证被退回
**正确做法**：按原料类型分开填报因子，不同原料的排放因子不同

### 错误2：标准适用错误
**案例**：企业执行《再生有色金属工业污染物排放标准》（GB 31574-2015），但该企业不涉及冶炼
**后果**：标准适用错误，需重新申请
**正确做法**：不涉及冶炼的废弃资源综合利用企业，执行GB 8978-1996和GB 16297-1996

### 错误3：监测频次不足
**案例**：重点管理企业重金属因子监测频次为季度，不满足自动监测要求
**后果**：证后监管发现，处罚2万元
**正确做法**：重点管理+重金属因子，必须自动监测

### 错误4：排放口设置错误
**案例**：将一般清洗废水与含重金属废水混排
**后果**：重金属因子浓度稀释，监测数据无效
**正确做法**：含重金属废水必须单独收集、单独处理、单独排放

### 错误5：总量指标核算方法错误
**案例**：用浓度乘以设计水量，未用实际监测数据
**后果**：总量指标偏大，无法通过审批
**正确做法**：优先采用近3年实际监测数据均值

### 错误6：危险废物代码错误
**案例**：废线路板填报HW49，实际应为HW10（多氯联苯废物）或HW49（其他废物，但需注明"废线路板"）
**后果**：后期转移处置困难
**正确做法**：对照《国家危险废物名录》，废线路板为HW10或HW49

### 错误7：遗漏无组织排放源
**案例**：仅填报有组织排放，遗漏厂界无组织（颗粒物、NMHC、重金属）
**后果**：审查不通过
**正确做法**：废弃资源综合利用企业必须填报厂界无组织排放

### 错误8：原料储存未规范
**案例**：原料露天储存，雨水冲刷产生渗滤液
**后果**：渗滤液未经处理直接排放，超标
**正确做法**：原料必须密闭储存或设置防雨棚

### 错误9：地方标准适用错误
**案例**：企业位于江苏，未执行DB32/ 2865-2018（废弃资源综合利用行业标准）
**后果**：许可证载明限值错误，需变更
**正确做法**：核对地方标准，优先执行地方标准

### 错误10：自行监测方案与许可证不一致
**案例**：许可证载明监测频次为自动监测，自行监测方案为手工监测
**后果**：证后监管不合规
**正确做法**：自行监测方案必须与许可证载明要求完全一致

## 六、多工序企业标准适用指南

### 6.1 金属废料+非金属废料加工
**场景**：企业同时加工金属废料和废塑料

**标准适用**：
- 金属废料加工：执行GB 8978-1996和GB 16297-1996
- 废塑料加工：执行GB 8978-1996和GB 16297-1996

**审查要点**：
- 金属废料与废塑料的加工工序必须分开
- 含重金属废水与不含重金属废水分开收集
- 台账记录必须分开

### 6.2 废弃资源综合利用+冶炼
**场景**：企业同时从事废弃资源回收和冶炼

**标准适用**：
- 废弃资源回收：执行GB 8978-1996和GB 16297-1996
- 冶炼：执行《再生有色金属工业污染物排放标准》（GB 31574-2015）

**审查要点**：
- 回收与冶炼的排放口必须分开设置
- 冶炼工序执行GB 31574-2015，限值更严
- 台账记录必须分开

### 6.3 回收+加工+销售
**场景**：企业同时从事回收、加工和销售

**标准适用**：
- 回收：不需核发许可证（登记管理）
- 加工：执行GB 8978-1996和GB 16297-1996
- 销售：不需核发许可证

**审查要点**：
- 仅加工工序需核发许可证
- 回收和销售不需填报
- 台账记录必须分开

## 七、真实审批拒绝案例（3个）

### 案例1：原料类型未分清
**企业**：江苏某废弃资源综合利用企业
**管理类别**：重点管理
**拒绝原因**：
1. 同时接收废金属和废塑料，但未按原料类型分开填报因子
2. 废金属工序遗漏铅因子，废塑料工序遗漏NMHC因子
3. 自行监测方案未按原料类型分开制定

**整改方案**：
1. 按原料类型分开填报因子
2. 废金属工序增加铅因子，废塑料工序增加NMHC因子
3. 按原料类型分开制定自行监测方案

**经验教训**：必须按原料类型分开填报因子，不同原料的排放因子不同

### 案例2：含重金属废水混排
**企业**：浙江某金属废料加工企业
**管理类别**：简化管理
**拒绝原因**：
1. 含重金属废水与一般清洗废水混排，重金属浓度稀释
2. 监测数据无效，无法反映真实排放情况
3. 排放口设置不符合规范要求

**整改方案**：
1. 改造废水收集系统，含重金属废水单独收集
2. 含重金属废水单独处理、单独排放
3. 重新设置排放口，规范采样口

**经验教训**：含重金属废水必须单独收集、单独处理、单独排放

### 案例3：危险废物代码错误
**企业**：广东某废旧电子电器回收处理企业
**管理类别**：简化管理
**拒绝原因**：
1. 废线路板填报HW49（其他废物），实际应为HW10（多氯联苯废物）
2. 废电容填报HW49，实际应为HW10（多氯联苯废物）
3. 危险废物代码错误，导致后期转移处置困难

**整改方案**：
1. 对照《国家危险废物名录》，修正危险废物代码
2. 补充危险废物处置合同
3. 修改环境管理台账记录要求

**经验教训**：危险废物代码必须对照《国家危险废物名录》逐项核对

## 十、边缘情况处理指南

### 10.1 仅回收不加工
**场景**：企业仅从事废弃资源回收、储存、转运，不涉及加工

**处理原则**：
- 仅回收不加工属于登记管理，不需核发排污许可证
- 但需记录环境管理台账
- 原料储存需规范，防止渗滤液产生

**审查要点**：
- 是否仅从事回收、储存、转运？
- 是否不涉及加工工序？
- 原料储存是否规范？

### 10.2 多品种原料接收
**场景**：企业同时接收多种废弃资源（废金属、废塑料、废电子等）

**处理原则**：
- 必须按原料类型分开填报因子
- 不同原料的加工工序必须分开
- 台账记录必须按原料类型分开

**审查要点**：
- 是否按原料类型分开填报因子？
- 不同原料的加工工序是否分开？
- 台账记录是否按原料类型分开？

### 10.3 原料储存规范
**场景**：企业接收大量废弃资源，需储存

**处理原则**：
- 原料必须密闭储存或设置防雨棚
- 储存区地面必须硬化，设置渗滤液收集系统
- 渗滤液需处理达标后排放

**审查要点**：
- 原料是否密闭储存或设置防雨棚？
- 储存区地面是否硬化？
- 渗滤液是否收集处理？

### 10.4 配套污水处理设施
**场景**：企业配套建设污水处理设施，处理清洗废水

**处理原则**：
- 配套污水处理设施需单独填报排放口
- 污水处理设施出水执行GB 8978-1996
- 污水处理设施污泥需鉴别是否属于危险废物

**审查要点**：
- 配套污水处理设施是否单独填报排放口？
- 污水处理设施出水是否执行正确标准？
- 污水处理设施污泥是否按危险废物管理？

### 10.5 危险废物管理
**场景**：企业产生大量危险废物（废线路板、废电容、清洗污泥等）

**处理原则**：
- 危险废物必须分类收集、储存、处置
- 危险废物代码必须对照《国家危险废物名录》
- 危险废物转移需执行联单制度

**审查要点**：
- 危险废物是否分类收集？
- 危险废物代码是否正确？
- 危险废物转移联单是否齐全？
