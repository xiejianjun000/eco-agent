## 一、行业概述与排污节点分析

### 1.1 行业范围界定

"其他电子设备制造"是《国民经济行业分类》（GB/T 4754-2017）中"计算机、通信和其他电子设备制造业"大类下的兜底类别，涵盖所有未被前述5个行业明确覆盖的电子设备制造活动。

**典型涵盖范围**：

| 细分类别 | 具体产品 | 污染特征 |
|---------|---------|---------|
| 电子专用设备制造 | 自动化设备、半导体设备、贴片机 | SMT废气+VOCs |
| 电子测量仪器制造 | 信号发生器、示波器、频谱分析仪 | SMT废气为主 |
| 工业自动控制系统装置制造 | PLC、DCS、工控机 | SMT废气+VOCs |
| 智能消费设备制造 | 智能手表、智能眼镜、无人机 | SMT+VOCs（表面处理） |
| 电气信号设备制造 | 交通信号设备、安防监控设备 | SMT+VOCs |
| 电子游戏设备制造 | 游戏机、VR设备 | SMT+VOCs（外壳喷涂） |
| 电子竞技设备制造 | 电竞键盘、电竞鼠标 | SMT+VOCs（RGB灯效喷涂） |
| 电子教育设备制造 | 教育平板、电子白板 | SMT+VOCs（触摸屏贴合） |
| 卫星通信设备制造 | 卫星电话、卫星接收器 | SMT+电镀（高频连接器） |
| 雷达及配套设备制造 | 气象雷达、车载雷达 | SMT+电镀（精密零件） |
| 可穿戴智能设备制造 | 智能手环、AR/VR头显 | SMT+VOCs |
| 电子信息产品制造（其他） | 未分类的电子产品 | 综合特征 |

### 1.2 管理类别判断

| 企业类型 | 管理类别 | 依据 |
|---------|---------|------|
| 其他电子设备制造（年用溶剂量≥10吨） | 重点管理 | 名录第66项，VOCs重点排放 |
| 其他电子设备制造（年用溶剂量＜10吨，无电镀） | 简化管理 | 名录第66项 |
| 其他电子设备制造（含表面喷涂） | 重点管理 | 名录第66项，VOCs重点排放 |
| 其他电子设备制造（含电镀工序） | 重点管理 | 名录第66项，含电镀 |
| 仅进行电子设备组装测试（无化学品） | 登记管理 | 名录第66项 |

**关键判断节点**：
- 有无SMT贴片工序 → 焊锡烟尘
- 有无表面喷涂工序 → VOCs（外壳、功能性涂层）
- 有无电镀/化学镀工序 → 重金属
- 有无清洗工序 → COD、VOCs（有机溶剂）
- 年用溶剂量是否≥10吨 → VOCs监测级别
- 是否涉及智能穿戴设备（功能涂层、点胶） → VOCs

## 三、监测频次决策树

### 3.1 水污染物监测频次决策树

```
开始
│
├─ 是否排放生产废水？
│   ├─ 否 → 仅填报生活污水
│   └─ 是 → 继续判断
│
├─ 是否含电镀/化学镀工序？
│   ├─ 是 → 重金属因子（总铜、总银、总金、总镍、六价铬）
│   │        总铜、六价铬：自动监测（重点管理+直接排放）
│   │        其他重金属：手工监测，每月1次
│   └─ 否 → 跳至下一步
│
├─ 是否直接排放？
│   ├─ 是 → pH值、COD、氨氮自动监测
│   │        其他因子手工监测，每月1次
│   └─ 否 → 所有因子手工监测，每季度1次
│
└─ 是否年用溶剂≥10吨？
    ├─ 是 → 总排口COD、氨氮自动监测
    └─ 否 → 手工监测即可
```

## 四、排放标准适用指南

### 4.1 水污染物排放标准体系

```
优先层级：
1. 地方排放标准（广东DB 44/1597、江苏DB 32/3841、浙江DB 33/887等）
   ↓（如无覆盖）
2. GB 21900-2008《电镀污染物排放标准》（含电镀工序）
   ↓（如无电镀）
3. GB 8978-1996《污水综合排放标准》
```

### 4.2 大气污染物排放标准

**GB 16297-1996《大气污染物综合排放标准》**（基准）：

| 污染物 | 最高允许排放浓度 | 备注 |
|--------|----------------|------|
| 颗粒物 | 120 mg/m³ | 焊接、金属加工 |
| 锡及其化合物 | 8.0 mg/m³（以Sn计） | SMT焊接 |
| 铅及其化合物 | 0.9 mg/m³（以Pb计） | 含铅焊锡 |
| 苯 | 12 mg/m³ | 溶剂型涂料 |
| 甲苯 | 40 mg/m³ | 喷涂溶剂 |
| 二甲苯 | 70 mg/m³ | 喷涂溶剂 |
| 非甲烷总烃（NMHC） | 120 mg/m³（参照） | VOCs综合控制 |

## 五、常见错误TOP 10（其他电子设备制造业）

### 错误1：智能消费设备企业遗漏点胶工序VOCs因子

**错误描述**：智能手表、AR/VR等智能消费设备制造涉及大量点胶工序（防水密封、元器件固定），VOCs排放被忽视。

**正确做法**：
- 点胶使用的胶水（聚氨酯、环氧树脂）含有机溶剂
- 防水涂层（纳米涂层）可能涉及VOCs排放
- 须识别点胶工序VOCs因子（VOCs、甲苯、二甲苯等）
- 须根据年用溶剂量（点胶材料中有机组分）判断VOCs监测级别

---

### 错误2：电竞设备制造企业RGB灯效喷涂VOCs遗漏

**错误描述**：电竞键盘、电竞鼠标等电竞设备大量使用RGB灯效喷涂（多彩涂层），VOCs排放被当作"装饰工艺"忽视。

**正确做法**：
- 电竞设备RGB喷涂同样产生大量VOCs
- 涂层中溶剂含量可达30%-50%
- 须填报VOCs因子，并根据年用溶剂量确定监测级别
- 电竞设备制造企业近年来快速增长，污染不容忽视

---

### 错误3：电子专用设备制造企业SMT工序废气因子遗漏

**错误描述**：电子专用设备（如贴片机、半导体设备）制造涉及大量SMT贴片，但企业未填报焊锡烟尘因子。

**正确做法**：
- SMT回流焊、波峰焊产生焊锡烟尘（锡及其化合物）
- 须填报锡及其化合物和颗粒物因子
- 电子专用设备制造企业SMT贴片量往往较大（板卡面积大、焊点多）
- 焊锡烟尘处理须设置除尘系统

---

### 错误4：无人机/智能穿戴企业遗漏清洗工序VOCs

**错误描述**：无人机、智能手环等精密产品制造使用大量酒精、丙酮清洗，但VOCs排放被忽视。

**正确做法**：
- 精密电子设备制造使用无水乙醇、异丙醇、丙酮清洗PCB和外壳
- 清洗工序有机溶剂挥发是重要的VOCs排放源
- 须填报乙醇、丙酮等清洗剂VOCs因子
- 清洗工序应设置废气收集系统

---

### 错误5：工业自动控制系统装置制造企业VOCs监测频次不足

**错误描述**：年用溶剂12万元的工业控制系统企业认为溶剂用量小，未安装VOCs监测设备。

**正确做法**：
- VOCs监测频次以年用溶剂量（质量/吨）为准，而非金额
- 年用溶剂量≥10吨 → 自动监测（重点管理）
- 年用溶剂量＜10吨 → 手工监测（每季度1次，重点管理）
- 须准确核算年用溶剂质量（吨），不得以金额代替

---

### 错误6：卫星通信设备制造企业遗漏高频连接器电镀因子

**错误描述**：卫星通信设备（高频连接器、射频同轴连接器）涉及镀银/镀金工艺，被当作"普通连接器"未填报重金属。

**正确做法**：
- 高频连接器须镀银/镀金以提高导电性和抗腐蚀性
- 镀银/镀金通常为电镀工艺，产生含银/含金废水
- 须填报总银、总金因子
- 镀银/镀金电镀液含氰化物，须严格管控含氰废水

---

### 错误7：电子游戏设备制造企业危废管理不规范

**错误描述**：游戏机制造使用大量塑料注塑、喷涂，产生废涂料桶、废胶水桶，但未按危废管理。

**正确做法**：
- 废涂料桶 → HW12（264-012-12），危废
- 废胶水桶 → HW12（264-012-12），危废
- 废电路板 → HW49（900-045-49），危废
- 须签订危废处置合同

---

### 错误8：雷达设备制造企业遗漏精密加工切削液因子

**错误描述**：雷达天线精密零件加工使用切削液，产生含油废水，但未填报石油类因子。

**正确做法**：
- 雷达精密零件（如铝合金天线罩）加工使用切削液（矿物油）
- 切削液清洗废水含石油类污染物
- 须填报石油类因子
- 切削液废液应按HW09危废管理

---

### 错误9：电子专用设备制造企业误判管理类别

**错误描述**：电子专用设备制造企业认为自己属于"专用设备制造"（如C34类），应适用不同的排污许可管理名录。

**正确做法**：
- 电子专用设备（如贴片机、半导体设备）属于"计算机、通信和其他电子设备制造业"（C39类）
- 须适用《固定污染源排污许可分类管理名录》第66项（其他电子设备制造）
- 不得按"专用设备制造业"（C35类）申请排污许可

---

### 错误10：间接排放企业特征因子监测缺失

**错误描述**：废水排入污水管网的间接排放企业大幅降低监测频次，特征重金属（如有）未监测。

**正确做法**：
- 间接排放仍须满足GB 8978-1996三级标准（或地方纳管标准）
- 特征重金属（如有电镀）须持续监测
- 提供与污水厂签订的接纳协议

## 六、省份差异要求（强化版）

### 6.1 广东省（珠三角其他电子设备产业聚集区）

**核心要求**：广东省是全国最大的智能消费设备、无人机、电子游戏设备制造聚集地（深圳、东莞、广州、惠州）。

**水污染物地方标准**：
- **DB 44/1597-2015《广东省电镀水污染物排放标准》**：
  - 适用于含镀银/镀金/化学镀工序的其他电子设备企业（卫星通信、雷达等）
  - 总铜：0.3 mg/L（现有）
  - 六价铬：0.05 mg/L（极严）
  - 总银：0.3 mg/L（适用于镀银连接器企业）

**大气污染物地方标准**：
- **DB 44/865-2011《广东省大气污染物排放限值》**：
  - VOCs排放参照电子行业标准从严
- 深圳市：智能消费设备、电子游戏设备VOCs排放须满足SZJG 51-2017标准

## 八、真实审批拒绝案例

### 案例1：广东省某电竞键盘制造企业VOCs因子严重遗漏

**基本信息**：
- 企业：广东省东莞市某电竞键盘制造企业
- 管理类别：重点管理（年用溶剂量约45吨）
- 问题发现：2024年7月技术审查退件

**拒绝理由**：
1. **VOCs监测因子严重不足**：企业RGB灯效喷涂年用溶剂45吨（多彩涂层溶剂），申报材料仅填报非甲烷总烃（NMHC），遗漏甲苯、二甲苯、乙酸乙酯等主要组分因子（合计占总溶剂量60%以上）。

2. **VOCs自动监测未安装**：年用溶剂45吨（远超国家标准10吨门槛），应安装VOCs自动监测设备，但企业仅申报手工监测每季度1次。

3. **RGB喷涂废气收集不完善**：企业有8个RGB喷涂工位，但废气收集系统仅覆盖4个工位，4个工位废气直排。

4. **危废管理不规范**：废涂料桶（HW12）未按危废管理，与一般工业固废混放。

**整改要求**：
1. 补充甲苯、二甲苯、乙酸乙酯等特征因子
2. 安装VOCs自动监测设备并联网
3. 改造RGB喷涂工位废气收集系统，覆盖全部8个工位
4. 废涂料桶按HW12危废管理

**经验教训**：电竞设备制造企业的RGB喷涂用溶剂量极大（远超手机制造），须充分识别VOCs组分并安装在线监测设备。

---

### 案例2：江苏省某工业自动控制系统装置制造企业SMT因子遗漏

**基本信息**：
- 企业：江苏省苏州市某工业自动化控制系统装置制造企业
- 管理类别：简化管理（年用溶剂量约3吨，无电镀）
- 问题发现：2024年10月技术审查退件

**拒绝理由**：
1. **SMT贴片工序废气因子遗漏**：企业SMT贴片工序年使用焊锡约2.5吨，产生大量焊锡烟尘，但申报材料完全未填报锡及其化合物和颗粒物因子。

2. **生产废水量填报不准确**：企业年排放生产废水约1200吨，但申报材料填报废水排放量为"0"。

3. **清洗工序VOCs因子遗漏**：企业使用乙醇、丙酮清洗PCB板，年用溶剂约3吨，但未填报清洗工序VOCs因子。

**整改要求**：
1. 补充锡及其化合物、颗粒物因子（SMT贴片工序）
2. 修正废水排放量申报数据
3. 补充清洗工序VOCs（乙醇、丙酮）因子
4. 简化管理企业须按HJ 915-2017要求填报监测方案

**经验教训**：工业自动控制系统装置制造企业虽规模相对较小，但SMT贴片工序和清洗工序污染不容忽视，不能以"组装"为由规避申报。

---

### 案例3：北京市某AR/VR设备制造企业VOCs严重超标

**基本信息**：
- 企业：北京市海淀区某AR/VR头显制造企业
- 管理类别：重点管理（年用溶剂量约22吨）
- 问题发现：2024年5月现场核查，暂缓发证

**拒绝/暂缓理由**：
1. **VOCs排放严重超标**：实测排放浓度为58 mg/m³，超出DB 11/501-2017要求的20 mg/m³（海淀区为科技教育核心区）的2.9倍。

2. **光学贴合工序VOCs未收集**：AR/VR头显制造涉及触摸屏与显示屏光学贴合（OCA光学胶），使用大量有机溶剂，但贴合工位废气未收集处理，直接无组织排放。

3. **在线监测未安装**：企业年用溶剂量22吨（远超北京市1吨门槛），应安装VOCs在线监测设备，但企业未安装。

4. **防水涂层工序VOCs因子遗漏**：AR/VR设备防水涂层使用聚氨酯涂层液，含大量VOCs，但企业未填报。

**整改措施**：
1. 改造光学贴合工位废气收集系统
2. 改造防水涂层工位废气收集系统
3. 新增活性炭吸附+催化燃烧处理设施
4. 安装VOCs在线监测设备并联网至北京市生态环境局平台
5. 补充光学贴合和防水涂层VOCs因子
6. 整改完成后重新申报

**经验教训**：AR/VR等新兴智能消费设备的制造工序多样（光学贴合、防水涂层、功能涂层），须逐一识别各工序的VOCs排放源，不能遗漏任何一道使用有机溶剂的工序。

## 十一、边缘情况处理指南

### 11.1 新兴电子设备制造（如智能眼镜、脑机接口设备）的工序识别

**问题**：智能眼镜、脑机接口等新兴电子设备制造涉及特殊工艺（如光波导镀膜、柔性电路印刷），无现有标准覆盖。

**处理原则**：
- 按实际工序逐一识别污染因子，不拘泥于现有标准
- 光波导加工可能涉及镀膜（参照真空镀膜工序管理）
- 柔性电路印刷可能涉及导电油墨（含重金属风险）
- 须根据实际使用的化学品（参照MSDS）识别特征因子
- 新型工艺的污染控制可参照相近行业（如半导体、光学仪器）标准从严执行

---

### 11.2 电子专用设备制造中半导体设备废气特殊性

**问题**：半导体设备（如刻蚀机、CVD设备）制造涉及设备集成，可能包含半导体工艺腔体。

**处理原则**：
- 半导体设备整机制造≠半导体制造，不涉及硅烷等特殊气体排放
- 半导体设备装配过程中不产生半导体工艺废气
- 如涉及设备调试（使用工艺气体）→ 须识别相应废气因子
- 半导体设备外壳喷涂 → 参照普通VOCs管理

---

### 11.3 智能消费设备制造中防水纳米涂层的管理

**问题**：智能手表、手机等使用纳米防水涂层（如荷叶效应涂层），是否属于VOCs排放源。

**处理原则**：
- 纳米防水涂层分两类：
  - 热固化型（含溶剂）→ 产生VOCs，须核算
  - 等离子体型（物理方法）→ 无VOCs排放
- 须根据涂层施工工艺判断是否产生VOCs
- 热固化型防水涂层溶剂含量通常5%-20%，须如实核算

---

### 11.4 可穿戴智能设备制造中柔性电路清洗溶剂的处置

**问题**：柔性电路（FPC）制造使用清洗剂（含N-甲基吡咯烷酮NMP），如何识别VOCs因子。

**处理原则**：
- N-甲基吡咯烷酮（NMP）为高沸点有机溶剂，挥发性低于丙酮/乙醇，但仍属于VOCs
- NMP的VOCs排放量应基于其挥发量核算（而非全量计入）
- NMP废气须经废气收集系统处理后排放
- 须在MSDS中识别NMP成分并填报相关因子

---

### 11.5 其他电子设备制造企业跨行业经营的处理

**问题**：企业同时生产电子设备和机械设备（如激光切割机同时含电子控制部分和机械切割部分），如何适用排污许可管理。

**处理原则**：
- 按主要产品确定行业类别（产值最大的产品对应的行业）
- 如电子设备产值占主导 → 适用C39类（其他电子设备制造）
- 如机械设备产值占主导 → 须区分处理，可能涉及C35类（通用设备制造业）
- 多行业混合生产须分别核算各行业的产排污情况
- 建议企业在环评阶段明确行业归类

---

### 11.6 其他电子设备制造企业年用溶剂量核算方法

**问题**：其他电子设备制造企业使用的化学品品种繁多（如点胶胶水、清洗剂、涂料），如何准确核算年用溶剂量。

**处理原则**：
- 年用溶剂量 = 各种有机溶剂的使用量之和
- 有机溶剂含量以产品MSDS中VOCs含量（质量百分比）为依据
- 年用溶剂量（吨）= Σ（每种溶剂年用量 × VOCs质量分数）
- 企业须建立完整的化学品采购、使用、库存台账
- 对于VOCs含量不明确的混合物，须委托检测或向供应商索取证明
