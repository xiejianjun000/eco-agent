# 家具制造行业排污许可技术审查深度指南

> **适用范围**：本标准适用于GB/T 4754—2017中行业代码211—219的家具制造企业排污许可证申请与核发，包括木制家具、金属家具、塑料家具、软体家具等制造。
> **核心技术规范**：HJ 1026-2019《排污许可证申请与核发技术规范 家具制造》

### 1.2 VOCs特征因子识别（核心重点）

家具制造行业VOCs因子填报是最容易出错的环节，需按以下规则识别：

**第一步：识别涂料类型**

| 涂料类型 | 主要VOCs成分 | 特征因子 |
|---------|-----------|---------|
| 溶剂型聚氨酯涂料 | 甲苯二异氰酸酯（TDI）、二甲苯、乙酸丁酯、环己酮 | VOCs、甲苯、二甲苯、乙酸丁酯 |
| 溶剂型硝基涂料 | 甲苯、二甲苯、乙酸乙酯、丙酮 | VOCs、甲苯、二甲苯、丙酮 |
| 溶剂型醇酸涂料 | 二甲苯、200#溶剂油、松节油 | VOCs、二甲苯 |
| 水性聚氨酯涂料 | 少量助剂VOCs（一般<50g/L） | VOCs（按实测或物料衡算） |
| UV固化涂料 | 丙烯酸酯类（固化后无VOCs） | VOCs（很低，按实测） |
| 粉末涂料 | 无溶剂 | 无需填报VOCs |

**第二步：识别稀释剂/固化剂成分**
- 稀释剂通常含大量VOCs（占涂料总VOCs 20-50%）
- 必须要求企业提供涂料、稀释剂、固化剂的MSDS（化学品安全技术说明书）
- 按MSDS中的挥发性成分占比，确定特征因子

**第三步：确定填报因子**
- 占VOCs总量≥10%的成分，必须单独填报
- 苯系物（苯、甲苯、二甲苯）无论占比多少，必须单独填报（GB 16297-1996要求）
- 甲醛必须单独填报（GB 16297要求）

### 2.1 决策树逻辑

```
开始
│
├─ 排放口类型？
│  ├─ 主要排放口？
│  │  ├─ 焚烧类（RTO/RCO/TO/CO）？→ 自动监测（VOCs小时均值）
│  │  ├─ 非焚烧类（活性炭/光氧/水帘等）？
│  │  │  ├─ 重点管理？→ VOCs：季度监测；颗粒物：季度监测
│  │  │  └─ 简化管理？→ VOCs：半年1次；颗粒物：半年1次
│  │  └─ 燃烧废气（SO₂/NOx/颗粒物）？→ 自动监测（按锅炉/炉窑要求）
│  │
│  ├─ 一般排放口？
│  │  ├─ 重点管理？→ VOCs：季度监测；颗粒物：半年1次
│  │  └─ 简化管理？→ VOCs：半年1次；颗粒物：年1次
│  │
│  └─ 无组织排放监控点？
│     ├─ 重点管理？→ VOCs：季度监测；颗粒物：季度监测
│     └─ 简化管理？→ VOCs：半年1次；颗粒物：半年1次
│
└─ 特别注意：江苏省/浙江省/广东省等VOCs重点区域
   → 无组织VOCs监测频次：重点管理每月1次（地标要求）
```

| 重点管理 | 主要排放口（非焚烧类） | VOCs | 每季度1次 | HJ 1026-2019 5.2.2 |

### 2.3 VOCs监测频次特别说明

1. **自动监测安装要求**（HJ 1026-2019 5.2.2）：
   - 重点管理企业的VOCs主要排放口，排气量≥10000m³/h的，应安装VOCs在线监测（CEMS）
   - 排气量<10000m³/h的，可手工监测（季度）
   
2. **江苏省特别要求**：
   - 重点管理企业，所有VOCs排放口（无论排气量大小），均需安装VOCs在线监测
   - 无组织VOCs监控点，重点管理企业每月监测1次（按DB 32/4041-2021）

3. **广东省特别要求**：
   - VOCs排放口排气量≥20000m³/h的，需安装VOCs在线监测
   - 无组织VOCs监测频次：重点管理每月1次（按DB 44/814-2010）

## 三、排放标准适用指南

### 3.1 VOCs排放标准选择决策树

```
确定企业所在地
│
├─ 位于有地标（DB）的省份？
│  ├─ 是 → 优先执行地标（地标优于国标）
│  │  ├─ 江苏：DB 32/4041-2021（表面涂装）
│  │  ├─ 浙江：DB 33/2146-2018（工业涂装）
│  │  ├─ 广东：DB 44/814-2010（家具制造）
│  │  ├─ 山东：DB 37/2801.1-2018（VOCs排放）
│  │  ├─ 北京：DB 11/1202-2015（工业涂装）
│  │  ├─ 上海：DB 31/933-2015（大气污染物综合）
│  │  └─ 河北：DB 13/2322-2016（工业企业VOCs）
│  │
│  └─ 否 → 执行国标GB 16297-1996（大气污染物综合排放标准）
│
├─ 特别说明：GB 16297-1996已被部分替代
│  ├─ VOCs有专门标准的行业，执行专门标准
│  └─ 家具制造属于"表面涂装"类，优先执行地标
│
└─ 无组织排放执行标准
```

### 3.3 标准适用常见错误

| 错误类型 | 错误表现 | 正确做法 |
|---------|---------|---------|
| 地标未执行 | 企业位于江苏省，仍执行GB 16297-1996 | 必须执行DB 32/4041-2021 |
| 标准过期 | 执行已废止的标准（如DB 44/814-2010第I时段） | 执行最新有效版本 |
| 限值用错 | 有地标但用了国标限值（120mg/m³ vs 50mg/m³） | 地标限值更严，必须用严值 |
| 无组织限值遗漏 | 许可证只填了排气筒限值，未填无组织限值 | 必须同时填报排气筒和无组织限值 |

## 四、常见错误TOP 10

### 错误1：VOCs特征因子大量遗漏（出现频率：★★★★★）

**表现**：许可证只填了"VOCs"一个因子，未填报苯、甲苯、二甲苯、乙酸乙酯等特征因子。

**后果**：导致自行监测方案不完整，企业只监测VOCs总量，不监测特征因子，无法判断特征污染物是否达标。

**审查要点**：
- 要求企业提供所有涂料、稀释剂、固化剂的MSDS
- 检查MSDS中挥发性成分占比≥10%的物质，是否单独填报
- 苯系物（苯、甲苯、二甲苯）必须单独填报

**正确填报示例**：
```
某家具企业使用溶剂型聚氨酯面漆：
- MSDS显示：二甲苯（40%）、乙酸丁酯（25%）、环己酮（15%）、VOCs总量（85%）
- 正确填报因子：VOCs、二甲苯、乙酸丁酯、环己酮
```

### 错误2：监测频次不足（出现频率：★★★★★）

**表现**：重点管理企业，VOCs监测频次填报为"每半年1次"或"每年1次"。

**后果**：不符合HJ 1026-2019要求，技术审查不予通过。

**审查要点**：
- 重点管理+主要排放口：VOCs季度监测（非焚烧类）或自动监测（焚烧类）
- 重点管理+一般排放口：VOCs季度监测
- 简化管理：VOCs半年1次（可接受）

### 错误3：地方标准未执行（出现频率：★★★★☆）

**表现**：企业位于江苏省/浙江省/广东省等地标严格省份，许可证仍执行GB 16297-1996。

**后果**：限值宽松（120mg/m³ vs 50mg/m³），企业实际排放可能超标而许可证未管控。

**审查要点**：
- 审查时先查企业所在地是否有地标
- 有地标必须执行地标，且地标限值更严

### 错误4：无组织排放因子遗漏（出现频率：★★★★☆）

**表现**：许可证只填报了有组织排放口，未填报无组织排放监控点。

**后果**：厂界VOCs无组织排放未纳入许可管理，企业不监测厂界VOCs。

**审查要点**：
- 家具制造企业必须有厂界VOCs无组织监控点
- 木制家具还必须有厂界颗粒物无组织监控点
- 软体家具（使用胶黏剂）还必须有厂界甲醛无组织监控点

### 错误5：多工序企业标准适用错误（出现频率：★★★☆☆）

**表现**：企业同时有木工工序+涂装工序+胶黏工序，所有排放口都套用同一个标准。

**后果**：不同工序适用不同标准，混用导致限值错误。

**审查要点**：
- 涂装工序：执行表面涂装类地标（如DB 32/4041-2021）
- 木工工序（颗粒物）：执行GB 16297-1996或地标中颗粒物限值
- 胶黏工序（甲醛）：执行GB 16297-1996或地标中甲醛限值

### 错误6：排气量填报错误导致自动监测要求判断错误（出现频率：★★★☆☆）

**表现**：企业填报排气量<10000m³/h，规避VOCs在线监测安装要求。

**后果**：应该装CEMS的企业未装，监管缺失。

**审查要点**：
- 核对排风机额定风量（铭牌）
- 如无铭牌，按车间体积×换气次数估算
- 江苏省/广东省等地标严格要求，无论排气量大小均需安装CEMS

### 错误7：涂料用量与VOCs排放量核算不匹配（出现频率：★★★☆☆）

**表现**：企业年使用涂料100吨（溶剂型），但填报VOCs年排放量仅0.5吨。

**后果**：VOCs排放量核算明显偏低，疑似数据造假。

**审查要点**：
- 溶剂型涂料VOCs含量一般≥60%
- 100吨溶剂型涂料，VOCs产生量至少60吨
- 即使有治理设施（去除率90%），VOCs排放量也有6吨
- 核算公式：VOCs排放量 = 涂料用量×VOCs含量%×(1-治理设施去除率%)

### 错误8：治理设施去除效率填报错误（出现频率：★★★☆☆）

**表现**：活性炭吸附设施，填报去除效率95%。

**后果**：活性炭实际去除效率一般50-80%，95%明显偏高，涉嫌虚假填报。

**审查要点**：
- 活性炭吸附：去除效率50-80%（需提供检测报告）
- RTO焚烧：去除效率95-99%（可提供）
- UV光解：去除效率30-50%（低效，很多地标已不认可）
- 水帘+活性炭：去除效率40-60%

### 错误9：排放口编号/名称不规范（出现频率：★★☆☆☆）

**表现**：排放口编号随意编写（如"排口1""废气排放口"），未按要求编码。

**后果**：自行监测报告中的排放口无法与许可证对应，监管混乱。

**审查要点**：
- 排放口编号格式：FQ-XXXXXXXX（废气）+ 序号
- 例：FQ-320581-001（江苏省苏州市常熟市第1号废气排放口）

### 错误10：许可证有效期与环评批复不一致（出现频率：★★☆☆☆）

**表现**：环评批复要求"本项目建成后3年内重新申请排污许可证"，但许可证有效期填5年。

**后果**：许可证有效期超出环评限定，属于违规发证。

**审查要点**：
- 核对环评批复中的特殊要求
- 如环评限定了许可证有效期（如3年），必须按环评执行

## 五、省份差异要求（强化版）

### 5.1 江苏省（DB 32/4041-2021）

| 要求类别 | 具体要求 | 与国标差异 |
|---------|---------|-----------|
| VOCs有组织排放限值 | 50mg/m³（表面涂装） | 国标120mg/m³，江苏严2.4倍 |
| VOCs无组织排放限值（厂界） | 2.0mg/m³ | 国标5.0mg/m³，江苏严2.5倍 |
| VOCs无组织排放限值（厂区） | 6.0mg/m³（监控点） | 国标无此要求 |
| 自动监测安装 | 所有VOCs排放口均需安装CEMS | 国标仅要求≥10000m³/h |
| 监测频次（无组织） | 重点管理：每月1次 | 国标：每季度1次 |
| VOCs物料储存 | 必须密闭储存+氮封/呼吸阀 | 国标无此要求 |
| 台账保存期 | 不少于10年 | 国标5年 |

**审查特别注意**：

## 六、多工序企业标准适用指南

### 6.1 典型多工序家具制造企业

```
某家具制造企业工艺流程：
1. 木工工序（开料→机加工→打磨）→ 颗粒物
2. 涂装工序（前处理→底漆→面漆→烘干）→ VOCs+颗粒物
3. 胶黏工序（组装→贴合）→ VOCs+甲醛
4. 焊接工序（金属框架）→ 颗粒物+锰
5. 金属表面处理（前处理→电镀）→ 酸碱废气+重金属
```

### 6.2 多工序企业标准适用原则

**原则1：按工序分别适用标准**
- 木工工序（颗粒物）：执行GB 16297-1996表2颗粒物的限值（120mg/m³）
- 涂装工序（VOCs）：执行地表（如DB 32/4041-2021）中VOCs限值（50mg/m³）
- 胶黏工序（甲醛）：执行GB 16297-1996表2甲醛的限值（25mg/m³）
- 焊接工序（颗粒物）：执行GB 16297-1996或地标中颗粒物限值

**原则2：有地标优先执行地标**
- 涂装工序：地标（表面涂装类）优于GB 16297
- 木工工序：如无地标专门规定颗粒物，执行GB 16297

**原则3：限值从严**
- 同一污染物有多个标准可选时，选择限值最严的
- 例：VOCs既有GB 16297（120mg/m³）又有地标（50mg/m³），选择50mg/m³

### 6.3 审查案例

**案例：某江苏家具企业，有木工+涂装+胶黏三道工序**

| 排放口 | 污染物 | 错误适用标准 | 正确适用标准 |
|-------|-------|------------|------------|
| 木工车间排气筒 | 颗粒物 | DB 32/4041-2021（表面涂装标准，不适用） | GB 16297-1996或DB 32/XXX（江苏大气综排） |
| 喷漆室排气筒 | VOCs | GB 16297-1996（120mg/m³） | DB 32/4041-2021（50mg/m³） |
| 胶黏工位排气筒 | 甲醛 | 未填报（遗漏） | GB 16297-1996（25mg/m³） |
| 厂界监控点 | VOCs无组织 | GB 16297-1996（5.0mg/m³） | DB 32/4041-2021（2.0mg/m³） |

## 七、真实审批拒绝案例（3个）

### 案例1：VOCs特征因子大量遗漏，许可证被退回

**企业基本情况**：
- 名称：苏州市XX家具有限公司
- 行业：木制家具制造
- 管理类别：重点管理
- 主要工艺：木工+底漆+面漆+烘干

**拒绝原因**：
许可证申请材料中，涂装工序VOCs特征因子仅填报了"VOCs"总量，未填报苯、甲苯、二甲苯、乙酸乙酯、环己酮等特征因子。

经审查发现：
- 企业使用溶剂型聚氨酯面漆（MSDS显示：二甲苯40%、乙酸丁酯25%、环己酮15%）
- 底漆使用溶剂型硝基涂料（MSDS显示：甲苯20%、二甲苯30%、丙酮10%）
- 上述特征因子占VOCs总量≥10%，且苯系物必须单独管控

**整改要求**：
补充填报苯、甲苯、二甲苯、乙酸乙酯、乙酸丁酯、环己酮、丙酮等特征因子，并相应完善自行监测方案。

**经验教训**：
审查时必须要求企业提供涂料/稀释剂/固化剂的MSDS，按MSDS成分逐一核对特征因子是否遗漏。

### 案例2：监测频次不足，不符合技术规范

**企业基本情况**：
- 名称：佛山市XX家具有限公司
- 行业：金属家具制造
- 管理类别：重点管理
- VOCs治理设施：活性炭吸附

**拒绝原因**：
许可证申请表中，VOCs监测频次填报为"每半年1次"。

经审查发现：
- 企业属于重点管理
- HJ 1026-2019 5.2.2明确规定：重点管理企业的VOCs排放口，监测频次为每季度1次（非焚烧类治理设施）
- "每半年1次"不符合技术规范要求

**整改要求**：
将VOCs监测频次修改为"每季度1次"，并相应调整自行监测方案。

**经验教训**：
重点管理的VOCs排放口，监测频次必须按HJ 1026-2019要求执行（季度监测），不得降低频次。

### 案例3：地方标准未执行，限值过宽

**企业基本情况**：
- 名称：杭州市XX家具有限公司
- 行业：软体家具制造
- 管理类别：重点管理
- 所在地：浙江省杭州市

**拒绝原因**：
许可证执行标准填报为GB 16297-1996（VOCs 120mg/m³），未执行浙江省地标DB 33/2146-2018（VOCs 50mg/m³）。

经审查发现：
- 浙江省有DB 33/2146-2018《工业涂装工序大气污染物排放标准》
- 家具制造属于"工业涂装工序"范畴，应执行该地标
- 地标限值（50mg/m³）比国标（120mg/m³）严2.4倍
- 执行国标导致限值过宽，企业实际排放可能超标而许可证未管控

**整改要求**：
修改为执行DB 33/2146-2018，VOCs限值按50mg/m³填报，无组织限值按2.0mg/m³填报。

**经验教训**：
审查时先查地标，有地标必须执行地标，且要在许可证中载明地标标准号。

## 十、边缘情况处理指南

### 边缘情况1：企业使用多种涂料，VOCs特征因子如何确定？

**情况描述**：企业同时使用溶剂型聚氨酯涂料、水性涂料、UV固化涂料，MSDS成分差异大。

**处理方法**：
1. 按涂料类型分别识别VOCs特征因子
2. 各种涂料的特征因子合并去重，全部填报
3. 例：溶剂型聚氨酯（二甲苯、乙酸丁酯）+ 水性涂料（少量醇醚类）+ UV涂料（丙烯酸酯，固化后无VOCs）
   → 填报因子：VOCs、二甲苯、乙酸丁酯、醇醚类（如乙二醇丁醚）

### 边缘情况2：涂料MSDS不全，如何确定特征因子？

**情况描述**：企业无法提供完整MSDS，或MSDS未标明各成分占比。

**处理方法**：
1. 要求企业向涂料供应商索取完整MSDS（含成分及占比）
2. 如供应商无法提供，要求企业委托第三方检测机构检测涂料VOCs成分
3. 审查时暂按"VOCs总量+苯+甲苯+二甲苯"填报，备注"待检测后补充特征因子"
4. 在许可证执行要求中载明：企业必须在X年X月前完成涂料VOCs成分检测，并申请变更许可证

### 边缘情况3：使用粉末涂料，是否需要填报VOCs因子？

**情况描述**：企业使用粉末涂料（无溶剂），认为无需填报VOCs。

**处理方法**：
1. 粉末涂料确实无VOCs，无需填报VOCs因子
2. 但需确认：粉末涂料固化过程中是否产生其他污染物（一般无）
3. 如企业同时使用粉末涂料+少量溶剂型涂料（修补用），则需填报VOCs因子

### 边缘情况4：木工工序和涂装工序在同一车间，排放口如何设置？

**情况描述**：企业车间较小，木工打磨和涂装在同一车间，共用一套废气收集系统。

**处理方法**：
1. 原则上不同工序应分开收集、分开排放
2. 如确实无法分开，可共用排放口，但需合并填报污染物因子
3. 合并排放口的限值按"就高不就低"原则：按最严的标准执行
4. 例：木工（颗粒物120mg/m³）+ 涂装（VOCs 50mg/m³）→ 合并排放口需同时满足两个限值

### 边缘情况5：企业位于两省交界处，执行哪个省的地标？

**情况描述**：企业注册地在安徽省，但生产厂址在江苏省苏州市。

**处理方法**：
1. 按生产厂址所在地（江苏省）的地标执行
2. 排污许可证中"生产地址"一栏必须准确填写
3. 审查时按生产地址所在地地标审查
