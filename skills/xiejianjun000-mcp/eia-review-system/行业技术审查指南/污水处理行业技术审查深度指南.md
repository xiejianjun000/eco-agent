## 二、监测频次决策树

### 2.1 决策流程
```
开始
 ↓
排放口类型？
 ├─ 主要排放口（出水口） → 自动监测（流量、pH、COD、氨氮）
 ├─ 一般排放口（进水口） → 日监测
 └─ 无组织排放（厂界） → 季度监测
      ↓
污染物特性？
 ├─ 常规污染物（COD、氨氮） → 自动监测
 ├─ 重金属 → 月监测或季度监测
 └─ 粪大肠菌群 → 月监测
      ↓
处理工艺？
 ├─ 生物处理 → 按GB 18918-2002要求
 └─ 深度处理 → 增加总氮、总磷监测频次
```

### 2.3 自动监测设备安装要求
必须安装自动监测设备的情形：
1. 处理规模≥1万m³/d的污水处理厂：流量、pH、COD、氨氮
2. 处理规模<1万m³/d的污水处理厂：流量、pH、COD、氨氮（重点管理）
3. 排入封闭水域或重点流域的污水处理厂：增加总氮、总磷自动监测

## 三、排放标准适用指南

### 3.1 多标准适用原则
城镇污水处理厂可能同时执行多个排放标准，按以下顺序确定：
1. **地方标准**（严于国家标准时）
2. **国家标准**：GB 18918-2002《城镇污水处理厂污染物排放标准》
3. **行业标准**
4. **综合排放标准**

### 3.2 主要排放标准清单

#### （1）出水排放
- **国家标准**：GB 18918-2002《城镇污水处理厂污染物排放标准》
- **地方标准**：各省市地方标准（如DB31/445-2023上海、DB11/890-2012北京）
- **特别排放限值**：重点流域执行特别排放限值

#### （2）废气排放
- **恶臭**：GB 14554-1993《恶臭污染物排放标准》
- **挥发性有机物**：GB 37822-2019《挥发性有机物无组织排放控制标准》（若有VOCs排放）

#### （3）污泥处置
- **农用**：GB 4284-2018《农用污泥污染物控制标准》
- **填埋**：GB 16889-2008《生活垃圾填埋场污染控制标准》
- **焚烧**：GB 18485-2014《生活垃圾焚烧污染控制标准》

#### （4）噪声
- **厂界噪声**：GB 12348-2008《工业企业厂界环境噪声排放标准》

### 3.3 标准适用决策表
| 工艺环节 | 污染物类型 | 优先执行标准 | 备注 |
|---------|-----------|------------|------|
| 出水排放 | COD、氨氮、总氮、总磷 | GB 18918-2002或地方标准 |  |
| 废气排放 | 氨、硫化氢、臭气浓度 | GB 14554-1993 |  |
| 污泥处置 | 重金属、粪大肠菌群 | 按处置方式执行相应标准 |  |
| 厂界 | 噪声 | GB 12348-2008 |  |

### 3.4 排放标准分级
| 级别 | 适用条件 | 排放限值 |
|-----|---------|---------|
| 一级A | 排入GB 3838-2002Ⅲ类水域 | COD 50mg/L、氨氮5mg/L |
| 一级B | 排入GB 3838-2002Ⅴ类水域 | COD 60mg/L、氨氮8mg/L |
| 二级 | 排入GB 3838-2002Ⅵ类水域 | COD 100mg/L、氨氮25mg/L |
| 三级 | 排入城镇排水系统 | COD 120mg/L、氨氮- |

## 四、常见错误TOP 10

### 错误1：进水水质超标未记录
**表现**：进水COD、氨氮等指标超标，但未记录
**后果**：无法判断污水处理厂运行负荷
**正确做法**：每日监测进水水质，超标时记录并报告

### 错误2：自动监测设备安装不全
**表现**：处理规模≥1万m³/d，但未安装总氮、总磷自动监测
**案例**：只安装流量、pH、COD、氨氮自动监测
**后果**：不符合HJ 978-2018要求
**正确做法**：重点流域污水处理厂应安装总氮、总磷自动监测

### 错误3：排放标準适用错误
**表现**：执行废止标准或适用错误标准
**案例**：仍执行GB 18918-2002一级B，实际应执行一级A
**正确做法**：根据受纳水体功能确定排放标准级别

### 错误4：地方标准未执行
**表现**：地方标准严于国家标准，但未执行地方标准
**案例**：北京企业仍执行GB 18918-2002，未执行DB11/890-2012
**正确做法**：优先执行地方标准

### 错误5：污泥处置未填报
**表现**：污泥产生量、处置方式未填报
**后果**：污泥非法处置
**正确做法**：填报污泥产生量、处置方式、处置单位

### 错误6：粪大肠菌群监测频次不足
**表现**：粪大肠菌群监测频次低于月监测
**案例**：填报为季度监测
**正确做法**：按GB 18918-2002要求，月监测

### 错误7：恶臭气体未收集处理
**表现**：格栅间、沉砂池、污泥浓缩池等恶臭气体未收集处理
**后果**：厂界恶臭超标
**正确做法**：恶臭气体收集处理后排放

### 错误8：出水总氮、总磷超标
**表现**：出水总氮、总磷超标
**后果**：水体富营养化
**正确做法**：调整生物处理工艺，加强脱氮除磷

### 错误9：自行监测方案未制定
**表现**：未制定自行监测方案
**后果**：无法开展自行监测
**正确做法**：按HJ 978-2018制定自行监测方案

### 错误10：执行报告未按时提交
**表现**：季度执行报告下季度15日后提交
**后果**：按条例第37条处罚
**正确做法**：季度执行报告下季度15日前提交

## 六、多工序企业标准适用指南

### 6.1 多工序类型
城镇污水处理厂常见多工序组合：
1. **预处理+生物处理**：常规处理工艺
2. **预处理+生物处理+深度处理**：出水要求高时
3. **预处理+生物处理+污泥处置**：同时有污泥处置设施
4. **全工序**：预处理、生物处理、深度处理、污泥处置全部具备

### 6.2 标准适用原则
1. **分别识别**：每个工序分别识别适用的排放标准
2. **从严执行**：多个标准同时存在时，从严执行
3. **出水水质优先**：以保证出水水质达标为优先目标

### 6.3 典型多工序企业标准适用表
| 工序组合 | 出水标准 | 废气标准 | 污泥标准 |
|---------|---------|---------|---------|
| 预处理+生物处理 | GB 18918-2002 | GB 14554-1993 | GB 18918-2002 |
| 预处理+生物处理+深度处理 | 地方标准（更严） | GB 14554-1993 | GB 18918-2002 |
| 预处理+生物处理+污泥处置 | GB 18918-2002 | GB 14554-1993 | 按处置方式执行相应标准 |

### 6.4 审查要点
1. 多工序企业是否分别填报各工序的排放口
2. 各排放口是否执行正确的排放标准
3. 出水水质是否能稳定达标

## 七、真实审批拒绝案例（3个）

### 案例1：进水水质超标未记录导致许可证不予核发
**企业**：某县城镇污水处理厂
**时间**：2023年8月
**拒绝原因**：
- 进水COD、氨氮等指标多次超标，但未记录
- 未向生态环境部门报告
- 无法判断污水处理厂运行负荷

**整改措施**：
1. 补充记录进水水质超标情况
2. 制定进水水质超标应急预案
3. 重新提交申请材料

**经验教训**：
- 必须每日监测进水水质
- 超标时必须记录并报告

### 案例2：自动监测设备安装不全导致整改
**企业**：某市城镇污水处理厂（处理规模5万m³/d）
**时间**：2023年11月
**拒绝原因**：
- 未安装总氮、总磷自动监测设备
- 企业位于太湖流域，地方标准要求安装
- 不符合DB32/4440-2022要求

**整改措施**：
1. 补充安装总氮、总磷自动监测设备
2. 自动监测设备联网
3. 重新提交申请材料

**经验教训**：
- 重点流域污水处理厂应安装总氮、总磷自动监测
- 审查时必须核对地方标准要求

### 案例3：地方标准未执行导致不予许可
**企业**：某市城镇污水处理厂（位于北京市）
**时间**：2024年4月
**拒绝原因**：
- 执行GB 18918-2002一级A标准
- 未执行DB11/890-2012地方标准
- 地方标准严于国家标准

**整改措施**：
1. 修改执行标准为DB11/890-2012
2. 重新核定排放限值
3. 升级改造处理工艺

**经验教训**：
- 必须优先执行地方标准
- 审查时必须查阅企业所在省的地方标准

## 十、边缘情况处理指南

### 10.1 进水水质超标如何处理
**情形**：进水COD、氨氮等指标超标
**处理流程**：
1. 立即停止进水
2. 启动应急预案
3. 调整处理工艺参数
4. 仍无法处理时，退回上游排水单位
5. 向生态环境部门报告

**审查要点**：
- 进水水质超标应急预案是否已制定
- 超标时是否及时报告

### 10.2 出水水质超标如何处理
**情形**：出水COD、氨氮、总氮、总磷等指标超标
**处理流程**：
1. 立即停止排放
2. 查明超标原因
3. 调整处理工艺参数
4. 仍无法达标时，停产整改
5. 向生态环境部门报告

**审查要点**：
- 出水水质超标应急预案是否已制定
- 超标时是否及时调整工艺

### 10.3 污泥处置不当如何处理
**情形**：污泥非法处置或处置不当
**处理流程**：
1. 立即停止污泥处置
2. 查明处置不当原因
3. 委托有资质单位处置
4. 向生态环境部门报告

**审查要点**：
- 污泥处置单位是否具备相应资质
- 污泥处置记录是否完整

### 10.4 自动监测数据异常如何处理
**情形**：自动监测数据异常（如零值、负值、恒定值）
**处理流程**：
1. 立即检查自动监测设备
2. 设备故障时，开展手工监测
3. 手工监测数据报送生态环境部门
4. 设备修复后，校准、比对
5. 数据标记异常时段

**审查要点**：
- 自动监测设备是否正常运行
- 数据异常时是否及时开展手工监测

### 10.5 恶臭气体扰民如何处理
**情形**：厂界恶臭气体超标，周边居民投诉
**处理流程**：
1. 立即检查恶臭气体收集处理设施
2. 加强恶臭气体收集处理
3. 开展厂界恶臭监测
4. 向周边居民解释
5. 向生态环境部门报告

**审查要点**：
- 恶臭气体收集处理设施是否正常运行
- 厂界恶臭是否达标
