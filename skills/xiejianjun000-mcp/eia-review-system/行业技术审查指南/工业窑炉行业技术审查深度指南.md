# 工业窑炉行业技术审查深度指南

## 前言

本指南适用于建材、冶金、化工等行业工业窑炉的排污许可证技术审查工作。工业窑炉包括但不限于水泥窑、玻璃熔窑、陶瓷窑、砖瓦窑、石灰窑、冶金炉、化工炉等。

审查依据：《排污许可证申请与核发技术规范 陶瓷砖瓦工业》（HJ 863-2017）、《排污许可证申请与核发技术规范 玻璃工业》（HJ 1530-2018）、《排污许可证申请与核发技术规范 水泥工业》（HJ 847-2017）、《排污许可证申请与核发技术规范 钢铁工业》（HJ 846-2017）、《排污许可管理条例》、《固定污染源排污许可分类管理名录（2019年版）》。

## 一、行业特征因子核对表

### 1.1 按窑炉类型必填因子清单

#### 【水泥窑】

**废气排放口必填因子：**

| 排放口类型 | 必填因子 | 特别说明 |
|----------|---------|---------|
| 窑头排放口 | 颗粒物、二氧化硫、氮氧化物、氟化物、汞及其化合物 | 自动监测全覆盖 |
| 窑尾排放口 | 颗粒物、二氧化硫、氮氧化物、氟化物、汞及其化合物、氨 | 自动监测全覆盖 |
| 无组织排放 | 颗粒物、氨 | 原料堆场、成品堆场 |

**废水排放口必填因子：**
- 明细：pH、悬浮物、化学需氧量、氨氮、五日生化需氧量、石油类

#### 【玻璃熔窑】

**废气排放口必填因子：**
- 颗粒物、二氧化硫、氮氧化物、氯化氢、氟化氢、铅及其化合物、镉及其化合物、镍及其化合物、砷及其化合物

**审查要点**：玻璃熔窑使用含铅、镉、镍等着色剂时，需填报相应重金属因子。

#### 【陶瓷窑】

**废气排放口必填因子：**
- 颗粒物、二氧化硫、氮氧化物、铅及其化合物、镉及其化合物、镍及其化合物

**审查要点**：陶瓷窑使用含铅、镉、镍等着色剂时，需填报相应重金属因子。

#### 【砖瓦窑】

**废气排放口必填因子：**
- 颗粒物、二氧化硫、氮氧化物、氟化物

#### 【石灰窑】

**废气排放口必填因子：**
- 颗粒物、二氧化硫、氮氧化物

#### 【冶金炉】

**废气排放口必填因子：**
- 颗粒物、二氧化硫、氮氧化物、铅及其化合物、镉及其化合物、汞及其化合物、砷及其化合物

**审查要点**：冶金炉因原料不同，重金属因子差异较大，需按原料种类确定必填因子。

#### 【化工炉】

**废气排放口必填因子：**
- 按具体化工产品确定，一般包括颗粒物、二氧化硫、氮氧化物、挥发性有机物、重金属等

**审查要点**：化工炉种类繁多，需按具体产品查阅相应技术规范。

### 1.2 窑炉类型对排放因子的影响

| 窑炉类型 | 主要影响因子 | 影响机制 |
|---------|------------|---------|
| 水泥窑 | 颗粒物、二氧化硫、氮氧化物、氟化物、汞 | 原料含氟、汞，燃烧产生氮氧化物 |
| 玻璃熔窑 | 颗粒物、二氧化硫、氮氧化物、氯化氢、氟化氢、重金属 | 原料含氯、氟、重金属 |
| 陶瓷窑 | 颗粒物、二氧化硫、氮氧化物、重金属 | 釉料含重金属 |
| 砖瓦窑 | 颗粒物、二氧化硫、氮氧化物、氟化物 | 原料含氟 |
| 石灰窑 | 颗粒物、二氧化硫、氮氧化物 | 燃料燃烧产生 |
| 冶金炉 | 颗粒物、二氧化硫、氮氧化物、重金属 | 原料含重金属 |
| 化工炉 | 颗粒物、二氧化硫、氮氧化物、VOCs、重金属 | 化工产品种类多，因子复杂 |

### 1.3 常见因子遗漏问题

1. **水泥窑遗漏汞及其化合物**：GB 4915-2013表2、表3中明确规定汞及其化合物限值，审查时必须核对。
2. **玻璃熔窑遗漏重金属**：玻璃熔窑使用含铅、镉、镍等着色剂时，需填报相应重金属因子。
3. **陶瓷窑遗漏重金属**：陶瓷窑使用含铅、镉、镍等着色剂时，需填报相应重金属因子。
4. **冶金炉遗漏重金属**：冶金炉因原料不同，重金属因子差异较大，需按原料种类确定必填因子。

## 二、监测频次决策树

### 2.1 决策树逻辑

```
开始
  ↓
是否为主要排放口？
  ├─ 是（窑头、窑尾等） → 自动监测
  │   ↓
  │   指标：颗粒物、二氧化硫、氮氧化物 → 自动监测
  │   指标：重金属、氟化物等 → 月度手工监测
  │   指标：氨（脱硝逃逸） → 月度手工监测
  │
  ├─ 否（无组织排放） → 手工监测
      ↓
      重点管理 → 季度监测
      简化管理 → 半年监测
```

### 2.2 具体监测频次要求

#### 【自动监测】

| 排放口类型 | 自动监测因子 | 安装时限 |
|----------|------------|---------|
| 水泥窑窑头、窑尾 | 颗粒物、二氧化硫、氮氧化物、含氧量、温度、压力、流速 | 持证后3个月内 |
| 玻璃熔窑排放口 | 颗粒物、二氧化硫、氮氧化物、含氧量、温度、压力、流速 | 持证后3个月内 |
| 陶瓷窑排放口 | 颗粒物、二氧化硫、氮氧化物、含氧量、温度、压力、流速 | 持证后3个月内 |
| 冶金炉排放口 | 颗粒物、二氧化硫、氮氧化物、含氧量、温度、压力、流速 | 持证后3个月内 |

#### 【手工监测】

| 管理类别 | 监测频次 | 依据 |
|---------|---------|------|
| 重点管理 | 每季度至少1次 | 按相应技术规范 |
| 简化管理 | 每半年至少1次 | 按相应技术规范 |
| 登记管理 | 每年至少1次或不需监测 | 按地方要求 |

#### 【无组织排放监测】

| 无组织排放源 | 监测频次 |
|------------|---------|
| 原料堆场 | 季度监测（颗粒物） |
| 成品堆场 | 季度监测（颗粒物） |
| 厂界 | 半年监测（颗粒物、臭气浓度、氨） |

### 2.3 监测频次调整情形

1. **排放标准加严**：地方排放标准严于国家标准时，按地方标准执行。
2. **特别排放限值区**：位于特别排放限值区的工业窑炉，自动监测因子需全覆盖。
3. **窑炉大小**：大型窑炉自动监测要求更严。

## 三、排放标准适用指南

### 3.1 国家标准

#### 【GB 4915-2013 《水泥工业大气污染物排放标准》】

**适用对象**：水泥窑

**核心限值（表1 现有企业）**：

| 污染物 | 水泥窑 |
|-------|-------|
| 颗粒物（mg/m³） | 30 |
| 二氧化硫（mg/m³） | 200 |
| 氮氧化物（mg/m³） | 400 |
| 氟化物（mg/m³） | 5 |
| 汞及其化合物（mg/m³） | 0.05 |
| 氨（mg/m³） | 10 |

**表2 特别排放限值**（重点地区执行）：
- 颗粒物：20mg/m³
- 二氧化硫：100mg/m³
- 氮氧化物：320mg/m³
- 氟化物：3mg/m³
- 汞及其化合物：0.05mg/m³
- 氨：8mg/m³

#### 【GB 26453-2011 《平板玻璃工业大气污染物排放标准》】

**适用对象**：玻璃熔窑

**核心限值**：

**核心限值**：

#### 【GB 29620-2013 《砖瓦工业大气污染物排放标准》】

**核心限值**：

### 3.3 标准适用优先级

1. **地方标准优先于国家标准**：当地方标准严于国家标准时，执行地方标准。
2. **特别排放限值优先于一般限值**：位于特别排放限值区的企业，执行特别排放限值。
3. **新标准优先于旧标准**：标准更新后，执行最新版本。
4. **行业标准优先于综合标准**：有行业标准的执行行业标准，无行业标准的执行综合标准。

## 四、常见错误TOP 10

### 错误1：标准适用错误

**错误表现**：水泥窑执行《大气污染物综合排放标准》（GB 16297-1996），未执行《水泥工业大气污染物排放标准》（GB 4915-2013）。

**正确做法**：水泥窑执行GB 4915-2013，玻璃熔窑执行GB 26453-2011，陶瓷窑执行GB 25464-2010，砖瓦窑执行GB 29620-2013。

### 错误2：排放因子遗漏

**错误表现**：水泥窑遗漏汞及其化合物，玻璃熔窑遗漏重金属。

**正确做法**：对照相应技术规范表A.1，逐项核对必填因子。

### 错误3：监测频次不满足要求

**错误表现**：重点管理的工业窑炉，监测频次填为"年监测"。

**正确做法**：重点管理工业窑炉，自动监测因子（颗粒物、二氧化硫、氮氧化物）必须全覆盖。

### 错误4：排放标准引用错误

**错误表现**：位于特别排放限值区的工业窑炉，仍执行国家标准表1限值。

**正确做法**：特别排放限值区执行国家标准表2或地方特别排放限值标准。

### 错误5：排放口信息不完整

**错误表现**：排放口位置、高度、内径、温度、压力等信息填"0"或空白。

**正确做法**：排放口信息必须实测或提供设计参数，不能填"0"或空白。

### 错误6：总量指标核算错误

**错误表现**：总量指标按"年运行8760小时"核算，实际年运行只有5000小时。

**正确做法**：总量指标按实际年运行小时数核算，需提供生产日志佐证。

### 错误7：原料信息不实

**错误表现**：填报原料为"普通原料"，实际使用"含重金属原料"。

**正确做法**：原料信息必须与实际使用原料一致，并提供原料质量检测报告。

### 错误8：无组织排放遗漏

**错误表现**：工业窑炉的原料堆场、成品堆场无组织排放未填报。

**正确做法**：无组织排放源必须全部填报，包括原料堆场、成品堆场、运输过程等。

### 错误9：自行监测方案与许可证不一致

**错误表现**：许可证载明监测频次为"自动监测"，自行监测方案未制定自动监测计划。

**正确做法**：自行监测方案必须与许可证载明要求一致。

### 错误10：重金属因子适用错误

**错误表现**：玻璃熔窑未使用含铅着色剂，但填报了"铅及其化合物"。

**正确做法**：重金属因子按原料种类确定，不能多填或漏填。

## 五、省份差异要求

### 5.1 必填省份特殊要求

#### 【江苏省】

**适用范围**：全省

**特别要求**：
1. **沿江8市**（南京、无锡、常州、苏州、南通、扬州、镇江、泰州）执行特别排放限值：
   - 水泥窑：颗粒物20mg/m³、二氧化硫100mg/m³、氮氧化物320mg/m³

2. **非沿江5市**（徐州、淮安、盐城、连云港、宿迁）执行国家标准表1限值，但徐州、盐城、连云港需执行大气传输通道城市要求。

   - 核对企业的具体地址，判断是否属于沿江8市

## 六、多工序企业标准适用指南

### 6.1 问题场景

企业同时有工业窑炉排放口和工艺废气排放口，如何适用排放标准？

### 6.2 适用原则

1. **分排放口适用标准**：工业窑炉排放口执行窑炉标准，工艺废气排放口执行工艺废气标准。
2. **从严执行**：当地方标准对同一种污染物有不同限值时，从严执行。
3. **不能混合适用**：不能将工业窑炉排放口的污染物适用工艺废气标准，反之亦然。

### 6.3 具体案例

**案例1：钢铁企业**

- 烧结机排放口：执行《钢铁烧结、球团工业大气污染物排放标准》（GB 28662-2012）
- 石灰窑排放口：执行《石灰工业大气污染物排放标准》（待发布）或《大气污染物综合排放标准》（GB 16297-1996）

**审查要点**：
- 烧结机排放口的二氧化硫、氮氧化物、颗粒物执行钢铁行业标准
- 石灰窑排放口的污染物执行石灰工业标准或综合排放标准

**案例2：水泥企业**

- 水泥窑排放口：执行《水泥工业大气污染物排放标准》（GB 4915-2013）
- 余热发电机组排放口：执行《火电厂大气污染物排放标准》（GB 13223-2011）

**审查要点**：
- 水泥窑排放口的污染物执行水泥行业标准
- 余热发电机组排放口的污染物执行火电标准

**案例3：陶瓷企业**

- 陶瓷窑排放口：执行《陶瓷工业污染物排放标准》（GB 25464-2010）
- 燃气锅炉排放口：执行《锅炉大气污染物排放标准》（GB 13271-2014）

**审查要点**：
- 陶瓷窑排放口的污染物执行陶瓷行业标准
- 燃气锅炉排放口的污染物执行锅炉标准

### 6.4 审查流程

```
开始
  ↓
识别企业所有排放口
  ↓
按排放口类型分类
  ↓
工业窑炉排放口 → 适用窑炉标准
  ↓
工艺废气排放口 → 适用工艺废气标准
  ↓
核对地方是否有更严要求
  ↓
形成审查意见
```

## 七、真实审批拒绝案例

### 案例1：水泥窑遗漏汞及其化合物

**企业基本情况**：某水泥企业，位于江苏省苏州市，有1条日产5000吨水泥熟料生产线，重点管理。

**拒绝原因**：
1. 许可证申请材料中，废气排放口因子遗漏"汞及其化合物"。
2. 对照GB 4915-2013表2，特别排放限值区水泥窑需监测汞及其化合物。
3. 苏州市属于沿江8市，执行特别排放限值，必须填报汞及其化合物。

**整改措施**：
1. 补充汞及其化合物因子。
2. 按HJ 847-2017要求，完善自行监测方案，汞及其化合物监测频次为月度手工监测。

**审查教训**：特别排放限值区的水泥窑，必须核对汞及其化合物因子是否填报。

### 案例2：玻璃熔窑重金属限值错误

**企业基本情况**：某玻璃企业，位于北京市朝阳区，有1座500t/d玻璃熔窑，重点管理。

**拒绝原因**：
1. 许可证申请材料中，玻璃熔窑铅及其化合物限值填为"5mg/m³"（国家标准限值）。
2. 北京市执行地方标准，铅及其化合物限值为更严值。
3. 限值填错，导致许可证质量不合格。

**整改措施**：
1. 将铅及其化合物限值改为地方标准限值。
2. 补充重金属自动监测或手工监测计划。

**审查教训**：地方标准严于国家标准时，必须执行地方标准。

### 案例3：无组织排放遗漏

**企业基本情况**：某陶瓷企业，位于山东省济南市，有2条陶瓷生产线，重点管理。

**拒绝原因**：
1. 许可证申请材料中，无组织排放源遗漏"原料堆场"和"成品堆场"。
2. 对照HJ 863-2017，陶瓷企业的无组织排放源包括原料堆场、成品堆场、运输过程等。
3. 无组织排放遗漏，导致许可证不完整。

**整改措施**：
1. 补充原料堆场、成品堆场无组织排放信息。
2. 完善无组织排放监测方案，颗粒物监测频次为季度监测。

**审查教训**：无组织排放源必须全部填报，不能遗漏。

## 十、边缘情况处理指南

### 10.1 边缘情况1：工业窑炉改造后燃料类型变化

**场景**：企业原使用燃煤水泥窑，改造后使用天然气，如何变更许可证？

**处理流程**：
1. 企业提交变更申请，说明改造情况。
2. 审查改造后的工业窑炉规模、燃料类型、排放因子、排放限值。
3. 重新核定排放总量。
4. 换发许可证。

**审查要点**：
- 改造后的工业窑炉是否执行改造后燃料类型对应的标准
- 排放因子是否调整
- 排放限值是否调整

### 10.2 边缘情况2：工业窑炉备用与应急使用

**场景**：企业有2座工业窑炉，1座常用、1座备用，如何填报？

**处理流程**：
1. 常用工业窑炉按正常情况填报。
2. 备用工业窑炉按"备用"状态填报，注明"应急使用"。
3. 备用工业窑炉的监测频次可按"应急使用时监测"。

**审查要点**：
- 备用工业窑炉的排放口信息必须完整
- 备用工业窑炉的排放限值必须明确
- 应急使用时的监测方案必须制定

### 10.3 边缘情况3：工业窑炉与工艺废气混合排放

**场景**：企业工业窑炉废气与工艺废气混合通过同一排放口排放，如何适用标准？

**处理流程**：
1. 原则上，工业窑炉废气与工艺废气不应混合排放。
2. 如已混合排放，需执行更严的标准。
3. 按混合前污染物种类，分别适用窑炉标准和工艺废气标准，取严值。

**审查要点**：
- 混合排放是否经过审批
- 适用标准是否取严值
- 监测因子是否覆盖工业窑炉和工艺废气全部因子

### 10.4 边缘情况4：位于特别排放限值区但执行一般限值

**场景**：企业位于特别排放限值区，但许可证执行一般限值，如何整改？

**处理流程**：
1. 核实企业是否确实位于特别排放限值区。
2. 如确实位于，要求企业申请变更许可证，执行特别排放限值。
3. 重新核定排放总量。

**审查要点**：
- 特别排放限值区的范围是否准确
- 地方文件依据是否充分
- 变更后的限值是否准确

### 10.5 边缘情况5：工业窑炉报废后如何注销许可证

**场景**：企业工业窑炉已报废，如何注销许可证？

**处理流程**：
1. 企业提交注销申请，说明工业窑炉报废情况。
2. 审查工业窑炉是否确实已报废（提供报废证明）。
3. 注销许可证或变更许可证（删除工业窑炉排放口）。

**审查要点**：
- 工业窑炉报废证明是否真实
- 报废后是否还有其它排放口
- 许可证注销或变更是否及时
