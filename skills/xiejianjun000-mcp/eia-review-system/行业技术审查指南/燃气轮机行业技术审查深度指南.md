# 燃气轮机行业技术审查深度指南

## 前言

本指南适用于以天然气、煤层气、页岩气、煤气化气、炼焦煤气、高炉煤气、转炉煤气、沼气等气体为燃料的燃气轮机机组的排污许可证技术审查工作。

审查依据：《排污许可证申请与核发技术规范 火电》（HJ 863-2017）、《火电厂大气污染物排放标准》（GB 13223-2011）、《锅炉大气污染物排放标准》（GB 13271-2014）、《排污许可管理条例》、《固定污染源排污许可分类管理名录（2019年版）》。

---

## 一、行业特征因子核对表

### 1.1 按燃料类型必填因子清单

#### 【天然气燃气轮机】

**废气排放口必填因子：**

| 排放口类型 | 必填因子 | 特别说明 |
|----------|---------|---------|
| 主要排放口（烟囱） | 氮氧化物、颗粒物、烟气黑度 | 氮氧化物是核心控制因子 |
| 无组织排放 | 颗粒物、臭气浓度 | 调压站、门站 |

**审查要点**：天然气含硫量极低，二氧化硫一般不填，但需注明"燃料含硫量<50mg/m³"。

#### 【煤层气燃气轮机】

**废气排放口必填因子：**
- 氮氧化物、颗粒物、二氧化硫（煤层气含硫，需填报）、烟气黑度

**审查要点**：煤层气含硫量较天然气高，二氧化硫需填报。

#### 【煤气化气燃气轮机】

**废气排放口必填因子：**
- 氮氧化物、颗粒物、二氧化硫、一氧化碳、烟气黑度

**审查要点**：煤气化气含硫量高，二氧化硫和一氧化碳需重点控制。

#### 【炼焦煤气燃气轮机】

**废气排放口必填因子：**
- 氮氧化物、颗粒物、二氧化硫、一氧化碳、苯系物、氰化氢、烟气黑度

**审查要点**：炼焦煤气成分复杂，需按《炼焦化学工业污染物排放标准》（GB 16171-2012）执行。

#### 【高炉煤气燃气轮机】

**废气排放口必填因子：**
- 氮氧化物、颗粒物、二氧化硫、一氧化碳、烟气黑度

**审查要点**：高炉煤气含一氧化碳高，需重点控制。

#### 【转炉煤气燃气轮机】

**废气排放口必填因子：**
- 氮氧化物、颗粒物、二氧化硫、一氧化碳、烟气黑度

**审查要点**：转炉煤气含一氧化碳高，需重点控制。

#### 【沼气燃气轮机】

**废气排放口必填因子：**
- 氮氧化物、颗粒物、硫化氢、氨气、臭气浓度

**审查要点**：沼气含硫化氢和氨气，需重点控制。

### 1.2 燃料类型对排放因子的影响

| 燃料类型 | 主要影响因子 | 影响机制 |
|---------|------------|---------|
| 天然气 | 氮氧化物 | 燃烧温度越高，氮氧化物生成越多 |
| 煤层气 | 二氧化硫、氮氧化物 | 煤层气含硫量较天然气高 |
| 煤气化气 | 二氧化硫、一氧化碳、氮氧化物 | 煤气化气含硫量高、燃烧不充分时一氧化碳高 |
| 炼焦煤气 | 二氧化硫、一氧化碳、苯系物 | 炼焦煤气成分复杂 |
| 高炉煤气 | 一氧化碳、氮氧化物 | 高炉煤气含一氧化碳高 |
| 转炉煤气 | 一氧化碳、氮氧化物 | 转炉煤气含一氧化碳高 |
| 沼气 | 硫化氢、氨气、臭气浓度 | 沼气含硫化氢和氨气 |

### 1.3 常见因子遗漏问题

1. **天然气燃气轮机遗漏氮氧化物**：氮氧化物是燃气轮机的核心控制因子，必须填报。
2. **煤气化气燃气轮机遗漏一氧化碳**：煤气化气燃烧不充分时一氧化碳易超标，必须纳入监测。
3. **炼焦煤气燃气轮机遗漏苯系物**：炼焦煤气含苯系物，必须填报。
4. **沼气燃气轮机遗漏硫化氢**：沼气含硫化氢，必须填报。

## 二、监测频次决策树

### 2.1 决策树逻辑

```
开始
  ↓
是否为主要排放口？
  ├─ 是（烟囱） → 自动监测
  │   ↓
  │   指标：氮氧化物、颗粒物、含氧量、温度、压力、流速 → 自动监测
  │   指标：二氧化硫（如燃料含硫） → 自动监测或月度手工监测
  │   指标：一氧化碳（如燃料不完全燃烧） → 月度手工监测
  │
  ├─ 否（无组织排放） → 手工监测
      ↓
      重点管理 → 季度监测
      简化管理 → 半年监测
```

### 2.2 具体监测频次要求

#### 【自动监测】

| 排放口类型 | 自动监测因子 | 安装时限 |
|----------|------------|---------|
| 天然气燃气轮机烟囱 | 氮氧化物、含氧量、温度、压力、流速 | 持证后3个月内 |
| 煤层气燃气轮机烟囱 | 氮氧化物、二氧化硫、含氧量、温度、压力、流速 | 持证后3个月内 |
| 煤气化气燃气轮机烟囱 | 氮氧化物、二氧化硫、一氧化碳、含氧量、温度、压力、流速 | 持证后3个月内 |
| 炼焦煤气燃气轮机烟囱 | 氮氧化物、二氧化硫、一氧化碳、苯系物、含氧量、温度、压力、流速 | 持证后3个月内 |
| 高炉煤气燃气轮机烟囱 | 氮氧化物、一氧化碳、含氧量、温度、压力、流速 | 持证后3个月内 |
| 转炉煤气燃气轮机烟囱 | 氮氧化物、一氧化碳、含氧量、温度、压力、流速 | 持证后3个月内 |
| 沼气燃气轮机烟囱 | 氮氧化物、硫化氢、氨气、含氧量、温度、压力、流速 | 持证后3个月内 |

#### 【手工监测】

| 管理类别 | 监测频次 | 依据 |
|---------|---------|------|
| 重点管理 | 每季度至少1次 | HJ 863-2017 |
| 简化管理 | 每半年至少1次 | HJ 863-2017 |
| 登记管理 | 每年至少1次或不需监测 | 按地方要求 |

#### 【无组织排放监测】

| 无组织排放源 | 监测频次 |
|------------|---------|
| 调压站 | 季度监测（臭气浓度） |
| 门站 | 季度监测（臭气浓度） |
| 厂界 | 半年监测（颗粒物、臭气浓度） |

### 2.3 监测频次调整情形

1. **排放标准加严**：地方排放标准严于国家标准时，按地方标准执行。
2. **特别排放限值区**：位于特别排放限值区的燃气轮机，自动监测因子需全覆盖。
3. **机组大小**：300MW及以上机组自动监测要求更严。

## 三、排放标准适用指南

### 3.1 国家标准

#### 【GB 13223-2011 《火电厂大气污染物排放标准》】

**适用对象**：单台出力65t/h以上的燃气轮机机组的发电部分。

**核心限值（表1 新建燃气轮机组）**：

| 污染物 | 燃气轮机组 |
|-------|-----------|
| 颗粒物（mg/m³） | 10 |
| 二氧化硫（mg/m³） | - |
| 氮氧化物（mg/m³） | 50 |
| 烟气黑度（级） | ≤1 |

**表2 特别排放限值**（重点地区执行）：
- 颗粒物：5mg/m³
- 氮氧化物：50mg/m³

**表3 大气污染物特别排放限值**（部分省份执行）：
- 京津冀、长三角、珠三角等地区执行更严限值

#### 【GB 13271-2014 《锅炉大气污染物排放标准》】

**适用对象**：单台出力65t/h及以下的燃气轮机机组的锅炉部分。

**核心限值（表1 新建锅炉）**：

| 污染物 | 燃气锅炉 |
|-------|---------|
| 颗粒物（mg/m³） | 20 |
| 二氧化硫（mg/m³） | - |
| 氮氧化物（mg/m³） | 200（重点地区150） |
| 烟气黑度（级） | ≤1 |

**表2 特别排放限值**（重点地区执行）：
- 颗粒物：20mg/m³
- 氮氧化物：150mg/m³

#### 【GB 16171-2012 《炼焦化学工业污染物排放标准》】

**适用对象**：使用炼焦煤气为燃料的燃气轮机。

**审查要点**：炼焦煤气燃气轮机需执行GB 16171-2012。

### 3.2 地方标准

#### 【北京市】

- DB11/ 139-2015《锅炉大气污染物排放标准》
- 核心限值：燃气锅炉氮氧化物30mg/m³（全国最严）

#### 【天津市】

- DB12/ 151-2016《锅炉大气污染物排放标准》
- 核心限值：燃气锅炉氮氧化物50mg/m³

#### 【上海市】

- DB31/ 387-2018《锅炉大气污染物排放标准》
- 核心限值：燃气锅炉氮氧化物150mg/m³

#### 【广东省】

- DB44/ 765-2019《锅炉大气污染物排放标准》
- 核心限值：珠三角地区燃气锅炉氮氧化物150mg/m³

#### 【山东省】

- DB37/ 2374-2018《锅炉大气污染物排放标准》
- 核心限值：7个传输通道城市燃气锅炉氮氧化物150mg/m³

#### 【河北省】

- DB13/ 5161-2020《锅炉大气污染物排放标准》
- 核心限值：8市及雄安新区燃气锅炉氮氧化物150mg/m³

#### 【浙江省】

- DB33/ 1415-2023《锅炉大气污染物排放标准》
- 核心限值：全省燃气锅炉氮氧化物150mg/m³

#### 【江苏省】

- DB32/ 4386-2022《锅炉大气污染物排放标准》
- 核心限值：沿江8市燃气锅炉氮氧化物150mg/m³

#### 【福建省】

- DB35/ 3225-2023《锅炉大气污染物排放标准》
- 核心限值：9市燃气锅炉氮氧化物150mg/m³

### 3.3 标准适用优先级

1. **地方标准优先于国家标准**：当地方标准严于国家标准时，执行地方标准。
2. **特别排放限值优先于一般限值**：位于特别排放限值区的企业，执行特别排放限值。
3. **新标准优先于旧标准**：标准更新后，执行最新版本。
4. **发电优先于锅炉**：65t/h以上执行GB 13223-2011，65t/h及以下执行GB 13271-2014。
5. **行业优先于综合**：使用炼焦煤气执行GB 16171-2012，不适用GB 13223-2011或GB 13271-2014。

## 四、常见错误TOP 10

### 错误1：标准适用错误

**错误表现**：65t/h以上的燃气轮机执行GB 13271-2014，未执行GB 13223-2011。

**正确做法**：65t/h以上的燃气轮机执行GB 13223-2011，65t/h及以下的燃气轮机执行GB 13271-2014。

### 错误2：排放因子遗漏

**错误表现**：天然气燃气轮机遗漏氮氧化物，煤气化气燃气轮机遗漏一氧化碳。

**正确做法**：对照HJ 863-2017表A.1，逐项核对必填因子。

### 错误3：监测频次不满足要求

**错误表现**：重点管理的燃气轮机，氮氧化物未自动监测。

**正确做法**：重点管理燃气轮机，氮氧化物必须自动监测。

### 错误4：排放标准引用错误

**错误表现**：位于特别排放限值区的燃气轮机，仍执行GB 13223-2011表1或GB 13271-2014表1限值。

**正确做法**：特别排放限值区执行GB 13223-2011表2或GB 13271-2014表2，或地方特别排放限值标准。

### 错误5：排放口信息不完整

**错误表现**：排放口位置、高度、内径、温度、压力等信息填"0"或空白。

**正确做法**：排放口信息必须实测或提供设计参数，不能填"0"或空白。

### 错误6：总量指标核算错误

**错误表现**：总量指标按"年运行8760小时"核算，实际年运行只有3000小时。

**正确做法**：总量指标按实际年运行小时数核算，需提供生产日志佐证。

### 错误7：燃料信息不实

**错误表现**：填报燃料为"天然气"，实际使用"煤气化气"（含硫量更高）。

**正确做法**：燃料信息必须与实际使用燃料一致，并提供燃料质量检测报告。

### 错误8：无组织排放遗漏

**错误表现**：燃气轮机的调压站、门站无组织排放未填报。

**正确做法**：无组织排放源必须全部填报，包括调压站、门站、运输过程等。

### 错误9：自行监测方案与许可证不一致

**错误表现**：许可证载明氮氧化物"自动监测"，自行监测方案未制定自动监测计划。

**正确做法**：自行监测方案必须与许可证载明要求一致。

### 错误10：炼焦煤气燃气轮机适用标准错误

**错误表现**：炼焦煤气燃气轮机执行GB 13223-2011或GB 13271-2014，未执行GB 16171-2012。

**正确做法**：炼焦煤气燃气轮机执行《炼焦化学工业污染物排放标准》（GB 16171-2012）。

## 五、省份差异要求

### 5.1 必填省份特殊要求

#### 【江苏省】

**适用范围**：全省

**特别要求**：
1. **沿江8市**（南京、无锡、常州、苏州、南通、扬州、镇江、泰州）执行特别排放限值：
   - 颗粒物：10mg/m³（燃气轮机组）、20mg/m³（燃气锅炉）
   - 氮氧化物：50mg/m³（燃气轮机组）、150mg/m³（燃气锅炉）

2. **非沿江5市**（徐州、淮安、盐城、连云港、宿迁）执行GB 13223-2011表1或GB 13271-2014表1限值，但徐州、盐城、连云港需执行大气传输通道城市要求。

3. **审查要点**：
   - 核对企业的具体地址，判断是否属于沿江8市
   - 沿江8市企业必须执行特别排放限值
   - 徐州、盐城、连云港企业需核对是否属于大气传输通道城市

**文件依据**：DB32/ 4386-2022《锅炉大气污染物排放标准》、苏环办〔2023〕XXX号

#### 【浙江省】

**适用范围**：全省

**特别要求**：
1. **全省执行特别排放限值**：
   - 颗粒物：10mg/m³（燃气轮机组）、20mg/m³（燃气锅炉）
   - 氮氧化物：50mg/m³（燃气轮机组）、150mg/m³（燃气锅炉）

2. **杭州、宁波、温州、湖州、嘉兴、绍兴、金华、衢州、舟山、台州、丽水市**全部执行特别排放限值。

3. **审查要点**：
   - 浙江省所有燃气轮机均执行特别排放限值
   - 需核对地方是否有更严要求（如杭州市可能对燃气锅炉氮氧化物有更严要求）

**特别要求**：
1. **珠三角地区**（广州、深圳、珠海、佛山、江门、东莞、中山、惠州、肇庆）执行特别排放限值：
   - 颗粒物：10mg/m³（燃气轮机组）、20mg/m³（燃气锅炉）
   - 氮氧化物：50mg/m³（燃气轮机组）、150mg/m³（燃气锅炉）

2. **非珠三角地区**执行GB 13223-2011表1或GB 13271-2014表1限值。

## 六、多工序企业标准适用指南

### 6.1 问题场景

企业同时有燃气轮机排放口和工艺废气排放口，如何适用排放标准？

### 6.2 适用原则

1. **分排放口适用标准**：燃气轮机排放口执行火电标准或锅炉标准，工艺废气排放口执行工艺废气标准。
2. **从严执行**：当地方标准对同一种污染物有不同限值时，从严执行。
3. **不能混合适用**：不能将燃气轮机排放口的污染物适用工艺废气标准，反之亦然。

### 6.3 具体案例

**案例1：钢铁企业**

- 烧结机排放口：执行《钢铁烧结、球团工业大气污染物排放标准》（GB 28662-2012）
- 燃气轮机排放口：执行《火电厂大气污染物排放标准》（GB 13223-2011）

**审查要点**：
- 烧结机排放口的二氧化硫、氮氧化物、颗粒物执行钢铁行业标准
- 燃气轮机排放口的污染物执行火电标准

**案例2：化工企业**

- 工艺废气排放口：执行《大气污染物综合排放标准》（GB 16297-1996）或地方标准
- 燃气轮机排放口：执行《锅炉大气污染物排放标准》（GB 13271-2014）

**审查要点**：
- 工艺废气排放口的污染物执行综合排放标准或地方标准
- 燃气轮机排放口的污染物执行锅炉标准

**案例3：炼焦企业**

- 炼焦炉排放口：执行《炼焦化学工业污染物排放标准》（GB 16171-2012）
- 燃气轮机排放口：执行《火电厂大气污染物排放标准》（GB 13223-2011）

**审查要点**：
- 炼焦炉排放口的污染物执行炼焦化学工业标准
- 燃气轮机排放口的污染物执行火电标准

### 6.4 审查流程

```
开始
  ↓
识别企业所有排放口
  ↓
按排放口类型分类
  ↓
燃气轮机排放口 → 适用火电标准或锅炉标准
  ↓
工艺废气排放口 → 适用工艺废气标准
  ↓
核对地方是否有更严要求
  ↓
形成审查意见
```

## 七、真实审批拒绝案例

### 案例1：天然气燃气轮机遗漏氮氧化物

**企业基本情况**：某电力企业，位于江苏省苏州市，有2台100MW天然气燃气轮机，重点管理。

**拒绝原因**：
1. 许可证申请材料中，废气排放口因子遗漏"氮氧化物"。
2. 对照GB 13223-2011表2，特别排放限值区燃气轮机组需监测氮氧化物。
3. 苏州市属于沿江8市，执行特别排放限值，必须填报氮氧化物。

**整改措施**：
1. 补充氮氧化物因子。
2. 按HJ 863-2017要求，完善自行监测方案，氮氧化物监测为自动监测。

**审查教训**：特别排放限值区的燃气轮机，必须核对氮氧化物因子是否填报。

### 案例2：燃气锅炉氮氧化物限值错误

**企业基本情况**：某电子企业，位于北京市朝阳区，有1台10t/h燃气锅炉，重点管理。

**拒绝原因**：
1. 许可证申请材料中，燃气锅炉氮氧化物限值填为"150mg/m³"（GB 13271-2014表2限值）。
2. 北京市执行DB11/ 139-2015，燃气锅炉氮氧化物限值为30mg/m³。
3. 限值填错，导致许可证质量不合格。

**整改措施**：
1. 将氮氧化物限值改为30mg/m³。
2. 补充自动监测设备安装计划（氮氧化物自动监测）。

**审查教训**：地方标准严于国家标准时，必须执行地方标准。北京市燃气锅炉氮氧化物限值为30mg/m³，为全国最严。

### 案例3：无组织排放遗漏

**企业基本情况**：某能源企业，位于山东省济南市，有2台50MW天然气燃气轮机，重点管理。

**拒绝原因**：
1. 许可证申请材料中，无组织排放源遗漏"调压站"和"门站"。
2. 对照HJ 863-2017，燃气轮机的无组织排放源包括调压站、门站、运输过程等。
3. 无组织排放遗漏，导致许可证不完整。

**整改措施**：
1. 补充调压站、门站无组织排放信息。
2. 完善无组织排放监测方案，臭气浓度监测频次为季度监测。

**审查教训**：无组织排放源必须全部填报，不能遗漏。

## 十、边缘情况处理指南

### 10.1 边缘情况1：燃气轮机改造后燃料类型变化

**场景**：企业原使用天然气燃气轮机，改造后使用煤气化气，如何变更许可证？

**处理流程**：
1. 企业提交变更申请，说明改造情况。
2. 审查改造后的燃气轮机装机容量、燃料类型、排放因子、排放限值。
3. 重新核定排放总量。
4. 换发许可证。

**审查要点**：
- 改造后的燃气轮机是否执行煤气化气标准
- 排放因子是否调整（如增加二氧化硫、一氧化碳）
- 排放限值是否调整（如氮氧化物限值可能变化）

### 10.2 边缘情况2：燃气轮机备用与应急使用

**场景**：企业有2台燃气轮机，1台常用、1台备用，如何填报？

**处理流程**：
1. 常用燃气轮机按正常情况填报。
2. 备用燃气轮机按"备用"状态填报，注明"应急使用"。
3. 备用燃气轮机的监测频次可按"应急使用时监测"。

**审查要点**：
- 备用燃气轮机的排放口信息必须完整
- 备用燃气轮机的排放限值必须明确
- 应急使用时的监测方案必须制定

### 10.3 边缘情况3：燃气轮机与工艺废气混合排放

**场景**：企业燃气轮机废气与工艺废气混合通过同一排放口排放，如何适用标准？

**处理流程**：
1. 原则上，燃气轮机废气与工艺废气不应混合排放。
2. 如已混合排放，需执行更严的标准。
3. 按混合前污染物种类，分别适用火电标准和工艺废气标准，取严值。

**审查要点**：
- 混合排放是否经过审批
- 适用标准是否取严值
- 监测因子是否覆盖燃气轮机和工艺废气全部因子

### 10.4 边缘情况4：位于特别排放限值区但执行一般限值

**场景**：企业位于特别排放限值区，但许可证执行一般限值，如何整改？

**处理流程**：
1. 核实企业是否确实位于特别排放限值区。
2. 如确实位于，要求企业申请变更许可证，执行特别排放限值。
3. 重新核定排放总量。

**审查要点**：
- 特别排放限值区的范围是否准确
- 地方文件依据是否充分
- 变更后的限值是否准确

### 10.5 边缘情况5：燃气轮机报废后如何注销许可证

**场景**：企业燃气轮机已报废，如何注销许可证？

**处理流程**：
1. 企业提交注销申请，说明燃气轮机报废情况。
2. 审查燃气轮机是否确实已报废（提供报废证明）。
3. 注销许可证或变更许可证（删除燃气轮机排放口）。

**审查要点**：
- 燃气轮机报废证明是否真实
- 报废后是否还有其它排放口
- 许可证注销或变更是否及时
