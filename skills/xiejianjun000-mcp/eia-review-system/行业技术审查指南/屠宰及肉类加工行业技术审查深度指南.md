# 屠宰及肉类加工行业技术审查深度指南

## 一、行业特征因子核对表

### 1.1 主要生产工艺及产污环节

屠宰及肉类加工行业主要包括畜禽屠宰、肉制品加工，主要生产工艺：

**畜禽屠宰工艺**：
- 活畜接收→静养→致昏→放血→烫毛/脱毛→开膛→去脏→劈半→检验→入库
- 产污环节：屠宰废水、肠胃内容物、粪便、恶臭气体、噪声

**肉制品加工工艺**：
- 原料肉→解冻→分割→腌制→灌肠→蒸煮→包装
- 产污环节：加工废水、油烟废气、恶臭气体、噪声

## 二、监测频次决策树

### 2.1 废气监测频次决策树

```
开始
↓
是否有恶臭污染物排放？
├─ 是 → 恶臭污染物：
│   ├─ 重点管理：每季度1次
│   └─ 简化管理：每半年1次
└─ 否 → 继续
↓
是否有锅炉？
├─ 是 → 锅炉烟气：
│   ├─ 重点管理：自动监测（SO₂、NOx、颗粒物）
│   └─ 简化管理：手工监测，每月1次
└─ 否 → 继续
↓
是否有食堂？
├─ 是 → 油烟：
│   ├─ 重点管理：每半年1次
│   └─ 简化管理：每年1次
└─ 否 → 结束
```

### 2.2 废水监测频次决策树

```
开始
↓
是否有生产废水排放？
├─ 是 → 继续
└─ 否 → 仅生活污水 → 简化管理：每季度1次
↓
废水排放量？
├─ ≥100吨/日 → 重点管理：每日采样，每月分析
├─ 10-100吨/日 → 重点管理：每周采样，每月分析
└─ <10吨/日 → 简化管理：每月1次
↓
是否有动植物油排放？
├─ 是 → 重点管理：每月1次
└─ 否 → 结束
```

## 四、常见错误TOP 10

### 错误1：恶臭污染物因子遗漏

**错误表现**：
- 仅填报锅炉烟气因子，遗漏恶臭污染物
- 遗漏屠宰车间、待宰圈、污水处理站恶臭污染物

**正确做法**：
- 屠宰车间、待宰圈、污水处理站必须填报恶臭污染物（氨、硫化氢、臭气浓度）
- 参考《排污许可证申请与核发技术规范 农副食品加工工业 屠宰及肉类加工工业》（待发布）或参照类似行业技术规范

### 错误2：大肠菌群数因子遗漏

**错误表现**：
- 废水因子中遗漏大肠菌群数
- 仅填报COD、氨氮等常规因子

**正确做法**：
- 屠宰及肉类加工行业废水特征因子为大肠菌群数，必须填报
- 参考相关技术规范

### 错误3：动植物油因子遗漏

**错误表现**：
- 废水因子中遗漏动植物油

**正确做法**：
- 屠宰及肉类加工行业废水特征因子为动植物油，必须填报

### 错误4：监测频次确定错误

**错误表现**：
- 重点管理简化为每季度1次
- 简化管理要求自动监测

**正确做法**：
- 严格按技术规范确定频次
- 重点管理：废水每日采样，每月分析；恶臭污染物每季度1次
- 简化管理：废水每月1次；恶臭污染物每半年1次

### 错误5：排放标准引用错误

**错误表现**：
- 引用已废止标准
- 未执行地方恶臭污染物特别排放限值
- 废水排放标准误用GB 8978-1996，未执行GB 13457-92

**正确做法**：
- 核对标准有效性
- 优先执行地方排放标准
- 废水排放应优先执行GB 13457-92
- 重点地区执行特别排放限值

### 错误6：管理类别判定错误

**错误表现**：
- 年屠宰能力判定错误
- 混淆重点管理和简化管理边界
- 未区分不同畜禽种类

**正确做法**：
- 依据《固定污染源排污许可分类管理名录（2019年版）》
- 区分生猪、肉牛、肉羊、禽类不同判定标准

### 错误7：排放口信息不完整

**错误表现**：
- 排放口位置描述模糊
- 排放口数量与实际不符

**正确做法**：
- 排放口位置：精确到经纬度坐标
- 排放口数量：与现场核对一致

### 错误8：总量指标核算方法错误

**错误表现**：
- 采用实测法但未提供监测报告
- 产污系数选用错误

**正确做法**：
- 优先采用实测法
- 其次采用产污系数法

### 错误9：自行监测方案不合理

**错误表现**：
- 监测点位设置不合理
- 监测因子遗漏

**正确做法**：
- 监测点位：覆盖所有排放口
- 监测因子：与许可证载明一致

### 错误10：省份差异要求未落实

**错误表现**：
- 未执行省份特别要求

**正确做法**：
- 审查时核对省份差异要求
- 确保地方标准优先执行

### 5.1 江苏省

**特别要求**：

1. **恶臭污染物排放限值**：
   - 执行《江苏省大气污染物综合排放标准》（DB32/4041-2021）

2. **监测频次加强**：
   - 重点管理：恶臭污染物自动监测或每月1次手工监测

   - 重点管理企业必须开展清洁生产审核

4. **在线监测要求**：
   - 排气筒高度≥15m且风量≥10000 m³/h的必须安装在线监测

5. **台账管理**：
   - 必须电子化台账

- 核对是否满足DB32/4041-2021要求

## 六、多工序企业标准适用指南

### 6.1 常见多工序组合

屠宰及肉类加工企业常见多工序组合：

1. **屠宰+肉制品加工**：
   - 主工艺：畜禽屠宰
   - 副工艺：肉制品加工
   - 适用标准：分别执行对应技术规范

2. **屠宰+饲料加工**：
   - 主工艺：畜禽屠宰
   - 副产物利用：饲料加工（生产血粉、骨粉等）
   - 适用标准：分别执行屠宰技术规范和饲料加工技术规范

3. **屠宰+生物质锅炉**：
   - 主工艺：屠宰
   - 供热：生物质锅炉
   - 适用标准：主工艺执行屠宰技术规范，锅炉执行GB 13271-2014

### 6.2 标准适用原则

1. **主工艺优先原则**
2. **综合排放标准兜底原则**
3. **从严执行原则**

### 6.3 审查步骤

**第一步**：识别企业所有生产工艺
**第二步**：确定各工艺对应技术规范
**第三步**：核对因子完整性
**第四步**：确定排放标准
**第五步**：确定管理类别

### 案例1：恶臭污染物因子大面积遗漏

**企业基本情况**：

- 所在地：江苏省徐州市
- 年屠宰能力：20万头生猪
- 管理类别：重点管理

**拒绝原因**：
技术审查发现，许可证申请材料中未填报恶臭污染物因子，遗漏了以下产污点：
1. 屠宰车间恶臭污染物
2. 待宰圈恶臭污染物
3. 污水处理站恶臭污染物

**审查意见**：
"依据相关技术规范，屠宰及肉类加工行业废气特征污染物为恶臭污染物（氨、硫化氢、臭气浓度）。申请人未填报恶臭污染物因子，不符合技术规范要求。请补充填报所有恶臭污染物产生点的污染物因子。"

**整改措施**：
企业补充填报了所有恶臭污染物产生点的因子，并完善了监测方案。

**经验教训**：
审查时必须核对特征污染物因子，不能仅依赖企业填报内容。

### 案例2：大肠菌群数因子遗漏

**企业基本情况**：
- 企业名称：某食品有限公司
- 所在地：山东省德州市
- 年屠宰能力：15万头生猪
- 管理类别：重点管理

**拒绝原因**：
技术审查发现，许可证申请材料中废水因子未填报大肠菌群数，不符合技术规范要求。

**审查意见**：
"依据相关技术规范，屠宰及肉类加工行业废水特征污染物为大肠菌群数。申请人未填报大肠菌群数因子，不符合要求，请修改申请表。"

**整改措施**：
企业修改了废水因子，补充填报了大肠菌群数。

**经验教训**：
审查时必须核对行业特征污染物因子，不能遗漏。

### 案例3：排放标准引用错误

**企业基本情况**：
- 企业名称：某屠宰有限公司
- 所在地：河北省石家庄市
- 年屠宰能力：25万头生猪
- 管理类别：重点管理

**拒绝原因**：
技术审查发现，许可证申请材料中废水排放标准引用了《污水综合排放标准》（GB 8978-1996），未执行《肉类加工工业水污染物排放标准》（GB 13457-92）。

**审查意见**：
"依据相关技术规范，屠宰及肉类加工行业废水排放应优先执行GB 13457-92。申请人引用GB 8978-1996不符合要求，请修改为GB 13457-92，并核对排放限值。"

**整改措施**：
企业修改了排放标准，执行GB 13457-92，并将COD排放限值从100 mg/L调整为80 mg/L。

**经验教训**：
审查时必须核对行业排放标准，确保优先执行行业标准。

## 十、边缘情况处理指南

### 10.1 边缘情况1：企业同时从事屠宰和肉制品加工

**问题描述**：
企业主工艺为畜禽屠宰（年屠宰生猪20万头），同时从事肉制品加工（年生产火腿、香肠等5000吨），如何确定管理类别和适用标准？

**处理原则**：
1. **管理类别确定**：
   - 屠宰：年屠宰20万头≥10万头，属于重点管理
   - 肉制品加工：如单独判定，需查名录
   - **结论**：按重点管理核发许可证

2. **适用标准确定**：
   - 屠宰工艺：执行屠宰技术规范
   - 肉制品加工工艺：执行对应技术规范
   - **结论**：分别执行对应技术规范

3. **因子填报**：
   - 屠宰因子：恶臭污染物、COD、氨氮、动植物油、大肠菌群数
   - 肉制品加工因子：油烟、COD、氨氮、动植物油
   - **结论**：全部因子均需填报

**审查要点**：
- 核对两个工艺的因子是否完整
- 核对两个工艺的监测方案是否合规
- 核对排放标准是否分别执行

### 10.2 边缘情况2：企业有自备锅炉但燃料类型不明

**问题描述**：
企业有自备锅炉用于生产供热，但申请材料未明确燃料类型（燃煤、燃油、燃气、生物质），如何审查？

**处理原则**：
1. **要求企业补充提供材料**
2. **根据燃料类型确定填报要求**
3. **执行标准**：GB 13271-2014

**审查要点**：
- 核对燃料类型证明材料
- 核对因子是否完整

### 10.3 边缘情况3：企业停产但许可证未到期

**问题描述**：
企业在许可证有效期内停产（如季节性停产、技术改造停产），如何审查执行报告要求？

**处理原则**：
1. **季节性停产**：
   - 企业在许可证中载明生产时段
   - 停产期间免予提交执行报告（需提前备案）
   - 复产前应开展自行监测

2. **长期停产**（超过3个月）：
   - 企业应向发证机关报告

**审查要点**：
- 核对生产时段是否与实际情况一致
- 核对停产备案材料是否完整

### 10.4 边缘情况4：企业无组织排放难以量化

**问题描述**：
屠宰及肉类加工企业无组织排放（待宰圈、屠宰车间、污水处理站恶臭）难以量化和监测，如何审查？

**处理原则**：
1. **无组织排放因子必须填报**
2. **无组织排放监测要求**
3. **无组织排放控制措施**

**审查要点**：
- 核对无组织排放因子是否填报
- 核对无组织排放监测方案是否合规

### 10.5 边缘情况5：企业位于环境敏感区

**问题描述**：
企业位于饮用水水源保护区、自然保护区等环境敏感区内，如何审查？

**处理原则**：
1. **检查环评批复**
2. **执行特别排放限值**
3. **总量指标倍量替代**
4. **建议搬迁**

**审查要点**：
- 核对敏感区证明材料
- 核对特别排放限值是否执行

### 10.6 边缘情况6：企业合并、分立、更名

**问题描述**：
企业在许可证有效期内发生合并、分立、更名，如何处理？

**处理原则**：
1. **企业合并**：重新申请
2. **企业分立**：分别申请
3. **企业更名**：申请变更

**审查要点**：
- 核对工商变更登记证明
- 核对总量指标分配协议（分立情形）
