## 一、行业概述与工艺特征

### 1.1 行业分类

钢铁压延加工涉及完整的钢铁生产流程：

| 工序类别 | 典型工艺 | 污染特点 |
|---------|---------|---------|
| 炼铁 | 高炉炼铁 | 大气污染为主（SO₂、NOx、颗粒物）、高炉渣 |
| 炼钢 | 转炉/电炉炼钢 | 大气污染（颗粒物、NOx、二噁英）、钢渣 |
| 轧钢 | 热轧/冷轧 | 大气（氧化铁皮粉尘、酸雾）+废水（含油、含酸） |
| 铁合金 | 矿热炉/电炉 | 大气（粉尘、SO₂）+ 废水（重金属） |

### 1.2 主要工艺流程

#### 典型长流程钢铁联合企业：

```
烧结/球团 → 炼铁（高炉） → 炼钢（转炉/电炉） → 轧钢（热轧+冷轧） → 成品
```

#### 短流程电炉炼钢+轧钢：

```
废钢 → 电炉炼钢 → 精炼 → 轧钢 → 成品
```

#### 单纯轧钢（无炼铁/炼钢）：

```
外购钢坯/热卷 → 加热 → 轧制 → 酸洗（冷轧） → 退火 → 精整 → 成品
```

### 1.3 行业特征

- **工序最多最复杂**：涵盖烧结、炼铁、炼钢、轧钢等多个工序
- **大气污染最重**：SO₂、NOx、颗粒物排放量大（尤其烧结、高炉、转炉）
- **二噁英问题**：烧结、炼钢（含铬镍合金钢）有二噁英排放
- **酚氰废水**：炼焦（如有）产生高浓度酚氰废水
- **含油/含酸废水**：轧钢酸洗产生大量含油含酸废水
- **钢渣处理**：转炉钢渣、电炉钢渣是大量固体废物
- **多排放口**：每个生产工序均有独立排放口，数量多

## 二、管理类别判断

### 2.1 管理类别划分

根据《名录》第33-34项：

| 生产类型 | 规模条件 | 管理类别 |
|---------|---------|---------|
| 炼铁 | 全部（独立球团/烧结） | **重点管理** |
| 炼钢 | 全部 | **重点管理** |
| 钢压延加工 | 有热轧/冷轧/涂镀工序 | **重点管理** |
| 钢压延加工 | 仅有拉拔等冷加工 | **简化管理** |
| 铁合金冶炼 | 全部 | **重点管理** |

### 2.2 钢铁联合企业vs独立轧钢

| 企业类型 | 典型特征 | 管理类别 |
|---------|---------|---------|
| 钢铁联合企业（长流程） | 有烧结+高炉+转炉 | 重点管理 |
| 短流程电炉钢+轧钢 | 无高炉，有电炉+轧钢 | 重点管理 |
| 独立轧钢厂 | 外购钢坯/热卷，仅轧制 | 简化管理（若有拉拔）或重点管理（若有热轧） |
| 独立冷轧厂 | 外购热卷，冷轧+酸洗+退火 | 重点管理 |

### 2.3 重点说明

**热轧工序是钢铁压延加工的关键判断点**：
- 有热轧工序 → 重点管理
- 无热轧，仅有冷轧/拉拔 → 简化管理

**短流程电炉企业**（无高炉/烧结）：
- 仍有轧钢工序 → 重点管理
- 轧钢（含热轧或冷轧）是大气污染的重要来源

## 三、行业特征因子核对表

### 3.1 按工序分类的特征因子

#### 3.1.1 烧结/球团工序（高炉配套或独立球团）

**废气特征因子**：

| 排放环节 | 特征因子 | 备注 |
|---------|---------|------|
| 烧结机头 | SO₂、NOx、颗粒物、二噁英、氟化物 | 烧结机头是最主要的SO₂排放源 |
| 烧结机尾 | 颗粒物 | 烧结矿冷却 |
| 球团焙烧 | SO₂、NOx、颗粒物、二噁英 | 回转窑/竖炉工艺 |
| 原料场/配料 | 颗粒物 | 无组织排放 |

**废水特征因子**：
- SS、COD、氨氮、总氮、总磷
- 硫化物（烧结冲渣水）
- 酚类（烧结焦炭带入）

#### 3.1.2 炼铁工序（高炉）

**废气特征因子**：

| 排放环节 | 特征因子 | 备注 |
|---------|---------|------|
| 高炉出铁场 | 颗粒物（含铁尘） | 出铁口/撇渣器 |
| 热风炉 | SO₂、NOx、颗粒物 | 燃料为高炉煤气/天然气 |
| 煤粉制备 | 颗粒物 | 煤粉制备系统 |
| 铸铁机 | 颗粒物 | 铸铁块 |
| 高炉渣处理 | 颗粒物、氨气 | 水淬渣粒化 |

**废水特征因子**：
- SS（高炉渣粒化水，悬浮物高）
- COD、氨氮
- 酚、氰化物（高炉煤气洗涤水）

#### 3.1.3 炼钢工序（转炉/电炉）

**废气特征因子**：

| 排放环节 | 特征因子 | 备注 |
|---------|---------|------|
| 转炉吹炼 | 颗粒物、SO₂、NOx、二噁英 | 转炉一次烟气 |
| 电炉熔炼 | 颗粒物、二噁英、NOx | 电炉烟气 |
| 精炼炉 | 颗粒物 | LF炉/RH炉 |
| 钢包修砌 | 颗粒物 | 无组织排放 |
| 混铁炉/铁水预处理 | 颗粒物、二氧化硫 | 铁水脱硫 |

**废水特征因子**：
- SS（转炉除尘废水，悬浮物高）
- 石油类（钢坯/轧辊冷却水）
- COD、氨氮
- 铬、镍（不锈钢/含合金钢炼钢）

**二噁英**：电炉和含铬/镍合金钢转炉是二噁英重要来源

#### 3.1.4 轧钢工序

**热轧废气特征因子**：

| 排放环节 | 特征因子 | 备注 |
|---------|---------|------|
| 加热炉 | SO₂、NOx、烟尘 | 燃煤/煤气/天然气加热炉 |
| 粗轧/精轧 | 氧化铁皮粉尘 | 颗粒物为主 |
| 轧机机架 | 油雾（轧制油） | 轧机密封 |
| 冷却段 | 水蒸气 | 少量 |
| 矫直/切头 | 金属粉尘 | 切头飞溅 |

**冷轧废气特征因子**：

| 排放环节 | 特征因子 | 备注 |
|---------|---------|------|
| 酸洗段 | 盐酸雾、硝酸雾（混酸） | 冷轧带钢酸洗 |
| 轧机段 | 油雾（轧制油） | 冷轧油雾 |
| 退火炉 | SO₂、NOx（燃煤/煤气） | 罩式退火/连续退火 |
| 镀锌/镀锡 | 锌烟（热镀锌） | 熔融锌挥发 |
| 涂镀（彩涂） | VOCs（涂料） | 彩涂线溶剂挥发 |

**冷轧废水特征因子**：

| 废水类型 | 特征因子 | 备注 |
|---------|---------|------|
| 酸洗废液 | SS、COD、pH、总铁、盐酸 | 废酸液HW34 |
| 轧制冷却水 | SS、石油类 | 含轧制油 |
| 退火炉急冷水 | COD、SS | 少量 |
| 镀锌钝化液 | 六价铬、总锌 | 含六价铬钝化液 |
| 彩涂清洗水 | COD、VOCs | 涂料清洗水 |
| 硅钢冷轧废水 | 氟化物 | HF酸洗 |

#### 3.1.5 铁合金冶炼工序

**废气特征因子**：

| 排放环节 | 特征因子 | 备注 |
|---------|---------|------|
| 矿热炉 | 颗粒物、SO₂、NOx、二噁英 | 敞口/半封闭矿热炉 |
| 精炼电炉 | 颗粒物 | 精炼炉 |
| 原料处理 | 颗粒物 | 原料破碎、筛分 |

**特征重金属**：
| 产品 | 特征重金属因子 |
|-----|-------------|
| 硅铁 | 颗粒物（SiO₂粉尘） |
| 锰铁 | 颗粒物（MnO₂粉尘）、锰及其化合物 |
| 铬铁 | 颗粒物（Cr粉尘）、六价铬 | 
| 镍铁 | 颗粒物（Ni粉尘）、镍及其化合物 |

**铁合金废水特征因子**：
- SS、COD、氨氮
- 总锰（硅锰合金）
- 总铬（铬铁合金）
- 总镍（镍铁合金）
- 六价铬（铬铁合金）

### 3.2 燃料类型对特征因子的影响

这是钢铁行业审查的核心要点：

| 燃料类型 | SO₂排放量 | NOx排放量 | 颗粒物 | 二噁英 | 备注 |
|---------|----------|----------|--------|-------|------|
| 焦炭 | 极高 | 高 | 高 | 有 | 烧结/高炉主力燃料 |
| 高炉煤气 | 低-中 | 中 | 低 | 少 | 副产品气体燃料 |
| 转炉煤气 | 极低 | 低 | 极少 | 无 | 副产品气体燃料 |
| 天然气 | 极低 | 中 | 极少 | 无 | 最清洁气体燃料 |
| 发生炉煤气 | 中 | 中 | 中 | 有 | 需净化处理 |
| 重油 | 高 | 高 | 中 | 有 | 加热炉燃料 |

**重点**：
- 烧结机头SO₂主要来自焦炭燃烧（焦炭含硫1%-2%）
- 钢铁联合企业大量使用高炉煤气/转炉煤气（副产品），SO₂较低
- 独立轧钢企业外购煤气或天然气，排放特征不同

## 六、常见错误TOP 10

### 错误1：混淆钢铁联合企业与独立轧钢的标准适用

**错误表现**：
- 独立轧钢企业错误套用钢铁联合企业全套标准（烧结/炼铁/炼钢标准）
- 独立轧钢实际上只有轧钢工序，无烧结/炼铁/炼钢
- 将GB 28662（烧结）、GB 28663（炼铁）等套用于轧钢企业

**正确做法**：
- 独立轧钢（无烧结/炼铁/炼钢）只适用GB 28665-2012（轧钢）
- 确认企业实际有哪些工序，只申请对应工序的许可
- 联合企业按各工序分别适用对应标准

### 错误2：酸洗废气因子遗漏

**错误表现**：
- 冷轧企业不测盐酸雾（盐酸酸洗）
- 硅钢/不锈钢混酸酸洗企业不测硝酸雾和HF
- 将酸洗废气等同于一般粉尘处理

**正确做法**：
- 盐酸酸洗 → 监测盐酸雾（HCl）
- 硝酸+氢氟酸混酸 → 监测硝酸雾（NOx）和氟化物
- 酸洗废气必须配套碱液喷淋处理设施

### 错误3：二噁英因子遗漏

**错误表现**：
- 烧结、炼钢（含铬/镍合金）企业不测二噁英
- 认为二噁英"检不出"就不需要测
- 二噁英监测频次不符合要求

**正确做法**：
- 烧结机头：GB 28662-2012要求二噁英每年1次
- 电炉：GB 28664-2012要求二噁英每年1次
- 含铬/镍合金钢转炉：同样要求测二噁英
- 二噁英排放标准：0.5 ng-TEQ/m³（烧结/炼钢）

### 错误4：镀锌钝化六价铬管理缺失

**错误表现**：
- 热镀锌企业遗漏六价铬监测
- 钝化液使用三价铬钝化但误报为"无铬钝化"
- 六价铬超标未被发现

**正确做法**：
- 热镀锌钝化工序：六价铬是特征因子
- 监测六价铬（GB/T 15555.4-1995）
- 排放标准：GB 13456-2012六价铬≤0.5 mg/L（间接排放）
- 鼓励使用无铬钝化工艺

### 错误5：含油/含酸废水混合排放

**错误表现**：
- 冷轧含油废水与酸洗废液混合后再处理
- 废酸液（HW34）与含油废水混合增加处理难度
- 含Cr⁶⁺钝化废水与其他废水混合

**正确做法**：
- **废酸液HW34单独收集**，委托有资质单位处置
- 含六价铬钝化废水单独收集，用亚硫酸钠还原Cr⁶⁺后处理
- 含油废水（轧制油）隔油+气浮+生化处理
- 不同性质废水分类收集、分质处理

### 错误6：钢铁联合企业排污口数量核算错误

**错误表现**：
- 将每个工序排放口单独核算，忽略联合企业的整体性
- 许可排放量远超实际排放能力
- 遗漏工序间的排放口

**正确做法**：
- 联合企业排放口多（高炉出铁场、热风炉、转炉、轧钢加热炉等数十个）
- 按工序逐一列出排放口
- 许可排放量按各工序分别核算后汇总
- 间接排放口与直接排放口分别管理

### 错误7：电炉短流程企业特殊要求被忽视

**错误表现**：
- 电炉+轧钢企业按传统长流程标准套用
- 遗漏电炉二噁英监测
- 遗漏电炉特殊粉尘（石墨电极氧化）

**正确做法**：
- 电炉：监测颗粒物、二噁英、NOx
- 电炉石墨电极消耗产生的石墨粉尘需关注
- 炉外精炼（LF炉）颗粒物监测

### 错误8：高炉煤气/转炉煤气燃烧排放管理缺失

**错误表现**：
- 高炉煤气/转炉煤气作为燃料使用时，其燃烧产物排放管理缺失
- 将副产品煤气视为"清洁能源"不监测SO₂

**正确做法**：
- 高炉煤气含硫（焦炭带入），燃烧后SO₂排放不可忽视
- 转炉煤气含可燃成分（CO），燃烧不完全时CO超标
- 使用高炉煤气/转炉煤气的炉窑（热风炉、加热炉）均需监测SO₂、NOx、CO

### 错误9：独立轧钢（冷轧）管理类别错误

**错误表现**：
- 有冷轧/酸洗的独立轧钢企业误申请简化管理
- 认为"冷"加工就是简化管理

**正确做法**：
- **冷轧+酸洗+退火属于热轧/冷轧/涂镀工序**
- 按《名录》第33项，属于重点管理
- 独立冷轧厂（有酸洗）为重点管理，不能简化

### 错误10：烧结工序氟化物因子遗漏

**错误表现**：
- 烧结企业遗漏氟化物监测
- 不了解铁矿石含氟导致的氟化物排放

**正确做法**：
- 部分铁矿石含氟（萤石共生矿），烧结过程中氟化物挥发
- GB 28662-2012对氟化物有排放限值要求
- 使用高氟矿的企业需增加氟化物监测频次

## 八、多工序企业标准适用指南

### 8.1 钢铁联合企业（全流程）

**工序**：烧结 → 炼铁 → 炼钢 → 轧钢

**标准适用**：
- 烧结/球团：GB 28662-2012
- 炼铁：GB 28663-2012
- 炼钢：GB 28664-2012
- 轧钢：GB 28665-2012
- 废水：GB 13456-2012
- 锅炉：GB 13271-2014

**特点**：排放口最多（数十个），许可编制最复杂

### 8.2 短流程电炉+轧钢

**工序**：废钢 → 电炉 → 精炼 → 轧钢

**标准适用**：
- 电炉：GB 28664-2012（炼钢）
- 轧钢：GB 28665-2012
- 无烧结/炼铁工序，不适用GB 28662/28663

### 8.3 独立热轧厂

**工序**：外购钢坯 → 加热 → 热轧 → 精整

**标准适用**：
- 加热炉：GB 28665-2012（轧钢）
- 轧机粉尘：GB 28665-2012
- 废水：GB 8978-1996（无炼铁/炼钢，不适用GB 13456）

### 8.4 独立冷轧厂

**工序**：外购热卷 → 酸洗 → 冷轧 → 退火 → 镀锌/彩涂

**标准适用**：
- 酸洗废气：GB 28665-2012
- 退火炉：GB 28665-2012
- 镀锌/彩涂：GB 28665-2012 + VOCs地方标准
- 废水：GB 8978-1996（无炼铁/炼钢，不适用GB 13456）
- 六价铬：GB 13456-2012（间接排放）

## 九、真实审批拒绝案例

### 案例1：独立冷轧企业管理类别误判（江苏某冷轧带钢企业）

**基本信息**：
- 行业：冷轧带钢生产（年产30万吨）
- 管理类别：简化管理（误报）
- 审批结果：不予核发，退回按重点管理重新申报

**拒绝原因**：
1. 企业有冷轧+酸洗+退火工序，属于"热轧/冷轧/涂镀工序"
2. 错误申请简化管理（冷加工误认为就是简化）
3. 遗漏二噁英监测（电退火炉可能产生）
4. 遗漏六价铬因子（镀锌钝化工序）

**整改要求**：
- 重新确认管理类别为重点管理
- 按重点管理要求补充全部材料
- 补充酸洗盐酸雾监测方案
- 补充六价铬监测方案

**经验教训**：冷轧+酸洗属于"涂镀工序"，按《名录》应为重点管理

### 案例2：烧结二噁英监测缺失（河北某钢铁企业）

**基本信息**：
- 行业：钢铁联合企业（年产300万吨）
- 管理类别：重点管理
- 审批结果：补充材料后通过

**拒绝原因**：
1. 遗漏烧结机头二噁英监测（每年1次）
2. 二噁英检测方法引用错误（应用HJ 77.3-2008）
3. 氟化物因子遗漏（部分高氟铁矿石）

**整改要求**：
- 补充烧结机头二噁英监测方案（每年1次）
- 补充高氟矿烧结的氟化物监测方案
- 重新核算烧结SO₂、NOx许可排放量

**经验教训**：烧结机头二噁英是钢铁联合企业的重要排放源，必须纳入监测

### 案例3：镀锌钝化六价铬因子遗漏（山东某热镀锌企业）

**基本信息**：
- 行业：热镀锌钢板生产（年产50万吨）
- 管理类别：重点管理
- 审批结果：不予核发，退回修改

**拒绝原因**：
1. 遗漏热镀锌钝化六价铬因子
2. 钝化液使用三价铬钝化剂但未核实
3. 实际使用含六价铬钝化液，超标排放未被监测发现

**整改要求**：
- 补充六价铬监测（废水每月1次）
- 核实钝化液类型（六价铬/三价铬/无铬）
- 按实际钝化液类型调整监测方案
- 制定六价铬超标整改方案

**经验教训**：镀锌钝化六价铬是钢铁行业重金属监管的重点，必须实地核实钝化液类型

## 十、边缘情况处理指南

### 10.1 不同钢种的特征因子差异

| 钢种 | 额外特征因子 | 备注 |
|-----|-----------|------|
| 碳素钢 | 基本因子 | 无特殊重金属 |
| 合金钢（铬系） | 六价铬、总铬 | 炼钢/轧制环节 |
| 不锈钢（镍铬系） | 总镍、总铬、六价铬 | 炼钢/酸洗环节 |
| 硅钢 | 氟化物（HF酸洗） | 冷轧硅钢酸洗 |
| 镀锌钢板 | 六价铬（钝化）、总锌 | 镀锌钝化环节 |
| 彩涂钢板 | VOCs | 涂层固化环节 |

### 10.2 短流程vs长流程企业的许可差异

| 项目 | 长流程联合企业 | 短流程电炉+轧钢 | 独立轧钢 |
|-----|-------------|--------------|--------|
| 管理类别 | 重点管理 | 重点管理 | 重点管理（有酸洗）/简化（无酸洗） |
| 烧结/炼铁 | 有 | 无 | 无 |
| 标准体系 | GB 28662-28665+GB 13456 | GB 28664+28665 | GB 28665 |
| 二噁英监测 | 烧结+炼钢 | 炼钢（电炉） | 仅电退火炉（若有） |
| 废酸液 | 无 | 无 | 冷轧酸洗HW34 |
| 酚氰废水 | 有（若有焦化） | 无 | 无 |

### 10.3 钢铁行业超低排放与许可证的关系

**超低排放要求**（生态环境部2019年《关于推进钢铁行业超低排放的意见》）：

| 工序 | 超低排放限值（mg/m³） |
|-----|----------------------|
| 烧结机头/球团焙烧 | SO₂≤35，NOx≤50，颗粒物≤10 |
| 高炉出铁场 | 颗粒物≤10 |
| 转炉 | 颗粒物≤10 |
| 轧钢加热炉（天然气） | SO₂≤50，NOx≤150，颗粒物≤10 |

**许可证与超低排放的关系**：
- 许可证限值执行GB 28662-2012等国家标准
- 超低排放是企业自愿达成的更高目标
- 达到超低排放的企业在重污染天气应急中可获得差异化管理
- 许可证中不强制要求超低排放，但鼓励超低排放改造
