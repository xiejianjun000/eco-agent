# 半导体制造行业技术审查深度指南

## 行业概述与适用范围

### 行业定义
根据《固定污染源排污许可分类管理名录（2019年版）》，半导体制造业属于计算机、通信和其他电子设备制造业（C39），具体包括：
- 集成电路制造（C3973）
- 半导体分立器件制造（C3972）
- 半导体照明器件制造（C3974）
- 其他电子器件制造（C3979）

### 行业特点
半导体制造是电子工业的核心，具有：
- **高能耗**：大量使用电力、纯水
- **高水耗**：清洗工序用水量大
- **高技术密度**：光刻、蚀刻、薄膜沉积等精密工艺
- **高污染风险**：使用大量特种气体、酸碱、有机溶剂

## 二、监测频次决策树

```
开始：确定管理类别
├─ 重点管理（12寸及以上集成电路晶圆制造）
│  ├─ 废水
│  │  ├─ CODcr、氨氮、氟化物 → 自动监测（日/实时）
│  │  ├─ 重金属因子 → 自动监测（日/实时）
│  │  ├─ 其他常规因子 → 手工监测，每周至少1次
│  │  └─ 流量 → 自动监测
│  └─ 废气
│     ├─ NMHC、酸雾 → 自动监测（小时值）
│     ├─ 特种气体（硅烷、磷化氢等） → 自动监测（小时值）
│     └─ 其他因子 → 手工监测，每周至少1次
├─ 简化管理（8寸及以下集成电路晶圆制造、分立器件、LED）
│  ├─ 废水
│  │  ├─ CODcr、氨氮 → 每月至少1次
│  │  ├─ 氟化物、重金属 → 每月至少1次
│  │  └─ 其他因子 → 每季度至少1次
│  └─ 废气
│     ├─ NMHC、酸雾 → 每月至少1次
│     └─ 其他因子 → 每季度至少1次
└─ 登记管理（封装测试）
   └─ 不需要自行监测（但需记录台账）
```

### 关键决策点

**决策点1：晶圆尺寸？**
- 12寸及以上 → 重点管理
- 8寸及以下 → 简化管理
- 仅封装测试 → 登记管理

**决策点2：是否有特种气体？**
- 是（硅烷、磷化氢、砷化氢等）→ 提高监测频次，自动监测
- 否 → 按标准执行

**决策点3：是否有重金属因子？**
- 是（铜、铝、金等）→ 提高监测频次，自动监测
- 否 → 按标准执行

## 四、常见错误TOP 10

### 错误1：遗漏特种气体因子
**案例**：某企业仅填报NMHC、酸雾，遗漏硅烷、磷化氢
**后果**：许可证被退回，补充监测花费5万元
**正确做法**：对照工艺流程图，逐项核对特种气体使用清单

### 错误2：标准适用错误
**案例**：企业执行GB 8978-1996（综排），未执行GB 39731-2020（电子行业标准）
**后果**：限值错误，需重新申请
**正确做法**：半导体行业必须执行GB 39731-2020

### 错误3：监测频次不足
**案例**：重点管理企业氟化物监测频次为季度，不满足自动监测要求
**后果**：证后监管发现，处罚3万元
**正确做法**：重点管理+氟化物，必须自动监测

### 错误4：排放口设置错误
**案例**：将一般清洗废水与含氟废水混排
**后果**：氟化物浓度稀释，监测数据无效
**正确做法**：含氟废水必须单独收集、单独处理、单独排放

### 错误5：总量指标核算方法错误
**案例**：用浓度乘以设计水量，未用实际监测数据
**后果**：总量指标偏大，无法通过审批
**正确做法**：优先采用近3年实际监测数据均值

### 错误6：危险废物代码错误
**案例**：废光刻胶填报HW49，实际应为HW06（废有机溶剂）
**后果**：后期转移处置困难
**正确做法**：对照《国家危险废物名录》，废光刻胶为HW06

### 错误7：遗漏无组织排放源
**案例**：仅填报有组织排放，遗漏车间无组织（NMHC、酸雾）
**后果**：审查不通过
**正确做法**：半导体制造企业必须填报厂界无组织排放（NMHC、酸雾、氟化物）

### 错误8：纯水制备废水未分清
**案例**：将纯水制备废水（低污染）与生产废水（高污染）混排
**后果**：生产废水浓度稀释，监测数据无效
**正确做法**：纯水制备废水单独收集，可排入雨水系统或单独处理

### 错误9：特别排放限值适用错误
**案例**：企业位于长三角，未执行特别排放限值
**后果**：许可证载明限值错误，需变更
**正确做法**：核对生态环境部公告2018年第14号，确认是否位于特别排放限值区域

### 错误10：特种气体泄漏监测缺失
**案例**：企业使用硅烷、磷化氢等特种气体，未安装泄漏监测报警装置
**后果**：存在安全隐患，审查不通过
**正确做法**：使用特种气体的企业必须安装泄漏监测报警装置，并与通风系统联锁

## 六、多工序企业标准适用指南

### 6.1 集成电路制造+封装测试
**场景**：企业同时从事集成电路制造和封装测试

**标准适用**：
- 集成电路制造：执行GB 39731-2020
- 封装测试：执行GB 39731-2020

**审查要点**：
- 制造与封装测试的排放口必须分开设置
- 相同因子（如CODcr、氨氮）执行较严标准
- 台账记录必须分工序记录

### 6.2 半导体制造+显示器件制造
**场景**：企业同时生产半导体器件和显示器件

**标准适用**：
- 半导体制造：执行GB 39731-2020
- 显示器件制造：执行GB 39731-2020

**审查要点**：
- 不同产品的排放口必须分开设置
- 相同因子执行较严标准
- 自行监测方案必须分别制定

### 6.3 半导体制造+光伏制造
**场景**：企业同时生产半导体器件和光伏产品

**标准适用**：
- 半导体制造：执行GB 39731-2020
- 光伏制造：执行《光伏制造行业规范条件》

**审查要点**：
- 不同行业的排放口必须分开设置
- 相同因子执行较严标准
- 自行监测方案必须分别制定

## 七、真实审批拒绝案例（3个）

### 案例1：特种气体因子遗漏
**企业**：江苏某12寸集成电路晶圆制造企业
**管理类别**：重点管理
**拒绝原因**：
1. 废气排放口遗漏硅烷、磷化氢因子（工艺使用特种气体）
2. 未安装特种气体泄漏监测报警装置
3. 自行监测方案未包含特种气体因子

**整改方案**：
1. 补充监测，确认硅烷、磷化氢因子存在
2. 修改许可证申请表，增加硅烷、磷化氢因子
3. 安装特种气体泄漏监测报警装置

**经验教训**：必须逐项核对特种气体使用清单，不得遗漏

### 案例2：含氟废水混排
**企业**：上海某8寸集成电路晶圆制造企业
**管理类别**：简化管理
**拒绝原因**：
1. 含氟废水与一般清洗废水混排，氟化物浓度稀释
2. 监测数据无效，无法反映真实排放情况
3. 排放口设置不符合规范要求

**整改方案**：
1. 改造废水收集系统，含氟废水单独收集
2. 含氟废水单独处理、单独排放
3. 重新设置排放口，规范采样口

**经验教训**：含氟废水必须单独收集、单独处理、单独排放

### 案例3：危险废物代码错误
**企业**：广东某LED制造企业
**管理类别**：简化管理
**拒绝原因**：
1. 废光刻胶填报HW49（其他废物），实际应为HW06（废有机溶剂）
2. 废酸碱填报HW49，实际应为HW34（废酸）或HW35（废碱）
3. 危险废物代码错误，导致后期转移处置困难

**整改方案**：
1. 对照《国家危险废物名录》，修正危险废物代码
2. 补充危险废物处置合同
3. 修改环境管理台账记录要求

**经验教训**：危险废物代码必须对照《国家危险废物名录》逐项核对

## 十、边缘情况处理指南

### 10.1 研发试制与规模化生产共线
**场景**：企业在同一车间进行研发试制和规模化生产

**处理原则**：
- 研发试制排放不计许可排放量，但需记录台账
- 规模化生产排放需核算许可排放量
- 排放口合并设置，但台账分开记录

**审查要点**：
- 研发试制与规模化生产是否明确区分？
- 台账记录是否分开？
- 许可排放量是否仅核算规模化生产部分？

### 10.2 多条生产线切换生产不同产品
**场景**：同一条生产线在不同时间段生产集成电路和分立器件

**处理原则**：
- 必须分清不同产品的排放因子
- 切换生产时需进行设备清洗，清洗废水单独收集处理
- 台账记录必须分产品类型记录

**审查要点**：
- 不同产品的排放因子是否分别填报？
- 清洗废水是否单独收集处理？
- 台账记录是否分产品类型？

### 10.3 纯水制备废水处理
**场景**：企业配套建设纯水制备设施，产生低污染废水

**处理原则**：
- 纯水制备废水（低污染）可排入雨水系统或单独处理
- 不得与生产废水（高污染）混排
- 纯水制备设施需单独填报排放口

**审查要点**：
- 纯水制备废水是否单独收集？
- 是否排入雨水系统或单独处理？
- 纯水制备设施是否单独填报排放口？

### 10.4 配套污水处理设施
**场景**：企业配套建设污水处理设施，处理自身废水

**处理原则**：
- 配套污水处理设施需单独填报排放口
- 污水处理设施出水执行GB 39731-2020
- 污水处理设施污泥需鉴别是否属于危险废物

**审查要点**：
- 配套污水处理设施是否单独填报排放口？
- 污水处理设施出水是否执行正确标准？
- 污水处理设施污泥是否按危险废物管理？

### 10.5 特种气体泄漏应急管理
**场景**：企业使用硅烷、磷化氢等特种气体

**处理原则**：
- 必须安装特种气体泄漏监测报警装置
- 泄漏监测报警装置需与通风系统联锁
- 必须制定特种气体泄漏专项应急预案

**审查要点**：
- 是否安装特种气体泄漏监测报警装置？
- 泄漏监测报警装置是否与通风系统联锁？
- 是否制定特种气体泄漏专项应急预案？
