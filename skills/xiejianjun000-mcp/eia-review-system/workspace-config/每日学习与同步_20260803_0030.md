## 三、关键发现

### 3.1 重大知识缺口（本次核心收获）

**GB 18466-2005《医疗机构水污染物排放标准》第1号修改单**（国家标准公告 2026 年第 28 号，2026-06-27 发布）——本地 20 份每日笔记**零覆盖**，属重大遗漏。

五大修改：
1. 适用范围首次写入“**排污许可证核发**”，并扩展至“平急两用”公共基础设施（方舱医院、集中隔离场所）
2. **直接排放**医疗机构新增“**斑马鱼卵急性毒性**”综合毒性控制项目
3. 20 张床位以下小型机构消毒要求 + 传染病区污水**分流预消毒**
4. **废水处理污泥不再定性为危险废物**（须消毒达标后转移；医疗废物 HW01 仍为危废）
5. 厘清卫健／疾控／生态环境三方监管职责

实施双时间轴：新扩改 2026-09-01 / 现有 2028-09-01（注意与 GB 4287-2026 的现有节点 2028-01-01 相差 8 个月）。

**根因分析**：该标准以“**修改单**”形式发布，不产生新标准号，被既有检索词过滤掉；且医疗行业不属传统“两高”，主观关注权重偏低。已固化检索方法论规则（R-20260803-07）。

### 3.2 其他新增知识
