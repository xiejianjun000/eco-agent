## 二、头号重点：排污许可证申领驳回高频原因深度解析

### 2.1 驳回原因一：排污数据与环评报告"脱节"（约占驳回案例40%）

**核心问题**：排污数据与环评批复文件不一致，是最常见的驳回原因，环保部门审核时重点比对两者一致性。

| 脱节类型 | 具体情形 | 后果 |
|---------|---------|------|
| **废水排放量不符** | 环评批复明确废水排放量500吨/月，企业申报填800吨/月 | 直接驳回 |
| **污染物种类不符** | 环评中未提及某污染物（如VOCs），企业申报时自行新增 | 须补充环评变更文件 |
| **排放量与环评文件逻辑不符** | 实际排污量明显超出环评预测范围，无合理解释 | 驳回+要求核实 |
| **新增排放口未备案** | 企业增设了环评中未载明的排放口 | 须先做环评变更 |

**审查专家操作规范**：
1. 受理前：要求企业提交环评批复文件（含批准排放量）
2. 核对：申请表填报的排污数据与环评批复逐项比对
3. 不符时：要求企业出具变更说明或补充环评变更批复
4. 注意：环评"未提及某类污染物"≠企业不能申报该因子；若企业确实排放该因子，须先办环评变更

**技术审查要点（HJ 942-2018总则）**：
- 排污许可申请数据应与环评批复保持逻辑一致
- 实际排放量可略低于环评批复，但不能超出（有充分理由的除外）
- 特征因子须以环评文件为依据，环评未载明因子须先变更环评

### 2.2 驳回原因二：污染治理方案"不落地"（缺乏可行性）

**核心问题**：治理方案仅笼统描述"达标排放"，未明确具体措施，被判定不合格。

**合格治理方案三要素**：

| 要素 | 要求 | 不合格示例 | 合格示例 |
|------|------|----------|---------|
| **处理工艺** | 须符合行业技术规范，写明具体工艺路线 | "废水经处理后排放" | "废水采用'调节池+厌氧+好氧+二沉池'工艺" |
| **设施运行参数** | 提供关键控制参数及监测方法 | 无参数说明 | "好氧池DO=2-4mg/L，pH=6.5-8.5，温度25-35℃" |
| **维护计划** | 明确责任人、时间节点、操作规程 | "定期维护" | "每月清理滤料，每季度校准监测设备，责任人生产部长" |

**技术审查专家核查要点**：
1. 工艺是否符合行业技术规范（对照HJ 863-2017食品/HJ 861-2017纺织印染等）
2. 可行技术判断：优先采用污染防治可行技术指南所列技术
3. 无可行技术时：须提供工程试验数据证明设施可达许可浓度
4. 维护计划与台账记录制度对应：后续检查要有据可查

### 2.3 驳回高频原因三：排污口设置不符合"规范化要求"

**规范化核心要求（依据 HJ 942-2018 + 条例第18条）**：

| 项目 | 要求 | 违规情形 |
|------|------|---------|
| 排放口位置 | 与许可证载明一致 | 擅自迁移排放口 |
| 排放口数量 | 与许可证载明一致 | 增设或减少排放口（须变更） |
| 排放方式 | 与许可证载明一致 | 间歇排放改为连续排放 |
| 排放去向 | 与许可证载明一致 | 直接排放改为间接排放 |
| 采样口设置 | 规范化建设，有标识牌 | 采样口不规范、无法采样 |

> **深圳南山案例印证**：UV废气处理装置（DA001）和有机废气排放口（DA002）已登记，但2个平版车间集尘机废气排放口被遗漏——这是典型的"排放口数量不符"。

### 2.4 驳回高频原因四：申请材料不完整（形式审查被退）

| 材料类型 | 具体要求 | 常见缺失 |
|---------|---------|---------|
| 排污许可证申请表 | 法定代表人签字/盖章一致 | 签字人与营业执照不一致 |
| 承诺书 | 法定代表人或主要负责人签字盖章 | 签字人无授权文件 |
| 自行监测方案 | 完整，包含点位/因子/频次/方法 | 缺失或过于简略 |
| 排污口规范化说明 | 包含规范化证明材料 | 仅文字描述，无支撑文件 |
| 环评批复文件 | 有效的环评批复文号 | 环评已过期/未验收 |
| 总量指标来源证明 | 明确总量指标来源 | 未注明总量来源或来源不明确 |
| 申请前信息公开说明表 | 重点管理须提交，日期在公示期后 | 简化管理误提交/重点管理未提交 |

## 三、深圳南山油墨企业排放口数量不符案（典型案例深度解析）

### 3.1 案件基本信息

| 项目 | 内容 |
|------|------|
| **地区** | 广东深圳南山区 |
| **企业** | 深圳某油墨公司 |
| **检查时间** | 2023年9月14日 |
| **总排放口数量** | 5个废气排放口 |
| **登记在册** | UV废气处理装置（DA001）、有机废气排放口（DA002）、锅炉废气排放口（3个均已登记） |
| **遗漏登记** | 2个平版车间集尘机废气排放口、连结料车间集尘机废气排放口 |

### 3.2 违法认定与法律适用

| 项目 | 内容 |
|------|------|
| **违反条款** | 《排污许可管理条例》第18条第2款 |
| **条文内容** | "污染物排放口位置和数量、污染物排放方式和排放去向应当与排污许可证规定相符" |
| **处罚依据** | 《排污许可管理条例》第36条第1项 |
| **处罚结果** | 罚款**2万元** |
| **整改要求** | 补充登记遗漏排放口，重新申请变更 |

### 3.3 执法检查技术要点

| 检查步骤 | 操作动作 |
|---------|---------|
| **第一步** | 统计企业全部排放口数量（含DA编号、排放类型） |
| **第二步** | 逐一比对许可证副本载明的排放口清单 |
| **第三步** | 现场核查实际排放口位置，确认是否与登记一致 |
| **第四步** | 重点关注：辅助生产设施排放口（集尘机、空压机、冷冻机组等）容易被遗漏 |
| **第五步** | 发现不一致时：拍照固定、现场笔录、平台截图三证合一 |

### 3.4 关联技术规范

**HJ 942-2018《排污许可证申请与核发技术规范 总则》**：
- 排放口信息须逐一登记
- 主要排放口须明确许可排放量
- 一般排放口须明确排放浓度限值
- 遗漏任何排放口均构成"排放口数量不符"

**法典第1109条（8月15日后）**：
- 违规设置排污口：罚款2万—10万（一般）；10万—50万（严重）
- 饮用水水源保护区等特殊区域：10万—50万（一般）；50万—100万（严重）

### 4.1 标准基本信息

| 项目 | 内容 |
|------|------|
| 标准编号 | HJ 944-2018 |
| 发布日期 | 2018-03-27 |
| 施行日期 | 2018-03-27 |
| 起草单位 | 生态环境部环境工程评估中心 |

| 与许可证关系 | 台账是许可证执行情况的原始记录，保存期≥5年 |

### 4.2 台账记录核心要求（HJ 944-2018第4章）

**台账记录对象**：
1. 主要生产设施运行管理信息
2. 污染防治设施运行管理信息
3. 监测数据记录
4. 其他环境管理信息（耗材更换、故障处理、应急事件等）

**台账记录格式**（附录A）：

| 台账类型 | 记录内容 | 记录频次 |
|---------|---------|---------|
| 生产设施运行记录 | 产品产量、原辅材料消耗、运行时间 | 班次/日 |
| 污染防治设施运行记录 | 运行参数（温度/pH/DO等）、加药记录、故障维修 | 班次/日 |
| 监测数据记录 | 监测时间、监测因子、监测结果、监测方法 | 按监测频次 |
| 特殊记录 | 设施故障、应急事件、整改情况 | 事件发生时 |

**台账保存要求**：
- 保存期限：**不少于5年**（与条例第22条一致）
- 保存形式：电子台账+纸质台账并行（均须保存）
- 不得篡改、伪造

### 4.3 执行报告编制技术规范（HJ 944-2018第5章）

**报告分类**：

| 报告类型 | 提交时间 | 适用对象 |
|---------|---------|---------|
| 月度报告 | 次月15日前 | 重点管理（按许可证要求） |
| 季度报告 | 次季度首月15日前 | 重点管理（按许可证要求） |
| 年度报告 | 次年1月底前（1月15日前：火电等行业） | 所有持证单位 |
| 停产报告 | 许可证有效期内发生停产时 | 停产期间也须创建报告 |

**执行报告内容**（附录D编写提纲）：

| 章节 | 内容 |
|------|------|
| 基本信息 | 报告周期、排放口变化情况 |
| 产排污变化 | 生产设施/污染治理设施变动情况 |
| 排放浓度合规性分析 | 各排放口污染物浓度达标情况 |
| 排放量核算 | 各污染物实际排放量（含计算方法） |
| 自行监测情况 | 监测方案执行情况、数据分析 |
| 环境管理台账执行情况 | 记录完整性说明 |
| 合规判定结论 | 是否符合许可证要求 |
| 整改情况 | 上周期问题整改情况 |

### 4.4 技术审查专家台账核查要点

| 核查项 | 常见问题 | 审查动作 |
|-------|---------|---------|
| 台账是否建立 | 未建立 | 检查纸质台账本/电子台账系统 |
| 台账格式是否合规 | 格式与许可证要求不符 | 对照许可证副本载明格式 |
| 记录内容是否完整 | 缺失运行参数/加药记录 | 逐项核对台账记录项目 |
