## 一、重大新标准发布：HJ 1480-2026《排污单位自行监测视频监控系统建设与联网技术要求》

### 1.1 标准基本信息

| 项目 | 内容 |
|------|------|
| 标准编号 | **HJ 1480-2026** |
| 标准名称 | 《排污单位自行监测视频监控系统建设与联网技术要求》 |
| 发布单位 | 生态环境部 |
| 公告文号 | 公告 2026年 第34号 |
| 发布日期 | **2026年7月22日** |
| 实施日期 | **2026年10月1日** |
| 法律依据 | 《中华人民共和国生态环境法典》+《生态环境监测条例》 |

### 1.2 标准适用范围与核心内容

**适用范围**：实行排污许可管理的排污单位自行监测活动过程及监测设备运行情况的视频监控系统建设、联网以及运行管理。

**涵盖主体**：所有持证排污企事业单位及生产经营者，包括生活垃圾焚烧厂、填埋场、厨余垃圾处理厂等环卫类排污主体。

**技术规范涵盖六大模块**：
1. 视频监控系统结构设计
2. 前端设备功能和性能要求
3. 视频数据汇聚系统规范
4. 前端设备安装技术要求
5. 联网传输规范
6. 运行管理要求

### 1.3 对排污许可技术审查的影响

**审查新要点**：
1. **许可证中自行监测方案需补充视频监控要求**：审查时需确认企业是否已按要求规划视频监控系统
2. **新申请许可证**：10月1日起应载明自行监测视频监控建设要求
3. **已持证企业**：需限期补充视频监控设施，审查时应关注整改进度
4. **环卫行业专项**：生活垃圾焚烧厂、填埋场首次被纳入视频监控强制性标准

**与现有系统的关系**：
- 该标准将视频监控从"辅助手段"升级为"法定要求"
- 与HJ 819-2017（自行监测总则）形成互补：HJ 819管"测什么、怎么测"，HJ 1480管"怎么看着测"
- 为宁夏等地自行监测视频监控要求提供了国家层面的技术标准依据

### 1.4 视频监控与执法证据链

此前7月31日学习的河南第七批典型案例中"道路视频监控+生态环境部门联动"模式，将被HJ 1480-2026标准化的排污单位内部监控所补充：
- 内部监控（HJ 1480标准）+ 外部道路监控（公安联动）= 双重监控执法体系
- 视频监控数据可作为"逃避监管方式排放"的证据，与法典相关规定衔接

### 2.3 税收优惠政策

| 绩效等级 | 减征比例 | 含义 |
|:---:|:---:|------|
| **A级** | 减按应纳税额的**50%** | 国家重点行业大气环境绩效A级 |
| **B级** | 减按应纳税额的**75%** | 国家重点行业大气环境绩效B级 |

**政策逻辑**："多排多缴、少排少缴"，引导企业实施源头替代、改进生产工艺、提高资源利用效率、强化收集治理。

### 2.4 排污许可技术审查的关联

1. **许可证中VOCs许可排放量**将直接影响企业环保税税基
   - 许可证载明的VOCs许可排放量 → 环保税计税依据的重要参考
   - 审查时VOCs许可排放量核算准确性更加关键
2. **A/B级绩效评定**与许可证中的治理设施要求直接相关
   - A级企业享受50%减征 → 审查时需核实企业绩效等级真实性
3. **分步推开策略**：先在8行业试点 → 评估效果 → 适时全面推开
   - 8个行业之外的企业暂不受影响，但须关注后续扩展

### 2.5 与现有环保税的关系

- 此前环保税法仅对苯、甲苯、甲醛等**18种**有毒或恶臭VOCs单项物质征税
- 新试点将现行税目以外的VOCs**作为一类大气污染物整体计税**
- 18种已征税的VOCs物质仍按原规定单项征税，其排放量在整体计算时予以扣除（避免重复征税）

## 四、宁夏出台自行监测管理新规（典型地方创新）

### 4.1 基本信息

| 项目 | 内容 |
|------|------|
| 文件名称 | 《宁夏回族自治区排污单位自行监测管理规定（试行）》 |
| 施行日期 | **2026年9月1日** |
| 有效期 | 至2028年8月31日 |
| 适用范围 | 宁夏所有持证排污企事业单位及生产经营者 |

### 4.2 核心制度设计（可全国推广参考）

**全链条质量管理制度**：覆盖点位布设、设备运维、样品采集、数据处理、台账归档、问题整改六个环节。

**联网时限**：取得排污许可证**3个月内**须完成自动监测设备调试与联网。

**7类行为直接认定为设备未正常运行**：
1. 未按规范运维设备导致数据失真
2. 设备故障、数据异常、指标超标未及时处置
3. 擅自改动、遮挡监控设备，篡改删除监控数据
4. 数据有效传输率、监控在线率不达标
5. 未规范标记设备及治污设施运行工况
6. 违规启停监测、监控设备
7. 其他未正常运行污染物排放监测、监控设备

**4类行为认定为监测数据失真**：
1. 监测关键环节违规，造成数据错误、无法复核
2. 自动监测设备技术指标超出规范限值2倍及以上
3. 擅自中断数据采集传输、违规标记处理数据
4. 其他违反监测规范、造成数据失真的行为

**6类"情节严重"认定标准**：
1. 两年内因数据造假被处罚后再次同类违法
2. 造假违法所得超10万元
3. 违规篡改、伪造10份及以上监测记录与报告
4. 删除、破坏设备运行日志导致数据无法溯源
5. 造成重大环境或恶劣社会影响
6. 其他依法应当认定为情节严重的情形

### 4.3 对排污许可技术审查的启示

1. **宁夏模式可作为配套HJ 1480-2026的地方实施范本**
   - 宁夏9月1日先于国家标准10月1日施行，属"地方先行先试"
2. **"3个月内联网"时限** → 审查新发证企业时应纳入整改跟踪
3. **联合信用惩戒机制** → 监测数据造假不再仅是行政处罚，还影响企业信贷、招投标、评优等
4. **柔性+刚性结合监管**：轻微违规约谈提醒+严重违法行为从严查处

## 五、最新典型案例深度分析

### 5.1 广东顺德均安三企逃避监管案（2026年7月）

**来源**：顺德城市网 2026年7月20日报道

| 案例 | 企业类型 | 违法方式 | 检测超标因子 | 许可证/环评要求 |
|------|------|------|------|------|
| 案例一 | 涂料企业 | **私设暗管**排放废水 | COD、悬浮物 | 许可证规定：废水应交由第三方外运处置 |
| 案例二 | 石材加工场 | **不正常运行治理设施** | COD、总磷、悬浮物 | 环评要求：废水三级沉淀处理后回用 |
| 案例三 | 木制品公司 | **利用渗坑排放**含油墨废水 | COD、总磷 | 未建设废水治理设施 |

**执法亮点**：
- 案例一：执法人员经"地毯式"检查，在厂房隐蔽位置发现擅自建设的废水处理设施+隐藏塑料管道→雨水管道→河涌
- 案例二：厂房改建破坏废水收集渠，负责人"任由废水流入河涌"→主观故意明显
- 案例三：厂外墙脚排水口→厂外无防渗土壤→形成渗坑

**法律适用分析（法典施行后）**：
- 三类行为均构成法典第34条第2项（原条例第34条第2项）"逃避监管方式排放"
- 罚款幅度：10万-100万元 + 移送公安行政拘留
- 涂料企业主观故意最明显（有证却私设暗管）→ 从重裁量

**对技术审查的启示**：
1. 审查时对许可证载明"废水外运处置"的企业，应核实第三方处置合同+转运联单
2. 石材加工、木制品等小微企业容易"省钱省事"走偏 → 审查时应标注为高风险关注对象
3. 厂房改建、生产线调整后治理设施是否仍完好 → 变更审查要点

### 5.2 顺德乐从许可证有效期届满案（参考时间对比）

## 七、技术审查知识深化

### 7.1 新标准体系下的自行监测审查框架升级

**旧框架**（仅HJ 819系列）：
```
自行监测方案审查
├── 监测点位 → HJ 819 + 行业指南
├── 监测因子 → 技术规范"产排污环节"
├── 监测频次 → 自行监测指南
├── 监测方法 → 排放标准规定方法
└── 自动监测要求 → 重点管理+主要排放口
```

**新框架**（加入HJ 1480-2026）：
```
自行监测方案审查（升级版）
├── 监测点位 → HJ 819 + 行业指南
├── 监测因子 → 技术规范"产排污环节"
├── 监测频次 → 自行监测指南
├── 监测方法 → 排放标准规定方法
├── 自动监测要求 → 重点管理+主要排放口
└── 🆕 视频监控要求 → HJ 1480-2026
    ├── 前端设备功能和性能
    ├── 安装位置与覆盖范围
    ├── 联网传输要求
    └── 运行管理要求
```

### 7.2 VOCs许可排放量审查精度提升

VOCs环保税实施后，许可证中的VOCs许可排放量将直接关联企业税负：

**审查强化点**：
1. VOCs许可排放量核算必须精确（不再可"大致估计"）
2. 有组织+无组织排放须分别核算
3. 原辅材料VOCs含量数据必须可溯源
4. 治理设施VOCs去除效率必须有检测报告支撑
