## 二、头号重点：生态环境部《关于优化排污许可证（副本）格式的通知》

### 2.1 基本信息

| 项目 | 内容 |
|------|------|
| 文件 | 《关于优化排污许可证（副本）格式的通知》 |
| 发布 | 生态环境部，2026-06-04发布 / 2026-06-09公开 |
| 施行 | **2026年8月15日起，分行业分批次在全国排污许可证管理信息平台更新** |
| 前提 | 无需企业重新填报、无需换发纸质证件，平台自行下载新版 |
| 立法背景 | 落实《中华人民共和国生态环境法典》精神、深化排污许可"一证式"管理 |

### 2.2 四大优化方向（对照旧版痛点）

| 痛点 | 优化措施 | 审查/执法意义 |
|------|---------|-------------|
| 基层和企业"看不懂" | 每个环境要素**独立成章**，**一个排放口对应一张表**（一口一表一码） | 管理逻辑清晰，企业自查、基层审核易上手 |
| 执法监管"不好用" | 删除与排放不直接相关的冗余内容，突出**排放标准、许可排放量**等关键指标 | 执法检查直击核心，效率提升 |
| 环境要素"没管全" | 将**大气、水、工业固废、工业噪声、土壤**五要素全部纳入 | 夯实"一证式"全要素管理基础 |
| 现场核验不便 | 加强**二维码标识**技术应用 | 扫码即查，执法便利 |

### 2.3 审查专家应对要点

| 阶段 | 操作动作 |
|------|---------|
| **8/15前** | 提醒企业在申报/变更时仍按现行格式填报；新版由系统自动转换，企业无需重复申报 |
| **8/15起** | 核发/延续/变更后下载的副本为**五要素分章**版；审查核对口径不变（因子、限值、监测要求仍按行业技术规范） |
| **格式变化注意** | 旧版"登记事项/许可事项"混排 → 新版按要素、按排口拆分；现场执法以新版副本"许可排放量""排放标准"栏为准 |
| **与法典衔接** | 新版副本是落实生态环境法典"一证式"管理的载体，法典8/15施行当日即启用，审查须同步切换法典条文体系（许可174-186条+责任1101-1112条） |

> **关键判断**：副本格式优化**不改变许可内容的技术审查标准**（仍依79项申请与核发技术规范、45项自行监测指南、HJ 1299-2023质量核查规范），仅改变呈现形式。审查准确率提升不靠格式，靠因子/限值/监测三核对。

## 三、生态环境部4个排污许可质量典型案例深度解析（支撑95%审批率）

> 来源：生态环境部排污许可证质量常态化技术复核（2024-03发布），是质量核查（HJ 1299-2023）落地的实战教材。

### 3.1 四个案例一览

| 编号 | 问题类型 | 行业/代码 | 错误事实 | 正确要求 | 依据 |
|------|---------|----------|---------|---------|------|
| Q-1 | 管理类别错误（降级管理） | 林产化学产品制造 2663 | 实际有炭化工序（热解工艺），许可证错填"简化管理" | 有热解/水解工艺→**重点管理** | 分类管理名录（2019版） |
| Q-2 | 遗漏主要排放口 | 环境卫生管理 782（畜禽油脂加工） | 畜禽油脂加工废水排放口应为主要排放口，错识为"一般排放口" | 依HJ 860.3-2018应为主要排放口 | HJ 1106-2020 + HJ 860.3-2018 |
| Q-3 | 排放标准及限值错误 | 粘土砖瓦及建筑砌块制造 3031 | 二氧化硫填原标准300mg/m³，未执行修改单 | 应执行GB 29620-2013**修改单**限值150mg/m³ | GB 29620-2013及修改单 |
| Q-4 | 许可排放量错误 | 化学农药制造 2631 | 遗漏废水主要排放口COD、氨氮许可排放量 | 依HJ 862-2017应许可COD、氨氮排放量 | HJ 862-2017 |

### 3.2 启示意义（审查操作规范）

| 问题 | 审查动作（必做） |
|------|----------------|
| **管理类别降级** | 结合生产设施、产品产能、工艺流程图、原辅材料用量、重点排污单位名录，依《名录》研判；重点查"有热解/水解/染色/电镀/前处理等工艺但填简化"的降级情形 |
| **遗漏主要排放口** | 对照环评及批复、验收文件、排口规范化说明、工艺流程图、产排污节点图；必要时现场检查；重点查"主要排放口误识为一般排放口" |
| **标准及限值错误** | 依《生态环境标准管理办法》（部令17号）判定标准适用性与优先级；**必须查修改单**；关注新标准实施时间与更新限值 |
| **许可量错误** | 依行业技术规范"废水/废气类别、污染物、排放方式、治理设施"+环评批复，逐因子核许可量；大气重点查主要排放口，水重点查COD/氨氮及总磷总氮（总磷总氮控制区） |

### 3.3 与本地"95%审批率攻坚"对应

- Q-1 → 本地"管理类别判断错误（8%）"：用"管理类别判断流程"复核
- Q-2 → 本地"排放口信息不完整（10%）"+"特征因子遗漏（35%）"交叉：排放口类别识别是高频雷区
- Q-3 → 本地"排放标准适用错误（15%）"：标准适用决策树必须含"修改单"节点
- Q-4 → 本地"总量指标核算错误（3%）"+"许可排放量"：依行业规范逐因子核

```

```
