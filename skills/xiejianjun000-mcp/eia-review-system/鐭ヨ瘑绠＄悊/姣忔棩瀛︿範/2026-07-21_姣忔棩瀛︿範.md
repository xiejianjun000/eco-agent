## 二、重大制度变革：法典删除"重点排污单位"，全面转向"排污许可重点管理"（今日头号重点）

### 2.1 变革背景

**变革前（双轨制）**：
- 2014年《环保法》修订：新增"重点排污单位"（安装监测设备、信息公开义务）
- 2021年《条例》颁布：引入"排污许可重点管理"概念
- 两种监管体系**并行**，产生管理重叠、职责不清问题

**变革后（单轨制）**：  
2026年3月《生态环境法典》颁布，全面整合为以"排污许可"为核心的统一监管体系，"排污许可重点管理"成为污染源监管领域的唯一核心锚点。

### 2.2 法典核心条文体系（正式条号）

| 推定条号 | 内容 | 关键要求 |
|---------|------|---------|
| **第140条** | 信息披露义务 | 排污许可重点管理单位须依法及时、真实、准确、完整披露污染物排放信息、温室气体排放信息 |
| **第175条** | 分类管理定义 | 重点管理：产生量/排放量/影响程度较大；简化管理：产生量/排放量/影响程度较小 |
| **第184条** | 自动监测义务 | 排污许可重点管理单位须安装、使用、维护污染物排放自动监测设备，并与生态环境主管部门联网；数据传输异常须及时报告并检查修复 |

> **注**：以上为法典研究文献标注条号，正式条文以官方文本为准（8月15日后可核验）。

### 2.3 与法释〔2026〕4号的联动

**法释〔2026〕4号**（2026年3月30日施行）与法典同步修改：  
污染环境罪入罪标准中原"重点排污单位"相关表述 → 修改为 **"实行排污许可重点管理的单位"**，与法典制度选择保持完全一致。

**法律适用一致性**：  
排污许可重点管理单位篡改/伪造监测数据 → 直接适用污染环境罪（第338条）；不再需要额外证明"属于重点排污单位"。

### 2.4 技术审查专家应用要点

| 编号 | 应用要点 | 操作动作 |
|:---:|------|---------|
| F-01 | 审查时使用"排污许可重点管理"表述 | 许可证审核、执行报告、执法文书均用此表述，替代"重点排污单位" |
| F-02 | 分类管理判定 | 以《分类管理名录》为主要依据（当前为2019年版，修订版待发布） |
| F-03 | 自动监测义务主体 | 排污许可重点管理单位须安装自动监测设备并联网（法典第184条） |
| F-04 | 信息公开义务主体 | 排污许可重点管理单位须披露污染物排放信息（法典第140条） |
| F-05 | 刑事责任适用 | 重点管理单位数据造假=直接入刑，无需另证"重点排污单位"身份 |
| F-06 | 与现行条例/办法的衔接 | 8/15法典施行后，条例/办法中"重点排污单位"相关表述须核查是否仍有法律效力 |

### 2.5 对技术审查的具体影响

**审查端**：
- 自动监测设备安装审查：须核对企业是否为"排污许可重点管理"类别（不再查"重点排污单位"名录）
- 信息公开审查：重点管理单位须在平台公开污染物排放数据
- 分类管理：严格按《分类管理名录》判定管理类别

**执法端**：
- 违法认定：不再需要同时满足"重点排污单位+排污许可重点管理"双重条件
- 刑事责任：重点管理单位数据造假直接入刑，证据链简化

**企业端**：
- 不知道自己是否属于"重点排污单位"的企业，只要持有重点管理排污许可证，即须履行全部义务

## 三、南通"带病运行"移送公安案（今日二号重点）

### 3.1 案件基本信息

| 项目 | 内容 |
|------|------|
| **地区** | 江苏南通 |
| **企业类型** | 家居饰品有限公司（废气产生企业） |
| **检查时间** | 2025年11月7日 |
| **违法行为** | 废气处理设施碱喷淋塔pH计故障→"带病运行"数天 |
| **发现方式** | 现场执法检查（pH试纸快速检测） |
| **处理时间** | 2026年1月下达处罚决定 |
| **处罚结果** | 公司：责令改正 + 罚款**20万元**；环保总监：**移送公安处理** |

### 3.2 违法链条还原

```
2025年11月4日 环保专员日常巡检发现：
  ↓ pH计故障（碱喷淋塔自动加药设施故障）
  ↓ 专员汇报给环保总监
  ↓ 环保总监：无安排手工加药、无要求加强巡检、无组织紧急维修
  ↓ 污水处理站"带病运转"（喷淋液pH值=2.1，强酸性）
  
2025年11月7日 执法人员检查：
  ↓ pH试纸快速检测→pH 1-2（应为碱性，实为强酸）
  ↓ 海门生态环境监测站正式报告：循环水箱pH=2.1
  
2025年11月8日 企业才换新pH计，设施恢复正常

2025年11月18日 执法人员复查：喷淋液已呈碱性，企业"亡羊补牢"
```

### 3.3 "不正常运行"设施的五种情形（官方明确）

| 情形 | 含义 | 本案属于 |
|------|------|---------|
| **明开暗停** | 设施表面运行，实际未处理 | — |
| **偷工减料** | 药剂添加不足、处理效果不达标 | 本案：未添加碱液 |
| **私设旁路** | 废气绕过治理设施直接排放 | — |
| **带病运行** | 设施有故障但不修复继续生产 | **本案** |
| **数据造假** | 篡改/干扰监测数据 | — |

### 3.4 违法认定与法律适用

| 项目 | 内容 |
|------|------|
| **违法行为** | 污染防治设施不正常运行（属于《条例》第34条第2项"逃避监管"） |
| **法律依据** | 《排污许可管理条例》第34条第2项 |
| **公司处罚** | 责令改正 + 罚款20万元 |
| **个人责任** | 环保总监移送公安（"直接负责的主管人员"） |
| **整改情况** | 11月18日才更换设备，违法行为持续约4天 |

### 3.5 关键教训（企业必读）

**误区纠正**：
- ❌ "设备坏了口头报告就行了" → ✅ 报告≠免责，必须立即采取补救措施
- ❌ "设备没关掉就没问题" → ✅ 设施在故障状态下运行 = "带病运行" = 违法
- ❌ "停产才构成违法" → ✅ 正常生产+设施故障 = 违法

**正确做法**：
1. 发现故障 → 立即报告 + **立即采取手工加药等临时补救措施**
2. 同步组织维修 → 故障期间全程应急管控
3. 记录留存 → 台账记录故障时间、原因、补救措施、维修完成时间
4. 报告环保部门 → 按规定向生态环境主管部门报告

| 场景 | 审查/核查动作 |
|------|--------------|
| 证后管理审查 | 台账记录中须包含污染防治设施运行异常情况及处理记录 |

## 四、GB 47946—2026《丹江口库区及上游主要水污染物排放控制标准》（新增流域标准）

### 4.1 标准基本信息

| 项目 | 内容 |
|------|------|
| 标准编号 | **GB 47946—2026** |
| 标准全称 | 《丹江口库区及上游主要水污染物（总锑、总钼等）排放控制标准（试行）》 |
| 发布时间 | **2026年6月30日** |
| 性质 | 流域排放标准（首个南水北调中线水源地专门标准） |
| 核心管控因子 | **总锑、总钼**等特征污染物 |
| 适用对象 | 丹江口库区及上游排放水污染物的排污单位 |
| 法律地位 | 地方标准严于国标时执行地方标准；本标准为南水北调水源地保护区标准 |

### 4.2 技术审查专家应用要点

| 编号 | 应用要点 | 操作动作 |
|:---:|------|---------|
| D-01 | 适用区域 | 河南、湖北相关县域（南水北调中线工程水源地及上游流域） |
| D-02 | 特征因子 | 总锑、总钼等（特定流域特征污染物，须核对许可证是否载入） |
| D-03 | 与许可证衔接 | 涉及企业排污许可证须关注该标准实施时间，是否属于许可条件之一 |
| D-04 | 地方标准关系 | 流域排放标准通常严于国家综合排放标准；须确认企业排放口所在流域区段 |

### 4.3 关联知识：HJ 1069-2019 斑马鱼卵急性毒性测定法

GB 4287—2026 新增"斑马鱼卵急性毒性"指标，测定方法依据为 **HJ 1069-2019《水质 急性毒性的测定 斑马鱼卵法》**（2019年发布，2020年6月30日实施）。

| 项目 | 内容 |
|------|------|
| 方法原理 | 检测待测物质对斑马鱼卵孵化影响，评估水体急性毒性 |
| 关键指标 | 孵化率、死亡率、畸形率、LC50（半数致死浓度） |
| 质控要求 | 温度控制28℃±0.5℃；阳性对照组（荧光染料Rhodamine B） |
| 适用场景 | 染整污水、集中处理设施出水毒性监测（GB 4287—2026） |

| 采样管断开 | 布条固定；无真实水样 | 现场检查站房 |
