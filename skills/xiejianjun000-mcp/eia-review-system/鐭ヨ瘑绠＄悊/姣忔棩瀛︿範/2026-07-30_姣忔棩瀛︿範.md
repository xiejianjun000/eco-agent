### 1.2 四川省生态环境厅通报两起执法典型案例（7月29日，最新）

**来源**：红星新闻 2026-07-29 22:04

#### 案例一：成都某新材料公司私设暗管排放生产废水

**案情概要**：
- 2025年12月2日，蒲江生态环境局通过**河道监控巡查**发现寿安工业园区沟渠水质浑浊发黄
- 排查发现某新材料公司雨水排口排放黄色浑浊液体
- 进一步检查：废气处理设施循环水池、清洗废水水箱有**三根管道连接至雨水井**，未经处理的生产废水通过雨水井直排
- 环评及批复要求：生产废水循环使用、不外排
- 监测结果：雨水井及厂区外雨水井COD、氨氮、总磷明显偏高

**处罚结果**：
- 罚款**17.58万元**
- 移送公安机关，对直接责任人员**行政拘留**

**启示**：
1. **河道监控巡查已成非现场监管有效手段**：通过远程视觉监控发现异常，无需先到现场
2. **三根管道同时私设**：隐蔽性强，需逐根管道溯源追查
3. **环评"不外排"是刚性约束**：实际排放行为与环评批复不符构成违法
4. **雨水排口是重点检查对象**：多次案例证明私设暗管常以雨水排放为掩护

#### 案例二：崇州某科技公司油污流入白马河

**案情概要**：
- 2025年10月，群众投诉白马河崇州经开区河段出现油污
- 经沿河排查→锁定入河雨水排口→联合经开区管委会摸排雨水管网→锁定企业
- 原因：CNC切削液油雾废气处理设施下方的油污收集容器满载未及时清运，油污溢出→沿屋面雨水地漏→厂区雨水管网→入河排口→白马河
- 监测：园区雨水管入白马河口水样石油类**469mg/L**（严重超标）

**处罚结果**：
- 罚款**10万元**
- 启动生态环境损害赔偿：损害价值核定**9.0572万元**（含污染处置费+风险防控费）
- 由四川省生态环境科学研究院出具鉴定评估报告

**启示**：
1. **群众投诉+技术排查**锁定污染源的闭环模式
2. **CNC切削液油污是制造业常见风险点**：日常清运管理疏漏→溢出入河
3. **生态环境损害赔偿已成标配**：不是单一行政处罚，还需承担损害修复费用
4. **雨水管网摸排需联合多部门**：园区管委会+生态环境部门协同排查

## 二、《生态环境监测"十五五"规划》深度解读（7月中旬印发）

### 2.1 规划基本信息

| 项目 | 内容 |
|------|------|
| 发文单位 | 生态环境部、国家发展改革委 |
| 印发时间 | 2026年7月中旬 |
| 规划期 | 2026—2030年（"十五五"） |
| 目标 | 基本建成天空地海一体化生态环境监测网络 |

### 2.2 5大重点任务

1. **健全"天空地海"一体化监测网络**：国家监测网络体系化运行+数智化升级，央地协同布局、互联互通
2. **推进监测业务支撑提质增效**：提升监测点位代表性、数据有效率、综合分析和业务应用能力
3. **加强全过程穿透式质量管理**：覆盖监测网络→运控→数据→应用全流程
4. **加速监测技术与装备数智化升级**：AI等新技术与监测业务深度融合，推动监测网络系统性重塑与技术范式迭代
5. **不断提升依法监测水平**

### 2.3 6项重大工程

1. 国家生态环境监测网络运行管理能力建设
2. **新污染物协同监测能力建设**（新增领域）
3. 生物多样性监测能力建设（新增领域）
4. 国家温室气体监测能力建设（新增领域）
5. **自行监测监管能力建设**（与排污许可直接相关⭐）
6. 国家生态环境监测网络数智化升级工程

### 2.4 与排污许可审查/执法的直接关联

**对自行监测的影响（最直接）**：
- 规划明确要求"**自行监测穿透式监管能力明显增强，数据质量持续提高**"
- 这意味着"十五五"期间对排污单位自行监测的监管将从"看报告"变为"穿透式核查"——不再是企业报什么信什么
- 排污许可审查时，自行监测方案的合理性审查将更加严格

**对许可证审查的启示**：
1. 审查自行监测方案时，需考虑未来"穿透式监管"能力——监测点位是否可远程验证、数据是否可自动比对
2. 新污染物（如微塑料、PFAS、抗生素等）的监测能力建设将影响许可证中"其他控制指标"的载明要求
3. 数智化升级意味着自动监测数据分析将更多依赖AI——异常数据识别更精准

**对执法检查的启示**：
1. "穿透式监管"= 从平台数据 → 企业原始记录 → 实际排放的多层穿透核查
2. AI筛查将成为非现场监管标配：数据"一动不动"、"贴线"、生产工况与数据不匹配等异常信号的识别
3. 关键监测装备自主可控将影响执法取证——设备技术标准的统一有利于数据作为证据的采信

## 三、今日深度学习：特征因子三段交叉核对表 精研

### 3.1 方法回顾

今天我重新精研了专家经验库中的《排污许可证特征因子三段交叉核对表》，该方法是根治"特征因子遗漏"（占审批退件原因≈35%，排名第一）的核心工具。

**三段交叉核对法**：

```
环评批复/验收文件列明的因子
        ∪
排放标准（国标/行标/地标）全文列明的因子
        ∪
申请与核发技术规范（HJ ×××）必填因子
        ↓
取并集 = 许可证应填因子全集
        ↓
逐项确认：填 / 不填（必须写理由）
```

**铁律**：只要三段任一来源列明，许可证就不应遗漏。

### 3.2 四类"看似可删其实不能删"的陷阱（重新强化）

| 陷阱类型 | 错误做法 | 正确做法 |
|---------|---------|---------|
| 企业称"已不使用某原料" | 直接删除对应因子 | 必须有变更/停用证明，否则因子保留 |
| 间接排放企业 | 认为不需要监测第一类污染物 | 第一类污染物（六价铬、总镍等）**仍在车间排放口达标**，不能删 |
| 地方标准有更严因子 | 只对国标 | 国标未列但地标列明的，**必须填** |
| 老环评（2015年前） | 按老环评列因子 | 新标准新增因子（总锑、苯胺类等）即便是老环评未列，按现标准须补 |

### 3.3 高频遗漏因子速记卡（我今天的记忆强化）

**TOP 5 最容易遗漏的因子**：
1. **六价铬** vs 总铬 — 电镀行业只填总铬不填六价铬（国标要求六价铬0.2mg/L，总铬1.0mg/L）
2. **苯胺类** — 纺织印染用偶氮染料必产生，但企业常不报
3. **总锑** — 涤纶生产用锑催化剂，老环评无此因子但HJ 861-2017已列入
4. **VOCs** — 涂装/印刷/化工均有，但无组织排放监测要求常遗漏
5. **总氮** — 只填氨氮不填总氮，脱氮效果无法评估

**六大行业新污染物因子**：
- 石化：多环芳烃、石油烃、苯系物
- 涂料：VOCs（苯系物、卤代烃）、铅、铬
- 纺织印染：苯胺类、重金属（锑、铅）、染料特征污染物
- 橡胶：VOCs、多环芳烃（PAHs）
- 农药：特征有机物、急性毒性物质、TOC
- 医药：特征有机物、抗生素残留、TOC

### 3.4 标准核查顺序（审查SOP固化）

1. 先读排放标准全文（不光表1，把所有"污染物项目"标记出来）
2. 再读技术规范产排污环节表
3. 交叉环评批复/验收文件
4. 三段取并集，与许可证比对
5. 差集即遗漏项，要求补正或书面说明理由

### 4.3 雨水管道暗管排查方法论（从四川案例提炼）

1. **预判阶段**：看环评——是否要求"生产废水不外排/循环使用"
2. **发现阶段**：园区雨水排口水质异常→锁定污染时段
3. **排查阶段**：从雨水井逐级向上游排查→打开所有窨井盖→比对水质
4. **溯源阶段**：入厂检查废水处理设施→查找所有管道连接→**每根管道追根溯源**
5. **确认阶段**：采样监测→生产废水 vs 雨水排口水质比对→锁定暗管
