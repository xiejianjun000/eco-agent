## 二、HJ 1478—2026：土壤地下水隐患排查技术指南（重大新标）

### 2.1 出台背景与法律依据

**标准编号**：HJ 1478—2026  
**发布时间**：2026年6月  
**替代关系**：替代2021年印发的《重点监管单位土壤污染隐患排查指南（试行）》  
**法律依据**：法典第414条（推定条号，以正式文本为准）——土壤污染重点监管单位应建立土壤、地下水污染隐患排查整治制度，保证持续有效防止有毒有害物质渗漏、流失、扬散  

**"十四五"成效**：累计推动1.7万余家重点监管单位开展隐患排查及一轮"回头看"，整治了一批隐患点  
**为何修订**：试行指南实践中发现3类典型问题：  
1. 地上设施排查与安全生产管理重复，企业负担重  
2. 隐蔽性设施（埋地/接地储罐、池体、管道）重视程度不够  
3. 隐患判定和整治标准不明确，自由裁量空间大  

### 2.2 三大核心修改（与试行指南对比）

**修改一：排查范围精准聚焦**

试行版：地上设施和隐蔽性设施均纳入排查  
HJ 1478—2026：精准聚焦风险较大的**隐蔽性设施**和**重点场所防渗阻隔设施**，与安全生产管理区分  

**经初步测算**：企业重点场所和重点设施设备数量可平均**减少约30%**（减负措施）  
但核心要求未降低：隐蔽性设施是土壤地下水污染高风险来源，是排查重点

**修改二：细化现场排查方法（四类方法）**

| 方法 | 适用场景 | 关键要求 |
|------|---------|---------|
| **资料检查** | 所有设施 | 查阅设计文件/施工记录/防渗检测报告 |
| **目视检查** | 所有设施 | 地面裂缝/腐蚀/渗漏痕迹 |
| **渗漏检测** | 隐蔽性设施（强化） | 筛选了一批技术较成熟、经济成本可接受的方法，明确应用场景 |
| **土壤地下水监测** | 高风险区域 | 针对性布点监测 |

**渗漏检测是本次新增强化项**：试行版以目视检查为主，难以发现隐蔽性设施隐患；HJ 1478—2026首次明确渗漏检测的适用条件和参考方法。

**修改三：明确138种隐患情形（照单排查）**

- **14类重点场所**：明确每类场所的隐患排查要点  
- **11类重点设施设备**：明确每类设施的隐患排查要点  
- **138种具体隐患情形**：供企业"照单排查"  
- **对应整治要点**：供企业"照单选择"，工程类整治总结典型模式与技术要点

### 2.3 与排污许可衔接要求（HJ 1478—2026明确）

下一步推动标准落地实施的三大工作方向中明确：

1. **加强宣传解读**：分层分类面向企业、第三方机构、生态环境部门解读，核心要求、技术要点讲清讲透
2. **强化工作衔接**（最重要，与排污许可直接相关）：
   - 推动隐患排查整治与排污许可"一证式"管理、环境执法等工作**协调联动**
   - 把标准要求**嵌入排污许可证核发**、**年度执行报告核查**、**现场执法检查**等关键环节
   - 推进自行监测、周边监测数据与隐患排查整治结果**相互印证、联动分析**
3. **做好跟踪指导**：鼓励各地方积极探索实践先进排查技术和隐患整治模式

**技术审查专家注意**：这是HJ 1478—2026的核心要点——土壤隐患排查整治**不是孤立的**，其结果须嵌入排污许可证核发和执行报告核查，执法检查须查隐患排查台账。

### 2.4 技术审查应用指南（新增知识点）

| 应用场景 | 具体动作 |
|---------|---------|
| **许可证核发审查** | 土壤分册中，须确认企业是否为重点监管单位；若是，须核对是否已建立隐患排查整治制度 |
| **年度执行报告核查** | 土壤要素章节须填写隐患排查开展情况；核查时查台账记录 |
| **现场执法检查** | 须查：隐患排查制度文件 + 排查记录 + 隐患整改记录（保存≥5年） |
| **许可证质量核查** | 土壤分册是否遗漏隐患排查要求（重点监管单位必填） |

## 四、排污许可证副本格式优化深层解读

### 4.1 为何"不只是格式调整"

**深层意义**：治理思路、监管模式、治理效能的系统性升级

**三个核心转变**：

| 转变维度 | 现行问题 | 优化方向 |
|---------|---------|---------|
| **监管理念** | 碎片化分散管控 | 全流程闭环治理 |
| **数据体系** | 信息孤岛多平台重复填报 | 数据互通+一网通办 |
| **管理重心** | 地上设施+重点排口 | 隐蔽性设施+全要素覆盖 |

### 4.2 企业侧"减负+提质"双重效应

**减负**（3项）：
- 删除与排放不直接相关的冗余内容（产品/产能/原料/设备清单约30页→大幅压缩）
- 隐蔽性设施排查数量平均减少约30%（HJ 1478-2026）
- 减少多平台重复填报，实现单点登录、一网通办

**提质**（3项）：
- 全要素独立成章→管理边界清晰
- 二维码数字化溯源→监管标准和企业合规边界一目了然
- 突出排放标准和许可排放量等关键指标→企业读得懂、执法查得准

### 4.3 数字化路径（三个"统一"）

**数据互通三个突破口**：
1. **统一数据底座**：依托全国生态环境统一数据底座
2. **统一关联标识**：统一社会信用代码 + 排污口编码 + 污染物指标编码（唯一标识）
3. **统一数据规范**：统一各平台数据规范与统计口径

**"许可平台统筹、多系统联动、数据同源共享"运行模式**：
- 企业基础信息/许可管控指标等核心数据推送至各业务系统
- 监测/执法/整改等一线监管数据同步归集
- 实现数据实时互通、动态更新、全程留痕

**对技术审查专家的意义**：
- 未来可通过全国平台数据核实企业自行监测数据的真实性和完整性
- 平台数据将成为执法检查证据链的重要来源
- 排放口编码是串联许可-监测-执法数据的唯一标识

## 五、湖北襄阳VOCs监测数据造假刑事立案案（重大突破）

### 5.1 案件基本信息

| 项目 | 内容 |
|------|------|
| **地区** | 湖北襄阳 |
| **发现方式** | 生态环境部大气环境司交办线索 |
| **发现时间** | 2026年4月15日 |
| **企业类型** | 精细化工有限公司（排污许可重点管理单位） |
| **涉及工序** | 三氟苯嘧啶中间体生产车间（高位槽、接收釜工序） |
| **违法依据** | DA003排放口须收集VOCs废气+自动监测设施监控 |
| **移送时间** | 2026年6月3日（襄阳生态环境局→公安） |
| **立案时间** | 2026年6月4日（公安正式刑事立案） |
| **当前状态** | 案件侦办中（涉案企业已全面停产） |

### 5.2 违法手段详解

**私设旁路规避在线监控的完整路径**：
```
生产车间VOCs废气
  ↓（正常路径）
废气治理设施（DA003排放口）→自动监测设施（真实数据）→平台上传
  ↓（实际走的路径）
私设PVC旁路管道 → 楼顶直排 → 无监测数据（造假）
```

**核心违法点**：
- 私自架设PVC旁路管道，将VOCs废气直接引至楼顶直排
- 全程绕开规范排污口和自动监测设施
- 导致在线监测数据无法真实反映排污状况
- 属于典型的规避监管、篡改监测数据行为

**适用依据**：《环境监测数据弄虚作假行为判定及处理办法》→认定为篡改环境监测数据违法行为

### 5.3 法律适用重大突破：法释〔2026〕4号

**为何这是"首例"**：
- 此前，VOCs排污造假行为**未纳入**环境污染刑事追责重点范畴
- 违法成本偏低、震慑不足
- 2026年施行的《关于办理环境污染刑事案件适用法律若干问题的解释》（法释〔2026〕4号）**首次将VOCs监测数据弄虚作假纳入刑法第338条"严重污染环境"认定情形**

**刑事追责闭环形成**：
```
VOCs监测数据造假 → 认定"篡改监测数据"（行政违法）
    ↓
法释〔2026〕4号：纳入"严重污染环境"认定情形
    ↓
移送公安 → 刑事立案 → 侦查 → 起诉 → 审判
```

### 5.4 办案难点与取证策略（实战参考）

**难点**：涉案企业已全面停产，无实时排污现场

**办案策略（精准证据链构建）**：
1. **全面调取历史资料**：环评、环保验收、排污许可、工艺管线图纸等
2. **分层约谈相关人员**：企业负责人、车间管理人员、环保运维人员
3. **现场勘验比对**：精准锁定污染物产生点位、非法排放路径、主观违法故意
4. **证据链闭合**：书证 + 言词证据 + 勘验记录相互印证

**行刑衔接机制**：
- 公安提前介入、联合会商
- 精准指导调查取证
- 有效破解取证难点
- 行政执法与刑事司法无缝贯通

### 5.5 对技术审查专家的实战启示

**审查端警示**：
- VOCs自动监测设施须重点审查：监测系统完整性、旁路设置（有无备用排放口）
- 重点管理单位+VOCs排放：须确认自动监测设备覆盖所有废气排放口，不得有"盲区"
- 发现旁路管道痕迹（如楼顶额外管道接口）：高度警惕，可能是规避监测线索

**执法端启示**：
- 现场检查时须核查废气收集路径：是否所有排放口均接入治理设施+监测系统
- 发现企业有多个废气产生工序但只有一个监测口：须核实其余工序废气去向
- 停产状态企业：调取历史平台数据+生产记录，排查停产前是否有异常

**帮企业迎检端**：
- 重点管理单位须确保VOCs监测系统全覆盖，无旁路、无遗漏
- 旁路排放=刑事风险（不再是简单行政处罚）
- 企业环保运维人员须接受专项培训：严禁私设旁路
