## 二、GB 4287—2026《纺织工业水污染物排放标准》（今日头号重点）

### 2.1 标准基本信息（已核实）

| 项目 | 内容 |
|------|------|
| 标准编号 | **GB 4287—2026** |
| 发布单位 | 生态环境部 + 国家市场监督管理总局（两部门联合发布） |
| 替代关系 | 替代 **GB 4287—2012《纺织染整工业水污染物排放标准》**、**GB 28936—2012** 等（整合纺织染整、缫丝、毛纺、麻纺四项行业排放标准） |
| 发布时间 | 2026年7月 |
| 实施时间 | **分阶段落地**：新建企业自 **2026年9月1日** 起实施；现有企业自 **2028年1月1日** 起实施 |
| 强制效力 | 强制执行 |

### 2.2 四大核心优化（对照 GB 4287-2012）

| 优化维度 | 具体内容 | 对技术审查的影响 |
|---------|---------|----------------|
| **① 拓宽适用范围** | 新增**化纤织造**、**产业用纺织制成品**等行业，实现纺织工业全覆盖 | 化纤织造、合成纤维、产业用纺织企业不再按综合标准/无标处理，统一适用本标 → 审查范围扩大 |
| **② 新增综合毒性指标** | 针对**染整污水**及**纺织工业污水集中处理设施出水**，新增**斑马鱼卵急性毒性**作为综合毒性控制指标 | **新特征因子！** 审查须核对是否载入许可证；污水厂纳管协议须同步关注 |
| **③ 双重控制** | 综合毒性指标协同理化指标，实现**双重控制**，精准强化水生态保护 | 染整污水排放口审查要素增加（毒性+理化） |
| **④ 强化水生态保护** | 整体上强化水生态风险管控要求 | 流域（太湖/钱塘江/闽江/九龙江）纺织企业须同步核对地方加严要求 |

### 2.3 技术审查专家应用要点（新增必备）

| 编号 | 应用要点 | 操作动作 |

| T-01 | 适用范围判定 | 纺织工业排污单位+生产设施+纺织工业污水集中处理设施均适用；化纤织造/产业用纺织明确纳入 |
| T-02 | 标准替换 | 新建企业2026-09-01起、现有企业2028-01-01起，逐步以 GB 4287—2026 替代 GB 4287-2012；过渡期须确认企业适用版本 |
