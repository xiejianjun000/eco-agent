## 一、前言：为什么需要例外情况指南

### 1.1 问题背景

在排污许可技术审查实践中,审查人员常遇到以下困惑：
- 电镀企业说"我只有前处理,没有电镀槽",该按重点还是简化？
- 化工企业说"我只有混合分装,没有化学反应",该按重点还是简化？
- 纺织企业说"我只有整理工序,没有染色印花",该按重点还是简化？

这些问题涉及《固定污染源排污许可分类管理名录（2019年版）》中的"除外"条款。**测试显示,审查人员对"除外"条款的掌握率仅80%,导致管理类别判断错误**。

### 1.2 指南目标

本指南专门解决"除外"条款盲区,通过：
- **完整梳理**：列出所有15个行业的"除外"条款
- **决策树**：提供快速判断工具
- **典型案例**：展示实际判断过程
- **核对清单**：避免遗漏例外情况

### 1.3 核心原则

**例外情况判断三大原则**：

1. **关键工序原则**：有核心工序的,按原管理类别；无核心工序的,按例外条款
2. **从严把握原则**：判断不清的,从高从严管理
3. **证据优先原则**：以环评批复、工艺流程图、设备清单为判断依据

## 二、完整例外情况清单（15个行业）

### 2.1 电镀行业（行业代码：C3360）

**标准管理类别**：重点管理

**例外情况**：仅含前处理、后处理工序,无电镀槽的

**例外后管理类别**：简化管理

**判断依据**：《固定污染源排污许可分类管理名录（2019年版）》第33项

**关键工序**：电镀槽（镀槽内进行金属沉积的工序）

**例外工序**：
- 前处理：酸洗、碱洗、除油、活化等表面预处理
- 后处理：钝化、封闭、烘干、涂装等表面后处理

**判断要点**：
- ✅ 有电镀槽 → 重点管理
- ✅ 无电镀槽,仅有前处理/后处理 → 简化管理
- ✅ 有电镀槽+前处理/后处理 → 重点管理（按有电镀槽判断）

**常见误区**：
- ❌ "有电镀设备"就按重点管理（应明确是否有电镀槽）
- ❌ "企业名称含电镀"就按重点管理（应以实际工序为准）

### 2.2 化工行业（行业代码：C261、C262、C263、C264、C265、C266）

**标准管理类别**：重点管理

**例外情况**：仅含混合、分装工序,无化学反应工序的

**例外后管理类别**：简化管理

**判断依据**：《固定污染源排污许可分类管理名录（2019年版）》第47项

**关键工序**：化学反应工序（合成、裂解、聚合、氧化、还原、硝化、磺化、氯化、氟化、氨化、重氮化、烷基化、水解、缩合等）

**例外工序**：
- 混合：物理混合,无化学反应
- 分装：产品分装、灌装
- 稀释：溶剂稀释
- 复配：配方调配（无化学反应）

**判断要点**：
- ✅ 有化学反应工序 → 重点管理
- ✅ 无化学反应,仅混合/分装 → 简化管理
- ✅ 有化学反应+混合/分装 → 重点管理（按有化学反应判断）

**常见误区**：
- ❌ "企业属于化工行业"就按重点管理（应判断有无化学反应）
- ❌ "使用化学原料"就按重点管理（应判断是否产生化学反应）

**特殊说明**：
- 涂料、油墨、颜料制造：有研磨、分散工序的,按重点管理
- 溶剂回收：有蒸馏工序的,按重点管理
- 化学试剂分装：仅分装无反应的,可按简化管理

### 2.3 纺织印染行业（行业代码：C171、C172、C174、C175）

**标准管理类别**：重点管理

**例外情况**：仅有前处理、整理工序,无染色、印花工序的

**例外后管理类别**：简化管理

**判断依据**：《固定污染源排污许可分类管理名录（2019年版）》第18项

**关键工序**：
- 染色：使用染料对织物进行染色
- 印花：使用染料/颜料对织物进行印花

**例外工序**：
- 前处理：退浆、煮练、漂白、丝光等
- 整理：定型、轧光、预缩、柔软整理、功能性整理等
- 水洗：单纯水洗

**判断要点**：
- ✅ 有染色或印花工序 → 重点管理
- ✅ 无染色印花,仅前处理/整理 → 简化管理
- ✅ 有染色印花+前处理/整理 → 重点管理

**常见误区**：
- ❌ "纺织企业"就按重点管理（应判断有无染色印花）
- ❌ "有废水排放"就按重点管理（应判断工序类型）

**特殊说明**：
- 针织、梭织：无染色印花的,可按简化管理或登记管理
- 家纺、服装：无染色印花的,可按简化管理或登记管理

## 三、例外情况判断决策树

### 3.1 通用判断决策树

```
【步骤1】确认行业类别
  ↓
【步骤2】确认是否属于例外情况范围
  → 不属于例外范围 → 按标准管理类别
  ↓
【步骤3】确认关键工序
  → 有关键工序 → 按标准管理类别
  → 无关键工序 → 进入步骤4
  ↓
【步骤4】确认例外工序
  → 仅有例外工序 → 按例外后管理类别
  → 有其他工序 → 重新评估
```

### 3.2 电镀行业决策树

```
问题1：企业是否有电镀槽（镀槽内电沉积）？
  → 是 → 重点管理
  → 否 → 进入问题2

问题2：企业是否仅有前处理/后处理工序？
  → 是 → 简化管理
  → 否（有其他金属表面处理工序） → 进入问题3

问题3：其他金属表面处理是否涉及重点管理？
  → 喷漆、喷塑、电泳、磷化等 → 简化管理
  → 其他特殊情况 → 咨询上级部门
```

### 3.3 化工行业决策树

```
问题1：企业是否有化学反应工序？
  → 是（合成、裂解、聚合、氧化、还原等） → 重点管理
  → 否 → 进入问题2

问题2：企业是否仅有混合/分装工序？
  → 是 → 简化管理
  → 否（有其他工序） → 进入问题3

问题3：其他工序是否涉及重点管理？
  → 涂料制造（有研磨分散） → 按涂料行业判断
  → 溶剂回收（有蒸馏） → 重点管理
  → 其他 → 咨询上级部门
```

### 3.4 纺织印染行业决策树

```
问题1：企业是否有染色工序？
  → 是 → 重点管理
  → 否 → 进入问题2

问题2：企业是否有印花工序？
  → 是 → 重点管理
  → 否 → 进入问题3

问题3：企业是否仅有前处理/整理工序？
  → 是 → 简化管理
  → 否（有其他纺织工序） → 简化管理或登记管理（视具体工序）
```

### 3.5 制药行业决策树

```
问题1：企业类型是原料药制造还是制剂制造？
  → 原料药制造 → 重点管理
  → 制剂制造 → 进入问题2

问题2：制剂制造是否有发酵/提取/化学合成工序？
  → 是 → 重点管理
  → 否 → 进入问题3

问题3：企业是否仅有制剂加工工序？
  → 是 → 简化管理
  → 否 → 重新评估
```

### 3.6 多工序混合企业决策树

```
问题1：企业有哪些工序？
  → 列出所有工序

问题2：每个工序对应的管理类别是什么？
  → 工序A：重点管理
  → 工序B：简化管理
  → 工序C：简化管理

问题3：按"就高不就低"原则
  → 只要有一个工序是重点管理 → 整体按重点管理
  → 所有工序都是简化管理 → 整体按简化管理
```

## 四、典型案例（12个）

### 案例1：电镀前处理企业

**企业情况**：某金属表面处理企业,主要业务为金属件酸洗、除油、磷化,年加工量5000吨,无电镀槽。

**判断过程**：
1. 确认行业类别：金属表面处理（行业代码C3360）
2. 确认工序：酸洗、除油、磷化（均为前处理工序）
3. 确认无电镀槽：现场核实无电镀槽设备
4. 对照例外条款：《分类管理名录》第33项"仅含前处理、后处理工序,无电镀槽的"

**最终管理类别**：简化管理

**注意事项**：
- 必须现场核实无电镀槽
- 核对环评批复、工艺流程图
- 检查设备清单,确认无电镀槽

---

### 案例2：化学品混合分装企业

**企业情况**：某化工企业,主要业务为化学原料混合、分装,年产量8000吨,无化学反应工序。

**判断过程**：
1. 确认行业类别：化工行业（行业代码C264）
2. 确认工序：混合（物理混合）、分装（产品分装）
3. 确认无化学反应：核对环评批复、工艺流程图,无合成、裂解、聚合等化学反应工序
4. 对照例外条款：《分类管理名录》第47项"仅含混合、分装工序,无化学反应的"

**最终管理类别**：简化管理

**注意事项**：
- 必须确认无化学反应（核对环评批复、工艺流程）
- 混合过程可能有温升,但物理混合不是化学反应
- 分装过程可能有挥发,但无化学反应

### 案例3：纺织整理企业

**企业情况**：某纺织企业,主要业务为织物定型、轧光、预缩,年加工量3000万米,无染色、印花工序。

**判断过程**：
1. 确认行业类别：纺织印染行业（行业代码C171）
2. 确认工序：定型、轧光、预缩（均为整理工序）
3. 确认无染色印花：现场核实无染色机、印花机
4. 对照例外条款：《分类管理名录》第18项"仅有前处理、整理工序,无染色、印花的"

**最终管理类别**：简化管理

**注意事项**：
- 必须现场核实无染色、印花设备
- 整理工序可能有废水排放,但按例外条款判断
- 定型工序有VOCs排放,需纳入废气管理

### 案例4：制药制剂企业

**企业情况**：某制药企业,主要业务为片剂、胶囊剂生产,年产量5亿片,无发酵、提取、化学合成工序。

**判断过程**：
1. 确认行业类别：化学药品制剂制造（行业代码C272）
2. 确认工序：压片、包衣、灌装、胶囊填充（均为制剂加工工序）
3. 确认无发酵提取化学合成：核对环评批复、工艺流程图
4. 对照例外条款：《分类管理名录》第37项"无发酵、提取、化学合成工序,仅有制剂加工的"

**最终管理类别**：简化管理

**注意事项**：
- 原料药制造企业属重点管理,与制剂制造不同
- 制剂企业使用外购原料药,不生产原料药
- 有化学试剂使用,但不是化学合成工序

### 案例5：金属表面处理-喷漆企业

**企业情况**：某金属表面处理企业,主要业务为金属件喷漆、喷塑,年加工量2000吨,无电镀槽。

**判断过程**：
1. 确认行业类别：金属表面处理（行业代码C3360）

### 案例8：食品分装企业

**企业情况**：某食品企业,主要业务为调味品分装,年分装量5000吨,无生产加工工序。

**注意事项**：

- 具体按地方规定执行

### 案例9：皮革整理企业

### 案例12：多工序混合企业

**企业情况**：某企业既有电镀前处理工序（简化管理）,又有涂装工序（简化管理）,还有机加工工序（登记管理）。

**判断过程**：
1. 列出所有工序：
   - 电镀前处理（简化管理）
   - 涂装（简化管理）
   - 机加工（登记管理）
2. 按"就高不就低"原则：
   - 最高管理类别是简化管理
3. 最终判断：简化管理

**最终管理类别**：简化管理

**注意事项**：
- "就高不就低"原则适用于多工序混合企业
- 只要有一个工序是重点管理,整体按重点管理
- 所有工序都是简化管理,整体按简化管理

### 6.3 例外条款适用规则

**规则1：关键工序优先**
- 有关键工序的,按原管理类别判断
- 无关键工序的,才适用例外条款

**规则2：证据优先**
- 以环评批复、工艺流程图、设备清单为判断依据
- 不能仅凭企业口头说明

**规则3：从严把握**
- 判断不清的,从高从严管理
- 避免管理类别偏低导致监管漏洞

**规则4："就高不就低"**
- 多工序混合企业,只要有一个工序是重点管理,整体按重点管理
- 所有工序都是简化管理,整体按简化管理

### 7.3 判断流程速查

**第一步**：确认行业类别
- 查《国民经济行业分类》
- 对照《分类管理名录》

**第二步**：确认是否属于例外范围
- 查本指南"完整例外情况清单"
- 对照例外情况描述

**第三步**：确认关键工序
- 查本指南"关键工序识别表"
- 核对环评批复、工艺流程图、设备清单

**第四步**：做出判断
- 有关键工序 → 按原管理类别
- 无关键工序+仅有例外工序 → 按例外后管理类别

**第五步**：留痕备查
- 记录判断过程
- 保存判断依据（环评批复、工艺流程图、设备清单）

### 🆕 法典第1106条：登记管理首次设罚则（8月2日更新）

**重大变化**：
- **原条例第43条**：登记单位未填报排污信息→仅责令改正（无实际经济处罚）
- **法典第1106条**：登记单位未依法填报排污信息→处**≤5万元罚款**

**执法注意**：
1. 超标仍违法：排放标准对所有排污单位均有约束力，与是否持证无关
2. 登记信息真实性：实际生产规模/工艺/排放情况须与登记信息一致
3. 应领证但只登记≠登记违规：虚报产能或工艺规避许可证→构成无证排污（法典第1102条，20万-100万），性质完全不同
4. 违规设排口：登记企业违规设排口依旧可罚2-10万
5. 逃避监管方式排放：对所有排污单位均适用（渗坑/暗管/篡改数据等）

**登记管理≠法外之地**："办了登记就能任意排污、规避监管"是严重认知误区。
