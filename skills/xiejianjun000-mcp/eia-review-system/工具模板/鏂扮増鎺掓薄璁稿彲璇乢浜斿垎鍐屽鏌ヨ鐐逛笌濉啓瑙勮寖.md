# 新版排污许可证五分册审查要点与填写规范

**依据文件**：环环评〔2026〕31号《关于发布排污许可证格式文本及审查技术规范的通知》
**发布时间**：2026年6月3日
**施行时间**：2026年8月15日
**文件级别**：规范性文件

---

## 一、总论

### 1.1 政策背景

环环评〔2026〕31号是排污许可制度自2016年全面实施以来最重大的一次格式改革。本次改革不是简单的"换版"，而是围绕"一证式"管理理念的制度重构，旨在解决旧版许可证"重填报、轻监管"、信息堆砌、重点不突出等长期痛点。

核心变化逻辑：让许可证成为"有用的工具"，而非"填完就锁抽屉"的纸面文件。

### 1.2 五大核心变化

| 变化 | 旧版做法 | 新版做法 | 实际意义 |
|------|---------|---------|---------|
| **分要素管理** | 全要素混排一页，重点不突出 | 按大气/水/固废/噪声/土壤分册管理 | 检查人员可直接翻到对应分册，无需全文检索 |
| **一口一表一码** | 排放口信息散落各处 | 每个排放口独立成表，配唯一二维码 | 扫码即可查排放口全量信息，便于公众监督和执法比对 |
| **预留许可排放量** | 许可量多为"许可排放浓度" | 许可排放量（浓度×排放量）必须明确载明 | 总量控制从"纸面管控"变为"硬约束"，超总量即违法 |
| **土壤分册** | 无此分册 | 新增独立土壤分册 | 落实《土壤污染防治法》第21条，填补土壤管理盲区 |
| **简化非核心内容** | 产品、产能、原辅材料、燃料信息全量填入副本 | 删除副本中上述内容，平台内仍可查询 | 许可证副本"减肥"，重点聚焦排放行为本身 |

### 1.3 格式结构

```
排污许可证
├── 正本：企业基本信息 + 许可总体信息（有效期、管理类别等）
└── 副本（五分册）
    ├── 大气分册：排放口信息 + 有组织/无组织排放要求 + 监测要求
    ├── 水分册：废水排放口信息 + 排放要求 + 监测要求
    ├── 固废分册：一般工业固废 + 危险废物信息
    ├── 噪声分册：厂界噪声监测点位 + 排放限值 + 监测频次
    └── 土壤分册：土壤污染重点监管单位特有内容（全新）
```

**审查时注意**：五分册为独立模块，但彼此有交叉引用（如大气分册排放口编号与总量表一致）。完整性审查时需交叉核对，防止编号、名称、数据出现矛盾。

## 二、大气分册审查要点

### 2.1 排放口信息完整性

**查什么**：
- 排放口编号与许可证编号体系是否一致（格式通常为 FQ-001 等）
- 排气筒位置：精确到车间/工段，而非仅填"厂区北侧"
- 排气筒数量：现场核查是否与填报一致（尤其警惕"拆了但没申报注销"的情况）
- 排气筒高度：是否满足《制定地方大气污染物排放标准的技术方法》（HJ/T 4）核算要求
- 排气筒内径：影响排放速率核算精确性

**怎么查**：
1. 现场实测排气筒几何参数，与许可证载明值比对
2. 关注"多根排气筒合并为1根排放"情形——内径是否如实填报
3. 有组织排放口应核查排气筒高度是否高于周围150m范围内建筑屋顶5m以上（通用要求，特殊行业除外）

**常见问题**：
- 排气筒高度低于标准要求但未在许可证中说明豁免依据
- 内径填报值与实际不符，导致"核算排放量"与实际排放量偏差超过20%
- 车间无组织排放未识别，排放口清单漏项

### 2.2 许可排放浓度与排放速率

**查什么**：
- 排放浓度限值：是否正确引用现行有效的排放标准（注意区分"国家标准"和"地方标准"，后者更严格时从其规定）
- 排放速率限值：有组织排放口须同时审查排放浓度和排放速率两项指标
- 标准适用性：排放标准版本是否正确（如GB 16297-1996已多次修订，引用废止版本为常见错误）

**怎么查**：
1. 确认排放口所属行业类别，对照《大气污染物综合排放标准》（GB 16297）或行业性排放标准
2. 区分"排放口适用标准"与"无组织排放控制标准"——两类标准体系不同，不可混淆
3. 地方标准严于国家标准时，须按地方标准执行

**常见问题**：
- 引用已废止标准版本（如GB 16297-1996代替GB 16297-1996+修改单）
- 多排放口共用同一排气筒时，许可排放浓度未进行"等效叠加"核算
- 特征污染物排放标准未识别（如电镀行业六价铬、硫酸雾等特征因子标准漏引）

### 2.3 有组织排放监控位置（CEMS安装要求）

**查什么**：
- 自动监测设备（Continuous Emission Monitoring System, CEMS）安装位置是否符合《固定污染源烟气（SO₂、NOₓ、颗粒物）排放连续监测技术规范》（HJ 75）要求
- 采样点位是否符合"在排气筒或烟道上安装"的基本要求
- 是否满足"距弯头、阀门、变径管下游方向≥4倍直径（或当量直径）"的位置要求

**怎么查**：
1. 现场核查CEMS设备铭牌型号与许可证申报是否一致
2. 核实CEMS数据是否已联网（未联网的自动监测数据不具法律效力）
3. 关注"调试期"——新建项目CEMS联网后有90天调试期，调试期内数据不得作为执法依据，但企业应主动记录

**常见问题**：
- CEMS安装位置不符合HJ 75要求，导致监测数据失真
- 数据联网但未验收（验收流程缺失）
- 应装未装：如火电行业SO₂排放量≥10t/a应安装自动监测，实际未装

### 2.4 无组织排放控制要求

**查什么**：
- 是否识别无组织排放环节（原料储存、物料转移、装卸、厂内运输等）
- 无组织排放控制措施是否符合《大气污染物无组织排放监测技术规范》（HJ/T 55）
- 厂界无组织排放监控浓度是否满足排放标准要求

**怎么查**：
1. 对照行业技术规范（如HJ 855-2017电镀工业要求），逐工段识别无组织排放源
2. 现场核查无组织控制设施（集气罩、密闭管道、除尘设备等）是否正常运行
3. 厂界无组织监测点位布设是否符合GB 16297要求（上风向1个+下风向2～3个）

**常见问题**：
- 无组织排放清单漏项（尤其原料堆场、污水处理站等隐蔽环节）
- 控制措施描述为"加强管理"等模糊表述，无具体技术参数
- 监测频次不满足要求（无组织排放监测频次通常为每季度1次）

### 2.5 特殊时段管控要求

**查什么**：
- 重污染天气应急响应期间是否载明"停产、限产、错峰生产"等差异化管控要求
- 特殊时段排放要求是否落实到具体排放口和具体因子
- 应急减排清单与许可证的一致性

**怎么查**：
1. 查地方政府发布的重污染天气应急减排清单，确认企业是否在列
2. 许可证中"特殊时段"章节是否明确"预警级别-管控措施-执行时限"对应关系
3. 核查企业是否按要求编制"一厂一策"应急操作方案

**常见问题**：
- 特殊时段管控要求与地方应急预案不一致
- 限产比例未量化（如"减少排放"而非"排放量降至×kg/h以下"）
- 未区分"黄色/橙色/红色预警"不同级别的差异化管控要求

### 2.6 监测频次审查

**查什么**（依据HJ 819-2017及行业指南）：

| 监测类型 | 重点管理要求 | 简化管理要求 | 常见问题 |
|---------|------------|------------|---------|
| 自动监测 | 24小时连续监测，数据实时上传 | 重点污染物自动监测 | 未联网或联网后未验收 |
| 手工监测 | 废气排放口每季度1次（Hg等重金属季度/半年） | 每半年1次 | 监测因子不全（漏特征因子） |

**怎么查**：
1. 对照《排污单位自行监测技术指南 总则》（HJ 819-2017）核实基准监测频次
2. 行业专项指南（如HJ 879-2017纺织印染）对特定行业有更严格要求的，从其规定
3. 特殊因子（如Hg、Cr⁶⁺）手工监测频次须高于常规因子

## 三、水分册审查要点

### 3.1 废水排放口基本信息

**查什么**：
- 排放口编号（格式通常为 WS-001 等）
- 排放口位置（总排口位置，精确到坐标）
- 排放方式：直接排放（进入环境）还是间接排放（进入城镇污水处理厂）
- 排放去向：进入外环境还是纳管，纳管则须注明接纳污水处理厂名称

**怎么查**：
1. 现场核查总排口位置与许可证载明是否一致
2. 间接排放企业须核实接纳污水厂设计处理能力与进水水质要求（纳管标准≠直接排放标准）
3. 雨水排放口须单独列示（与生产废水排放口区分）

**常见问题**：
- 间接排放企业错用直接排放标准（这是最常见、最致命的错误之一）
- 排放去向填报为"城市管网"但未注明具体接纳污水处理厂名称
- 初期雨水收集处理系统未在排放口信息中体现

### 3.2 许可排放浓度与许可排放量

**查什么**：
- 许可排放浓度限值：正确引用现行排放标准（注意区分《污水综合排放标准》GB 8978与行业水污染物排放标准）
- 许可排放量：排放量（t/a）= 排放浓度（mg/L）× 年排放废水量（m³）× 10⁻⁹
- 直接排放企业：许可排放量须满足区域总量控制要求

**怎么查**：
1. 许可排放量计算过程须在许可证中完整呈现（计算公式+参数取值依据）
2. 直接排放许可量与环评批复总量指标一致性核查
3. 间接排放企业许可排放量与纳管协议约定的接纳量一致性核查

**常见问题**：
- 许可排放量仅填浓度限值，未核算年排放总量
- 间接排放企业许可浓度超纳管标准（接纳污水厂进水标准）
- 年排放水量取值无依据（如取环评值但环评本身已过期）

### 3.3 自动监测设备安装

**查什么**（依据HJ 819-2017及行业指南）：

| 管理类别 | 监测因子 | 安装要求 |
|---------|---------|---------|
| 重点管理 | COD、氨氮 | 必须安装自动监测，数据实时上传 |
| 简化管理 | COD、氨氮 | 可采用手工监测，但须满足频次要求 |
| 总磷/总氮 | 行业有要求时 | 按行业指南执行（HJ 985-2018电镀行业等） |

**怎么查**：
1. 核查自动监测设备型号、量程是否与废水特性匹配
2. 数据是否已与生态环境部门监控平台联网
3. 自动监测设备是否定期校准（核查校准记录）
4. "数采仪"是否正常运行（数据从设备到平台的中间环节）

**常见问题**：
- 应装未装：重点管理企业COD、氨氮未安装自动监测
- 设备运行不正常：设备故障期间数据缺失，未按规定补测并说明原因
- 数据造假：擅自修改自动监测设备参数或稀释排放

### 3.4 监测频次审查

**查什么**（依据HJ 819-2017及行业指南）：

| 监测类型 | 重点管理（直接排放） | 重点管理（间接排放） | 简化管理 |
|---------|------------------|------------------|---------|
| COD/氨氮 | 自动监测（实时） | 自动监测（实时） | 手工监测每月1次 |
| 其他因子 | 手工监测每季度1次 | 手工监测每季度1次 | 手工监测每半年1次 |
| 流量 | 自动监测（实时） | 自动监测（实时） | 手工监测每月1次 |

**怎么查**：
1. 废水排放量计量设备（流量计）是否安装并正常运行
2. 手工监测频次是否满足规范要求（特别注意"每月"与"每季度"的区别）
3. 监测因子是否完整（除常规污染物外，特征污染物不得遗漏）

## 四、固废分册审查要点

### 4.1 一般工业固废

**查什么**：
- 固废类别：按《一般工业固体废物贮存和填埋污染控制标准》（GB 18559）分类
- 贮存设施信息：贮存场/贮存仓库位置、面积、防渗措施
- 处置/利用去向：须明确具体去向单位（不接受"综合利用"等模糊表述）

**怎么查**：
1. 一般工业固废须与生活垃圾分开统计
2. 贮存设施防渗措施是否满足GB 18559要求
3. 核查处置合同有效期（合同过期视为"去向不明"）
4. 副产品（如粉煤灰、炉渣）是否已在固废分册中体现

**常见问题**：
- 副产品当作产品处理，规避固废管理要求（这是常见的打"擦边球"行为）
- 贮存设施信息填报不完整（仅填名称，未填位置和防渗等级）
- 处置去向单位不具备相应资质

### 4.2 危险废物

**查什么**：
- 危废种类：《国家危险废物名录》（2021年版）HW01～HW49，对照环评/排污许可证逐一核对
- 产生量：年产生量（t/a），须与台账记录一致
- 贮存设施：贮存仓库位置、面积、贮存能力、防渗措施（须满足GB 18597要求）
- 处置去向：处置单位名称+处置方式+处置能力

**怎么查**：
1. 危废识别须逐批次核实，不可仅依据环评（环评可能遗漏新产生的危废）
2. 贮存设施须满足"三防"要求（防风、防雨、防渗漏）
3. 危废经营单位许可证须在有效期内，且处置类别覆盖本企业产生的危废种类
4. 危废转移须填写危废转移联单（电子联单，环保部门可查）

**常见问题**：
- 危废种类识别不全（尤其工艺变更后新产生的危废未申报）
- 贮存超过1年未处置（违反《危废许可证管理办法》："贮存不得超过1年"）
- 危废包装容器标识不规范（须张贴危废标签，填写危废名称、代码、产生日期等）
- 危废委托处置合同过期

### 4.3 台账要求

| 固废类型 | 台账保存年限 | 关键记录内容 |
|---------|------------|------------|
| 一般工业固废 | ≥5年 | 产生量、去向、转移时间、接收单位 |
| 危险废物 | ≥3年（建议≥5年） | 产生量、贮存量、处置量、转移联单编号 |

**审查重点**：台账记录频次是否与生产设施运行记录匹配（不能出现"月产生量=月处置量+月贮存量"不平衡的情况）

## 五、噪声分册审查要点

### 5.1 厂界噪声监测点位布设

**查什么**（依据GB 12348-2008）：
- 监测点位数量：厂界外每50m设一个监测点（不足50m的单独测），高噪声设备突出处须加密布点
- 监测时段：昼间（6:00-22:00）和夜间（22:00-次日6:00）分别测定
- 背景噪声修正：被测声源声级≤扣景噪声声级10dB(A)时，须修正

**怎么查**：
1. 现场确认监测点位与许可证载明是否一致
2. 核查声功能区划（1类区：居住文教；2类区：混合区；3类区：工业区；4类区：交通干线两侧）
3. 夜间生产的企业须额外关注"夜间噪声"限值

**常见问题**：
- 监测点位未覆盖全部厂界（遗漏高噪声侧）
- 未区分昼间和夜间限值
- 背景噪声未测量就直接报告测量值（违法）

### 5.2 排放限值审查

| 声功能区类别 | 昼间限值 dB(A) | 夜间限值 dB(A) |
|------------|-------------|-------------|
| 1类区（居住文教） | 55 | 45 |
| 2类区（混合区） | 60 | 50 |
| 3类区（工业区） | 65 | 55 |
| 4a类（交通干线） | 70 | 55 |
| 4b类（铁路干线） | 70 | 60 |

**查什么**：
- 声功能区类别与地方政府声环境功能区划图一致性
- 夜间限值是否比昼间严格10dB(A)
- 同一企业厂界不同侧适用不同声功能区时，是否分别列明限值

**常见问题**：
- 声功能区类别认定错误（如将2类区认定为3类区，导致限值偏松）
- 夜间生产时段未单独说明夜间限值适用条件
- 紧邻交通干线的厂界未按4类区标准执行

### 5.3 监测频次与高噪声设备隔声

**监测频次**：每季度1次（昼间+夜间）
**高噪声设备隔声**：设备声功率级>85dB(A)的须采取隔声、消声、减振措施

**审查重点**：
- 监测报告是否由具备资质的环境监测机构出具
- 监测期间生产工况是否正常（须在报告附注中说明）
- 隔声措施是否有效（可要求企业提供隔声效果检测报告）

## 六、土壤分册审查要点（重点章节）

> 土壤分册是本次新版许可证的最大变化。依据《土壤污染防治法》第21条，土壤污染重点监管单位须在排污许可证中载明土壤污染防控措施。审查人员须充分重视此分册的审查质量。

### 6.1 重点监管单位认定

**查什么**：
- 企业是否在各省级生态环境主管部门公布的"土壤污染重点监管单位名录"中
- 依据《土壤污染防治法》第21条，重点监管单位须履行以下义务：
  ① 严格控制有毒有害物质排放，并落实排放申报
  ② 建立土壤污染隐患排查制度
  ③ 制定并实施自行监测方案

**怎么查**：
1. 登录各省级生态环境厅网站，核查企业是否在名录内（名录通常按年度更新）
2. 不在名录内但实际存在土壤污染风险的企业（如涉及重金属排放），仍须按行业规范落实土壤监测

**常见问题**：
- 企业已被列入重点监管单位名录但许可证未载明土壤分册（这是"漏载"）
- 土壤分册内容与地方土壤监测规范不一致
- 名录动态更新后，许可证未及时变更

### 6.2 审查依据标准体系

| 标准编号 | 标准名称 | 适用范围 |
|---------|---------|---------|
| HJ 1209—2021 | 工业企业土壤污染隐患排查与监测技术指南 | 隐患排查方法、频次要求 |
| GB 36600—2018 | 土壤环境质量 农用地土壤污染风险管控标准 | 农用地及一般建设用地基本项目（45项） |
| GB/T 14848—2017 | 地下水质量标准 | 地下水监测指标（感官性状及一般化学指标等） |

**审查重点**：监测指标须同时覆盖"基本项目"和"特征污染物"，特征污染物因行业而异，须对照行业技术规范识别。

### 6.3 土壤监测布点方案审查

#### 6.3.1 布点原则

布点须聚焦潜在污染区域，不得"均匀网格布点"（除非企业全场均质）。重点关注以下区域：

| 区域类型 | 潜在污染物 | 布点要求 |
|---------|----------|---------|
| 原料堆场/仓库 | 原料特征污染物 | 堆场边界内及下游方向 |
| 生产车间/工段 | 工艺特征污染物 | 车间内部及车间外下风向 |
| 储罐区 | 化学品特征污染物 | 储罐围堰内及围堰外 |
| 污水处理设施 | 污水特征污染物 | 设施周边及下游方向 |
| 固废贮存区 | 固废特征污染物 | 贮存边界及下游方向 |
| 事故应急池 | 多污染物 | 应急池周边及下游方向 |

#### 6.3.2 点位数量要求

| 区域类型 | 最低布点密度 | 审查要点 |
|---------|------------|---------|
| 重点场所（潜在污染严重区域） | ≥1个点/500m² | 堆场、车间、储罐区等 |
| 一般防渗区（防渗措施一般区域） | ≥1个点/2000m² | 一般生产区、办公区 |

**怎么查**：
1. 核实企业实际占地面积和重点场所面积
2. 核查实际布点数量是否满足上述最低密度要求
3. 关注"隐蔽区域"（地下罐区、地下管线等）的布点

**常见问题**：
- 布点数量严重不足（如全场仅布3～5个点，但重点场所面积达数千平方米）
- 布点未覆盖潜在污染最严重区域（如仅在厂界布点，未进入车间）
- 未区分"重点场所"和"一般防渗区"，统一按低密度布点

### 6.4 监测指标审查

#### 6.4.1 基本项目（45项，GB 36600表1）

| 监测类别 | 项目数量 | 代表性指标 |
|---------|---------|----------|
| 重金属类 | 8项 | 砷、镉、六价铬、铜、铅、汞、镍 |
| 半挥发性有机物（SVOCs） | 11项 | 多环芳烃、邻苯二甲酸酯类 |
| 挥发性有机物（VOCs） | 27项 | 苯系物、卤代烃类 |

#### 6.4.2 特征污染物（行业差异大，须逐一识别）

| 行业 | 特征污染物（举例） | 审查重点 |
|------|-----------------|---------|
| 电镀 | 六价铬、镍、锌、镉 | 六价铬是必测项，行业普遍超标因子 |
| 石油化工 | 石油烃类（TPH）、苯系物 | 石油烃须单独列明（TPH） |
| 皮革/制革 | 六价铬、硫化物、氨氮 | 皮革废水特征因子 |
| 电子元器件 | 多氯联苯（PCBs）、多溴联苯醚（PBDEs） | 电路板清洗工序特征因子 |
| 金属表面处理 | 重金属（六价铬、镍、镉、铜） | 与电镀类似 |

**怎么查**：
1. 基本项目45项是否全部覆盖（不得删减）
2. 特征污染物是否依据环评批复/行业特征完整识别
3. 特征污染物须在许可证中逐一列明，不得以"其他特征污染物"笼统替代

### 6.5 监测频次审查

| 监测类型 | 监测频次 | 周期调整条件 |
|---------|---------|-----------|
| 重点场所 | ≥1次/年 | 连续3年无异常→调整为1次/3年 |
| 一般防渗区 | ≥1次/年 | 连续3年无异常→调整为1次/3年 |
| 监测周期调整 | 须经省级生态环境主管部门同意 | 不得企业自行调整 |

**怎么查**：
1. 确认监测频次是否满足"≥1次/年"
2. 调减频次须有官方批准文件，不可仅凭企业自行判断
3. "无异常"认定须有专业机构评估报告支撑

**常见问题**：
- 监测频次填报为"必要时监测"，无具体频次（不符合规范要求）
- 周期调整未经批准，企业自行减少监测
- 监测数据连续超标但未启动风险管控措施

### 6.6 地下水监测井审查

**适用条件**：涉及地下水环境的排污单位（废水直接排放或渗漏风险高的企业）

#### 6.6.1 监测井布设

| 监测井类型 | 数量要求 | 布设位置 |
|---------|---------|---------|
| 上游背景井 | ≥1个 | 企业厂址上游地下水主流向 |
| 下游监控井 | ≥2个 | 企业厂址下游地下水主流向及侧向 |

**审查要点**：
- 监测井数量是否满足"至少3个"的基本要求
- 监测井是否穿透包气带（打到含水层）
- 监测井井管材质是否合规（不得对地下水造成二次污染）

#### 6.6.2 地下水监测指标

| 指标类别 | 代表性指标 | 说明 |
|---------|----------|------|
| 基础项（必测） | pH、氨氮、硝酸盐氮、亚硝酸盐氮、总大肠菌群、菌落总数 | GB/T 14848-2017表1 |
| 重金属项 | 砷、镉、六价铬、铅、汞、镍、铜、锌 | 依据行业特征选测 |
| 有机项 | 石油烃类（PH）、VOCs | 石油化工等行业必测 |

#### 6.6.3 地下水监测频次

**≥1次/半年**（比土壤监测更频繁，因为地下水流动性强，污染扩散快）

**常见问题**：
- 监测井数量不足（仅布1～2个，无法反映污染扩散范围）
- 监测井维护不当（井口无防护、井内沉积物影响采样代表性）
- 监测指标不全（仅测pH等简单指标，特征污染物未测）

### 6.7 污染隐患排查与整治

#### 6.7.1 隐患排查要求

| 要求 | 具体内容 |
|------|---------|
| 排查频次 | ≥1次/年 |
| 排查方法 | 对照HJ 1209-2021附录，逐区域排查 |
| 排查范围 | 原料储存→生产过程→污染防治设施→固废贮存→废水排放→地下水监测井 |
| 隐患台账 | 须建立隐患清单，记录发现时间、内容、整治措施、整改时限 |

#### 6.7.2 隐患台账保存

**保存年限：≥5年**

#### 6.7.3 整治要求

- 发现隐患立即启动整改，不得"带病运行"
- 重大隐患须制定整治方案，报地方生态环境主管部门备案
- 整治完成后须进行效果评估

**常见问题**：
- 隐患排查走过场（仅填写"未发现问题"而无实际排查记录）
- 隐患整改无闭环（发现问题后未跟踪整改情况）
- 台账保存年限不足（须≥5年，部分企业仅保存1～2年）

## 七、"一口一表一码"审查要点

> "一口一表一码"是本次新版许可证的核心管理机制创新。每个排放口对应：一张信息表+一个二维码。审查时须将"纸面信息"与"扫码信息"进行一致性比对。

### 7.1 排放口一张表内容完整性

每个排放口信息表须包含以下五个模块：

| 模块 | 具体内容 | 审查要求 |
|------|---------|---------|
| **基本信息** | 排放口编号、位置、类型（废气/废水）、排放方式 | 与现场一致性核查 |
| **治理设施信息** | 治理工艺、设施型号、设计处理能力、投运时间 | 须与实际设备铭牌一致 |
| **排放要求** | 许可排放浓度限值、许可排放速率/量、执行标准编号 | 须正确引用现行有效标准 |
| **监测要求** | 监测因子、监测频次、自动/手工监测方式、监测标准方法 | 须满足HJ 819要求 |
| **管理要求** | 运行维护要求、故障报告要求、记录频次 | 须具有可操作性 |

**常见问题**：
- 五项内容不齐全（如仅有"基本信息"和"排放要求"，缺少"监测要求"）
- 治理工艺填报与实际不符（如填报"生化处理"但实际采用物化处理）
- 二维码对应信息与许可证载明不一致（平台数据陈旧未更新）

### 7.2 二维码验证

**查什么**：
1. 扫码后平台显示的排放口信息与许可证载明内容是否完全一致
2. 平台数据是否实时更新（自动监测数据应实时上传，非滞后更新）
3. 二维码是否清晰可辨（印刷模糊或遮挡的二维码不具可追溯性）

**怎么查**：
1. 执法人员现场扫码核查（手机扫描排放口标识牌上的二维码）
2. 平台端数据与现场数据比对（如排气筒高度、排放口位置坐标）
3. 关注"平台数据更新滞后"问题——新建/改建排放口上线后平台数据未及时录入

### 7.3 许可排放量表审查

**许可排放量表**是本次改革新增的核心内容，须包含：

| 内容 | 说明 |
|------|------|
| 主要排放口许可排放量 | 逐一列明每个主要排放口的年许可排放量（t/a） |
| 一般排放口许可排放量合计 | 各一般排放口排放量之和 |
| 全厂许可排放总量 | 主要排放口+一般排放口之和 |

**审查要点**：
- 主要排放口与一般排放口划分是否正确（依据排放标准或行业规范划分）
- 许可排放量计算过程是否清晰（有公式、有参数取值依据）
- 许可排放量与环评批复总量指标一致性核查
- 许可排放量与实际排放量偏差分析（偏差超过20%须说明原因）

## 八、简化删除内容审查要点

### 8.1 已删除内容

| 旧版副本内容 | 新版处理方式 | 平台是否可查 |
|------------|------------|------------|
| 产品产能信息 | 删除副本，平台内保留 | 是 |

## 十、审查自查清单

### 10.1 正本与基本信息审查

| 审查项目 | 审查要点 | 常见问题 |
|---------|---------|---------|
| 许可证有效期 | 是否在有效期内（5年） | 过期未延续 |
| 管理类别 | 重点/简化/登记类别是否正确 | 管理类别判定错误 |
| 行业类别 | 国民经济行业分类代码是否正确 | 代码填写错误导致适用标准错误 |
| 排放口总数 | 现场数量与许可证申报数量是否一致 | 私设暗管或排放口未申报 |
| 总量指标 | 许可排放总量与环评批复是否一致 | 总量超环评批复 |

### 10.2 大气分册审查

| 审查项目 | 审查要点 | 常见问题 |
|---------|---------|---------|
| 排气筒参数 | 高度/内径与现场实测是否一致 | 参数填报失实 |
| 标准引用 | 引用标准编号是否现行有效 | 引用已废止标准 |
| 许可浓度/速率 | 是否正确引用排放标准对应限值 | 限值引用错误（套错标准） |
| 无组织排放 | 是否识别全部无组织排放环节 | 漏识别原料堆场等环节 |
| CEMS安装 | 应装设备是否全部安装、联网、验收 | 未联网或未验收 |
| 监测频次 | 是否满足HJ 819及行业指南要求 | 频次不足（重点管理用简化管理频次） |
| 特殊时段 | 重污染天气管控要求是否载明 | 特殊时段要求缺失或不量化 |

### 10.3 水分册审查

| 审查项目 | 审查要点 | 常见问题 |
|---------|---------|---------|
| 排放方式 | 间接/直接排放判定是否正确 | 间接排放企业套用直接排放标准 |
| 纳管去向 | 间接排放是否注明接纳污水厂名称 | 未注明接纳污水厂 |
| 许可排放量 | 许可浓度×排放量核算是否正确 | 仅填浓度，未核算排放量 |
| 自动监测 | 重点管理企业COD、氨氮是否自动监测 | 应装未装 |
| 监测因子 | 特征污染物是否完整 | 特征因子漏填 |
| 监测频次 | 自动/手工监测频次是否满足规范 | 频次不达标 |

### 10.4 固废分册审查

| 审查项目 | 审查要点 | 常见问题 |
|---------|---------|---------|
| 危废种类 | HW01～HW49是否全部识别 | 危废识别不全 |
| 危废产生量 | 年产生量与台账是否一致 | 台账数据与许可证不符 |
| 贮存设施 | 贮存能力是否满足实际需求 | 贮存超能力 |
| 处置去向 | 处置单位资质是否有效 | 合同过期或资质不匹配 |
| 危废标签 | 现场危废包装是否张贴规范标签 | 标签缺失或信息不完整 |
| 台账保存 | 危险废物台账是否保存≥3年 | 保存年限不足 |

### 10.5 噪声分册审查

| 审查项目 | 审查要点 | 常见问题 |
|---------|---------|---------|
| 声功能区 | 声功能区类别与地方区划图是否一致 | 区划类别认定错误 |
| 监测点位 | 厂界监测点位是否全覆盖 | 遗漏高噪声侧 |
| 昼间/夜间限值 | 是否分别列明昼间和夜间限值 | 仅填昼间限值 |
| 监测频次 | 每季度1次（昼间+夜间）是否满足 | 频次不足 |
| 背景噪声 | 监测时是否同步测量背景噪声 | 缺少背景噪声测量 |

### 10.6 土壤分册审查（重点监管单位）

| 审查项目 | 审查要点 | 常见问题 |
|---------|---------|---------|
| 认定依据 | 企业是否在省级重点监管单位名录中 | 名录内企业未载明土壤分册 |
| 布点方案 | 重点场所布点密度≥1点/500m²是否满足 | 布点数量严重不足 |
| 基本项目 | 45项是否全部覆盖（GB 36600表1） | 基本项目漏项 |
| 特征污染物 | 行业特征因子是否完整识别 | 特征污染物笼统填报 |
| 监测频次 | 重点场所≥1次/年是否满足 | 频次不足 |
| 地下水监测井 | 数量是否≥3个（上游1+下游≥2） | 监测井数量不足 |
| 地下水频次 | ≥1次/半年是否满足 | 频次不足 |
| 隐患排查 | ≥1次/年是否满足 | 隐患排查走过场 |
| 台账保存 | 隐患台账是否保存≥5年 | 保存年限不足 |

### 10.7 "一口一表一码"审查

| 审查项目 | 审查要点 | 常见问题 |
|---------|---------|---------|
| 排放口一张表 | 五项内容（基本信息+治理设施+排放要求+监测要求+管理要求）是否齐全 | 内容不完整 |
| 二维码有效性 | 扫码后平台数据与许可证载明是否一致 | 平台数据陈旧 |
| 许可排放量表 | 主要排放口许可量+一般排放口合计是否完整 | 仅填浓度未填排放量 |
| 数据一致性 | 各分册交叉引用数据是否一致（如排放口编号） | 分册间数据矛盾 |
