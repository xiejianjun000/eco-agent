## 七、使用说明

### 7.1 填写说明

1. **核对结果**：
   - 符合：许可证填报正确
   - 不符合：许可证填报有误或遗漏

2. **问题说明**：
   - 详细描述问题内容
   - 提出整改建议

3. **统计计算**：
   - 符合率 = 符合因子数 / 总因子数 × 100%
   - 用于评估许可证质量

### 7.2 导入Excel步骤

1. 复制表格内容
2. 粘贴到Excel
3. 使用"数据"→"分列"功能调整格式
4. 添加下拉菜单（"数据"→"数据验证"）
5. 添加自动计算公式

### 7.3 自动计算公式

**符合率计算**：
```
=COUNTIF(G:G,"符合")/COUNTA(G:G)
```

**问题统计**：
```
=COUNTIF(G:G,"不符合")
```
