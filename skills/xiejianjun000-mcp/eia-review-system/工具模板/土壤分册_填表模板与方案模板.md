### 第三章 监测点位布设方案

#### 3.1 土壤监测点位

**布点原则**：
- 重点场所：≥1个点位/500m²
- 一般防渗区：≥1个点位/2000m²
- 优先布设在污染物迁移路径上（主导下风向、地下水下游方向）

| 序号 | 监测点编号 | 对应场所 | 坐标X | 坐标Y | 布设深度/m | 监测指标 | 布设理由 |
|------|----------|---------|-------|-------|-----------|---------|---------|
| 1 | S-01 | | | | 0~0.5 | | |
| 2 | S-02 | | | | 0~0.5 | | |
| 3 | S-03 | | | | 0~0.5 | | |
| ... | ... | | | | ... | | |

> 注：每个重点场所至少设置1个监测点位。监测深度通常为0~0.5m（表层），根据需要可增加深层样品。

#### 3.2 地下水监测井

**布井原则**：
- 至少3口井：上游1口（对照井）+ 下游≥2口（监测井）
- 监测井应设置在污染源下游，平行于地下水流方向
- 井深应穿透潜水面，进入含水层至少1m

| 序号 | 井编号 | 位置描述 | 坐标X | 坐标Y | 井深/m | 静水位/m | 监测指标 | 井类型 |

| ... | ... | | | | | | | |

### 第五章 监测频次与周期

#### 5.1 监测频次安排

| 监测类型 | 点位数量 | 监测指标 | 监测频次 | 监测时间 | 备注 |
|---------|---------|---------|---------|---------|------|
| 土壤（重点场所） | [X]个 | 基本项目+特征污染物 | **1次/年** | [上/下半年度] | |
| 土壤（一般防渗区） | [X]个 | 基本项目 | **1次/年** | [上/下半年度] | |
| 地下水 | [X]口井 | 基础项+特征污染物 | **2次/年** | 6月 + 12月 | 上、下半年各1次 |

#### 5.2 监测周期调整条件

满足以下条件，可向当地生态环境局申请调整为1次/3年：
1. 连续3年监测结果均低于 GB 36600—2018 表1筛选值
2. 无新增污染源或工艺变化
3. 获得生态环境局书面批准

#### 5.3 触发加密监测的情形

| 情形 | 处理方式 |
|------|---------|
| 新、改、扩建项目投入生产 | 在投产前完成1次背景监测 |
| 发生污染物泄漏事故 | 事故后30日内启动应急监测 |
| 土壤或地下水异常超标 | 加密监测至连续2次合格 |

### 第六章 监测方法与质量控制

#### 6.1 土壤样品采集（简述）

- 采集方法：GB/T 29140—2012《土壤质量 土壤样品的采集与保存》
- 采样设备：不锈钢土钻 / 土壤采样器
- 样品保存：4°C冷藏，7日内送实验室分析

#### 6.2 地下水样品采集（简述）

- 采集方法：HJ 164—2020 监测井采样规程
- 洗井要求：水位恢复后洗井，pH/电导率/浊度稳定后方可采样
- 样品保存：4°C冷藏，48小时内送实验室分析

#### 6.3 质量保证与质量控制

| QC措施 | 要求 |
|-------|------|
| 现场空白 | 每批次1个 |
| 现场平行样 | 每批次≥10% |
| 运输空白 | 每批次1个 |
| 实验室密码平行 | 每批次≥10% |
| 全程序空白 | 每批次1个 |

## 四、许可证变更中的土壤分册处理

### 什么情况下需要变更土壤分册

| 变更情形 | 是否需要变更 | 变更类型 | 说明 |
|---------|------------|---------|------|
| 被新列入重点监管单位 | **是** | 重新申请 | 补充完整土壤分册 |
| 新增生产车间/储罐区 | **是** | 变更申请 | 补充新场所布点 |
| 生产工艺变化导致特征污染物变化 | **是** | 变更申请 | 更新监测指标 |
| 监测井损坏需重新布设 | 是 | 变更申请 | 更新监测井信息 |
| 连续3年达标申请调整监测频次 | 是 | 变更申请 | 附批准文件 |
| 企业名称/地址变更 | **否** | 变更申请 | 不涉及土壤分册内容 |

### 变更流程

```
步骤1：确认变更情形（参考上表）
步骤2：在全国排污许可证管理信息平台提交变更申请
步骤3：上传更新后的土壤分册相关材料
步骤4：生态环境局审核
步骤5：平台自动生成新版许可证（无需换发纸质证件）
```
