## 五、执法检查指南深度研读：五分册+二维码+28项清单

### 5.1 五分册核心检查逻辑

> **核心变化**：从旧版"一揽子查阅"变为新版"按要素逐册核查"，每个排放口对应唯一二维码。

| 分册 | 核心检查项 | 常见致命问题 |
|------|---------|-----------|
| **大气分册** | 排放口数量/位置/高度/内径一致；CEMS监测断面合规（≥10D+≥5D）；无组织排放控制；重污染天气停限产台账 | CEMS装弯头下游（数据无效）；无组织逸散未控制 |
| **水分册** | 排放口位置/方式/去向一致；COD/氨氮在线监测联网；手工监测频次；纳管协议 | 在线设备断网/干扰采样；去向与载明不符 |
| **固废分册** | 危废台账+联单逻辑（转移量≤产生+期初）；贮存"三防"；标签；执行GB 18597—2023 | 台账倒挂；贮存未防渗；仍用旧版2001标准 |
| **噪声分册** | 厂界4角点+必要中间点；夜间测量**22:00后**；气象条件+仪器检定；连续3天数据 | 夜间22:00前测量；无气象记录；单日数据不足 |
| **土壤分册** | 重点监管单位身份核实（书面告知）；布点覆盖重点场所；8项重金属+pH+石油烃+特征；隐患排查≥1次/年；地下水≥3井+半年1测 | 土壤分册空白（属重点监管单位）；特征因子遗漏（六价铬）；多年未测 |

### 5.2 二维码扫描执法操作规程（三方比对）

```
现场扫码 → 平台数据回传（排放口编号/位置/高度/许可限值/监测要求）
→ 与许可证分册文字载明比对 → 与现场实际状况实测比对
→ 三方不一致 → 记录异常 → 平台修正申请 → 跟踪复核
```

### 7.1 文某某等非法倾倒危险废物案（污染环境罪）

| 项目 | 内容 |
|------|------|
| 案发时间 | 2025年8月27日 |
| 案发地点 | 郑州航空港华夏大道附近雨水管道 |
| 涉案人员 | 文某某、赵某某、虎某某等三人（自然人） |
| 委托方 | 开封市美鸿化工有限公司（产生单位） |
| 非法行为 | 将约**33吨化工废液**（危险废物）倾倒入雨水管道 |
| 倾倒方式 | 罐车运输至路边雨水管道入口，停留约1.5小时全部倾倒 |
| 鉴定结论 | 雨水管道倾倒点废液与该公司污水处理站化工废液主要有机成分相同，**属危险废物** |
| 法律定性 | 污染环境罪（非法倾倒危险废物3吨以上） |
| 案发机制 | 群众举报→气味追溯→视频监控→行刑衔接（生态+公安联合） |
| 来源 | 河南省生态环境厅2026年第七批典型案例（2026-07-13） |

**与排污许可关联**：
- **产生单位责任**：开封市美鸿化工有限公司作为危险废物产生单位，委托无资质人员处置危废（360元/吨口头协议），构成**非法转移/倾倒危废**的共同违法。
- 许可关联审查：持有排污许可证的企业若同时产生危废，须建立**危废管理台账**（危废产生、贮存、转移全流程）；转移须通过**危险废物转移联单**（电子联单）；不得将危废交无资质单位处置。
- 排污许可监管提示：执法人员检查时发现危废管理台账缺失或联单倒挂，应同步排查危废非法转移/倾倒风险，必要时启动行刑衔接。
