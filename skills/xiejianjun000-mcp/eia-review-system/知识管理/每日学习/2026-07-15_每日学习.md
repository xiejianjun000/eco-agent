## 二、重大政策更新——排污许可证副本格式优化

### 2.1 政策概览

| 项目 | 内容 |
|------|------|
| 文件 | 《关于优化排污许可证（副本）格式的通知》 |
| 部务会审议通过 | 2026年4月20日 |
| 正式印发 | 2026年6月 |
| 副本更新启动 | 2026年8月15日 |
| 全面应用目标 | 2026年底前 |
| 核心理念 | 分要素、分排口管理——"一口一表一码" |

### 2.2 三大变化

**变化一：各要素独立成章**
- 新版副本全面涵盖大气、水、工业固废、工业噪声、土壤等环境要素
- 各要素管理要求独立成章，解决企业"看不懂"问题
- 删除与排放不直接相关的冗余内容

**变化二：一口一表一码**
- 每个排放口对应一张表
- 每个排放口对应唯一二维码
- 便于企业执行和政府监管

**变化三：无需企业重新填报**
- 现有企业直接登录全国排污许可证管理信息平台自行下载
- 首次申请企业直接申领新版
- 分行业分批次推进

### 2.3 对技术审查的影响

1. **审查重点转移**：排放口信息准确性的要求进一步提高（"一口一表"对排放口定位精确性提出更高要求）
2. **要素全覆盖核查**：审核时需逐一核对大气/水/固废/噪声/土壤各要素是否齐全
3. **二维码应用**：执法检查时将扫描二维码核对，排放口信息必须与系统一致
4. **冗余精简**：审核时重点突出排放标准和许可排放量等关键指标

## 五、边缘情况决策树（8大类精读）

### 5.1 管理类别判断边缘情况（4种）

| 场景 | 判断依据 | 结论 |
|------|---------|------|
| 多行业混合企业 | "就高不就低"原则 | 按最高管理类别 |
| 规模化边缘企业（接近门槛） | 建议从严+考虑锅炉/污水处理站 | 建议按重点管理 |
| 季节性生产企业 | 按设计能力判断 | 设计能力≥门槛=重点 |
| 以外协加工为主的企业 | 按实际生产工序判断 | 有重点工序=重点 |

### 5.2 监测频次确定边缘情况（3种）

| 场景 | 结论 |
|------|------|
| 重点管理+间接排放 | COD、氨氮可手工监测（不需自动），每月1次 |
| 简化管理+直接排放 | COD、氨氮每周1次，总磷、总氮每月1次 |
| 自动监测设备未验收 | 填"手工监测（待验收后改为自动监测）"，注明验收时限 |

### 5.3 排放标准适用边缘情况（2种）

| 场景 | 规则 |
|------|------|
| 有行业标准+有地方标准 | 执行更严格的标准（地方标准优先于国家标准） |
| 间接排放 | 有接管标准执行接管标准，无接管标准执行行业标准间接排放限值 |

### 5.4 排放口管理边缘情况（2种）

| 场景 | 要求 |
|------|------|
| 多个排放口 | 分类管理：生产废水/生活污水/雨水/冷却水分别填报 |
| 排放口坐标精度 | 经纬度精确到秒，平面坐标精确到米 |

## 八、今日核心知识点提炼

### 8.1 审查实操关键点

1. **特征因子审核**：排名第一的拒绝原因（35%），必须用"三维核对法+逆向核对法"双重验证
2. **监测频次审核**：记住"重点管理+直接排放→自动监测"这条硬线，自动监测未验收不能填"自动监测"
3. **标准适用**：行业标准>综合标准，地方标准>国家标准，必须核对企业所在地是否执行特别排放限值
4. **排放口信息**：6月副本格式优化后，"一口一表"对排放口信息准确性要求进一步提高，10项必填信息一个不能少

### 8.2 法典实施过渡期应对（倒计时31天）

- 本周重点任务：更新法律依据引用模板，确保8月15日后正确引用法典条款
- 审查/执法文书中避免引用已被法典废止的10部单行法
- 关注"不正常运行污染防治设施"的二分法变化（是否属于逃避监管）
- 新版副本更新启动在即，提前了解"一口一表一码"格式

### 8.3 地方动态关注方向

- 上海细则（首个依据法典修订的地方细则）→ 可能成为其他省份模板
- 山东"许小可"助企志愿行动 → 优化营商环境+技术帮扶模式
- 大连"1+1+(1+N)"执法模式 → 清单式执法+行业细化的可复制经验
- 河北排污权确权 → 排污许可证作为确权凭证的实务变化
