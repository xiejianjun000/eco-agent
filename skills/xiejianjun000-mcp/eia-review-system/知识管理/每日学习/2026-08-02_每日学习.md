## 五、海南经济特区排污许可管理条例修正草案（最新地方立法）

### 5.1 基本信息

| 项目 | 内容 |
|------|------|
| 文件名称 | 《海南经济特区排污许可管理条例（修正草案）》 |
| 状态 | 公开征求意见中 |
| 时间 | 2026年7月下旬 |
| 核心增补 | 增加排污单位建立管理台账和保存管理台账的要求 |
| 核心增补 | 明确生态环境监测机构的管理规定 |

### 5.2 政策意义

1. **经济特区立法权的运用**：海南作为全国最大经济特区，可以在不违背法典前提下制定更严格的排污许可管理要求
2. **台账管理法定化**：在原条例基础上增加台账要求 → 将台账管理从技术规范要求上升为地方法规要求
3. **监测机构管理规定**：首次在排污许可领域立法层面明确生态环境监测机构的责任边界
4. **立法趋势**：海南模式可能被其他经济特区（深圳、厦门、珠海、汕头）借鉴

### 5.3 对技术审查的启示

- 海南持证企业许可证审查时需额外关注：台账保存要求（可能严于国家规定的"5年"）、监测机构资质要求
- 其他省份类似修正案将陆续出台，须逐省追踪

## 六、最新执法典型案例深度分析

### 6.1 四川蒲江：私设暗管排放生产废水案（2026年7月29日通报）

| 项目 | 内容 |
|------|------|
| 违法企业 | 成都某新材料科技有限公司 |
| 发现方式 | 河道监控巡查 → 寿安工业园区新园二路沟渠水质浑浊发黄 |
| 违法事实 | 环评要求废水循环使用不外排 → 实际通过3根管道将废气处理设施循环水池+清洗废水水箱连接至雨水井直排 |
| 监测结果 | 化学需氧量、氨氮、总磷浓度明显偏高 |
| 处罚 | 罚款**17.58万元** + 移送公安**行政拘留**直接责任人 |
| 法律依据 | 《环境保护法》+《水污染防治法》 |

**技术审查启示**：
1. **环评"废水不外排"要求的证后核查至关重要**：环评写"循环使用不外排"但企业实际留了暗管 → 审查时对声称"零排放"或"不外排"的企业应标注为高风险核查对象
2. **三根管道**说明企业主观故意明显（蓄意建设暗管系统）→ 不是偶然泄漏，而是系统性逃避监管
3. **河道监控**发挥了关键预警作用 → 与HJ 1480-2026标准的内部视频监控形成互补

### 6.2 四川崇州：油污泄漏白马河生态环境损害赔偿案（2026年7月29日通报）

| 项目 | 内容 |
|------|------|
| 违法企业 | 成都某科技有限公司 |
| 发现方式 | 群众投诉 → 白马河出现油污 → 沿河排查 → 锁定雨水排口 |
| 违法事实 | CNC切削液油雾废气处理设施油污收集容器满载未清空 → 溢出 → 屋面雨水地漏 → 厂区雨水管网 → 白马河 |
| 监测结果 | 园区雨水管入白马河口水样石油类含量**469mg/L** |
| 行政处罚 | 罚款**10万元** |
| 生态损害赔偿 | **9.0572万元**（污染处置费+风险防控费） |
| 评估机构 | 四川省生态环境科学研究院 |

**技术审查启示**：
1. **"非故意"也能构成逃避监管**：油污收集容器未及时清运看似"管理疏漏" → 但法律上污染后果成立 + 企业有日常管理义务 → "不正常运行治理设施"可适用
2. **油污→雨水管网→河流**是经典污染路径 → 审查时对涉及油类/切削液的企业，须核查雨污分流+应急收集设施
3. **行政处罚+生态损害赔偿双罚**模式 → 10万行政处罚 + 9万余元赔偿 = 总成本约20万
4. **469mg/L石油类**远超排放标准（GB 8978-1996石油类一级标准5mg/L）→ 超标约94倍

### 6.3 山东青岛：食品企业超标排放25万案（2026年7月22日）

| 项目 | 内容 |
|------|------|
| 违法企业 | 青岛西微雅食品有限公司 |
| 违法事实 | 外排废水COD浓度**1.03×10⁴mg/L**（10300mg/L） |
| 对比许可限值 | 远超排污许可证载明的许可排放限值 |
| 处罚 | 罚款**25万元** |
| 处罚日期 | 2026年7月22日 |
| 法律依据 | 《排污许可管理条例》第17条+第34条第1项 |
| 裁量基准 | 《山东省生态环境行政处罚裁量基准（2022年版）》排污许可类 |

**异常数据警示**：COD = 10300mg/L，典型生活污水COD约250-500mg/L，该数值是生活污水的20-40倍，接近工业原液浓度。说明企业基本未进行任何有效处理。

**技术审查启示**：
1. 食品制造行业COD浓度异常极高 → 审查时对食品企业废水处理设施设计能力应重点核查
2. 处罚依据是《排污许可管理条例》而非《水污染防治法》 → 直接用许可证载明限值判定"超许可排放"
3. 企业截至公示时未履行 → 下一步可能面临按日连续处罚、吊销许可证

### 6.4 安徽滁州：超年度许可排放量罚20万案（2026年7月29日公示）

| 项目 | 内容 |
|------|------|
| 违法企业 | 安徽修一制药有限公司 |
| 违法事实 | 超过排污许可证规定的**年度许可排放量限值** |
| 法律依据 | 《排污许可管理条例》第17条第2款+第34条第1项 |
| 处罚决定书 | 皖滁环﹝天﹞罚﹝2026﹞13号 |
| 处罚 | 罚款**20万元** |

**技术审查启示**：
1. **超许可排放量 ≠ 超浓度**：即使浓度达标，总量超了也构成违法（条例第34条第1项同时涵盖"超浓度"和"超总量"两种情形）
2. 年度许可排放量超限的发现依赖执行报告中的实际排放量核算 → 证明执行报告审核制度是发现此类违法的关键
3. 处罚额20万元在法定幅度（20万-100万）中属下限 → 可能与企业在发现问题后积极整改有关
4. 审查时应对企业许可排放量核算的合理性进行验证，避免因核算偏低导致企业"注定超标"

### 6.5 西藏林芝：排污登记首违不罚案（2026年7月15日）

| 项目 | 内容 |
|------|------|
| 涉事企业 | 林芝某食品制造企业 |
| 管理类别 | 应完成排污许可登记备案（非申领许可证） |
| 违法情形 | 未按要求完成排污许可登记备案 |
| 背景 | 企业曾于2025年10月主动咨询，被告知"无需申领许可证"，误将"无需申领"等同于"无需任何手续" |
| 处理结果 | **不予行政处罚** |
| 法律依据 | 《行政处罚法》第33条第1款：违法行为轻微并及时改正，没有造成危害后果 |
| 处置过程 | 核查当日当场完成登记备案，立行立改 |

**技术审查启示**：
1. **登记管理 ≠ 不需要管理**：登记管理企业仍需在全国排污许可平台完成登记备案，否则仍属违法
2. 首违不罚的适用条件：首次违法 + 主观无故意 + 积极配合 + 立行立改 + 无危害后果
3. 宣传引导的重要性：企业在咨询时被告知"无需申领许可证"但没有被告知"需要登记" → 说明基层宣传仍有改进空间
4. 法典施行后，登记管理的法律依据将更为明确

## 七、法典型号信息深化学习

### 7.1 法典结构精炼

| 编次 | 名称 | 核心内容 |
|:---:|------|------|
| 第一编 | 总则 | 立法目的、基本原则、管理体制 |

| 第三编 | 生态保护 | 生态空间管控、生物多样性、自然保护地等 |
| 第四编 | 绿色低碳发展 | 清洁生产、循环经济、碳达峰碳中和等 |
| 第五编 | 法律责任和附则 | 罚则、衔接条款、施行日期 |

**条文总数**：1242条

**整合对象**：分散于多部单行法律中的生态环境制度规范（约10部单行法不再保留）

### 7.2 法典意义再认识

- 我国第二部以"法典"命名的法律（第一部为民法典）
- **世界上第一部以"生态环境"命名的法典**（全球首创）
- 标志着生态环境治理从"单行法分散管理"迈入"体系化法治化"新阶段
- 为以美丽中国建设全面推进人与自然和谐共生的现代化提供坚实法治保障

### 7.3 对排污许可制度的影响

1. **法律位阶提升**：从行政法规（条例）→ 基本法律（法典），违法的法律后果更严重
2. **制度整合**：排污许可与环评、总量控制、环境监测、环境应急等制度的衔接由法典统一规范
3. **执法依据统一**：不再需要在不同单行法中寻找法律依据，一处违法可直接引用法典对应条款

### 10.3 "废水不外排"企业的审查升级规则

基于四川蒲江案教训，建立专项审查规则：

**审查触发条件**：许可证/环评中载明"废水循环使用不外排""零排放""全部回用"等

**审查必查项**：
1. 水平衡图验证：新鲜水用量+回用水量是否平衡
2. 现场管道走向：有无隐蔽管道连接至雨水井/外环境
3. 循环水池容量与生产规模匹配性
4. 定期清运/处置的合同和联单（如委托第三方）
5. 雨水排口是否有在线监控或定期监测
6. 是否有突发环境事件应急预案（含事故排水收集措施）

**风险等级标注**：高风险 → 建议执法部门优先现场核查
