### 1.2 排污许可证（副本）格式优化 — 8月15日起分行业分批更新

**来源**：生态环境部《关于优化排污许可证（副本）格式的通知》（2026年6月，文号推测：环环评〔2026〕31号）

**改革背景**：
- 现行副本格式依据2018年要求制定，存在三大痛点：
  1. **内容多且杂**：部分排污单位副本达150多页，与排放无直接关联的产品/产能/原料/设备信息占30+页
  2. **环境要素"管不全"**：仅大气和水独立成章，工业固废、工业噪声、土壤零散体现
  3. **企业+执法人员阅读费时费力**

**优化要点**：
1. **五大环境要素全部纳入**：大气、水、工业固废、工业噪声、土壤独立成章，夯实"一证式"管理基础
2. **一个排放口对应一张表**：分要素、分排口管理，优化管理逻辑
3. **删除冗余内容**：聚焦排放标准和许可排放量等关键指标
4. **二维码标识技术**：扫码即可溯源查询，方便执法
5. **无需企业重新填报**：依据历史信息更新

**实施安排**：
- 2026年8月15日起，分行业分批次在全国排污许可证管理信息平台更新

**证后管理衔接要求**（执法/审查要点）：
- 生态环境部门应主动提醒排污单位及时下载新副本
- 核对新章节信息是否完整准确
- 指导企业确认新的环境管理要求
- 历史信息可能存在缺失或不符合当前实际：督促补充、及时变更
- **信息平台一体化**：依托全国排污许可证管理信息平台，以统一社会信用代码、排污口编码、污染物指标编码为唯一标识，打通数据壁垒

### 2.1 湖北省首例VOCs监测数据造假刑事追责案（襄阳·2026-06-04立案）

**来源**：中国环境报 2026-07-02

**案情概要**：
- 涉事企业：某精细化工有限公司（排污许可重点管理单位）
- 违法事实：三氟苯嘧啶中间体生产车间产生VOCs废气，应收集至DA003排放口并自动监测，企业私自架设PVC旁路管道将废气直排楼顶，绕过规范排污口和自动监测设施
- **适用新法**：依据法释〔2026〕4号《关于办理环境污染刑事案件适用法律若干问题的解释》，首次将VOCs监测数据弄虚作假纳入刑法第338条"严重污染环境"认定情形
- 处置流程：2026-04-15接部交办线索→突击检查→行刑联动公安提前介入→2026-06-03移送公安→06-04刑事立案

**审查/执法启示**：
1. **VOCs数据造假已入刑**：此前VOCs排污造假未纳入刑事追责重点，新司法解释填补了空白
2. **旁路管道是典型逃避监管手段**：证据链需包含工艺管线图纸、现场勘验比对、分层约谈记录
3. **停产不等于无法取证**：即使企业已停产，通过环评/验收/许可/图纸等书面资料+人员约谈，仍可形成完整证据链
4. **取证层次化**：企业负责人（决策层）+ 车间管理人员（执行层）+ 环保运维人员（操作层）分层约谈，互相印证

**来源**：行政处罚决定书 2026-06-30

**案情概要**：
- 涉事企业：广州市荣森水务有限公司（水环境重点排污单位，花东镇污水处理厂）
- 违法手段：自2021年中下旬起持续超3年，厂长授意运营人员实施"瓶测"操作——对污水样本人工稀释后再用自动监测设备分析，掩盖氨氮、COD等污染物超标
- 2024-10-30现场检查发现氨氮自动监测采样管路与供样管线断开，插入装有不明液体的白色塑料瓶
- 处罚结果：罚款45万元

**审查/执法启示**：
1. **"瓶测"是经典造假手段**：检查时注意采样管路与供样管线的连接状态
2. **造假持续周期长需追究持续违法**：从2021年至2024年跨度3年+
3. **追责层级**：从厂长（决策授意）→运营主管（安排实施）→一线人员（具体操作）全链条追责

## 四、今日深度学习：生态环境法典·排污许可专章核心条款对照

### 4.1 法典 vs 条例 关键变化速查

| 维度 | 条例（国务院令736号） | 法典（2026-08-15施行） | 变化要点 |
|------|----------------------|----------------------|---------|
| 法律层级 | 行政法规 | 法律 | ↑提升 |
| 无证排污处罚 | 20万-100万 | 20万-100万 + 拒不停止移送公安拘留5-15日 | +拘留手段 |
| 超许可排放 | 20万-100万 | 10万-100万 | 下限降低（10万起） |
| 不正常运行设施 | 统一处罚 | 区分"非逃避监管"（5-20万）vs"逃避监管"（10-100万+拘留） | 精准化分层 |
| 未运行维护设施 | 无明确规定 | 2万-5万 | 新增 |
| 擅自拆除设施 | 无单独规定 | 10万-100万 | 新增重罚 |
| 登记单位未填报 | 5万以下 | ≤5万 | 基本一致 |
| 逃避监管方式 | 列举4类 | 扩大：暗管/渗井/渗坑/灌注/裂隙/溶洞/篡改数据/临时停产避检/非紧急开启应急通道/不正常运行设施 | +临时停产/应急通道 |
| 排放种类不符 | 未明确 | 明确列为违法（与超浓度/超量并列） | 新增独立违法形态 |
| 自动监测 | 重点管理单位应安装 | 重点管理单位应安装 + 发现异常应及时报告 | +报告义务 |
| VOCs数据造假 | 未纳入刑事追责 | 法释〔2026〕4号纳入刑法第338条 | 刑事追责闭环 |

### 4.2 技术审查中应关注的5大变化

1. **许可证格式**：8月15日后新副本有5个独立章节，审查时需逐一核对
2. **工业固废专章**：固废管理要求从零散→系统化，需检查是否遗漏固废类别
3. **工业噪声专章**：噪声排放限值和监测要求独立成章
4. **土壤专章**：土壤污染重点监管单位管控要求系统纳入
5. **二维码溯源**：扫码可查，执法检查效率大幅提升

## 五、技术审查技能强化

### 5.1 审查精准度自检要点（今日复盘）

#### 许可证质量核查清单（HJ 1299-2023 + 法典新要求）

| 核查项 | 易错点 | 审查方法 |
|--------|--------|---------|
| **管理类别判断** | 仅按行业名称判断，忽略工艺/规模细分 | 对照分类管理名录逐条核对，特别注意"有XX除外"表述 |
| **特征因子遗漏** | 仅对照环评，未对照排放标准和技术规范 | 三段交叉核对：环评→排放标准→技术规范 |
| **标准引用错误** | 引用已废止标准、适用范围错误 | 核对标准有效性+适用范围条款 |
| **监测频次不足** | 简化管理按重点管理频次、行业无指南时按总则但遗漏特殊要求 | 先查行业自行监测指南→无则查总则HJ 819 |
| **排放口信息不全** | 位置描述模糊、排放去向不明确 | 经纬度坐标+排放去向+受纳水体/环境功能区 |
| **总量核算错误** | 用设计值代替实际值、产污系数法选错系数 | 优先实测法→物料衡算→产污系数法（HJ 884准则） |
| **工业固废遗漏** | 新要求：8月15日后必须独立成章 | 逐类核对固废类别+去向+处置方式 |
| **土壤管控要求遗漏** | 非重点监管单位遗漏土壤要求 | 确认是否列入土壤重点监管名录 |

### 5.2 VOCs监测执法新要点（法释〔2026〕4号之后）
