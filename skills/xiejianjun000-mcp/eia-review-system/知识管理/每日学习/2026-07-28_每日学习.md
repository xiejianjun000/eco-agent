## 二、头号重点：宁夏自行监测管理规定——全国首个省级"设备未正常运行+数据失真"认定标准

### 2.1 基本信息

| 项目 | 内容 |
|------|------|
| **文件名称** | 《宁夏回族自治区排污单位自行监测管理规定(试行)》 |
| **发布日** | 2026年7月27日 |
| **施行日** | 2026年9月1日 |
| **有效期** | 至2028年8月31日（试行2年） |
| **适用范围** | 宁夏所有持证排污企事业单位及生产经营者 |
| **核心创新** | 全国首个明确界定"自动监测/视频监控设备未正常运行"7类情形+"监测数据失真"4类情形的省级规定 |

### 2.2 核心制度框架

**1. 全链条质量管理体系**
企业须建立覆盖以下环节的全链条质量管理制度：
- 点位布设 → 设备运维 → 样品采集 → 数据处理 → 台账归档 → 问题整改

**2. 自动监测设备调试联网时限**
取得排污许可证 **3个月内**，须完成自动监测设备调试与联网，确保数据稳定传输。

**3. 刚性监管红线——7类"设备未正常运行"认定**

| 序号 | 情形 |
|:----:|------|
| 1 | 未按规范运维设备导致数据失真 |
| 2 | 设备故障、数据异常、指标超标未及时处置 |
| 3 | 擅自改动、遮挡监控设备，篡改删除监控数据 |
| 4 | 数据有效传输率、监控在线率不达标 |
| 5 | 未规范标记设备及治污设施运行工况 |
| 6 | 违规启停监测、监控设备 |
| 7 | 其他未正常运行污染物排放监测、监控设备的情形 |

**4. "监测数据失真"认定——4类情形**

| 序号 | 情形 |
|:----:|------|
| 1 | 监测点位布设、样品采集、流转保存、实验检测、数据处理等关键环节违规，造成数据错误、无法复核 |
| 2 | 自动监测设备经现场比对、标准物质测试，技术指标超出规范限值**2倍及以上** |
| 3 | 擅自中断数据采集传输、违规标记处理数据，导致数据失真，影响环境评价结果 |
| 4 | 其他违反监测规范、造成数据失真的行为 |

### 2.3 审查/执法实务影响

**自监测方案审查**：
1. 宁夏企业许可证审查时，自行监测方案须增加"全链条质量管理制度"描述——不再仅是监测频次的罗列。
2. **7类/4类认定的启示**：其他省份虽尚未出台类似细化标准，但"十五五"规划已明确自行监测穿透式监管目标，各地将陆续跟进→**建议将宁夏规定写入《标准更新追踪表》地方标准部分**。
3. **视频监控新要求**："擅自改动、遮挡监控设备"属于设备未正常运行——提示：重点管理单位排放口视频监控如被遮挡（工人作业时无意遮挡或有意遮挡），可能被直接认定为违法行为。
4. **超标2倍红线**：比对测试超标2倍=数据失真，不再是"设备偏差可申诉"→审查自动监测设备验收报告时须核对比对测试结果是否在2倍以内。

**取证启示**：
- "数据有效传输率、监控在线率不达标"作为独立认定项——执法人员在调取平台数据时，**传输率是否达标**可作为独立违法证据，无需额外监测。
- "未及时处置异常"要求企业建立 **5分钟内响应、24小时值班** 等制度——见VOCs刑案（湖北襄阳）启示。

### 5.2 特征因子遗漏（35%）——高频遗漏因子TOP10

| 排名 | 因子 | 所属行业 | 遗漏原因 |
|:----:|:----:|---------|---------|
| 1 | **六价铬** | 电镀 | 只填总铬 |

| 3 | **总锑** | 纺织印染 | 不知道用锑催化剂 |

| 6 | **氰化物** | 电镀、焦化 | 不知道用氰化工艺 |
| 7 | **总磷** | 食品、屠宰 | 只填COD、氨氮 |
| 8 | **硫化物** | 制革、造纸 | 不知道脱硫工序 |
| 9 | **二噁英** | 垃圾焚烧、钢铁烧结 | 不知道产生机理 |
| 10 | **总氮** | 化工、印染 | 只填氨氮 |

**审查方法：工艺-原料-产品三维核对法**
```
步骤1：核对企业生产工艺流程图→对照技术规范"产排污环节"→标记所有工序
步骤2：核对企业原料清单（MSDS）→标记所有有毒有害成分
步骤3：核对企业产品方案→标记特征污染物
步骤4：三步取并集→形成必填因子清单→与排放标准表核对
```

### 5.3 监测频次不足（25%）——决策树

```
管理类别（重点/简化）
    ↓
排放方式（直接/间接）
    ↓
自动监测设备情况（已验收/未验收/无）
    ↓
因子类型（COD/氨氮 vs 特征因子）
    ↓
确定监测频次
```

**关键陷阱**：
- 自动监测设备未验收 → 填"手工监测（待验收后改为自动监测）"
- 重点管理+直接排放 COD/氨氮 → **必须自动监测**，不能填"手工每月1次"
- VOCs有组织排放 → **至少每季度1次**，不能填"每年1次"

### 5.4 排放标准适用错误（15%）——决策树

```
有行业标准？→ 执行行业标准（非综合标准）
有地方标准？→ 比较地方与国标，执行更严格的
在重点流域/区域？→ 执行特别排放限值
标准最新版本？→ 检查废止状态
```

### 5.5 排放口信息不完整（10%）——必填清单

每个排放口必填：编号、名称、**坐标（精确到秒）**、高度、内径、排放方式（连续/间歇）、**排放去向（具体水体名称或污水处理厂名称）**

## 十二、学习心得

**今日头号收获——宁夏自行监测规定（试行）**：这是全国首个在省级层面明确"自动监测/视频监控设备未正常运行"7类认定情形和"监测数据失真"4类认定情形的规范性文件，9月1日施行。其核心价值在于"穿透式监管"的操作化——不再仅仅说"数据造假要罚"，而是给出7+4条可量化、可执行的认定标准。这对自行监测方案审查提出了**全链条质量管理制度**的新要求：审查方案时不仅要看"测什么、测几次"，更要看"怎么保证数据真实、全链条可追溯"。宁夏规定落地后，预计各省将陆续跟进，成为"十五五"自行监测穿透式监管的地方执行模板。

**审批精准度工具化取得实质突破**：6大行业（印染·造纸·石化·钢铁·水泥·玻璃）的8省差异速查表通读完成，各省标准号全部核实，为后续行业核查形成了"一句话精华审查要点+省份差异速查+典型问题"三位一体的快速定位能力。配合95%攻坚指南的Top5拒绝原因精读，审批准确率预估从90.2%升至91.0%，距95%目标收窄至4个百分点。

**法典倒计时18天**：地方立法清理进入密集区——山东已交卷（112件），重庆/北京/安徽等正冲刺中。每日跟踪是关键能力护城河。
