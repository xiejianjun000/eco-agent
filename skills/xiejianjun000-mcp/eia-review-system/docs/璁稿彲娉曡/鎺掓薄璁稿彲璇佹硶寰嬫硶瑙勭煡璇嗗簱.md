## 二、生态环境法典·排污许可专章（2026年8月15日施行）

> 2026年3月12日第十四届全国人大四次会议通过，2026年8月15日起施行。法典将排污许可从行政法规提升为法律层级，构建了全新的法律责任体系。

### 2.1 排污许可管理条款（第174—186条）

| 条文 | 核心规定 |
|------|----------|
| 第174条 | **制度定位**：国家建立健全以排污许可制为核心的固定污染源监督管理制度；未取得排污许可证不得排放污染物 |
| 第175条 | **分类管理**：重点管理（影响较大）、简化管理（影响较小）；范围名录由国务院生态环境主管部门拟订报国务院批准 |
| 第176条 | **适用范围**：排放工业废气/有毒有害大气污染物、工业废水/医疗污水、城镇污水集中处理设施运营、海岸/海洋工程、产生工业固体废物单位、排放工业噪声、排放放射性废液/产生放射性固体废物单位、运行电磁辐射设施等9类 |
| 第177条 | **监督管理**：设区的市级以上人民政府生态环境主管部门加强排污许可监督管理 |
| 第178条 | **申请地点**：生产经营场所所在地设区的市级以上地方人民政府生态环境主管部门；海洋工程向国务院生态环境主管部门或其海域派出机构申请 |
| 第179条 | **许可证法律地位**：排污许可证是对排污单位进行生态环境监督管理的主要依据 |
| 第180条 | **核发条件**：依法取得环评批准文件、污染物排放符合标准与总量控制要求、采用污染防治设施可达许可浓度或符合可行技术、自行监测方案符合规范等5项条件 |
| 第181条 | **记载信息**：排污口位置数量、排放方式去向、污染物种类/许可浓度/许可量、污染防治设施运行维护要求、特殊时段禁限排要求等 |
| 第182条 | **有效期与重新取得**：有效期5年；新建改建扩建项目、生产经营场所/排污口/排放方式发生变化、排污口数量或排放种类/浓度/量增加时应重新取得 |
| 第183条 | **自行监测与台账**：依法开展自行监测、建立管理台账、保存原始记录不少于5年 |
| 第184条 | **重点管理单位自动监测**：安装使用维护自动监测设备并与生态环境主管部门联网；发现数据异常应及时报告 |
| 第185条 | **信息公开**：向社会公开排放种类/浓度/量及污染防治设施运行情况、自行监测数据等 |
| 第186条 | **排污登记表制度**：影响很小的单位填报排污登记表（有效期5年），不实行排污许可管理 |

### 2.2 违反排污许可管理规定的法律责任（第1101—1112条）

| 条文 | 违法行为 | 罚款标准 | 其他处罚 |
|------|----------|----------|----------|
| 第1102条 | 未依法取得排污许可证排放污染物 | 20万—100万 | 可责令限制生产/停产整治；情节严重责令停业关闭；噪声2-20万；拒不停止移送公安拘留5-15日 |
| 第1103条 | 未按许可证载明种类排放/超过许可浓度/许可量/许可限值排放 | 10万—100万 | 可责令限制生产/停产整治；情节严重吊销许可证+责令停业关闭；噪声2-20万 |
| 第1104条 | 未按规定运行维护污染防治设施 | 2万—5万 | 致使设施不能正常发挥作用（不属于逃避监管）：5-20万；擅自拆除设施：10-100万；情节严重吊销许可证+责令停业关闭 |
| 第1105条 | 以欺骗/贿赂等不正当手段取得排污许可证 | 20万—50万 | 撤销许可证 |
| 第1106条 | 排污登记单位未依法填报排污信息 | ≤5万 | 责令改正 |
| 第1107条 | 超排放标准或超总量控制指标排放 | 10万—100万 | 可责令限制生产/停产整治；情节严重责令停业关闭；噪声2-20万 |
| 第1108条 | **逃避监管方式排放**：暗管、渗井、渗坑、灌注、裂隙、溶洞、篡改/伪造监测数据、以逃避检查为目的临时停产、非紧急开启应急排放通道、不正常运行污染防治设施等 | 10万—100万 | 责令限制生产/停产整治+移送公安拘留5-15日；情节严重吊销许可证+责令停业关闭+拘留10-15日 |
| 第1109条 | 违规设置排污口 | 2万—10万（一般）/10-50万（严重） | 限期拆除，逾期强制拆除；饮用水水源保护区等特殊区域10-50万/严重50-100万 |
| 第1110条 | 未公开或不如实公开污染物排放信息等 | 2万—20万 | 拒不改正责令限制生产/停产整治+公告信息 |
| 第1111条 | 建设单位未将污染防治资金列入工程造价 | 2万—10万 | 拒不改正10-100万+停产整治 |

> **法典与条例的衔接**：法典施行后，《排污许可管理条例》中与法典不一致的条款将自动废止或修改。法典将"不正常运行污染防治设施"细分为"不属于逃避监管"（5-20万）和"属于逃避监管"（10-100万+拘留），解决了条例的模糊问题。

- **法典第1106条**：登记单位未依法填报排污信息→处**≤5万元罚款**

- **区分两大易混情形**：
  - 应领证但只登记→无证排污（条例第33条/法典第1102条，20万-100万）
