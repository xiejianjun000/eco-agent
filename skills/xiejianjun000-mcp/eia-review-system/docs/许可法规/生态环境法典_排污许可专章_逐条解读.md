## 二、排污许可专章位置

排污许可制度在法典中居于**污染防治编的统领性位置**：

```
第二编 污染防治
└── 第一分编 通则
    ├── 第一章 一般规定        （第148条—第159条，污染防治共性制度）
    └── 第二章 排污许可管理    （排污许可专章，法典确立排污许可制度的核心章节）
        └── 后续各分编（大气、水、海洋、土壤、固废、噪声等）在专章基础上分项细化
```

专章定位要点：
1. **通则属性**：排污许可管理置于"第一分编 通则"，表明其是贯穿大气、水、土壤、固废、噪声等各要素的基础性、通用性制度，而非某一要素的附属制度。
2. **上位法确认**：此前排污许可制度主要依托《排污许可管理条例》（行政法规）和《排污许可管理办法》（部门规章），法典施行后上升为**法律层级**的统领性制度。
3. **与法律责任衔接**：违法行为罚则集中于**第五编 法律责任和附则 → 第二章 法律责任分则 → 第三节 违反排污许可管理规定**（对应原条例第五章法律责任）。

## 三、逐条解读

### （一）法典与条例/办法的关系（上位法优先适用原则）

**层级结构：**

```
法律   《中华人民共和国生态环境法典》（全国人大，2026.8.15施行）   ← 最高位阶
  │
行政法规 《排污许可管理条例》（国务院令第736号，2021.3.1施行）
  │
部门规章 《排污许可管理办法》（生态环境部令第32号，2024.7.1施行）
```

**适用规则：**
1. **上位法优先**：法典施行后，排污许可管理事项优先适用法典。法典有规定的，以法典为准。
2. **配套继续有效**：条例、办法属于行政法规、部门规章，不在"不再保留"的10部法律之列，**与法典不抵触的条款继续有效**，作为法典的操作细则和配套实施规定。
3. **抵触自动失效**：条例、办法中任何与法典规定不一致的条款，自法典施行之日起不再适用（下位法不得抵触上位法）。
4. **引用衔接**：办法第1条原引用"大气、水、固体废物、土壤、噪声等专项污染防治法律"，该等单行法纳入法典后不再保留，办法相关引用由配套规定统一衔接至法典相应编章，但办法本身的程序性、操作性规定仍可作为执行依据。

**实务提示：** 技术审查与执法文书中，自2026.8.15起法律依据应表述为"依据《中华人民共和国生态环境法典》第×条及《排污许可管理条例》《排污许可管理办法》相关规定"，避免仅引用已被法典吸收的单行法（如原《大气污染防治法》第×条）。

### （二）法典新增内容（土壤、固废、噪声全要素许可）

法典对排污许可制度的核心拓展在于**全要素综合许可**：

**1. 全要素纳入（要素法定化）**
- 《排污许可管理办法》第6条已明确：生态环境主管部门对排污单位的大气污染物、水污染物、**工业固体废物、工业噪声**等污染物排放行为实行综合许可管理。
- 法典以**法律层级**确认综合许可制度，并将**土壤污染**要素明确纳入排污许可管理范畴，实现大气、水、土壤、固体废物、噪声等全要素"一证式"管理。
- 法典第150条将土壤污染与大气污染、水污染、海洋污染、固体废物污染、噪声污染并列，作为排放污染物单位应当防治的污染类型，为土壤要素纳入排污许可提供总则依据。

**2. 单行法条款统一上升为法典专章**
- 原分散于《大气污染防治法》第19—21条、《水污染防治法》第20—24条、《固体废物污染环境防治法》《噪声污染防治法》《土壤污染防治法》中的排污许可条款，统一整合、编订纂修为法典第二编第一分编第二章"排污许可管理"专章，消除多头立法、规范冲突。

**3. 概念体系统一**
- 法典全面删除"重点排污单位"等分散称谓，统一为"**排污许可重点管理**"概念，与分类管理名录（重点管理/简化管理/登记管理）一致，避免"国家重点监控单位""环境监管重点单位""重点排污单位"多概念混用。

**4. 与配套改革衔接**
- 落实《全面实行排污许可制实施方案》（生态环境部，2024）要求：到2025年全面完成工业噪声、工业固体废物排污许可管理，基本实现环境管理要素全覆盖；法典将这一改革成果固化为法律。

### （三）过渡期安排

**1. 过渡期界定**
- 法典2026年3月12日通过、2026年8月15日施行。自通过至施行为过渡准备期（约5个月）。

**2. 已核发许可证效力**
- 法典不溯及既往。2026年8月15日前依条例、办法核发的排污许可证，**继续有效**，无需重新申领；许可证载明事项与法典不抵触的，按原证执行。

**3. 新申请与变更**
- 过渡期内新申请、变更、延续，仍按条例、办法办理；
- 2026年8月15日后，按法典及配套规定办理，但审批平台、分类管理名录、申请与核发技术规范、自行监测技术指南等配套文件继续适用（不抵触部分）。

**4. 管理衔接**
- 生态环境主管部门应在过渡期内完成：执法依据更新、文书模板调整、人员培训、信息平台功能适配（全要素许可字段）。

### （四）对排污单位的主要新增义务（第二章 排污许可管理 逐条推定解读）

> 说明：以下条号（第160—175条）为按"第一章 一般规定止于第159条、第二章 排污许可管理紧接其后"逻辑推定，用于内部研究；对应《条例》《办法》条号均为现行有效条文，可直接引用。

**第160条【持证排污义务】**
依照法律规定实行排污许可管理的企业事业单位和其他生产经营者，应当依法申请取得排污许可证，并按照排污许可证的规定排放污染物；**未取得排污许可证的，不得排放污染物**。依法需要填报排污登记表的，应当在全国排污许可证管理信息平台进行排污登记。（对应《条例》第2条、《办法》第3条）

**第161条【分类管理】**
根据污染物产生量、排放量、对环境的影响程度等因素，对排污单位实行排污许可**重点管理、简化管理和排污登记管理**。实行重点管理、简化管理的具体范围，依照固定污染源排污许可分类管理名录执行。（对应《条例》第2条、《办法》第4条）

**第162条【综合许可与全要素管理】**（法典新增要点）
生态环境主管部门对排污单位的大气污染物、水污染物、土壤污染物、工业固体废物、工业噪声等污染物排放行为实行**综合许可管理**。法典将土壤污染要素纳入综合许可，实现多要素"一证式"管理。（对应《办法》第6条，法典拓展至土壤）

**第163条【申请条件】**
取得排污许可证应当具备下列条件：（一）依法取得建设项目环境影响报告书（表）批准文件，或者已办理环境影响登记表备案；（二）污染物排放符合污染物排放标准要求，重点污染物排放符合排污许可证申请与核发技术规范、环境影响报告书（表）批准文件、重点污染物排放总量控制要求；（三）采用的污染防治设施或者措施有能力达到许可排放浓度要求；（四）自行监测方案符合相关技术规范。（对应《条例》第7条、办法第24—30条）

**第164条【申请材料】**
排污许可证申请表应当包括：（一）排污单位名称、住所、法定代表人或者主要负责人、生产经营场所所在地、统一社会信用代码等信息；（二）建设项目环境影响报告书（表）批准文件或者环境影响登记表备案材料；（三）按照污染物排放口、主要生产设施或者车间、厂界申请的污染物排放种类、排放浓度和排放量，执行的污染物排放标准和重点污染物排放总量控制指标；（四）污染防治设施、污染物排放口位置和数量，污染物排放方式、排放去向、自行监测方案等信息；（五）主要生产设施、主要产品及产能、主要原辅材料、产生和排放污染物环节等信息。（对应《条例》第7条）

**第165条【审批与平台办理】**
排污许可证的申请、受理、审查、审批决定、变更、延续、注销、撤销、信息公开等应当通过全国排污许可证管理信息平台办理。国务院生态环境主管部门对排污单位及其生产设施、污染防治设施和排放口实行统一编码管理。（对应《条例》第4条、《办法》第7—8条、第13条）

**第166条【许可证内容】**
排污许可证应当载明基本信息、登记事项、许可事项。许可事项包括排放口和无组织排放源、污染物种类、许可排放浓度、许可排放量、排放方式、排放去向、自行监测要求、执行报告要求、信息公开要求等。（对应《条例》第11条、《办法》第21—23条）

**第167条【有效期与延续】**
排污许可证有效期为**5年**。排污单位需要继续排放污染物的，应当于许可证有效期届满**60日前（日历日）**向审批部门提出申请。（对应《条例》第13条、《办法》第24条；注意：此处为60日日历日，非"30个工作日"）

**第168条【变更与重新申请】**
污染物排放口位置或者数量、污染物排放方式或者排放去向、污染物种类等发生变化，应当变更排污许可证；新建、改建、扩建项目，生产经营场所变化，产能、工艺、原辅材料变化导致排污许可管理类别变化等，应当**重新申请**取得排污许可证。（对应《条例》、《办法》第34条、第38条）

**第169条【按证排污义务】**
持证排污单位应当按照排污许可证规定设置规范化污染物排放口并设置标志牌，控制大气污染物无组织排放，特殊时段按照许可证规定停止或者限制排放污染物。（对应《条例》第19条）

**第170条【自行监测】**
实行排污许可管理的排污单位应当按照排污许可证规定和有关监测规范，对所排放的污染物**自行监测，并保存原始监测记录**。重点排污单位应当安装污染物排放自动监测设备，与生态环境主管部门监控设备联网，保证监测设备正常运行。（对应《条例》第21条、办法及《排污单位自行监测技术指南 总则》HJ 819-2017）

**第171条【台账记录】**
排污单位应当建立环境管理台账记录制度，如实记录主要生产设施、污染防治设施运行情况以及污染物排放浓度、排放量等，环境管理台账记录保存期限**不少于5年**。（对应《条例》第22条、《办法》及《排污单位环境管理台账及排污许可证执行报告技术规范 总则》HJ 944-2018）

**第172条【执行报告】**
排污单位应当按照排污许可证规定的内容、频次和时间要求，编制并提交**排污许可证执行报告**（季度报告、年度报告）。执行报告中报告的污染物实际排放量，可作为年度生态环境统计、重点污染物排放总量考核、污染源排放清单编制等工作的依据。（对应《条例》第23条、《办法》第9条）

**第173条【信息公开】**
排污单位应当按照排污许可证规定，如实公开污染物排放种类、浓度、排放量，以及污染防治设施运行情况、自行监测数据等信息。（对应《条例》第24条）

**第174条【排污登记管理】**
依法实行排污登记管理的企业事业单位和其他生产经营者，应当在全国排污许可证管理信息平台填报排污信息；填报内容发生变化的，应当及时变更填报。（对应《条例》第43条）

**第175条【监督检查与法律责任衔接】**
生态环境主管部门依照法定职责对排污许可执行情况进行监督检查。违反排污许可管理规定的，依照法典第五编第二章第三节"违反排污许可管理规定"及有关法律责任的条款追究法律责任。（对应《条例》第33—45条，罚则上升为法典法律层级）

### （五）对执法人员的主要影响

**1. 法律依据位阶提升**
- 执法与处罚的直接依据由"条例/办法"升级为"法典专章 + 法典罚则"。现场检查笔录、责令改正通知书、处罚决定书的法律援引应优先写法典条号。

**2. 全要素"一证式"监管成为法定要求**
- 土壤、工业固废、工业噪声正式纳入排污许可综合监管。执法人员现场检查不得再局限于大气、水，应当核对许可证中载明的全要素排放口、许可限值、监测要求。

**3. 罚则集中且层级清晰**
- 原条例第五章（第33—45条）的罚则体系被法典第五编第二章第三节"违反排污许可管理规定"吸收并法定化。无证排污、超许可排放、逃避监管、无组织排放、排污口不符、自行监测/台账/执行报告违法等情形，均有对应法典罚则。

**4. 概念统一带来的文书调整**
- 原"重点排污单位"相关表述统一为"排污许可重点管理单位"，执法文书、检查清单、公开模板需同步更新。

**5. 衔接要求**
- 法典施行后，与法典吸收的单行法（大气法、水法、土壤法、固废法、噪声法等）中重复的排污许可条款不再单独引用，避免"法条引用落空"。
