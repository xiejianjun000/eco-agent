# 土壤分册 技术审查专项指南

> 编制依据：HJ 1209—2021《工业企业土壤和地下水自行监测技术指南（试行）》、环环评〔2026〕31号《关于全面实施新版排污许可证的通知》、《中华人民共和国土壤污染防治法》（2018）、《生态环境法典》（自2026年8月15日起施行）、GB 36600—2018《建设用地土壤污染风险管控标准（试行）》、GB/T 14848—2017《地下水质量标准》、HJ 164—2020《地下水环境监测技术规范》。
>
> 适用范围：被列入"土壤污染重点监管单位"名录的在产排污单位，其排污许可证"土壤（含地下水）分册"的技术审查与证后核查。本文件为技术参考，最终审查结论以生态环境主管部门依法作出的决定为准。

---

## 一、概述

### 1.1 法律依据

| 依据 | 条文 | 核心要求 |
|------|------|---------|
| 《土壤污染防治法》 | 第21条 | 土壤污染重点监管单位应当按规**开展土壤和地下水自行监测**，并**对监测数据的真实性、准确性负责**；监测结果报生态环境主管部门。 |
| 《土壤污染防治法》 | 第22条 | 重点监管单位应当建立**土壤污染隐患排查制度**，保证持续有效防止有毒有害物质渗漏、流失、扬散。 |
| 《生态环境法典》 | 污染防治相关编章（2026年8月15日起施行） | 以法典吸收并整合现行土壤、排污许可制度，明确**按环境要素分册许可**、土壤污染重点监管单位**自行监测与隐患排查**义务，与环环评〔2026〕31号衔接。具体条文以正式公布文本为准。 |
| 环环评〔2026〕31号 | 全文 | 新版排污许可证自2026年8月15日起施行，采用"**分要素许可 + 一口一表一码**"，其中设**土壤（含地下水）分册**，载明布点、指标、频次及隐患排查要求。 |
| HJ 1209—2021 | 全文 | 工业企业土壤和地下水自行监测技术依据，规定重点监测单元划分、布点、指标、频次及报告。 |

**审查定位**：土壤分册审查属于排污许可"证后管理"与"许可证质量核查"的交叉环节——既审查许可证分册**载明内容是否合规、完整、可操作**，也审查企业**实际执行是否与分册一致**。

### 1.2 适用范围

- **适用对象**：设区的市级生态环境主管部门确定并公布的"土壤污染重点监管单位"（书面告知或名录公告）。
- **典型纳入行业**：有色金属矿采选、有色金属冶炼、石油开采、石油加工、化工、焦化、电镀、制革、危险废物经营；年产生危险废物100吨以上单位；持有危险废物经营许可证单位。
- **状态**：在产企业（非关停、非退役场地）。退役/关停场地按建设用地风险管控另行适用，不在本分册审查范围。
- **不限定排污许可管理类别**：重点监管单位身份与排污许可"重点/简化/登记"管理类别**无直接对应关系**——简化管理单位被纳入重点监管名录后，同样须履行土壤分册义务。

### 1.3 HJ 1209—2021 核心内容摘要

| 章节 | 核心内容 |
|------|---------|
| 适用范围 | 土壤污染重点监管单位（在产企业）的土壤和地下水自行监测。 |
| 监测对象 | 土壤（表层/深层）+ 地下水（监测井）。 |
| 重点监测单元 | 依据企业平面布局与工艺，划分涉及**有毒有害物质**的场所/设施为"重点监测单元"，其余为"一般监测单元"。 |
| 布点原则 | 重点监测单元内布点应覆盖全部**重点场所**，并考虑潜在污染**迁移路径**（如地下水流向、厂区地势）。 |
| 监测指标 | **基本项目**（依据 GB 36600—2018 表1）+ **特征项目**（依据行业特征污染物、原辅料及工艺）。 |
| 监测频次 | 重点监测单元基础频次较高；一般监测单元基础频次较低（审查口径见本指南第2.3、3.3节）。 |
| 频次调整 | 连续监测达标可按规定**降低频次**；出现新改扩建、泄漏等情形应**加密监测**。 |
| 监测报告 | 监测结果纳入排污单位自行监测年度报告，并按要求公开、归档。 |

### 1.4 GB 36600—2018 关键限值（表1 基本项目）

GB 36600—2018 表1"基本项目"共**45项**（重金属和无机物 7项 + 挥发性有机物 27项 + 半挥发性有机物 11项）。在产企业土壤分册一般以**第二类用地**（工业用地）筛选值/管制值为管控基准。下表列出土壤分册审查最常用的核心限值（单位：mg/kg）：

| 污染物 | 第一类用地 筛选值 | 第二类用地 筛选值 | 第二类用地 管制值 | 备注 |
|--------|:---:|:---:|:---:|------|
| 砷 | 20 | 60 | 140 | 重金属 |
| 镉 | 20 | 65 | 172 | 重金属 |
| 铬（六价） | 3.0 | 5.7 | 78 | 重金属（电镀必查） |
| 铜 | 2000 | 18000 | 36000 | 重金属 |
| 铅 | 400 | 800 | 2500 | 重金属（铅蓄电池必查） |
| 汞 | 8 | 38 | 82 | 重金属 |
| 镍 | 150 | 900 | 2000 | 重金属 |
| 石油烃（C10-C40） | 826 | 4500 | 9000 | 所有企业基本项目 |

**审查用途**：
- 监测数据**低于筛选值** → 通常认为污染风险可接受，可按频次调整规则考虑降频。
- 监测数据**高于筛选值** → 应启动详细调查（HJ 25.1）、风险评估（HJ 25.3），确定是否需风险管控/修复。
- 第一类用地（居住、学校等敏感用地）筛选值更严，若厂区存在此类用地规划或周边敏感目标，应按第一类从严。

> 注：GB 36600 表1 另有 27项挥发性有机物（苯、甲苯、二甲苯、氯乙烯等）与 11项半挥发性有机物（苯并[a]芘、萘等），化工、石化、农药等行业特征评价时必须纳入。

### 1.5 GB/T 14848—2017 地下水分类指标

地下水质量按指标分为 Ⅰ~Ⅴ 类，分类依据为**感官性状及一般化学指标、微生物指标、毒理学指标**。

| 类别 | 适用用途 |
|------|---------|
| Ⅰ类 | 化学组分含量低，适用于各种用途 |
| Ⅱ类 | 化学组分含量低，适用于各种用途 |
| Ⅲ类 | 以人体健康基准值为依据，主要适用于**集中式生活饮用水水源及工农业用水** |
| Ⅳ类 | 以农业和工业用水要求为依据，除适用于农业和部分工业用水外，适当处理后可作生活饮用水 |
| Ⅴ类 | 不宜饮用，其他用水可根据使用目的选用 |

土壤分册地下水基础监测项限值（主要类别，单位：除标注外为 mg/L，总大肠菌群为 CFU/个·L）：

| 指标 | Ⅲ类 | Ⅳ类 | Ⅴ类 |
|------|:---:|:---:|:---:|
| pH（无量纲） | 6.5~8.5 | 5.5~9.0 | <5.5 或 >9.0 |
| 溶解性总固体 | ≤1000 | ≤2000 | >2000 |
| 耗氧量（COD_Mn） | ≤3.0 | ≤10.0 | >10.0 |
| 氨氮 | ≤0.50 | ≤1.50 | >1.50 |
| 硝酸盐氮 | ≤20.0 | ≤30.0 | >30.0 |
| 亚硝酸盐氮 | ≤1.00 | ≤4.30 | >4.30 |
| 总大肠菌群（CFU/个·L） | ≤3 | ≤100 | >100 |

**审查用途**：地下水监测数据按 GB/T 14848—2017 判定类别；若检出**超过Ⅳ类**（达Ⅴ类）或特征污染物超标，应启动超标响应程序（查、评、控，详见第2.5节）。

## 二、土壤监测方案审查要点

### 2.1 布点方案审查

#### 2.1.1 重点场所识别

审查第一步：调阅企业平面布置图、工艺流程图、原辅料清单，逐项核对以下**重点场所**是否均在布点范围内。任一遗漏即构成布点方案缺陷。

| 重点场所 | 审查关注点 |
|---------|-----------|
| 原料堆场（含散装原料） | 散装矿粉、煤、污泥等易扬散/渗滤物料堆存区 |
| 液体储存区（储罐/桶） | 原料油罐、酸碱罐、有机溶剂桶、中间罐区 |
| 生产车间（重点工艺区） | 涉及有毒有害物质的反应、电镀、涂镀、萃取等工序区 |
| 污水处理设施 | 调节池、曝气池、污泥浓缩/脱水区、排放渠 |
| 固体废物贮存/处置区 | 一般固废堆场、危废暂存库、污泥堆场 |
| 输送管廊 | 地下/架空输送有毒有害物料的管线及泵站 |
| 其他重点场所 | 依行业特征确定（如电镀企业的镀槽区、化工企业的中间罐区） |

> 审查动作：将许可证分册附图《土壤监测布点方案图》与企业**实际平面布局图**叠加比对，标注遗漏场所。

#### 2.1.2 布点数量要求（审查口径）

| 区域类型 | 布点密度 | 说明 |
|---------|---------|------|
| 重点场所 | **≥1点/500 m²** | 单一重点场所面积不足500 m²的，至少布设1点 |
| 一般防渗区 | **≥1点/2000 m²** | 一般监测单元按面积折算控制 |

> 依据 HJ 1209—2021 布点原则，上述密度为土壤分册审查控制下限；涉及高毒/高迁移性物质的场所应适当加密。

#### 2.1.3 布点位置合理性审查

- 点位须**覆盖潜在污染迁移路径**：重点核查地下水流向下游、厂区地势低洼处、雨污流汇处。
- 表层采样点应布在重点场所**使用功能区域内**，不得回避疑似污染重区。
- 深层点（如存在垂向迁移风险）应穿透包气带至潜水面附近。
- 点位坐标须与分册附图一致，现场可复核（GPS定位）。

**判定标准**：布点方案覆盖全部重点场所 + 符合密度下限 + 体现迁移路径控制 = 合格；任一不满足即要求补充布点。

### 2.2 监测指标审查

#### 2.2.1 基本项目（所有企业必填）

| 类别 | 指标 |
|------|------|
| 重金属类 | 砷、镉、六价铬、铜、铅、汞、镍（共7项基础重金属） |
| 基础指标 | pH |
| 有机类 | 石油烃（C10-C40） |

> 备注：依据《执法检查指南_更新版_含土壤分册》，部分审查口径将"锌"一并列入基本必查，形成**8项重金属监控组合**（砷、镉、铬、铜、铅、汞、镍、锌）。本指南以 GB 36600 表1 重金属和无机物7项为基础，行业确有锌污染风险的应增列锌。

#### 2.2.2 特征污染物审查（按行业）

| 行业 | 必查特征污染物 | 审查依据 |
|------|--------------|---------|
| 电镀 | 六价铬、镍、锌、总铬、氰化物 | 行业特征 + 原辅料 |
| 石油化工 | 石油烃、苯系物（苯、甲苯、二甲苯）、挥发性有机物 | 原辅料含烃类/芳烃 |
| 农药/化工 | 挥发性有机物（VOCs）、半挥发性有机物（SVOCs）、氰化物、特征中间体 | 工艺特征污染物 |
| 金属冶炼 | 重金属类（铅、镉、砷、汞、镍等，依矿种） | 矿种/产品特征 |
| 铅蓄电池 | 铅及铅化合物 | 行业特征（铅） |
| 加油站/储油库 | 石油烃（C10-C40）、苯系物 | 油品特征 |
| 制革 | 铬（六价/总铬）、硫化物 | 鞣制工艺特征 |
| 危险废物经营 | 依接收危废类别确定特征因子 | 经营许可证载明类别 |

**审查动作**：将企业《监测方案指标清单》与"许可证分册载明因子 + 行业特征污染物表"逐项比对，标记遗漏项。

#### 2.2.3 监测方法审查

- 必须使用**现行有效的国家标准（GB/T）或生态环境行业标准（HJ）**方法，禁止采用无标方法或废止方法。
- 常用方法示例：

| 指标 | 推荐方法标准 |
|------|------------|
| 砷、汞 | GB/T 22105（或 HJ 680 等） |
| 铅、镉 | GB/T 17141（或 HJ 766 等） |
| 铜、镍 | HJ 491（或 GB/T 17138） |
| 六价铬 | HJ 1082（或 GB/T 7467） |
| 石油烃（C10-C40） | HJ 1021（土壤）/ 相应地下水方法 |
| 挥发性有机物（VOCs） | HJ 605、HJ 642 等 |
| 半挥发性有机物（SVOCs） | HJ 643、HJ 783 等 |

- 审查要点：监测报告须注明**方法标准号**；方法标准已废止或不适用的，数据不予采信。

### 2.3 监测频次审查

| 区域类型 | 基础频次 | 调整规则 |
|---------|---------|---------|
| 重点场所 | **≥1次/年** | 连续3年监测结果均低于 GB 36600 筛选值，可依据 HJ 1209 第8.4条调整为 **≥1次/3年** |
| 一般防渗区 | **≥1次/年** | 同上，达标后可降频 |

**触发加密监测的情形**：
1. 新、改、扩建项目投入运行（新增污染隐患）；
2. 发生有毒有害物质泄漏、渗漏、流失、扬散事故；
3. 隐患排查发现新增隐患点或原有隐患加重；
4. 监测数据出现异常升高或检出超标；
5. 周边环境敏感目标新增或用地规划变更。

**审查动作**：核对《监测计划》载明频次是否满足下限；抽查历年监测报告时间戳，核算实际频次是否达标；查看是否有"连续3年达标"的降频依据文件。

## 三、地下水监测方案审查要点

### 3.1 监测井设置审查

#### 3.1.1 布设原则

- **上下游对照**：须设上游对照井（背景值）与下游监测井（监控扩散）。
- **重点区域覆盖**：下游井位应覆盖重点场所地下水流向的下游路径。
- **控制扩散**：井位应能反映污染羽的迁移范围。

#### 3.1.2 监测井数量

| 项目 | 要求 |
|------|------|
| 井数下限 | **≥3个** |
| 构成 | 上游对照井 **≥1个** + 下游监测井 **≥2个** |
| 位置 | 上游井位于厂区地下水流向来水方向；下游井位于重点场所下游 |

#### 3.1.3 监测井建设规范

- 建设、成井、采样执行 **HJ 164—2020《地下水环境监测技术规范》**。
- 审查要点：井管材质、滤水管位置、止水、井深、井号标牌；成井洗井与建井记录；采样前洗井（至水位、水温、电导率稳定）。
- 重点场所下游须有井控制；无上游对照井或下游井不足2个，直接判定不合格。

### 3.2 监测指标审查

#### 3.2.1 基础项（所有企业必填）

| 指标 | 审查依据 |
|------|---------|
| pH | GB/T 14848—2017 |
| 溶解性总固体 | GB/T 14848—2017 |
| 耗氧量（COD_Mn） | GB/T 14848—2017 |
| 氨氮 | GB/T 14848—2017 |
| 硝酸盐氮 | GB/T 14848—2017 |
| 亚硝酸盐氮 | GB/T 14848—2017 |
| 总大肠菌群 | GB/T 14848—2017 |

#### 3.2.2 特征污染物

- 参照**土壤特征污染物**（第2.2.2节行业表）确定，重点关注可迁移至地下水的因子（如重金属、石油烃、苯系物、硝酸盐等）。
- 铅蓄电池企业重点查铅；电镀企业重点查六价铬、镍；石化企业重点查石油烃、苯系物。

#### 3.2.3 执行标准

- 地下水质量判定执行 **GB/T 14848—2017**，按 Ⅲ类/Ⅳ类/Ⅴ类 分类。
- 特征污染物无 GB/T 14848 分类限值的，可参照 GB 36600、行业标准的地下水推导值或经论证的筛选值。

### 3.3 监测频次审查

| 项目 | 要求 |
|------|------|
| 频次 | **≥1次/半年**（即每年上、下半年各不少于1次） |
| 审查动作 | 核对监测计划 + 抽查历年报告时间（应每年≥2份） |

> 与土壤频次区别：地下水受补给/径流影响，须每半年1次以捕捉季节性变化；土壤可年度监测。审查时不得用"全年1次但分上下半年采样"凑数——须确认两次采样时间间隔合理且均在半年窗口内。

## 四、污染隐患排查审查要点

依据《土壤污染防治法》第22条，重点监管单位应建立隐患排查制度。

| 审查项 | 要求 | 审查动作 |
|--------|------|---------|
| 排查频次 | **≥1次/年** | 查年度排查计划与实施记录 |
| 隐患台账内容 | 须含：**隐患位置、隐患类型、整改措施、整改时限、责任人员** | 逐项核对台账字段完整性 |
| 台账保存 | **≥5年** | 核验台账起止年限与归档 |
| 整改闭环 | 发现隐患→整改通知→整改措施→整改完成→验收，形成闭环 | 查隐患整改通知单 + 整改前后对比 + 验收记录 |

**隐患类型示例**：防渗层破损、储罐腐蚀渗漏、管道阀门滴漏、危废库"三防"缺陷、雨污分流失效、标识缺失。

**审查判定**：无隐患排查制度 / 年度未排查 / 台账字段缺失 / 无整改闭环 = 不合格，要求限期建立或补做。

## 五、常见问题与典型案例

### 5.1 常见问题

| 问题 | 表现 | 处理 |
|------|------|------|
| 问题1：企业未被告知为"重点监管单位"，土壤分册空白 | 许可证土壤分册无任何监测/排查要求，企业称"不知道是重点监管单位" | 核实告知程序：调阅设区的市级生态环境部门书面告知书或名录公告；身份以书面告知/名录为准，不以企业自述。属重点监管单位的，分册空白直接构成《土壤污染防治法》第21条违法，应补充分册并补测。 |
| 问题2：布点方案未覆盖全部重点场所 | 漏危废库、罐区或污水设施中的某一类重点场所 | 补充布点：将遗漏场所纳入布点方案，按密度下限增设点位，重新出具布点图与监测报告。 |
| 问题3：监测指标遗漏特征污染物 | 电镀未测六价铬、铅蓄电池未测铅、化工漏特征有机物 | 补充检测：按行业特征污染物表增列因子，委托具备 CMA 资质单位补测并归档。 |
| 问题4：监测频次不足（实际1次/年但分上下半年） | 土壤/地下水实际未按下限频次开展，或全年仅1次却标注"上下半年" | 合理解释后调整监测计划：若确因客观原因可说明；否则按频次下限重新制定监测计划，补测缺失频次，严禁以"分上下半年"凑数替代达标频次。 |

### 5.2 典型案例：某电镀企业土壤分册遗漏六价铬指标案

| 要素 | 内容 |
|------|------|
| 地区 | 浙江 |
| 行业 | 电镀（重点管理） |
| 违法情节 | 企业属土壤污染重点监管单位。技术审查发现其土壤监测方案及历年监测报告**未包含行业特征污染物"六价铬"和"镍"**，监测因子不完整，与许可证土壤分册载明要求不符。 |
| 证据 | ① 监测方案指标清单（缺六价铬）；② 历年监测报告（无六价铬数据）；③ 许可证土壤分册载明要求（应含六价铬等特征污染物）；④ 重点监管单位书面告知书。 |
| 定性依据 | 《土壤污染防治法》第21条第1款（重点监管单位应按规定开展土壤和地下水自行监测）；《排污许可管理条例》第36条（自行监测不符合规定）。 |
| 处罚结果 | 责令限期改正（补充监测六价铬、镍等特征因子），并处罚款。 |
| 整改要求 | 重新编制土壤监测方案 → 增列六价铬、镍等特征因子 → 委托 CMA 资质单位补测 → 数据归档备查 → 后续按方案执行。 |
| 审查要点 | 电镀行业特征污染物必须含六价铬、总铬、镍、氰化物；审查时须将监测方案指标与许可证分册、行业指南**逐项比对**，不得仅看"基本项目"是否齐全。"特征因子遗漏"在土壤类问题中占比约35%，为最高频错误。 |

> 关联案例：某化工企业土壤分册空白案（未开展任何土壤/地下水监测）、某造纸企业布点数量不符案（方案8点实际仅3点）、某铅蓄电池企业地下水超标未处理案（铅超 GB/T 14848 Ⅳ类未启动调查）——详见《典型案例库_更新版_新增土壤违法案例.md》与《执法检查指南_更新版_含土壤分册.md》。

### 6.6 HJ 1478—2026 嵌入式审查要点（本周新增，2026年7月19日更新）

> **来源**：HJ 1478—2026《重点监管单位土壤和地下水污染隐患排查整治技术指南》（2026年6月发布，替代2021年试行版）

#### 6.6.1 三大核心修改（与试行版对比）

| 修改项 | 试行版问题 | HJ 1478—2026新规 | 审查影响 |
|-------|---------|----------------|---------|
| **排查范围精准化** | 地上+隐蔽性设施均纳入，企业负担重 | 精准聚焦**隐蔽性设施**（埋地/接地储罐、池体、管道）及重点场所防渗阻隔设施；排查数量平均减少约30% | 重点场所和重点设施数量可相应核实是否合理减少 |
| **渗漏检测强化** | 以目视检查为主，难以发现隐蔽性隐患 | 首次明确**渗漏检测**的适用条件和参考方法（技术成熟、经济可接受） | 须核对隐患排查台账是否包含渗漏检测记录（高风险设施） |
| **138种隐患情形** | 隐患判定标准不明确 | 明确**14类重点场所+11类重点设施设备=138种具体隐患情形**，配套整改要点 | 企业"照单排查"→审查时可要求企业提供138种情形的自查记录 |

#### 6.6.2 与许可证核发的嵌入式衔接

| 场景 | 许可证核发审查动作 |
|------|------------------|
| **发证前核查** | 确认企业是否为重点监管单位（书面告知/名录公告）；若是，须核对是否已建立隐患排查整治制度 |
| **土壤分册载明** | 土壤分册须载明隐患排查开展情况及台账保存要求 |
| **年度执行报告** | 土壤要素章节须填写隐患排查年度开展情况；核查时查台账记录 |
| **执法检查** | 查：隐患排查制度文件+排查记录+隐患整改记录（保存≥5年）；按138种情形逐项核对 |

#### 6.6.3 审查专家必备速查

- **法律依据**：法典第414条（推定条号，以正式文本为准）——土壤污染重点监管单位应建立隐患排查整治制度
- **保存期限**：隐患排查台账保存期限不少于5年（与台账总要求一致）
- **排查频次**：隐患排查≥1次/年
- **发现隐患**：须按138种隐患情形对应的整改要点实施，验收记录存档

## 七、专项违法案例（本周更新，2026年7月24日）

### 7.1 某化工企业土壤分册空白案

| 项目 | 内容 |
|------|------|
| **企业类型** | 石油加工+化工行业 |
| **触发条件** | 被设区市级生态环境部门列入"土壤污染重点监管单位"名录并书面告知 |
| **违法事实** | 新版许可证土壤（含地下水）分册为空白，未记载任何土壤监测/地下水监测井/隐患排查要求 |
| **定性依据** | 《土壤污染防治法》第21条（重点监管单位未制定/实施自行监测方案） |
| **处罚依据** | 《土壤污染防治法》第86条第1款第1项（责令限期改正+罚款） |
| **审查要点** | **重点监管单位身份以书面告知/名录为准**，不以企业自述；土壤分册空白属明显违法，直接立案 |

### 7.2 某电镀企业土壤监测指标遗漏六价铬案

| 项目 | 内容 |
|------|------|
| **企业类型** | 电镀行业（属土壤污染重点监管单位） |
| **违法事实** | 土壤监测方案未将行业特征污染物"**六价铬**"纳入监测指标；历年监测报告均无六价铬数据 |
| **定性依据** | 许可证土壤分册载明要求+行业监测技术指南；自行监测方案不完整 |
| **处罚依据** | 《排污许可管理条例》第36条（未按许可证规定提交/保存监测数据） |
| **裁量** | 责令限期改正；处2万元以上20万元以下罚款 |
| **审查要点** | 电镀行业特征污染物必须含**六价铬、总铬、镍、氰化物**等；审查时将监测方案指标与许可证+行业指南逐项比对 |
