# 排污许可典型案例库（更新版）

> 收录说明：本案例库按违法行为类型分类，涵盖土壤、固废、噪声三大领域近年典型案例，供排污许可执法检查与技术审查参考使用。案例要素包括：地区、行业、管理类别、违法情节、证据、定性依据、法律适用、处罚结果、整改要求。

## 一、土壤污染违法典型案例

### 案例1：某电镀企业土壤自行监测指标遗漏案

| 要素 | 内容 |
|------|------|
| **地区** | 浙江 |
| **行业** | 电镀（重点管理） |
| **管理类别** | 重点管理 |
| **违法情节** | 土壤分册监测方案未包含特征污染物"六价铬"和"镍"，监测因子不完整 |
| **证据** | 监测报告（无六价铬数据）+ 排污许可证载明的土壤监测要求 |
| **定性依据** | 《土壤污染防治法》第21条第1款（重点监管单位应当按照规定开展土壤和地下水自行监测） |
| **法律适用** | 《土壤污染防治法》第86条 |
| **处罚结果** | 责令限期改正；罚款人民币X万元 |
| **整改要求** | 重新编制土壤监测方案，补充监测六价铬、镍等特征因子，存档备查 |

**技术要点**：电镀行业土壤监测的特征因子必须涵盖六价铬、镍、镉等重金属，不得遗漏。许可证分册中载明的因子与自行监测方案必须一致。

### 案例2：某化工企业未开展土壤监测案

| 要素 | 内容 |
|------|------|
| **地区** | 江苏 |
| **行业** | 化工（重点管理） |
| **管理类别** | 重点管理 |
| **违法情节** | 企业属于土壤污染重点监管单位，但许可证有效期内从未开展任何土壤或地下水监测 |
| **证据** | 重点监管单位告知书（书面）+ 土壤监测空白台账 |
| **定性依据** | 《土壤污染防治法》第21条第2款（重点监管单位应当对监测数据的真实性和准确性负责） |
| **法律适用** | 《土壤污染防治法》第86条 |
| **处罚结果** | 罚款；责令限期改正（90日内完成首次监测） |
| **整改要求** | 制定监测方案 → 委托具备CMA资质的监测单位 → 开展土壤和地下水监测 → 台账存档 |

**技术要点**：重点监管单位告知书是证明企业负有土壤监测义务的关键证据，必须书面留存。监测频次原则上不少于每年1次。

### 案例3：某铅蓄电池企业地下水超标未处理案

| 要素 | 内容 |
|------|------|
| **地区** | 广东 |
| **行业** | 铅蓄电池（重点管理） |
| **管理类别** | 重点管理 |
| **违法情节** | 地下水监测井检出铅浓度超过GB/T 14848 Ⅳ类标准，企业未启动详细调查或风险管控 |
| **证据** | 监测报告（铅超标数据）+ 企业未响应记录 |
| **定性依据** | 《土壤污染防治法》第21条（未按照要求采取风险管控措施） |
| **法律适用** | 《土壤污染防治法》第92条 |
| **处罚结果** | 责令限期采取风险管控措施；罚款 |
| **整改要求** | 启动土壤与地下水详细调查 → 风险评估 → 编制风险管控/修复方案 → 实施管控措施 |

**技术要点**：地下水超标不等于必然需要修复，但必须启动调查程序。铅蓄电池行业特征污染物为铅，须重点关注。

### 案例4：某造纸企业土壤分册与实际不符案

| 要素 | 内容 |
|------|------|
| **地区** | 山东 |
| **行业** | 造纸（重点管理） |
| **管理类别** | 重点管理 |
| **违法情节** | 土壤分册列明的布点方案为8个点位，实际监测仅覆盖3个点位，布点数量严重不足 |
| **证据** | 许可证分册附件布点方案文件 + 实际监测报告（仅3个点） |
| **定性依据** | 《排污许可管理办法》（2024年）第58条（未按许可证规定制定或执行监测方案） |
| **处罚结果** | 责令限期改正；通报批评 |
| **整改要求** | 重新开展土壤监测，覆盖许可证分册规定的全部8个点位，出具完整监测报告并存档 |

**技术要点**：监测方案中布点数量、点位坐标由排污许可证分册载明，企业不得擅自减少。实际执行必须与许可证一致。

| **管理类别** | 简化管理 |

**技术要点**：加油站虽为简化管理，但被纳入重点监管单位后须履行隐患排查义务，与排污许可管理类别无直接关联。

## 二、固废违法典型案例

### 案例6：某电镀企业危险废物台账不规范案

| 要素 | 内容 |
|------|------|
| **地区** | 河北 |
| **行业** | 电镀（重点管理） |
| **管理类别** | 重点管理 |
| **违法情节** | 危废台账记录数量与危废转移联单不一致（台账记录10吨，联单8吨，相差2吨） |
| **证据** | 危废台账 + 危废转移联单 + 危废库房盘点记录 |
| **定性依据** | 《固体废物污染环境防治法》第78条（危险废物台账保存期限不得少于5年，且须与实际情况一致） |
| **处罚结果** | 责令限期改正；罚款 |
| **整改要求** | 核实危废实际产生量/处置量差异原因，更新台账记录，确保台账与联单一致，存档备查 |

**技术要点**：危废台账与转移联单数量必须一一对应。电镀行业危废种类主要包括含铬污泥、含镍废物、酸碱废液等。

### 案例7：某化工企业危废标签不规范案

| 要素 | 内容 |
|------|------|
| **地区** | 福建 |
| **行业** | 化工（重点管理） |
| **管理类别** | 重点管理 |
| **违法情节** | 危废贮存仓库内部分桶装废物未张贴危废标签，标签缺失 |
| **证据** | 现场检查照片（桶身无危废标签）+ 现场笔录 |
| **定性依据** | 《固体废物污染环境防治法》第77条（危险废物须规范包装并张贴危废标签） |
| **处罚结果** | 责令限期改正；罚款 |
| **整改要求** | 立即张贴危废标签（注明废物名称、代码、产生日期、危害特性），逾期未改正加重处罚 |

**技术要点**：危废标签须包含废物名称、废物代码、产生单位、产生日期、危险特性五项基本要素，缺失任何一项均为不规范。

## 三、噪声违法典型案例

### 案例8：某水泥企业夜间噪声超标案

| 要素 | 内容 |
|------|------|
| **地区** | 湖南 |
| **行业** | 水泥（重点管理） |
| **管理类别** | 重点管理 |
| **违法情节** | 夜间（23:00）厂界噪声测量值为65 dB(A)，超过GB 12348 3类功能区夜间标准60 dB(A)，超标5 dB(A) |
| **证据** | 监测报告（连续3天夜间监测数据）+ 测量现场记录（时间、地点、气象条件） |
| **定性依据** | 《噪声污染防治法》第36条（排放工业噪声应当符合国家规定标准） |
| **处罚结果** | 责令限期治理；罚款 |
| **整改要求** | 制定噪声治理方案（如隔声、消声、减振措施），限期完成治理后复测达标 |

**技术要点**：水泥企业噪声源主要包括磨机、风机、破碎机等。GB 12348—2008 3类区夜间标准为60 dB(A)，须连续监测2天。

### 案例9：某铸造企业噪声监测记录造假案

| 要素 | 内容 |
|------|------|
| **地区** | 河南 |
| **行业** | 铸造（简化管理） |
| **管理类别** | 简化管理 |
| **违法情节** | 企业噪声监测记录显示每季度1次，但实际监测记录缺失，且台账中季度记录数据雷同，涉嫌伪造监测数据 |
| **证据** | 许可证要求的季度监测报告 + 台账中季度记录数据高度雷同 + 企业陈述 |
| **定性依据** | 《排污许可管理条例》第39条（未建立环境管理台账记录制度或台账记录弄虚作假） |
| **法律适用** | 《排污许可管理条例》第39条 |
| **处罚结果** | 罚款 + 没收违法所得 + 移送公安机关（情节严重） |
| **整改要求** | 重新委托具备资质监测单位开展监测，规范记录监测数据，建立完整台账 |

**技术要点**：台账记录弄虚作假属于严重违法行为，可能面临刑事移送。数据须真实记录，禁止伪造或复制。

## 四、典型案例分析总结

### 4.1 土壤违法的新特点

1. **土壤分册成为执法重点**：排污许可证格式更新后，越来越多的许可证附有土壤与地下水监测分册，执法检查已将其纳入常规检查项。
2. **重点监管单位认定扩大**：不仅重点管理企业，简化管理单位被纳入重点监管名单后同样须履行土壤义务。
3. **地下水超标响应机制**：企业须建立超标响应机制，发现超标不得置之不理，须启动调查→评估→管控流程。

### 4.2 证据固定要点

| 证据类型 | 说明 |
|---------|------|
| 重点监管单位告知书 | 证明企业负有土壤监测义务的**必要书面证据**，不得缺失 |
| 监测方案 | 须与许可证分册一致，布点+指标+频次三要素齐全 |
| 监测报告 | 须有CMA资质章，监测因子须覆盖许可证要求 |
| 现场照片/视频 | 危废标签、贮存状态、现场检查过程 |
| 台账与联单 | 数量须一致，跨年度逻辑自洽 |

### 4.3 监测方案合规性三要素

```
监测方案合规性 = 布点规范 + 指标完整 + 频次达标
```

- **布点规范**：点位数量、坐标须与许可证分册一致，不得擅自减少
- **指标完整**：特征污染物不得遗漏（电镀→六价铬、镍；铅蓄电池→铅；化工→特征有机物）
- **频次达标**：原则上每年不少于1次，重点监管单位不得空白

### 4.4 常见错误分布

| 排名 | 错误类型 | 占比（参考） | 典型案例 |
|------|---------|------------|---------|
| 1 | 监测指标遗漏 | 约35% | 案例1（特征因子遗漏） |
| 2 | 监测频次不足/空白 | 约30% | 案例2（未开展监测） |
| 3 | 布点数量不符 | 约20% | 案例4（8点仅做3点） |
| 4 | 台账记录不规范 | 约10% | 案例6、7（危废台账/标签） |
| 5 | 数据弄虚作假 | 约5% | 案例9（噪声记录造假） |

### 4.5 执法检查建议清单

**土壤分册检查**：
- [ ] 是否为重点监管单位（查告知书）
- [ ] 是否制定土壤监测方案（查方案文件）
- [ ] 监测指标是否覆盖特征污染物（对照许可证分册）
- [ ] 布点数量是否与方案一致（查监测报告）
- [ ] 监测频次是否达标（查监测时间记录）
- [ ] 超标数据是否启动响应程序（查详细调查报告）

**固废管理检查**：
- [ ] 危废台账是否建立（查台账记录）
- [ ] 台账与转移联单数量是否一致
- [ ] 危废标签是否完整张贴
- [ ] 危废库房是否规范贮存

**噪声检查**：
- [ ] 监测频次是否达标（查监测报告）
- [ ] 监测数据是否真实（对比台账记录一致性）
- [ ] 超标数据是否超标治理
