# 环评审批流程与申请要件清单

> 环评审批（行政审批）的程序、要件与时限。供审批要件核查、企业办事引导使用。审批准入的实质判断以生态环境部门为准。

---

## 一、环评审批基本流程

```
1. 项目立项/备案（发改部门）
   ↓
2. 委托编制环评文件（报告书/报告表）
   ↓
3. 报告书类：公众参与（信息公开+意见征询，部令第4号）
   ↓
4. 向有审批权的生态环境部门提交申请
   ↓
5. 受理（材料齐全、符合法定形式）
   ↓
6. 技术评估/技术审查（报告书一般组织专家技术评估）
   ↓
7. 审批决定（批准/不予批准）
   ↓
8. 出具环评批复文件
   ↓
9. "三同时"建设 → 竣工环境保护验收（自主验收）
   ↓
10. 申请排污许可证（衔接）
```

---

## 二、申请要件清单

### 2.1 报告书类审批申请材料
- [ ] 建设项目环境影响报告书（正式文本）
- [ ] 建设项目环评审批申请文件
- [ ] 公众参与说明（报告书类必需）
- [ ] 项目立项/备案证明（如适用）
- [ ] 选址意见/用地预审（如适用）
- [ ] 其他依审批部门要求的材料

### 2.2 报告表类审批申请材料
- [ ] 建设项目环境影响报告表
- [ ] 审批申请文件
- [ ] 告知承诺制的：告知承诺书（适用时）
- [ ] 立项/备案证明（如适用）

### 2.3 登记表类
- 网上备案，无需审批，填报《建设项目环境影响登记表》

## 三、审批时限（法定，具体以受理告知为准）

| 环评文件类型 | 一般审批时限 |
|-------------|-------------|
| 报告书 | 自受理之日起法定工作日内（含技术评估时间另计） |
| 报告表 | 自受理之日起法定工作日内 |
| 告知承诺制 | 即时/大幅压缩 |

> 具体时限以各地政务服务事项标准和受理告知书为准。

---

## 四、审批要件核查要点

| 核查项 | 要点 |
|--------|------|
| 审批权限 | 项目是否属于本级审批权限，防止越级 |
| 材料齐全性 | 对照要件清单，缺项不予受理 |
| 公众参与 | 报告书类公参程序是否合规（信息公开、意见征询、说明） |
| "三线一单"符合性 | 是否符合生态环境准入清单 |
| 产业政策符合性 | 是否属于限制/淘汰类 |
| 选址合规性 | 是否触碰生态保护红线、饮用水源保护区等 |
| 总量指标来源 | 新增总量是否有来源（区域削减/替代） |

---

## 五、不予批准的情形（准入否决）

1. 选址、布局不符合环境功能区划、"三线一单"、相关规划
2. 属国家明令淘汰、禁止的落后工艺、设备、产品
3. 依法应征求意见的重大项目未征求或未采纳
4. 环境质量不能满足环境功能区要求且无有效削减措施
5. 建设可能造成重大环境影响、编制不符合要求且拒不修改
6. 直接关系公共利益的重大项目，公众有重大意见且未采纳合理意见

---

## 六、环评审批 → 排污许可衔接节点

| 节点 | 衔接要求 |
|------|---------|
| 环评批复取得 | 作为排污许可申请前置要件 |
| "三同时"落实 | 治理措施须与排污许可载明一致 |
| 竣工环保验收 | 验收合格情况反映治理设施有效性 |
| 排污许可申请 | 提交环评批复，按两证衔接指南逐项核对 |

> 提示：本模块处理审批**要件与程序**的核查；审批**准入的实质合规性判断**（选址、产业政策、区域平衡）属生态环境部门环评审批职权，技术审查意见仅供参考。
