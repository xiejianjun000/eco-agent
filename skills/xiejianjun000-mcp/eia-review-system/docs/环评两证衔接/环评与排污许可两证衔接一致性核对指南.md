# 环评与排污许可"两证衔接"一致性核对指南

> 主线文件。环评批复是排污许可申请的**前置要件**（《排污许可管理条例》第七条），两证不衔接是排污许可技术审查中最高频的否决原因之一。本指南给出6大咬合点的逐项核对方法、常见不一致情形及处置规则。

---

## 一、政策依据

| 文件 | 关键要求 |
|------|---------|
| 《排污许可管理条例》（国令第736号）第七条 | 申请排污许可证应当提交与污染物排放有关的环评文件审批意见 |
| 《环境影响评价法》（2018修正）第二十五条 | 未依法经审批的建设项目不得开工建设 |
| 《关于做好环境影响评价制度与排污许可制衔接相关工作的通知》（环环评〔2017〕84号） | 明确两证衔接的核心内容：排放口、污染因子、排放限值、总量、措施 |
| 《固定污染源排污许可分类管理名录（2019年版）》 | 与《建设项目环境影响评价分类管理名录（2021年版）》分类逻辑需协调判断 |
| 《排污许可证申请与核发技术规范 总则》（HJ 942-2018） | 载明排放限值、总量等不得突破环评及批复要求 |

**核心逻辑**：环评是"事前预测评估+准入"，排污许可是"事中事后管理+许可排放量"。排污许可载明的内容**不得突破**环评及其批复的要求，两者严于取严。

---

## 二、6大咬合点逐项核对表

### 咬合点1：产污环节 / 生产工艺

| 核对项 | 环评文件对应位置 | 排污许可对应位置 | 一致性判断 |
|--------|----------------|-----------------|-----------|
| 主要生产设施 | 工程分析章节、设备清单 | 排污许可证正本"主要生产设施" | 设施名称、数量、规模一致 |
| 生产工艺 | 工艺流程图及产污节点分析 | 申请表"生产工艺流程" | 工序、产污节点一致 |
| 原辅料 | 原辅材料及燃料表 | 申请表"原辅料及燃料" | 种类、年用量匹配 |

**不一致情形**：企业实际扩产、增加工序、更换原辅料，但未重新报批环评 → 排污许可**不得**按现状核发，应先补办环评变更/重新报批。

### 咬合点2：污染因子

| 核对项 | 要点 |
|--------|------|
| 废气因子 | 环评识别的特征因子（如VOCs、苯系物、重金属）必须全部纳入排污许可，不得遗漏 |
| 废水因子 | 环评确定的一类污染物（总铬、六价铬、总镍、总镉、总砷、总铅、总汞等）+ 二类污染物均须载明 |
| 因子一致性 | 排污许可因子 ≥ 环评因子 ∩ 排放标准因子 ∩ 技术规范因子，取并集 |

**高频问题**：环评已识别特征因子（如印染的苯胺类、电镀的六价铬），但排污许可申报时遗漏 → 直接否决项。

### 咬合点3：排放口（数量、位置、编号、排放方式、去向）

| 核对项 | 环评 | 排污许可 | 判断 |
|--------|------|---------|------|
| 排放口数量 | 环评预测的有组织排放口 | 证载排放口 | 数量一致，不得漏报 |
| 排放口位置/编号 | 环评平面布置图 | "一口一表一码"编码 | 位置对应，新版按DW/DA编码 |
| 排放方式 | 连续/间歇、有组织/无组织 | 证载排放规律 | 一致 |
| 排放去向 | 直接排放/间接排放（进污水厂/水体） | 证载受纳水体或污水厂 | 一致，间接排放须有纳管协议 |

**注意**：新版排污许可证（环环评〔2026〕31号）实行"一口一表一码"，排放口编码须与环评平面图可追溯对应。

### 咬合点4：排放限值（浓度限值）

| 判断规则 | 说明 |
|---------|------|
| 从严原则 | 环评批复限值、国家排放标准、地方排放标准、总量控制要求中**取最严值** |
| 环评加严 | 若环评批复要求严于排放标准（如敏感区域要求），排污许可须执行环评加严值 |
| 不得突破 | 排污许可载明浓度限值**不得宽于**环评批复限值 |

**高频问题**：环评批复要求COD执行50mg/L（严于标准的100mg/L），但排污许可按标准填100mg/L → 不一致，须改为50mg/L。

### 咬合点5：总量指标

| 核对项 | 要点 |
|--------|------|
| 总量来源 | 环评批复的总量控制指标是排污许可总量的核心来源之一 |
| 总量核算 | 排污许可许可排放量核算结果**不得超过**环评批复总量 |
| 指标种类 | 主要污染物（COD、氨氮、SO₂、NOx、VOCs等）总量须与环评批复对应 |
| 削减替代 | 新改扩建项目环评要求的"以新带老""区域削减"须在总量中体现 |

**高频问题**：环评批复COD总量20t/a，排污许可核算出25t/a → 必须核减至不超过环评批复值，或先办理总量指标来源证明。

### 咬合点6：污染治理措施 + 自行监测要求

| 核对项 | 要点 |
|--------|------|
| 治理设施 | 环评要求的治理工艺（如RTO、SCR、生化+深度处理）须在排污许可中载明并落实 |
| 措施规模 | 治理设施处理能力与环评一致 |
| 监测要求 | 环评"三同时"及批复要求的自动监测/手工监测，须纳入排污许可自行监测方案 |
| 环境管理要求 | 环评批复的特殊管理要求（如错峰生产、重污染天气应急）须体现 |

## 三、两证衔接核对流程（技术审查用）

```
第一步：调取环评文件及批复
  ↓
第二步：逐项比对6大咬合点（用本指南第二节核对表）
  ↓
第三步：识别不一致项，分类判断
  ├── 排污许可宽于环评 → 收严至环评要求
  ├── 排污许可漏项（因子/排放口/措施）→ 补充
  ├── 实际情况超出环评 → 退回，先办环评变更/重新报批
  └── 环评未涵盖（如环评前已建）→ 按"衔接特殊情形"处理
  ↓
第四步：出具衔接一致性核对意见
```

## 四、常见不一致情形与处置规则

| 序号 | 不一致情形 | 处置规则 |
|------|-----------|---------|
| 1 | 排污许可污染因子少于环评识别因子 | 补充遗漏因子，否则否决 |
| 2 | 排污许可排放口数量少于环评 | 补充排放口，核查是否存在私设/漏报 |
| 3 | 排污许可浓度限值宽于环评批复 | 收严至环评批复值 |
| 4 | 排污许可总量超环评批复 | 核减至环评批复值，或补总量来源 |
| 5 | 实际生产规模/工艺超出环评 | 退回，先办环评变更或重新报批环评 |
| 6 | 治理措施与环评不符（降级/未建） | 退回整改，落实环评"三同时" |
| 7 | 环评为"未批先建"违法项目 | 排污许可不得核发，先依法处理环评违法 |
| 8 | 老项目无环评（环评制度前已建） | 按《关于加强固定污染源氮磁污染防治...》等衔接政策，据实申报，不因无环评拒发但须说明 |

## 五、衔接特殊情形

### 5.1 环评制度实施前已建成的老项目
- 依据：环境保护部关于"无环评手续但符合产业政策"项目的衔接处理精神
- 处置：可据实核发排污许可，但不得以排污许可替代环评手续豁免；涉及"未批先建"的按《环境影响评价法》第三十一条另行处理时效已过的历史遗留项目

### 5.2 环评"未批先建"项目
- 排污许可**不得核发**
- 先由生态环境部门依据《环境影响评价法》第三十一条查处（罚款+责令停止建设/恢复原状），补办环评手续后方可申请排污许可

### 5.3 重大变动 vs 一般变动
- 依据：《污染影响类建设项目重大变动清单（试行）》（环办环评函〔2020〕688号）
- 属重大变动：须重新报批环评 → 排污许可须待新环评批复后办理
- 非重大变动：纳入竣工环保验收，排污许可可衔接办理

### 5.4 环评告知承诺制 / 登记表备案项目
- 登记表类：一般对应排污登记管理，不核发排污许可
- 报告表告知承诺制：批复即时取得，衔接逻辑不变

## 六、两证衔接核对清单（可直接用于现场/技术审查）

- [ ] 环评文件及批复是否齐全、在有效期内
- [ ] 环评审批级别与项目是否匹配（越级审批无效）
- [ ] 生产设施、工艺、原辅料与环评一致
- [ ] 污染因子无遗漏（对照环评识别的特征因子）
- [ ] 排放口数量、位置、编号、方式、去向一致
- [ ] 浓度限值不宽于环评批复（从严取值）
- [ ] 许可总量不超过环评批复总量
- [ ] 治理措施与环评"三同时"一致并已落实
- [ ] 自行监测要求涵盖环评批复要求
- [ ] 环评批复特殊管理要求已体现（错峰/应急等）
- [ ] 无"未批先建""重大变动未重新报批"等违法情形

---

## 七、红线提醒

1. **排污许可不得突破环评** —— 严于取严，不得放宽。
2. **环评违法项目不得核发排污许可** —— 未批先建、越级审批、重大变动未报批的先处理环评问题。
3. **技术审查意见 ≠ 审批决定** —— 衔接核对意见供核发参考，最终以生态环境部门决定为准。
4. **不做环评审批本身的准入判断** —— 本模块处理的是环评与排污许可的衔接一致性，环评审批的准入符合性（选址、产业政策、总量区域平衡）以生态环境部门环评审批环节为准。
