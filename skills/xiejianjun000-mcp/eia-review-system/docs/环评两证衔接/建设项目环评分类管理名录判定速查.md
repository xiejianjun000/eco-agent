# 建设项目环境影响评价分类管理名录（2021年版）判定速查

> 判定建设项目应编制报告书 / 报告表 / 登记表，是环评审批的第一步，也直接决定后续排污许可管理类别的协调判断。具体行业条目以《建设项目环境影响评价分类管理名录（2021年版）》原文为准。

---

## 一、分类逻辑

| 环评文件类型 | 适用情形（原则） | 管理方式 |
|-------------|----------------|---------|
| 环境影响报告书 | 可能造成重大环境影响、涉及环境敏感区、污染重的项目 | 审批制 |
| 环境影响报告表 | 可能造成轻度环境影响的项目 | 审批制（部分可告知承诺） |
| 环境影响登记表 | 环境影响很小的项目 | 网上备案制 |
| 不纳入名录 | 名录外项目 | 不需办理环评手续 |

---

## 二、环境敏感区（升级判定关键）

名录中大量条目以"是否涉及环境敏感区"作为报告书/报告表的分界。环境敏感区包括：

1. **自然保护地**：国家公园、自然保护区、风景名胜区、世界文化和自然遗产地、地质公园、森林公园等
2. **重要生态功能区**：生态保护红线、重要湿地、天然林、珍稀濒危物种栖息地等
3. **环境质量敏感区**：饮用水水源保护区、居民区、学校、医院、疗养地等人口集中区，以文物保护单位
4. **其他**：基本农田保护区、水土流失重点防治区等

**判定规则**：项目位于或紧邻敏感区的，通常升级为报告书或从报告表升级管理。

---

## 三、名录使用步骤

```
第一步：确定项目所属行业大类、小类
  ↓
第二步：在名录中定位对应条目
  ↓
第三步：读取该条目的分类界定（规模阈值、工艺、敏感区条件）
  ↓
第四步：判断是否涉及环境敏感区（可能升级）
  ↓
第五步：确定环评文件类型（报告书/报告表/登记表/不纳入）
```

---

## 四、环评分类 与 排污许可分类 协调判断

| 环评文件类型 | 常见对应排污许可管理类别 | 说明 |
|-------------|------------------------|------|
| 报告书 | 重点管理 / 简化管理 | 以《固定污染源排污许可分类管理名录（2019年版）》为准 |
| 报告表 | 简化管理 / 登记管理 | 两名录分类口径不同，须分别对照 |
| 登记表 | 排污登记 | 一般不核发排污许可 |

**关键提示**：环评分类名录（2021版）与排污许可分类名录（2019版）是**两套独立名录**，不能直接画等号。判断排污许可管理类别时，必须回到排污许可分类名录逐项核对，不能仅凭环评文件类型推定。

---

## 五、常见误区

| 误区 | 正解 |
|------|------|
| "报告书项目就是排污许可重点管理" | 两名录独立，须分别对照 |
| "登记表项目也要办排污许可证" | 登记表项目一般对应排污登记，不核发证 |
| "名录外项目无需任何手续" | 仍须依法排污登记（如属排污许可登记管理范围） |
| "涉敏感区不影响分类" | 涉敏感区通常升级环评文件类型 |

---

## 六、判定速查清单

- [ ] 已确定项目行业大类/小类
- [ ] 已在名录中定位准确条目
- [ ] 已读取规模阈值、工艺、敏感区界定条件
- [ ] 已判断是否涉及环境敏感区
- [ ] 已确定环评文件类型
- [ ] 已单独对照排污许可分类名录确定排污许可管理类别
- [ ] 已核对环评审批级别与项目权限匹配
