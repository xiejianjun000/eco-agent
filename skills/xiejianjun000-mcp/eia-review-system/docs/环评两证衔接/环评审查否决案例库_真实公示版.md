# 环评审查否决案例库 —— 真实公示案例

> 本文件为《环评审查否决案例库.md》的补充，收录从生态环境部门公开公示、处罚决定书、典型案例通报中提取的**真实案例**。
> 案例分类沿用原库10大类否决原因体系，每类下列入实际搜到的真实案例，未搜到的类别标注"暂无公开公示案例"。

---

## 使用说明与免责

1. **数据来源**：全部案例要素提取自各级生态环境部门依法公开的审批公示、退回函、行政处罚决定书、生态环境部通报，每个案例标注信息来源。
2. **案例性质**：本库收录的均为**真实公示案例**，可直接用于技术审查培训、执法参照。涉及的企业/项目名称均为公开信息，不构成对企业声誉的评价。
3. **严禁编造**：只收录实际搜索到的案例，未搜到的类别明确标注"暂无公示案例"，宁可缺也不编。
4. **时效**：案例时间跨度 2018-2026年，以2022-2025年案例为主。
5. **效力边界**：技术审查意见仅供参考，不替代生态环境部门的审批/核发决定。

## 第一部分：按否决原因分类的真实公示案例

### ① 工程分析产污遗漏 / 源强偏小

#### 案例1-1：广西马山县养殖项目 —— 源强核算不全被不予许可
- **地区**：广西南宁市马山县
- **项目类型**：养殖项目（油茶种植基地配套养殖）
- **否决/退回原因**：《报告书》对区域地表水、地下水及生态环境等现状调查不清，养殖粪污收集处理工艺、病死猪处置、消纳区施肥方式等描述不清，污染物产排源强核算不全
- **依据条款**：《建设项目环境保护管理条例》第十一条第（五）项 + 《行政许可法》第三十八条第二款
- **处理结果**：不予行政许可（南政务（生态）环审不予许可〔2024〕1号）
- **来源**：南宁市生态环境局 https://sthjj.nanning.gov.cn/xxgk/zfxxgkml/xzsp/t6004945.html （2024-08-23）

#### 案例1-2：江苏泰兴慧芃新材料项目 —— 源强核算内容不全被失信记分
- **地区**：江苏省
- **项目类型**：汽车/航空/军工/5G通信零部件扩建
- **退回原因**：设备清单有120台CNC机床但遗漏切削液原辅料和废切削液固废；水平衡缺失初期雨水、水帘用水
- **依据条款**：《建设项目环境影响报告书（表）编制监督管理办法》第二十六条
- **处理结果**：编制单位及编制人员分别失信记分5分
- **来源**：江苏省生态环境厅通报，腾讯网 https://new.qq.com/rain/a/20250919A04MU900 （2025-09-19）

#### 案例1-3：江苏盐城鼎蓝科技水泥制品项目 —— 源强遗漏、概况描述不全
- **地区**：江苏省泰州市
- **项目类型**：水泥制品生产（利用生活垃圾焚烧炉渣作原料）
- **退回原因**：未对照固废综合利用管理要求进行相符性分析；未说明厂区公辅工程/环保工程/风险防控设施现状；产品检测内容不清；机械维保固废产生因素未明确
- **处理结果**：编制单位及编制人员分别失信记分5分
- **来源**：泰州市生态环境局，企鹅号报道 （2026-01-22）

### ⑩ 环境风险评价缺失或深度不足

> **备注**：以"环境风险评价缺失"为唯一原因导致不予批准的公开公示极少，多数案例中风险评价问题与其他质量问题合并出现。以下为相关案例：

#### 案例10-1：扬州危废焚烧项目 —— 环境风险但否决主因为规划不符
- **地区**：江苏省扬州市
- **项目类型**：危险废物焚烧及综合利用
- **相关风险问题**：报告指出项目原料主要为各类危险废物，建有较多的甲类工艺装置及甲类贮存库房，具有较高的环境风险（但否决主因是规划不符）
- **处理结果**：拟不予批准（因规划不符）
- **来源**：扬州市生态环境局（同上案例9-2）

> **补充说明**：在生态环境部及各省通报的环评文件质量问题中，环境风险预测与评价内容不全属于《监督管理办法》第二十六条所列情形之一（如安徽2025年第一批通报11份问题环评中包含此类），但因环境风险评价缺失单独导致"不予批准"的公示案例确实较少，多数以编制质量问题通报和失信记分方式处理。**暂无单独以环境风险评价缺失为由不予批准的公示案例。**

## 第五部分：技术复核与失信记分典型案例（按通报批次）

### 生态环境部2020年第一季度常态化复核
- **范围**：24个省（区、市）各级审批部门审批的101份环评文件
- **发现问题**：8份环评文件存在质量问题（遗漏评价因子、降低评价工作等级、缩小评价范围、源强核算错误、监测因子不符、现状调查不全、风险预测不全、环保措施论证不符等）
- **处理**：7家编制单位及9名编制人员通报批评和失信记分；8家建设单位通报批评；2家技术评估单位及8个审批部门通报
- **来源**：生态环境部 环办环评函〔2020〕393号

### 海南2024年第二、三次技术复核
- **范围**：海南省各市县审批的环评文件
- **发现问题**：6份环评文件存在质量问题
- **处理**：5家编制单位和9名编制人员失信记分；1家技术评估单位、6个审批部门通报
- **来源**：海南省生态环境厅 琼环函〔2025〕38号 https://hnsthb.hainan.gov.cn/xxgk/0200/0202/hjywgl/hjyxpj/202503/t20250303_3826102.html

### 安徽2025年第一批通报
- **发现问题**：11份环评文件存在质量问题 + 1起挂证
- **问题类型**：建设项目概况描述不全、源强核算内容不全或错误、环境风险影响预测与评价内容不全、降低评价标准、遗漏污染物排放标准规定的相关污染物、所提环保措施不符合规定
- **处理**：涉及编制单位和人员被失信记分；挂证人员被失信记分15分
- **来源**：安徽省生态环境厅，企鹅号报道 （2025-09-05）

### 大理州2024年第三季度通报
- **发现问题**：多份环评文件存在明显质量问题，包括工程内容与备案证不一致、评价等级和标准依据不充分、多要素现状调查和影响预测遗漏等
- **来源**：大理州生态环境局，搜狐报道 https://www.sohu.com/a/857940420_121123741
