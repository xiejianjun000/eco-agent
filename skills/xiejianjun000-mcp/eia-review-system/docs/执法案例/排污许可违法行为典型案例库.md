## 一、无证排污案例

### 案例1：南通某金属制品公司无证排污案

**违法主体**：南通某金属制品有限公司
**行业类型**：金属制品
**管理类别**：应为重点管理，实际未申领
**发现时间**：2024年3月
**发现方式**：专项执法检查

**违法事实**：
企业有电镀槽，年加工量500吨，应按重点管理申领排污许可证，但实际只做了排污登记，未取得排污许可证排放污染物。

**证据链**：
1. 企业营业执照、生产设备清单
2. 电镀槽数量、容积照片
3. 生产记录、产品销售记录
4. 监测数据（废水排放口采样）

**法律适用**：
《排污许可管理条例》第33条第1项：未取得排污许可证排放污染物，由生态环境主管部门责令改正或者限制生产、停产整治，处20万元以上100万元以下的罚款；情节严重的，责令停产停业。

**处罚结果**：
- 罚款：45.6万元
- 责令停产整治

**案例启示**：
1. 电镀企业有电镀槽必须按重点管理申领许可证
2. 排污登记不能代替排污许可证
3. 生产规模、工艺类型是判断管理类别的关键

## 二、许可证届满未延续案例

### 案例6：上海某制造公司许可证届满未延续案

**违法主体**：上海某制造有限公司
**行业类型**：机械制造
**管理类别**：简化管理
**发现时间**：2024年9月
**发现方式**：许可证到期提醒检查

**违法事实**：
企业排污许可证于2024年6月30日到期，未在有效期届满前**60日（日历日）**申请延续，继续排放污染物。

**证据链**：
1. 许可证有效期证明
2. 许可证延续申请记录（无）
3. 生产记录、监测数据
4. 企业负责人询问笔录

**法律适用**：
《排污许可管理条例》第33条第2项：排污许可证有效期届满未申请延续或者延续申请未经批准排放污染物。

**处罚结果**：
- 罚款：25万元
- 责令停止排污

**案例启示**：
1. 许可证有效期届满前**60日（日历日）**必须申请延续
2. 许可证到期后不得继续排污
3. 企业要建立许可证到期预警机制

## 四、逃避监管排放案例

**行业类型**：化工

- 罚款：100万元（顶格处罚）
- 拘留：企业负责人行政拘留15日
- 责令停产停业
- 移送公安机关

**案例启示**：
1. 暗管排污是严重违法行为
2. 逃避监管方式排放可拘留
3. 可能涉嫌污染环境罪

《排污许可管理条例》第37条：未建立环境管理台账记录制度，或者未按照排污许可证规定记录。

**处罚结果**：

**案例启示**：
1. 台账记录必须完整，不能有空白
2. 生产设施、污染防治设施运行状态都要记录
3. 执法检查会逐日核对台账

## 九、案例总结

### 9.1 违法行为统计

| 违法类型 | 案例数量 | 平均罚款 | 最高罚款 | 最低罚款 |
|---------|---------|---------|---------|---------|
| 无证排污 | 5 | 49.68万元 | 80万元 | 20万元 |
| 许可证届满未延续 | 2 | 22.5万元 | 25万元 | 20万元 |
| 超许可排放 | 3 | 73.3万元 | 90万元 | 60万元 |
| 逃避监管排放 | 3 | 83.3万元 | 100万元 | 70万元 |
| 自行监测问题 | 4 | 4.17万元 | 6.68万元 | 2.5万元 |
| 台账记录问题 | 3 | 0.77万元 | 1万元 | 0.5万元 |
| 执行报告问题 | 3 | 2.43万元 | 3万元 | 2万元 |
| 信息公开问题 | 2 | 1.25万元 | 1.5万元 | 1万元 |

### 9.2 处罚特点

**罚款幅度**：
- 无证排污、超许可排放、逃避监管排放：罚款较重（20-100万元）
- 自行监测、台账、执行报告、信息公开：罚款较轻（0.5-10万元）

**拘留情况**：
- 逃避监管排放：可行政拘留
- 无证排污情节严重：可行政拘留
- 涉嫌污染环境罪：移送公安机关

**责令措施**：
- 停产整治、停产停业：针对严重违法行为
- 限制生产：针对超标排放
- 停止排污：针对无证排污

### 9.3 预防措施

**企业自查清单**：
1. 是否取得排污许可证
2. 许可证是否在有效期内
3. 排放口数量、位置是否与许可证一致
4. 是否按许可证要求开展自行监测
5. 是否建立环境管理台账
6. 是否按时提交执行报告
7. 是否按规定公开信息

**证后管理要点**：
1. 按许可证载明要求开展自行监测
2. 建立环境管理台账，记录完整
3. 按时提交季度、年度执行报告
4. 按规定公开排放信息
5. 发现问题及时整改
