# 环评技术导则体系与技术审查要点

> 环评文件（报告书/报告表）技术审查的技术标准依据。分总纲、要素导则、专题导则、行业导则四类。行业专项导则先列体系，具体行业逐条要求以现行导则原文为准。

---

## 一、导则体系框架

### 1.1 总纲
| 标准号 | 名称 | 核心内容 |
|--------|------|---------|
| HJ 2.1-2016 | 环境影响评价技术导则 总纲 | 评价工作程序、评价等级、评价范围、工程分析、环境保护措施 |

### 1.2 环境要素导则
| 标准号 | 名称 | 关键要点 |
|--------|------|---------|
| HJ 2.2-2018 | 大气环境 | 评价等级判定（估算模型）、预测模型（AERMOD等）、防护距离 |
| HJ 2.3-2018 | 地表水环境 | 评价等级、水质预测、排放口混合区 |
| HJ 2.4-2021 | 声环境 | 评价等级、噪声预测、达标距离 |
| HJ 610-2016 | 地下水环境 | 评价等级、包气带防污性能、防渗要求 |
| HJ 964-2018 | 土壤环境（试行） | 评价等级、占地类型、土壤现状监测、防控措施 |
| HJ 19-2022 | 生态影响 | 生态现状、生态保护红线、生物多样性影响 |

### 1.3 专题导则
| 标准号 | 名称 | 关键要点 |
|--------|------|---------|
| HJ 169-2018 | 建设项目环境风险评价技术导则 | 风险物质识别、风险源、事故预测、应急 |
| HJ 2.5 / 相关 | 环境影响经济损益分析等 | 视项目需要 |

### 1.4 行业建设项目环评技术导则（体系，逐行业以现行导则为准）
- 涵盖石化、化工、制药、钢铁、有色、水泥、火电、纺织印染、制浆造纸、农药、电镀、煤炭、公路、铁路、港口、水利水电等行业专项技术要求。
- 审查时须同时对照"总纲 + 要素导则 + 行业导则"，行业导则从严。

## 二、环评文件技术审查要点（报告书/报告表质量）

### 2.1 工程分析（最核心）
- [ ] 生产工艺流程完整，产污节点标注清晰（"三废+噪声"全覆盖）
- [ ] 物料平衡、水平衡、特征污染物平衡账算清
- [ ] 产污系数/源强核算方法合理（优先实测＞类比＞物料衡算＞系数）
- [ ] 污染源强与后续排放标准、总量核算逻辑一致

### 2.2 评价等级与范围
- [ ] 各要素评价等级判定依据充分（大气估算模型结果、废水排放量/受纳水体、噪声）
- [ ] 评价范围符合导则要求
- [ ] 环境敏感目标识别无遗漏（居民区、学校、医院、水源地、自然保护地）

### 2.3 现状调查与评价
- [ ] 现状监测点位、因子、频次符合导则
- [ ] 现状数据引用合规、时效性满足
- [ ] 区域达标情况判断准确（达标区/不达标区影响准入）

### 2.4 环境影响预测
- [ ] 预测模型选用正确（大气AERMOD、地表水模型等）
- [ ] 预测参数合理、预测结果可信
- [ ] 达标性结论有数据支撑

### 2.5 环境保护措施与"三同时"
- [ ] 治理措施可行、达标可达
- [ ] 措施与源强、预测结果匹配
- [ ] "三同时"清单明确，投资估算合理

### 2.6 总量控制
- [ ] 主要污染物总量核算准确
- [ ] "以新带老""区域削减""等量/倍量替代"落实
- [ ] 总量指标来源明确（可作为排污许可总量依据）

### 2.7 环境风险与应急
- [ ] 风险物质、风险源识别全面
- [ ] 事故情形预测、防范与应急措施到位（对照HJ 169-2018）

### 2.8 公众参与（报告书类）
- [ ] 公参程序、信息公开、意见征询符合部令第4号

### 2.9 结论与建议
- [ ] 环境可行性结论明确、有依据
- [ ] 选址/选线符合"三线一单"及规划

## 三、环评文件常见质量问题（高频退回原因）

| 序号 | 常见问题 | 后果 |
|------|---------|------|
| 1 | 工程分析产污环节遗漏、源强偏小 | 后续限值/总量失真，退回 |
| 2 | 特征污染物识别不全 | 影响两证衔接因子，退回 |
| 3 | 评价等级判定错误（就低不就高） | 评价深度不足，退回 |
| 4 | 敏感目标遗漏 | 影响防护距离/选址结论，退回 |
| 5 | 预测模型/参数错误 | 达标结论不可信，退回 |
| 6 | 治理措施与达标要求不匹配 | 措施不可行，退回 |
| 7 | 总量核算与源强矛盾 | 总量失真，影响排污许可衔接 |
| 8 | 引用已废止标准/导则 | 技术依据错误，退回 |
| 9 | "三线一单"符合性未论证 | 准入结论缺依据 |
| 10 | 环境风险评价缺失或深度不足 | 涉危项目退回 |

## 四、"三线一单"与准入约束

| 约束 | 含义 | 审查要点 |
|------|------|---------|
| 生态保护红线 | 禁止/限制开发 | 项目选址是否触碰红线 |
| 环境质量底线 | 区域达标要求 | 不达标区域项目准入从严、须区域削减 |
| 资源利用上线 | 水、能源、岸线等 | 资源消耗合理性 |
| 生态环境准入清单 | 分区管控要求 | 项目是否符合所在管控单元准入清单 |

> 审查环评时，"三线一单"符合性是准入判断的前置条件；不符合的项目环评不予批准，排污许可自然无从衔接。
