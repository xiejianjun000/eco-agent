# 第一篇 刑事大案（判刑入罪）

## 1.1 山东锦华环保科技有限公司环评造假案

**——环评造假入刑第一案，2023年5月宣判**

| 项目 | 内容 |
|------|------|
| **法院** | 山东省青岛市即墨区人民法院 |
| **罪名** | 提供虚假证明文件罪（《刑法》第229条） |
| **宣判时间** | 2023年5月 |

**背景**：2021年，山东一名环评工程师在4个月内编制了63本环评报告书和1541份环评报告表，涉及全国25个省市，引发行业震动。生态环境部将此定性为"环保形式主义"。

**判决结果**：

| 被告人 | 角色 | 刑罚 | 罚金 |
|--------|------|------|------|
| 林某鑫 | 空壳公司实际控制人 | 有期徒刑3年 | 50万元 |
| 汪某 | 法定代表人 | 有期徒刑1年6个月 | 7万元 |
| 谷某欢 | 中介掮客 | 有期徒刑1年2个月 | 6万元 |
| 靳某燕 | "挂靠"环评工程师 | 有期徒刑1年，缓刑1年 | 5万元 |

- 违法所得近80万元，造成直接经济损失100余万元
- 四人违法所得全部没收

**案件意义**：
- 《刑法修正案（十一）》施行后，环评造假入刑司法实践的重大突破
- 覆盖造假日链条：空壳公司控制人 + 法人 + 挂靠工程师 + 中介掮客
- 生态环境部将此作为"环境行政执法与刑事司法衔接机制的标志性成果"
- 2024年6月被最高人民检察院列入"检察机关依法惩治第三方环保服务机构弄虚作假犯罪典型案例"（案例一）

**来源**：生态环境部2023年5月例行新闻发布会；最高人民检察院2024年6月5日发布

## 1.2 江西展航环保科技有限公司环评造假案

**——江西省首例环评造假刑案，8人终身禁业**

| 项目 | 内容 |
|------|------|
| **法院** | 九江市濂溪区法院（一审）/ 九江市中级人民法院（二审） |
| **罪名** | 提供虚假证明文件罪 |
| **一审宣判** | 2023年9月13日 |
| **二审宣判** | 2025年12月27日（驳回上诉，维持原判） |

**案情概要**：
- 2019年12月，余某、肖某甲等5人共同成立江西展航环保科技有限公司
- 通过联系具有环评工程师资格的常某某"挂靠"——常某某不参与任何编制审核工作，仅出售资格证书
- 2019年12月至2020年10月，利用常某某的环评师资格，对外出具700余份环评报告书（表），违法所得70余万元
- 田某某、郑某某另成立公司，向展航公司购买环评编制单位和编制人员情况表，承揽13家企业环评业务，出具14份报告书（表），获利71.35万元

**判决结果**：

| 被告人 | 刑罚 | 罚金 |
|--------|------|------|
| 余某双 | 有期徒刑2年2个月 | 35万元 |
| 肖某风 | 有期徒刑2年 | — |
| 其他6人 | 有期徒刑1年6个月至1年不等 | 8万—35万元不等 |

- **8人全部终身禁止从事环境影响评价工作**
- 违法所得全部退缴
- 2024年4月16日起被列入信用平台"黑名单"

**来源**：九江市中级人民法院二审判决书；封面新闻2026年7月18日报道；生态环境部2024年上半年黑名单通报

## 1.3 福建皓月环保科技有限公司伪造环评批复文件案

**——福建省首起生态环境领域伪造环评批复犯罪案件**

| 项目 | 内容 |
|------|------|
| **法院** | 泉州市丰泽区人民法院 |
| **罪名** | 伪造国家机关公文罪（《刑法》第280条第1款） |
| **宣判时间** | 2024年1月 |

**案情概要**：
- 2022年8月，执法人员检查某工艺品公司，企业提供一份环评报告表
- 文件虽有批复内容但无批复编号，加盖"泉州市生态环境局审批专用章（丰泽）"公章
- 经核对审批清单——该项目不在审批清单内，批复文件系伪造
- 环评文件由福建皓月环保科技有限公司提供，并告知企业该环评"已经正式批复"

**处理结果**：
- 杜某犯伪造国家机关公文罪，判处有期徒刑6个月，罚金1万元
- 工艺品公司因"未批先建"+"未验先投"被罚款23.33万元

**来源**：福建省生态环境厅2023年第八批典型案例（第三方环保服务机构造假）；丰泽区人民法院刑事判决书

# 第五篇 典型造假手法分类

## 5.1 抄袭/复制类（跨文件对比可识别）

# 第六篇 识别路径与审查要点（对AI系统的启示）

## 6.1 可程序化自动检测项

| 检测项 | 实现方式 | 置信度 |
|--------|---------|--------|
| 同一环评工程师编制数量异常 | 信用平台数据比对 | 高 |
| 跨文件文本相似度 | 文本查重算法 | 高 |
| 标准引用有效性 | 标准数据库比对（是否废止/是否适用） | 高 |
| 保护目标距离一致性 | GIS坐标运算 vs 文本数值 | 高 |
| 物料平衡校验 | 输入=输出+排放+固废 | 中 |
| 检出限逻辑 | 数值vs方法检出限比对 | 中 |
| 噪声衰减规律 | 距离加倍→衰减≤3/6 dB检验 | 中 |

## 6.2 需要AI推理判断的检测项

| 检测项 | AI能力需求 |
|--------|----------|
| 异地地名/无关工艺残留 | NLP文本理解 |
| 前后矛盾（不同章节数据不一致） | 跨章节信息抽取+核对 |
| 环评等级判定是否正确 | HJ导则规则推理 |
| 科学规律违背（气象vs浓度） | 多模态数据分析 |
