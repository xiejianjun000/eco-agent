## 重要说明（准确性红线）

1. **专项环评导则概念区分**：本总库所述的"专项环评导则"指**建设项目环境影响评价技术导则（行业）**，如 HJ 708-2014《环境影响评价技术导则 钢铁建设项目》。它与**排污许可证申请与核发技术规范**（如 HJ 855-2017 电镀、HJ 853-2017 石化）是两套不同体系——前者管"事前预测评估"，后者管"事中事后许可"，切勿混用。
2. **国家发布的行业专项环评导则数量有限**。经核对《建设项目环境影响评价技术导则 总纲》（HJ 2.1-2016）体系说明，行业建设项目环评技术导则目前主要覆盖**水利水电、采掘、交通基础设施**及少量重点制造业（钢铁、石油化工、制药、农药、煤炭采选等）。**绝大多数制造业行业无专项环评导则**，执行"总纲 HJ 2.1-2016 + 环境要素导则 + 专题导则"，并对照本行业**排污许可技术规范**与**排放标准**开展审查。
3. **不编造编号**。对不确定的专项导则编号，一律标注"（待核实）"，不硬编。专项导则编号以生态环境部官方发布文本为准。
4. **本总库 ≠ 审批决定**。技术审查意见仅供参考，环评审批与排污许可核发以生态环境部门决定为准。

# 第二部分：重点行业EIA审查要点详解（17个重点行业）

> 每段结构：①行业专项导则说明 ②工程分析要点（产污环节）③特征污染因子 ④评价等级关注点（大气/水/风险/地下水土壤）⑤治理措施要点 ⑥两证衔接特别注意（对应6大咬合点）。

## 1. 石化（石油化学工业）

**① 专项导则说明**：有。HJ/T 89-2003《环境影响评价技术导则 石油化工建设项目》，适用于以石油/石油气为原料的炼油、化工、化纤、化肥生产及储运、科研等新建、改扩建和技术改造项目。

**② 工程分析要点**：以装置为单元做全厂物料衡算、水平衡、能量衡算。核心产污环节：工艺反应（裂解、重整、加氢）、储运（罐区呼吸、装卸）、污水处理场、锅炉/加热炉、火炬。重点核查 VOCs 无组织排放源（LDAR 泄漏）。

**③ 特征污染因子**：废气——SO₂、NOx、VOCs、非甲烷总烃、苯、甲苯、二甲苯、H₂S、NH₃、石油类；废水——石油类、COD、氨氮、硫化物、挥发酚、氰化物；特征——苯并[a]芘（焦化/重整）。

**④ 评价等级关注点**：大气（判定等级高，关注超标区及防护距离）；水（直排/进污水厂）；**环境风险（重大危险源，对照 HJ 169-2018，须做事故预测、应急）；地下水/土壤（防渗分区、隐蔽工程）**。

**⑤ 治理措施要点**：工艺废气脱硫脱硝、RTO/催化氧化、LDAR 泄漏检测与修复；污水处理场加盖除臭；硫磺回收；清污分流、事故池（容量须满足最大事故废水量）。

**⑥ 两证衔接特别注意**：咬合点2（因子）——环评识别的所有 VOCs 特征因子、苯系物、重金属须全部纳入排污许可，不得遗漏；咬合点4（限值）——环评批复严于排放标准的须执行环评加严值；咬合点5（总量）——SO₂/NOx/VOCs 总量不得超过环评批复；咬合点6（措施+监测）——LDAR、自动监测要求须写入自行监测方案。

## 2. 化工（基础化学原料、合成材料、专用化学品、涂料等）

**① 专项导则说明**：石油化工类（炼油、乙烯、化肥等）参照 HJ/T 89-2003；**其他化工行业（基础化学原料、合成材料、专用化学品、涂料油墨颜料等）目前无专项行业环评技术导则**，执行总纲 HJ 2.1-2016 + 要素导则 + 本行业排污许可技术规范（HJ 853、HJ 860、HJ 881 等自行监测/申请规范）对照审查。

**② 工程分析要点**：依产品工艺做反应、分离、精制全流程物料衡算。重点：反应副产物、高浓废液/母液、废气无组织、废催化剂/废盐等危废产生节点。

**③ 特征污染因子**：随产品变化大——VOCs、苯乙烯、丙烯腈、MDI/TDI、氯气、氯化氢、氨气、硫酸雾、特征有机物；废水——COD、氨氮、总氮、特征因子。

**④ 评价等级关注点**：大气（VOCs 复杂，须做大气预测）；**风险（多涉及重点监管危险化学物质，对照 HJ 169-2018）**；地下水/土壤（防渗、特征因子迁移）；水（高浓废水）。

**⑤ 治理措施要点**：密闭化生产、VOCs 应收尽收（RTO/冷凝/吸附）；高浓废液优先资源化（如废盐精制）；废催化剂、废活性炭规范处置（危废）；应急池与围堰。

**⑥ 两证衔接特别注意**：咬合点2（因子）——因产品而异的特征因子须在排污许可中全量载入，切忌"只写常规因子"；咬合点5（总量）——特征因子（如 VOCs 细分物质）须纳入总量核算；咬合点6（措施）——危废代码、产生量须与排污许可一致。

## 3. 制药（含原料药、生物药品）

**① 专项导则说明**：有。HJ 611-2011《环境影响评价技术导则 制药建设项目》，适用于新建、改建、扩建及企业搬迁的制药建设项目（生产兽药和医药中间体的参照）。

**② 工程分析要点**：化学药——合成各步反应、溶剂回收、母液；生物药/发酵——菌种培养、发酵、提取、纯化；制剂——混合、压片、包衣。重点：有机溶剂使用量（VOCs 源强）、菌渣/废活性炭、高浓废水。

**③ 特征污染因子**：VOCs（甲醇、丙酮、二氯甲烷等有机溶剂）、COD、氨氮、总氮；特征——青霉素类/头孢类（抗生素）、遗传毒性杂质（关注）；固废——菌渣（危废）、废溶剂。

**④ 评价等级关注点**：大气（VOCs + 恶臭，关注防护距离）；水（高浓难降解有机废水，关注受纳水体）；风险（有机溶剂、菌毒种，生物安全）；地下水/土壤（防渗）。

**⑤ 治理措施要点**：VOCs 收集+蓄热燃烧（RTO）/冷凝回收；高浓废水预处理（微电解、芬顿等）+ 综合生化；菌渣按危废焚烧或资源化；生物安全三级/二级防护。

**⑥ 两证衔接特别注意**：咬合点2（因子）——所有使用的有机溶剂对应的 VOCs 细分因子须纳入；咬合点3（排放口）——废气排放口须与环评一致，无组织排放与控制要求对应；咬合点6（措施）——危废（菌渣、废溶剂）代码与处置去向须一致。

## 4. 农药

**① 专项导则说明**：有。HJ 582-2010《环境影响评价技术导则 农药建设项目》，适用于我国所有农药（原药、制剂和中间体）新建、改建、扩建项目。

**② 工程分析要点**：原药合成全流程物料衡算（反应、结晶、分离、干燥）；制剂加工（配料、混合、包装）；重点：高毒/高残留原药的特殊产污、母液、废盐、副产。

**③ 特征污染因子**：VOCs；特征——依原药种类（有机磷、氨基甲酸酯、拟除虫菊酯、酰胺类等）对应的特征因子；废水——COD、氨氮、总磷、特征原药残留；危废——废盐、废母液、废包装。

**④ 评价等级关注点**：大气（特征因子毒性大，关注最大落地浓度与防护距离）；水（高毒特征因子，关注受纳水体与饮用水源）；**风险（高毒物质，HJ 169-2018 重点）**；地下水/土壤（重点防渗、特征因子监控）。

**⑥ 两证衔接特别注意**：咬合点2（因子）——原药特征因子必须纳入排污许可，这是高频否决点；咬合点4（限值）——对有毒特征因子，若环评/地方加严，须执行加严值；咬合点5（总量）——特征因子总量不得超环评批复；咬合点6（措施）——危废代码（废盐、废母液）须一致。

## 5. 电镀

**② 工程分析要点**：镀前（除油、酸洗、活化）→电镀/化学镀→镀后（钝化、封闭）。重点：镀种（镀锌、镀镍、镀铬、镀铜等）决定因子；槽液带出量（源强核心）；老化槽液、废滤芯。

**③ 特征污染因子**：一类污染物——总铬、六价铬、总镍、总镉、总铅、总铜、总锌、总氰化物；废气——铬酸雾、硫酸雾、氯化氢、氮氧化物。

**④ 评价等级关注点**：水（一类污染物须车间排口达标，关注受纳水体）；大气（铬酸雾、酸雾，关注防护距离）；地下水/土壤（槽液渗漏，重点防渗分区）；风险（氰化物）。

**⑤ 治理措施要点**：**分质分流**（含铬、含镍、含氰、酸碱分开设管）；含铬/含镍废水车间单独处理达标后排入综合废水；氰化镀废水破氰处理；铬酸雾、酸雾收集（网格式/侧吸）；废槽液按危废。

**⑥ 两证衔接特别注意**：咬合点2（因子）——六价铬、总镍等**一类污染物因子必须全部纳入**，遗漏即否决；咬合点3（排放口）——**一类污染物须在车间或车间设施排口单独设排放口**，与环评平面布置一致；咬合点4（限值）——一类污染物执行特别/从严限值；咬合点6（监测）——车间排口须自动监测或按规范手工监测，纳入自行监测方案。

## 6. 纺织印染

**① 专项导则说明**：**无专项行业环评技术导则**，执行总纲 + 要素导则（注：HJ 709-2014 为《建设项目竣工环境保护验收技术规范 纺织染整》，非环评导则）。

**② 工程分析要点**：前处理（退浆、煮练、漂白）→染色/印花→后整理（水洗、定型）。重点：水耗与废水产生量（行业用水大户）、各种助剂/染料使用量。

**⑥ 两证衔接特别注意**：咬合点2（因子）——苯胺类等特征因子须纳入；咬合点3（排放去向）——直接排放 vs 间接排放（纳管）必须一致，间接排放须有纳管协议；咬合点5（总量）——COD、氨氮、总氮总量不得超环评批复，流域限排区域须落实区域削减。

## 12. 炼焦

**① 专项导则说明**：**无专项行业环评技术导则**，执行总纲 + 要素导则（有2022年版《钢铁/焦化建设项目环境影响评价文件审批原则》作为审查政策依据）。

**② 工程分析要点**：备煤→炼焦（焦炉）→熄焦（干熄焦/湿熄焦）→煤气净化（冷凝鼓风、脱硫、硫铵、粗苯）。重点：焦炉烟气、装煤/推焦/熄焦无组织、酚氰废水、化产回收。

**③ 特征污染因子**：焦炉烟气——SO₂、NOx、颗粒物、苯并[a]芘（B[a]P）；无组织——H₂S、NH₃、VOCs、B[a]P、苯系物；废水——酚、氰、COD、氨氮；特征——B[a]P（高频特征因子）。

**④ 评价等级关注点**：大气（SO₂/NOx/B[a]P，关注防护距离与区域达标）；地下水/土壤（酚氰废水、焦油，重点防渗）；风险（煤气、焦油）；水（酚氰废水）。

**⑤ 治理措施要点**：焦炉烟气脱硫脱硝（活性焦/SCR+半干法）；**干熄焦**（节能、减无组织）；装煤/推焦除尘、焦炉煤气净化；酚氰废水处理（蒸氨+生化+深度）；VOCs 治理（罐区、装卸）。

**⑥ 两证衔接特别注意**：咬合点2（因子）——B[a]P、VOCs、特征因子须全部纳入；咬合点4（限值）——执行焦化行业特别排放限值（含 B[a]P）；咬合点5（总量）——SO₂/NOx/VO Cs 总量不超环评批复；咬合点6（措施）——干熄焦、装煤推焦除尘等须写入排污许可与自行监测。

## 13. 汽车制造

**① 专项导则说明**：**无专项行业环评技术导则**，执行总纲 + 要素导则（HJ 991 为自行监测规范，用于两证衔接对照）。

**② 工程分析要点**：冲压→焊装→涂装（前处理电泳→中涂→面涂）→总装。重点：**涂装工序是 VOCs 核心源**（电泳、中涂、面涂、烘干），前处理含磷/重金属废水，焊接烟尘，危废（漆渣、磷化渣、废溶剂）。

**③ 特征污染因子**：VOCs（甲苯、二甲苯、酯类、酮类）；废水——COD、石油类、总磷、总镍（前处理）、Zn；废气——焊接烟尘、颗粒物；危废——漆渣、磷化渣、废漆雾过滤材料。

**④ 评价等级关注点**：大气（VOCs，关注防护距离与区域 VOCs 管控）；水（涂装废水含重金属、磷）；风险（油漆/溶剂仓储）；地下水/土壤（涂装车间防渗）。

**⑤ 治理措施要点**：**涂装废气 RTO+沸石转轮浓缩**（高效）；前处理废水分质处理（含镍废水单独）；焊接烟尘净化；危废分类贮存委外。

**⑥ 两证衔接特别注意**：咬合点2（因子）——所有涂装 VOCs 细分因子须纳入；咬合点3（排放口）——涂装废气排放口与烘干废气排口与环评一致；咬合点6（措施+监测）——RTO 运行、VOCs 自动监测要求须写入自行监测方案；危废代码一致。

## 14. 电子（半导体 / PCB 印制电路板）

**① 专项导则说明**：**无专项行业环评技术导则**，执行总纲 + 要素导则（电子工业排污许可规范用于两证衔接）。

**② 工程分析要点**：半导体——光刻、刻蚀、薄膜沉积、离子注入、清洗（大量酸碱、特种气体、超纯水）；PCB——开料、钻孔、电镀/化学镀（铜/镍/金）、蚀刻、阻焊（大量重金属废水）。

**③ 特征污染因子**：半导体——酸碱废气、VOCs、特种气体（AsH₃、PH₃、SiH₄）、废水（氟、氨氮、重金属、TOC）；PCB——废水（总铜、总镍、总氰、络合铜）、废气（VOCs、酸雾、锡及其化合物）；一类污染物（总铜/总镍/总氰）。

**④ 评价等级关注点**：大气（酸碱、VOCs、有毒特种气体，关注防护距离与下风向敏感点）；水（含氟/含重金属废水，关注受纳水体）；**地下水/土壤（酸碱、重金属、特种气体，重点防渗与监测）**；风险（有毒气体、氰化物）。

**⑤ 治理措施要点**：特种气体 monitored+洗涤塔；含氟废水、含重金属废水分质处理；PCB 含铜/含镍/含氰废水车间单独处理；废气洗涤+活性炭。

**⑥ 两证衔接特别注意**：咬合点2（因子）——总铜、总镍、总氰等**一类污染物必须纳入**；咬合点3（排放口）——含重金属废水须车间排口单独设口，与环评一致；咬合点6（监测）——车间排口重金属自动/手工监测须纳入；特种气体安全与危废（废光刻胶、废化学品）代码一致。

## 15. 食品制造

**① 专项导则说明**：**无专项行业环评技术导则**，执行总纲 + 要素导则（HJ 863 为排污许可规范）。

**② 工程分析要点**：原料处理→加工（加热、调配）→杀菌/灭菌→灌装。重点：高有机废水（COD、氨氮、总磷、总氮）、清洗废水、锅炉废气、固废（废包装、残渣）。

**③ 特征污染因子**：废水——COD、氨氮、总磷、总氮、SS、动植物油、BOD₅；废气——锅炉 SO₂/NOx/颗粒物、恶臭（部分发酵/腌制）；固废——废原料、污泥。

**④ 评价等级关注点**：水（**核心**，高有机负荷，关注受纳水体与纳管可行性）；大气（锅炉、恶臭）；无重大风险；地下水/土壤（污水站、储罐防渗）。

**⑤ 治理措施要点**：**生化处理为主**（厌氧+好氧，如 UASB+A/O）；优先间接排放（纳管）；锅炉烟气治理；污泥脱水处置。

**⑥ 两证衔接特别注意**：咬合点3（排放去向）——间接排放须有纳管协议，直接排放须论证受纳水体容量；咬合点5（总量）——COD、氨氮总量不超环评批复；咬合点6（措施）——污水站与纳管要求须写入排污许可。

## 16. 生活垃圾焚烧

**① 专项导则说明**：**无专项行业环评技术导则**，执行总纲 + 要素导则（排放执行 GB 18485《生活垃圾焚烧污染控制标准》；排污许可焚烧类参照 HJ 1034；有生活垃圾焚烧发电项目环评审批原则作政策依据）。

**② 工程分析要点**：垃圾接收贮存→焚烧炉（炉排炉/流化床）→余热锅炉→烟气净化→发电→渗滤液处理→灰渣处置。重点：烟气（酸性气体、二噁英、重金属、恶臭）、渗滤液、飞灰（危废）、炉渣。

**③ 特征污染因子**：废气——颗粒物、SO₂、NOx、HCl、HF、CO、二噁英类、重金属（Hg/Pb/Cd 等）、NH₃（脱硝逃逸）、恶臭；废水——渗滤液（COD、氨氮、总氮极高）；固废——飞灰（危废，须固化/螯合后填埋）、炉渣。

**④ 评价等级关注点**：大气（**核心**，二噁英、重金属、恶臭，关注最大落地浓度、防护距离与敏感点）；地下水/土壤（渗滤液、飞灰填埋，重点防渗）；风险（渗滤液泄漏、恶臭）；水（渗滤液处理达标与回用）。

**⑤ 治理措施要点**：烟气"SNCR/SCR 脱硝 + 半干法脱酸 + 活性炭喷射 + 布袋除尘"（二噁英、重金属协同去除）；渗滤液"厌氧+膜处理"达标（优先回用）；飞灰稳定化后送危废填埋场；恶臭收集处理。

**⑥ 两证衔接特别注意**：咬合点2（因子）——二噁英类、重金属、HCl/HF 等特征因子须全部纳入；咬合点4（限值）——执行 GB 18485 限值（含二噁英、Hg 等），地方加严执行加严值；咬合点5（总量）——大气污染物总量不超环评批复；咬合点6（措施+监测）——焚烧炉 CEMS（颗粒物/SO₂/NOx/CO/HCl 等）、二噁英定期监测、飞灰处置去向须写入排污许可与自行监测。

## 17. 医院 / 医疗废物处置

**① 专项导则说明**：**无专项行业环评技术导则**，执行总纲 + 要素导则（医院、医废处置均按总纲+要素导则审查；医废处置可参照危险废物治理相关审查要求）。

**② 工程分析要点（医院）**：门诊/住院/化验/影像/洗衣/锅炉；废水（含病原体的医疗污水）、废气（污水处理站恶臭、消毒废气）、医疗废物（感染性、损伤性、药物性、化学性）。
**工程分析要点（医废处置）**：收集→转运→处置（焚烧/高温蒸汽/微波/化学消毒）；焚烧烟气、消毒废水、残渣。

**③ 特征污染因子**：医院废水——粪大肠菌群、肠道致病菌、肠道病毒、余氯（消毒）、COD、氨氮、SS；废气——恶臭、病原微生物气溶胶；医废焚烧——二噁英、重金属、酸性气体、VOCs、恶臭；固废——医疗废物（**危废**，代码须准确）。

**④ 评价等级关注点**：大气（恶臭、病原微生物，关注周边居民与敏感人群）；水（**核心**，医疗污水须消毒达标，关注受纳水体与敏感水体）；地下水/土壤（污水站、医废贮存防渗）；风险（病原微生物、危废泄漏）。

**⑤ 治理措施要点**：医院——污水处理站（二级处理+消毒，如次氯酸钠/二氧化氯）、污泥消毒、危废分类贮存委外；医废处置——焚烧尾气急冷+活性炭+布袋、废水消毒、残渣按危废。

**⑥ 两证衔接特别注意**：咬合点2（因子）——粪大肠菌群等微生物指标、余氯须纳入；咬合点3（排放口）——医疗污水排放口与环评一致，禁止私设；咬合点6（措施+监测）——污水处理设施、消毒要求、危废（医疗废物）代码与处置去向、污水监测频次须写入排污许可；医废处置的焚烧炉 CEMS 与二噁英监测须纳入。

**使用链路**：拿到环评文件 → ① 用本总库定位行业专项导则（有则查原文，无则按总纲+要素） → ② 对照《环评技术导则体系与审查要点.md》做文件质量审查 → ③ 用《两证衔接指南》6大咬合点核对环评与排污许可一致性 → ④ 参考《79行业技术审查指南索引》核对该行业排污许可规范（HJ 8xx 申请规范、HJ 9xx 自行监测、源强核算指南）。

## 2. 专项环评导则编号以官方为准

- 本总库所引专项环评导则编号（如 HJ 708-2014、HJ/T 89-2003、HJ 611-2011、HJ 582-2010、HJ 619-2011、HJ/T 88-2003、HJ 1358-2024、HJ 87-2023、HJ 453-2008 等）均依据生态环境部公开文本核对，但**最终以生态环境部正式发布的标准文本及编号为准**。
- 标注"（待核实）"的行业（如铁路专项导则 HJ 号、油气开采、毛皮制鞋等），审查前须核实现行有效编号，不凭本表直接引用。
- 标注"无，执行总纲+要素导则"的行业，**并非无审查依据**——仍须严格执行：
  - 总纲：HJ 2.1-2016
  - 要素导则：HJ 2.2-2018（大气）、HJ 2.3-2018（地表水）、HJ 2.4-2021（声）、HJ 610-2016（地下水）、HJ 964-2018（土壤）、HJ 19-2022（生态）
  - 专题导则：HJ 169-2018（环境风险）
  - 本行业**排污许可证申请与核发技术规范**（HJ 8xx）与**自行监测技术指南**（HJ 9xx）、**污染源源强核算技术指南**——用于两证衔接一致性核对。

## 3. 特别提示

1. **区分两套"导则/规范"**：行业环评技术导则（HJ 2.1/708/611/582 等，管事前）≠ 排污许可申请与核发技术规范（HJ 855/853/860 等，管许可）。审查时两套都要用到，但不可互相替代。
2. **多数行业确无专项环评导则**：如实按"总纲+要素"审查即可，不必强行寻找不存在的专项编号；重点是把特征污染因子、一类污染物、风险识别齐全，并与排污许可 6 大咬合点对齐。
3. **技术审查意见 ≠ 审批决定**：本总库供技术审查与两证衔接核对参考，环评审批与排污许可核发以生态环境部门决定为准；不做环评审批本身的准入判断（选址、产业政策、总量区域平衡以环评审批环节为准）。
4. **无环评/未批先建项目**：按《两证衔接指南》第五部分"衔接特殊情形"处理，排污许可不得突破环评或违规核发。
