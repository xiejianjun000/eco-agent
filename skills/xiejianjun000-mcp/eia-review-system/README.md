## 🔑 六大审查支柱

1. **技术导则遵循度** — 评价等级判定、导则条款执行
2. **污染因子全识别** — 特征因子无遗漏、产污节点全覆盖
3. **排放标准适用性** — 标准正确、限值取严、无废止标准
4. **总量控制合理性** — 核算方法正确、与总量文件衔接
5. **污染防治措施可行性** — 技术可行、依托可行、长期稳定达标
6. **许可证载明事项完整性** — 因子/限值/监测/台账/执行报告/排放口信息齐全
