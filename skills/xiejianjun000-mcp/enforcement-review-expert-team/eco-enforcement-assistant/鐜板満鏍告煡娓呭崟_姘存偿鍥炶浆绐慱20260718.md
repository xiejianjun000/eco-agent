# 现场核查清单（水泥回转窑 · 自动监测异常 + 脱硫设施线索）

> 调用知识库：`onsite-checklist` / `9种现场异常信号识别` / `采样程序合法性审查`(废气6D/3D) / `证据链闭环核验`
> 案件来源：2026-03 自动监测异常线索排查（累计超标99次、工况标记94次）+ 2026-07 排污许可合规检查（MF0002/0032/0018 脱硫塔低效疑似难稳定达标）
> 法律适用提示：**结案在 2026-8-15 前 → 引用旧《大气污染防治法》，严禁引已废止生态环境法典（一票否决）**

---

## 〇、核查准备（出发前）
- [ ] 人员：≥2 名执法人员持证；建议配监测人员；**保密、错峰突击**（防企业"提前表演运行"）
- [ ] 装备：执法记录仪 / 相机 / 便携打印机 / GPS；便携式烟气分析仪 + 标气；pH 试纸；废气采样设备（符 HJ/T 194）；询问提纲
- [ ] 资料：排污许可证副本（限值/排放口/监测要求）、环评+验收、近12月在线数据+运维记录、原辅材料/药剂发票、生产运行记录（电/水/产量）、厂区平面图（管网/隐蔽点）

## 一、设施运行核查（对标 信号1 设施"假运行"）
- [ ] 脱硫塔：药剂空桶/投加记录；**投加量 ÷ 处理水量**是否匹配；循环液 pH、液位；**进出口 SO₂ 浓度差**（有无"处理无效"平直曲线）；风机水泵电耗 vs 产量
- [ ] 除尘设施：布袋/电除尘运行、压差、清灰工况（对应颗粒物超标 68 次/占 68.7%）
- [ ] 脱硝：氨水/尿素耗量 vs NOₓ 超标（SCX05 达 18 次）
- [ ] 中控/DCS 运行曲线：与 94 次工况标记时段比对（标"停炉"时炉温/DCS 是否真降）
- [ ] 夜间/节假日是否真运行（突击核查）

## 二、台账核查（对标 信号2 穿越/复制 + 信号9 反向印证）
- [ ] 运行台账 vs 加药记录 vs DCS **三方比对**；查"整月同笔迹/周日满负荷"反常
- [ ] **工况标记原始记录**：94 次（停炉39/焖炉33/启炉22）与 DCS / 站房视频 / 用电曲线交叉 → 标记真实性判定
- [ ] 要求提供**原始记录**（非汇总表）；固定企业自认（截图、签字确认台账）
- [ ] 原辅材料购耗、危废转移联单（如涉）

## 三、在线监测核查（对标 信号3 数据失真）
- [ ] 站房视频回放：超标时段设施/采样是否真运行；采样时间比对
- [ ] 采样管：有无**旁路 / 清洗水稀释**；采样点位与许可证一致
- [ ] 运维台账 + 故障记录：是否长期"故障维修"却不停数据
- [ ] **标气/质控样突击测试**：数据是否失真
- [ ] 自动监测 vs 手工监测数据趋势比对

## 四、采样核查（对标 采样程序合法性审查 · 废气）
- [ ] 采样孔：避开弯头/阀门/变径，**下游 ≥6D、上游 ≥3D**（先测管径 D）
- [ ] 同步采样：颗粒物 + SO₂ + NOₓ **同点位同步**；覆盖正常工况与标记时段对照
- [ ] 质控：每批配**全程序空白 + 运输空白**；仪器在检定有效期内
- [ ] 见证人（当事人/第三方）在采样记录签字
- [ ] 采样同步录像 + GPS 定位；**快测仅作线索，不以之定案**

## 五、排污口核查（对标 信号6 暗道机关）
- [ ] 晴天查雨排口是否出水
- [ ] 沿墙根/绿化带/近期动土处查暗管/未申报口
- [ ] 管网图纸 vs 现状差异；应急排放通道非紧急是否开启
- [ ] SCX01/06、SCX05 排放口与许可证一致性

## 六、物料/水平衡核查（对标 信号7 逻辑矛盾）
- [ ] 产量 vs 排放量；用电/药剂 vs 处理规模 相关性分析
- [ ] 与同行业同规模企业对标

## 七、证据固化要求（对标 证据链闭环核验）
- [ ] 照片/录像注明：证明对象 / 时间 / 地点 / 拍摄人 / 证明内容
- [ ] 书证复制件注明"经核对与原件无误" + 提供人 + 执法人员签章
- [ ] 询问笔录**固定故意认定**（调用 企业博弈应对话术）；当事人逐页签字捺印
- [ ] **不以在线监测数据单独定案**；须手工 CMA 监测报告印证

## 八、合规红线（结案前必核）
- [ ] 结案日 < 2026-8-15 → 引旧《大气污染防治法》（§20 逃避监管 / §99 超标及逃避监管 / §100 不正常运行设施 / §108 篡改伪造监测数据）
- [ ] ≥2 人持证、保密错峰、见证人签字
- [ ] 单一证据不定案；复制件/视听资料合规
