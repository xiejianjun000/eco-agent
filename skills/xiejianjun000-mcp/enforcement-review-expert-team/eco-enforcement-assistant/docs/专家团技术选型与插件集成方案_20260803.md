## 三、两条业务线的插件映射矩阵

### 3.1 案卷评查线

```
案卷输入（PDF 扫描件 / Word 案卷）
    │
    ├── pdf ──→ OCR 提取卷宗文本（pages → text）
    ├── docx ─→ 读取结构化案卷（标题/段落/表格）
    │
    ├── summarize ──→ 长篇案卷自动摘要（识别关键事实/争议焦点）
    ├── qmd ──→ 检索历史相似案卷、先例评查结论、法规匹配
    ├── agent-browser ─→ 抓取裁判文书网同类案件参考
    │
    ├── 【领域 Skill】案卷评查 ─→ 合法性审查 + 一票否决扫描 + 规范性评分
    ├── 【领域 Skill】法律合规 ─→ 法条精准匹配（含法典双标注）
    │
    ├── docx ──→ 生成评查报告（彩色标题/分级表格/跟踪修订痕迹）
    ├── xlsx ──→ 输出问题清单、评分台账、扣分统计
    ├── pdf ──→ 合并证据附件材料
    ├── humanizer ─→ 公文语言润色（去 AI 味）
    │
    └── agent-mail ──→ 评查结果推送承办人
```

### 3.2 文档处理线

```
文档输入（环评报告 PDF / 监测数据 Excel / 法规文件 Word）
    │
    ├── pdf ──→ 拆分大型环评报告（按章节）/ 提取表格
    ├── docx ─→ 读取审批文书模板
    ├── xlsx ─→ 核对在线监测数据、排污量计算
    │
    ├── summarize ──→ 几百页环评报告浓缩为核心要点
    ├── nano-pdf ──→ 轻量修改已有 PDF（日期/批注/页码）
    │
    ├── pdfkit-py ──→ 批量处理（50 命令覆盖全部 PDF 操作）
    ├── pptx ──→ 督查汇报 PPT
    │
    └── tencent-docs ──→ 在线协作审阅
```
