### 2.2 认知升级

**原结构（碎片化）**：
```
法律法规 → 散落在各文件中
评查标准 → 需要查阅才能使用
典型案例 → 缺乏系统整理
实务经验 → 未形成方法论
```

**新结构（体系化）**：
```
┌─────────────────────────────────────────┐
│         核心原则（固化在MEMORY.md）         │
│  程序合法性优先 | 证据链思维 | 全链条追踪    │
└──────────────┬──────────────────────────┘
               ↓
┌─────────────────────────────────────────┐
│      判断标准（数值化、表格化、口诀化）      │
│  废水参数 | 废气参数 | 移送标准 | 期限规则  │
└──────────────┬──────────────────────────┘
               ↓
┌─────────────────────────────────────────┐
│          应用场景（分类案例库）              │
│  机动车造假 | 第三方造假 | 危废管理 | ...   │
└──────────────┬──────────────────────────┘
               ↓
┌─────────────────────────────────────────┐
│         风险防控（预警机制）                 │
│  法典施行 | 复议条例 | 起诉期限 | 高频扣分  │
└─────────────────────────────────────────┘
```

**决策流程优化**：
- 原流程：用户提问 → 搜索资料 → 阅读多个文档 → 整合信息 → 给出判断（分钟级）
- 新流程：用户提问 → 触发记忆检索 → 快速定位 → 查表验证 → 精准回答（秒级）

### 4.2 必须记住的核心规则

**程序合法性三大铁律**：
1. 采样程序不合法 = 行政处罚败诉首要原因
2. 一类污染物必须在车间排放口采样
3. 计量类仪器超期未检定的数据不具备法律效力

**移送公安两大标准**：
1. 重金属超标3倍以上：`(实测值-标准限值)/标准限值 ≥ 3`
2. 危废3吨以上：多次少量倾倒累计计算同样入刑

**败诉风险四大点**：
1. 采样程序不合法
2. 证据链不完整
3. 法律适用错误
4. 程序违法（未告知、超期、送达错误）

**告知义务五要素**：
1. 事实、理由、依据
2. 陈述权、申辩权
3. 听证权
4. 复议权（期限、机关）
5. 诉讼权（期限、法院）

### 4.3 必须记住的判断标准

**废水处理设施快速诊断**：
- SV30: 15%-30%正常，>50%污泥膨胀，<10%污泥老化
- DO（好氧段）: 2-4 mg/L正常，<1 mg/L硝化菌受抑制
- 指示生物: 钟虫、等枝虫出现 → 水质好

**废气处理设施快速诊断**：
- 布袋除尘器压差: 1000-2000 Pa正常，过低破损，过高堵塞
- RTO燃烧温度: ≥760℃正常，<760℃产生二次污染
- 活性炭碘值: ≥800 mg/g正常，使用>12个月降至<400 mg/g基本失效
