## 二、登录机制（已完整逆向）

### 关键发现：两步登录 + RSA 加密
不是普通的表单 POST，而是：

**第1步：AJAX 预验证**
- 端点：`POST /zfpt_zf/pages/platform/ajax.jsp?method=userValida`
- 参数（均为 RSA 加密后的值）：
  - `user` = RSA_encrypt(用户名)
  - `password` = RSA_encrypt(密码)
  - `valicode` = 验证码
- 返回 JSON：`{result: "true", userid: "..."}` 表示验证通过

**第2步：表单提交**
- 端点：`POST /zfpt_zf/login.do`
- 参数：`method=authenticate`, `needValicode=true`, `needpriCode=false`, `org.apache.struts.taglib.html.TOKEN=...`, `userid=RSA(用户名)`, `password=RSA(密码)`, `valicode=验证码`

### RSA 加密细节
- **公钥**（PEM/DER 格式，写在 `login.js` 里）：
  ```
  MFwwDQYJKoZIhvcNAQEBBQADSwAwSAJBAKPsJh9rvDq7CIKjjvtsS6YndC52KPis14uFdrsWP7YlMB01nI+w4LCiFOj5BzJCCeahZiVO/xqxuMHm1O2e9NMCAwEAAQ==
  ```
- **算法**：RSA + PKCS#1 v1.5 填充（JSEncrypt 默认）
- **后处理**：加密后的 base64 中 `+` 替换为 `@`（与 JS `passwordRSA.replace(/\+/g, "@")` 一致）
- Python 实现：`cryptography` 库 `asym_padding.PKCS1v15()`；Node 实现：`crypto.publicEncrypt` with `RSA_PKCS1_PADDING`

### 验证码
- 端点：`GET /zfpt_zf/initIndex.do?method=code`
- 95×25 像素，4-5位字母数字混合（区分大小写）
- 每次请求刷新，约 15 次自动识别中可蒙对 1 次（ddddocr 准确率约 20%）
- **人工读图准确率高**（image 工具读图后手动输入验证码可稳定通过"验证码不正确"校验）
