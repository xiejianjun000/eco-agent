## 二、对金竹山电厂案的核心补齐（5 大短板）

### 短板 1：工况标记规则与豁免认定标准 ✅ 已补齐

**补齐内容**：
- **《污染物排放自动监测设备标记规则》**（生态环境部公告 2022 年第 21 号，2023-01-01 施行）
  - 第六条明确两类豁免情形：
    1. 设备标记规则标记为**无效** → 不作为超标判定依据
    2. 工况标记规则标记为**非正常工况** + 设施达标 + 限定时间内 → 不作为超标判定依据
  - 第四条：非正常工况 = 生产设施或污染防治设施的**启停机、故障**
  - 第五条：**每日 12 时前**完成前一日数据的人工标记，逾期视为对有效性无异议
  - 标记 = 向生态环境主管部门**主动报告异常情况**

- **《启停炉超标豁免认定标准》**（执法实务）
  - **豁免三大条件**（缺一不可）：
    1. 须如实进行工况标记（DCS 曲线 + 操作记录须与标记一致）
    2. 污染防治设施须达到标准要求（启炉期间颗粒物 ≤ 150mg/m³）
    3. 须在限定时间内（火电启动 ≤ 4h，可延至 8h；停机 1h）
  - **执法认定关键**：
    - 不同污染因子豁免范围不同（锅炉仅豁免 NOx，颗粒物/SO₂ 未明确）
    - 豁免 ≠ 免责（河北省执法局明确：需依法调查，符合免罚条款才可免罚）
    - **DCS 曲线核验是必查项**（若 DCS 显示仍在投料但标记为"停炉" → 涉嫌弄虚作假）

**对金竹山案的补齐**：
- 大唐电厂 24 次"启动"工况标记 → 需核实：
  1. 是否在**每日 12 时前**完成标记？
  2. 标记时段是否**真实启炉**？（DCS 曲线 + 电力调度日志核验）
  3. 启炉时段是否**在限定时间内**？（火电 ≤ 4-8h）
  4. 启炉期间污染防治设施是否**达标运行**？
- 若 DCS 显示仍在生产但标记为"启动" → **工况标记造假** → 伪造自动监测数据

### 短板 2：DCS 曲线取证指引 ✅ 已补齐

**补齐内容**：
- **《DCS 曲线取证指引——在线监测执法证据固定》**
  - **核心逻辑**："透过数据看工况、透过工况查合规"
  - **三大应用场景**：
    1. 核验工况标记真实性（停炉 = 窑温下降 + 投料停止 + 氧含量升高）
    2. 发现隐蔽数据造假（修改参数 / 植入造假软件 → DCS 工况参数与排放数据逻辑一致性分析）
    3. 穿透式监管（淄博案：调取湿电除尘装置电压曲线 + 视频监控 → 认定人为干扰在线设备）
  - **取证内容**：
    - DCS 历史曲线（启停炉时段、异常排放时段前后 1 小时）
    - 运行参数（温度 / 投料量 / 氧含量 / 电压 / 电流 / pH 值）
    - 排放数据（CEMS 同步数据）
    - 操作日志 / 运维记录
  - **证据链闭环**（五环闭合）：
    - 现场笔录 → 拍照录像 → 书证调取 → 手工比对监测 → 询问笔录
  - **新趋势**：
    - 从"末端数据核查" → "全过程工况溯源"
    - 融合在线监测 + DCS + 分表计电 + 视频
    - AI 智能取证（宁夏宁东研发固定污染源异常数据 AI 分析核验系统）

**对金竹山案的补齐**：
- 现场 DCS 取证要点：
  1. 调取 2 号/3 号炉**蒸发量 / 主蒸汽温度压力 / 给煤量 / 给风量 / 炉膛温度 / 机组负荷**等曲线
  2. 对比"标记为启动"时段与"正常运行时段"的 DCS 参数
  3. 若曲线一致 → 启动标记为虚假 → **工况标记造假**
  4. 调取**湿电除尘装置电压曲线**（类似淄博案）
  5. 结合**分表计电 + 视频监控**穿透验证

### 短板 3：污染源自动监控执法取证指引 ✅ 已补齐

**补齐内容**：
- **《污染源自动监控执法取证指引》**
  - **法律地位**：
    - 《排污许可管理条例》第 23 条：自动监测数据可作为超标判定证据
    - 《生态环境行政处罚办法》第 30 条：经过标记的自动监测数据可作为认定案件事实的证据
    - **同一时段数据冲突处理**：现场监测数据优先
  - **数据标记规则体系**（"1+N"）：
    - "1"：设备标记规则（适用于所有行业）
    - "N"：分行业工况标记规则（生活垃圾焚烧 / 火电 / 水泥 / 造纸 等）
  - **现场检查程序**（第 13 条 + 第 15 条）：
    - 排放口规范化 / 自动监控设施建设 / 变更 / 运行状况 / 运维记录 / 资质证书 / **生产工况与数据相关性**
    - 查看测听问录六字法
  - **关键证据固定**（2023 征求意见稿新增）：
    1. 物证书证（篡改工具 / 不明设备 / 运行记录）
    2. 视听资料电子数据（站房视频 / 历史数据 / 操作日志 / 干扰行为视频）
    3. **能够证明当事人主观故意的证据**：
       - 从业经历 / 业务培训 / 对违法性质的了解程度 / 造假手段获取途径
       - 违法行为被发现后是否存在**转移 / 灭绝 / 删除证据**
    4. 能够证明后果严重的证据：
       - 多次或长期造成系统不能正常运行 / 多次删除修改操作 / 违法所得 ≥ 5000 元
  - **自动监测数据作为证据的条件**：
    1. 设备依法安装并通过验收
    2. 设备正常运行并经有效性审核
    3. 数据按规定标记
    4. 采集 / 传输 / 存储符合 HJ 212 等技术规范
    5. 数据未被篡改伪造

**对金竹山案的补齐**：
- 现场取证清单（10 类核心证据已补齐）：
  - CEMS 工况标记历史 + 浓度分钟级数据
  - DCS 连续生产曲线
  - 电力调度日志
  - 入炉煤量台账
