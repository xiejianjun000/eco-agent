## 三、任务办理闭环流程（第45-49页）

```
线索产生 → 3.3.3 任务指派 → 3.3.4 任务核实 → 3.3.5 核实确认 → 3.3.6 问题整改
              ↓                     ↓                 ↓
         省级→市级→区县       属地在线填报       属实→省级确认
                             佐证材料上传       不属实→部级确认
```

### 关键规则
- **非本级任务**：可查看全流程流转记录
- **核实提交**：核实信息→保存暂存→确认提交→进入上级确认环节
- **省级核实为属实/部分属实**：二次确认后办结
- **不属实任务**：部级确认后才完成

## 六、与执法督察评查工作的关联分析

### 6.1 涉重金属排放执法（第38-44页）→ 移送公安前置环节
- 涉重金属企业线索的发现→核实→派发→办理，是"重金属超标3倍入刑"的案前线索来源
- 线索导入、批量派发的流程决定了**线索来源合法性**和**程序合规性**
- **案卷评查关键点**: 线索导入时间、派发记录、核实结论、佐证材料上传完整性

### 6.2 断面水质异常溯源（第18-25页）→ 暗管偷排取证
- 模型溯源+人工溯源可定位上游异常排污单位
- 溯源到入河排污口→工业企业明细→直排情况，形成**证据链闭环**
- **督察实战应用**: 现场发现河段异常→使用溯源工具定位来源→结合现场执法固定证据

### 6.3 任务闭环证据链（第45-49页）
- 从线索到任务到核实到确认到整改的**全流程留痕**
- 每一环节的**佐证材料上传**要求→倒逼执法规范化
- **败诉风险防控**: 任务办理记录本身就是程序合法的证据

### 6.4 自动监测执法（第9-13页）→ 数据造假识别
- 在线监测数据异常→线索产生→任务核实
- 企业排放详情（原辅料、产能、治理设施）为**物料衡算**提供数据支撑
