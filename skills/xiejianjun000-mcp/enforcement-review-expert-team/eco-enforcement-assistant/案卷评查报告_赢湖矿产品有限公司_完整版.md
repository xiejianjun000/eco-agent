#### 🔴 整改项③：现场检查记录检查主体错误

**问题描述：**
> 现场检查记录中的检查主体（执法机关名称）填写不准确，应为"娄底市生态环境局"。

**为什么这是高严重性问题？**

| 分析维度 | 说明 |
|---------|------|
| **法律后果** | 根据《行政诉讼法》第七十条，行政行为"适用法律、法规错误的"或"违反法定程序的"，法院可判决撤销或部分撤销。检查主体错误属于**执法主体表述错误**，可能被认定为程序瑕疵甚至导致执法行为无效 |
| **实务影响** | 如当事人以该瑕疵为由提起行政复议或诉讼，复议机关/法院可能以此质疑整个现场检查环节的合法性 |
| **发生原因推测** | 冷水江分局作为娄底市生态环境局的派出机构，执法人员习惯性填写"娄底市生态环境局冷水江分局"或"冷水江市生态环境保护综合行政执法大队"，而未使用法定主体名称"娄底市生态环境局" |
| **正确做法** | 根据《行政处罚法》和湖南省行政执法公示制度，对外执法文书的主体名称应当填写**具有独立行政执法主体资格的机关全称**，即"娄底市生态环境局" |

**⚠️ 关联风险：**
- 如果现场检查记录的主体错误未被纠正，则基于该检查记录作出的**后续全部程序**（立案→调查→审核→决定）都可能受到"连坐"效应
- 但从本案实际情况看，处罚决定书的主体（娄底市生态环境局）是正确的，因此**实体处理结果不受影响**

**建议补正方式：**
1. 在现场检查记录上由执法人员作出**更正说明**并签名注明日期
2. 或在法制审核阶段提交《情况说明》，解释系笔误并确认实际执法主体无误

|---------|------|
| **法律意义** | "案源"即案件的来源渠道，直接影响**管辖权**和**立案合法性**。常见案源包括：日常巡查发现、群众举报、上级交办、部门移送、媒体曝光等。不同案源的初核要求和时限不同 |
| **可能的矛盾情形** | 立案审批表写的是"A类案源"（如"上级交办"），而案件审查表写的是"B类案源"（如"日常检查发现"）。这种不一致可能意味着：① 两表由不同人员填写，信息沟通不畅；② 案件来源确实复杂（既有上级督办的背景，也有日常检查的直接触发）；③ 简单的笔误 |
| **对本案的影响** | 无论哪种案源，娄底市生态环境局对辖区内排污单位的违法行为均有管辖权，因此**不影响实体管辖权**。但案源不一致反映出**内部文书管理不够严谨** |
| **司法实践中的态度** | 在行政复议/诉讼中，案源不一致通常不导致撤销处罚决定（除非涉及管辖权争议），但会被作为"执法不规范"的典型例子在裁判文书中指出 |

**建议补正方式：**
1. 核查两表的原始填写内容，确认哪个准确
2. 由承办人在案件审查表上作出**更正**或附《情况说明》统一表述
3. 在今后工作中建立"一案一表"的信息一致性核对机制

## 八、总体评价（完整版）

### 8.1 案件质量综合评价

**评分：93分 / 等级：优秀**

本案是一起典型的**重污染天气预警期间违反排污许可管理规定**的行政处罚案件，代表了基层生态环境执法的较高水平。

### 8.2 亮点（做得好的方面）

| 维度 | 具体表现 | 评价 |
|------|---------|------|
| **证据链完整性** | 预警文件→微信通知→现场检查→笔录→照片→督导清单→解除公告，形成完整闭环 | ⭐⭐⭐⭐⭐ |
| **三级法制审核** | 案件审查(P84-85)→法制审核意见书(P86-87, 7项整改)→法制复核(P88)，层层把关 | ⭐⭐⭐⭐⭐ |
| **法律顾问参与** | 谢琳律师独立签字审核，体现外部监督 | ⭐⭐⭐⭐ |
| **集体决策规范** | 案审会第八次会议，苏建主主持，11人全到，4案集体审议 | ⭐⭐⭐⭐⭐ |
| **裁量透明可验** | 各因子均为0%，计算过程清晰，与同类案件尺度一致 | ⭐⭐⭐⭐⭐ |
| **当事人权利保障** | 听证告知→放弃权利→催告→缴款→结案，全流程规范 | ⭐⭐⭐⭐ |
| **后督查落实** | 12-17后督查拍照确认停产，体现"处罚与改正相结合" | ⭐⭐⭐⭐ |

### 8.3 不足（需要改进的方面）

| 维度 | 具体表现 | 评价 |
|------|---------|------|
| **基础文书质量** | 法制审核一次性发现7项问题，反映初次制作不够严谨 | ⚠️ 需加强 |
| **信息一致性** | 姓名（杨根飞vs杨程云）、案源、法定代表人简称等多处不一致 | ⚠️ 需加强校核 |
| **签名规范性** | 涂改、缺年份、异常标记等 | ⚠️ 需培训 |
| **立案时效** | 检查到立案间隔3天 | ⚠️ 可缩短 |

### 8.4 同批次案件横向对比启示

案审会第八次会议同时审议了4起案件，其中**赢湖矿产品与明桓矸石砖厂**完全同案由、同条款、同罚款，而芊林农业科技适用"首违不罚"不予处罚。这说明：

1. **裁量尺度统一**：同类违法行为同等对待，无明显畸轻畸重
2. **差异化处置得当**：对"未批先建"首犯适用不处罚政策，对"预警期间违规生产"依法处罚，体现了过罚相当原则
3. **批量审理效率高**：4案一次会议审议，程序集约化

### 8.5 对今后执法工作的建议

1. **推行"文书自查清单"**：在送审法制部门前，承办人按清单逐项核对（主体名称、案源、当事人信息、签名日期等）
2. **建立"标准文本模板库"**：现场检查记录、接受调查通知书等常用文书使用模板，减少手写/自由填写导致的错误
3. **强化"信息一致性核对"**：立案审批表→案件审查表→案审会纪要中的关键信息（当事人姓名、案源、违法行为、法律依据）应当逐表一致
4. **缩短"查立间隔"**：现场发现违法线索时，力争当日完成立案审批
5. **完善整改闭环验证**：法制审核提出的整改意见，应在补正后附《整改完成确认表》，便于日后查验
