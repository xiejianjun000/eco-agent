## 〇、案件定性预判

**行为本质**：在线监测不正常运行（擅自停运 / 干扰自动监控设施 / 数据失真）＝「以逃避监管方式排放污染物」的典型表现，常伴随篡改、伪造监测数据。

- **关联法条（现行有效，至 2026-8-14；✅ 已 kb_read 滯源核验）**：
  - 《环境保护法》第四十二条（严禁篡改伪造监测数据/逃避监管方式排污）、第六十三条（逃避监管→移送公安 5-15 日行政拘留）
  - 《大气污染防治法》第二十条（禁止篡改伪造监测数据等逃避监管方式排放）、第二十四条（重点排污单位应安装废气自动监测并联网）、第九十九条（10万—100万 + 责令改正/停产整治）
  - 《水污染防治法》第二十三条（重点排污单位应安装自动监测并联网）、第三十九条（禁止篡改伪造监测数据逃避监管排放）、第八十三条（10万—100万）
  - 《刑法》第三百三十八条（污染环境罪）、第二百八十六条（破坏计算机信息系统罪）
- **案由归类**：一般行政处罚 ＋（符合情形）移送拘留 ＋（涉刑）移送涉嫌环境污染犯罪
- **关联知识库文件**：`concepts/在线监测.md`、`concepts/按日连续处罚.md`、`concepts/enforcement/违法排污行政拘留意见.md`、`entities/典型案例_2026-07-10.md`（在线监测数据造假）、`entities/典型案例_2026-07-11.md`（自动监测造假移送量化）
- **区分说明**：`cases/清河市永丰纸业有限公司环保设施不正常运行案.md` 属「污染治理设施（防治设施）不正常运行」类，与本案（在线监测/自动监控设施不正常运行）**分属不同行为**，证据重心在设施运行/药剂/电耗/污泥，非监测设备，本案不混用其作为锚点。

## 二、现场取证方案（本案核心）

### 2.1 在线监测异常信号识别（9 种异常信号之「在线监测异常」）

- **O₂ 含量恒为 21.0%** → 采样管漏气（空气稀释，数据被人为拉低）
- **监测数据长时间恒定不变 / 与工况明显背离** → 设备停摆或数据造假
- **频繁校准、标气异常** → 掩盖失真
- **采样管路稀释、旁路、喷淋** → 稀释排放 / 干扰采样
- **擅自停运、拆除、改动设备、屏蔽数据** → 不正常运行
- **工控机 / 数采仪参数被篡改、数据被删除或修改** → 篡改监测数据

> 关联：`concepts/eco_import/环境监测.md`（禁止篡改伪造监测数据）、`sources/污染源自动监控数据弄虚作假执法取证指引.md`

### 2.2 证据链闭环设计（五环闭合）

1. **现场笔录**：时间 / 地点 / 设备状态 / 指示灯 / 屏幕数据 / 管路接口；当事人逐页签字
2. **拍照录像**：全景（站房）→ 近景（设备屏幕 / 管路接口）→ 特写（O₂ 读数 / 参数设置）+ 时间戳 + 参照物
3. **书证调取**：自动监控原始数据、数采仪存储、运维台账、校准记录、试剂更换记录、工控机操作日志、运维合同、设备验收及最近校准证书
4. **监测报告**：必要时同步手工比对监测（同一排放口），用数据偏差印证失真
5. **询问笔录**：固定「谁、何时、为何」停运 / 改动 → **故意认定**（企业博弈 / 故意认定话术）

> 风险点：单一证据不得定案；须 现场笔录 + 询问笔录 + 原始数据 + 运维台账 + 监测报告 多证相互印证。

### 2.3 知识库关键依据

- **《污染源自动监控数据弄虚作假执法取证指引》**（KB：`sources/污染源自动监控数据弄虚作假执法取证指引.md`）：
  - 两高司法解释第一条：重点排污单位篡改、伪造自动监测数据或干扰自动监测设施，排放 COD、氨氮、SO₂、NOx 等污染物 → 认定为「严重污染环境」
  - 两高司法解释第十条：针对环境质量监测系统修改参数、干扰采样等 → 以破坏计算机信息系统罪论处
- **《环境监测数据弄虚作假行为判定及处理办法》**（环发〔2015〕175号，KB：`sources/环境监测数据弄虚作假行为判定及处理办法.md`）：
  - 伪造监测数据：凭空编造监测数据、原始记录等
  - 篡改 vs 伪造的界定（决定定性与移送路径）
- **《违法排污行政拘留意见》**（KB：`concepts/enforcement/违法排污行政拘留意见.md`）：暗管 / 渗井 / 渗坑排放 ＋ 篡改 / 伪造监测数据 → 移送公安，罚款 10 万—100 万元

## 三、程序节点把控

告知 →（听证）→ 法制审核 →（集体讨论）→ 决定 → 送达

- **事先告知五要素**：事实 / 陈述申辩 / 听证 / 复议 / 诉讼（复议机关 + 诉讼法院 + 期限须准确）
- **期限**：陈述申辩 ≥3 日、听证 ≥5 日；听证期满前不得作出处罚决定；决定后依法送达
- **法制审核**：事实 / 证据 / 法律 / 程序实质审查（注意 KB 永丰纸业案评查中「法制审核指出 7 项问题需核实」的教训）
- **集体讨论**：情节复杂 / 重大违法 / 较大数额罚款

## 五、移送标准（拘留 / 犯罪）

- **移送行政拘留**：以逃避监管方式排污（含不正常运行 / 篡改伪造数据）→ 对直接责任人拘留（环境保护法第63条 / 法典拘留条款）
- **移送涉嫌犯罪（两高司法解释）**：重点排污单位 ＋ 干扰自动监控设施 / 篡改伪造数据 ＋ 排放 COD/氨氮/SO₂/NOx → 「严重污染环境」→ 移送公安
- **移送拘留案卷评查要点**（KB：`playbooks/enforcement/移送拘留案卷评查.md`）：**拘留关乎人身自由，证据标准最高；任一核心项命中 = 整体零分 + 面临国家赔偿风险** → 证据须铁证（原始数据 + 操作日志 + 运维记录 + 询问相互印证）

## 六、败诉风险防控（四大风险点）

1. **采样 / 取证程序不合法（败诉首要原因）**：在线监测数据作为定案依据的合法性 —— 设备是否检定 / 校准、数据是否可证明未被篡改、取证过程是否全程留痕。
2. **证据链不完整**：严禁单一证据定案；须多证印证（见 2.2）。
3. **法律适用错误**：废止法引用红线（8-15 后）、篡改 vs 伪造定性准确、拘留 / 犯罪移送标准把握。
4. **程序违法**：未告知权利、超期办案、送达错误（回证不完整）。
