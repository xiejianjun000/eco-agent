## 一、执法核心原则（必须遵循）

### 1.1 程序合法性优先
- **采样程序不合法是行政处罚败诉的首要原因**
- 一类污染物必须在车间排放口采样（总铬、六价铬、总镍、总镉、总银、总铅、总汞、总砷）
- 采样孔位置：距弯头/阀门/变径管下游≥6D、上游≥3D
- 样品保存：废水4℃冷藏、24小时内送检，每批配全程序空白+运输空白
- **计量类仪器须定期检定/校准，超期未检定的数据不具备法律效力**

### 1.2 证据链思维
- 单一证据不具备独立性，需形成**书证+物证+视听资料相互印证**的闭环
- 水平衡异常（用水量远超排水量+蒸发量）→ 暗管偷排信号
- O₂含量恒为21% → 采样管漏气（在线监测造假）
- 电耗突然下降、药剂消耗为零 → 不正常运行设施

### 1.3 全链条追踪（危废执法）
- **五步核实**: 产生 → 分类 → 贮存 → 转移 → 处置
- **五联单制度**: 第一联产生单位留存、第二联移出地环保部门、第三联接受单位留存、第四联接受地环保部门、第五联返还产生单位
- **贮存期限**: 危废贮存不得超过1年（确需延长需报批）
- **台账保存**: 危废管理台账保存至少10年

## 三、移送公安量化标准

### 3.1 重金属超标入刑标准
- **超标3倍以上**: `(实测值-标准限值)/标准限值 ≥ 3`
- 计算示例：排放标准0.5 mg/L，实测值≥2.0 mg/L即入刑

### 3.2 危废入刑标准
- **3吨以上**: 多次少量倾倒累计计算同样入刑
- 鉴别关键：毒性、腐蚀性、易燃性、反应性、感染性

## 五、行业特性关键点

### 5.1 电镀行业
- **分质分流是核心**: 含铬、含氰废水必须单独收集处理
- 含铬废水还原反应pH 2.5-3.0
- 含氰废水一级破氰pH 10-11
- 一类污染物在车间排放口采样，不在总排口

### 5.2 印染行业
- 退浆、丝光废水COD数万mg/L，需独立预处理设施
- 污水处理站废气（硫化氢、氨、臭气）需生物除臭+活性炭吸附

### 5.3 化工行业
- 高盐废水未经脱盐直接生化会导致微生物渗透压失衡死亡
- 危废种类多：HW06废有机溶剂、HW08废矿物油、HW49废活性炭等

### 5.4 火电行业
- 脱硫废水重金属、氯离子含量高，需单独处理
- 灰渣贮存场需防渗防尘

## 十七、执法战略博弈知识体系（2026-07-14新增）

### 17.1 博弈论核心概念与执法应用
- **囚徒困境**：企业间串供/集体违法时，各自的最优选择导致集体最坏结果 → 执法者可通过提高"背叛代价"打破均衡
- **信号甄别**：企业在询问中的主动表态是信号，需要甄别真实意图（合规意愿 vs 试探底线）
- **激励机制设计（激励相容）**：让守法企业获得比较优势，让违法成本持续高于合规成本
- **重复博弈**：建立稳定的"违规→必被查→成本固定"预期，比偶发严惩更有效
- **可信威胁**：对多次违规企业，需要发布"可置信的威胁"（如提请按日连续处罚），而非口头警告

### 17.2 谈判力（Getting to Yes）执法应用
- **把人与事分开**：企业负责人≠企业违法行为；先解决情绪，再谈处理方案
- **聚焦利益而非立场**：企业要"不罚款"是立场；背后的利益是"现金流压力"和"市场声誉" → 可探讨分期整改换减轻处罚
- **创造多选项**：避免"要么全罚要么不罚"的二选一；提供整改承诺书+分期执行等中间选项
- **使用客观标准**：以国家标准、行业惯例、历史数据说话，而非主观裁量
- **BATNA（最佳替代方案）**：执法人员自身的BATNA = 充分固证的案卷 → 底气来源于证据质量

### 17.3 清单革命执法应用
- **执法履职免责清单**：每项检查任务逐项打勾 → 证明"我做了该做的"，避免渎职认定
- **现场检查标准化清单**：不漏项、不遗漏关键点位 → 证据链完整的程序保障
- **采样质控清单**：采样时间/位置/仪器编号/保存方式/运输条件 → 应对企业事后质疑采样程序
- **部门联动清单**：联合检查前明确各方职责 → 避免推诿和证据归属争议

### 17.4 组织协同与基层治理
- **合作惰性四大根源**：领地意识/解决方案偏见/信任赤字/不对等回报 → 行刑衔接中的常见堵点
- **按需集成（Lean Integration）**：不是所有部门都需同等协作强度 → 按案件需求精准配置协同资源
- **差序格局（费孝通）**：县域/乡镇企业的人情网络 → 执法者需理解"波纹外推"式信任结构
- **礼治 vs 法治**：基层首次轻微违规时，可借"长老调解"路径替代直接处罚，降低对抗
- **乡土欲望 vs 理性计算**：企业违法行为有时是文化欲望驱动，而非理性成本收益计算

## 十八、系统思维与认知科学（2026-07-14新增）

### 18.1 系统循环图（CLD）执法诊断
- **存量（Stock）**：污染负荷、环境容量、群众健康损害 → 随时间积累
- **流量（Flow）**：排放量（in）vs 净化量（out）→ 关键杠杆在"out"
- **增强回路**：企业越多违规→监管越严→合规成本越高→更多企业想偷排（恶性循环）→ 政策杠杆：降低合规成本
- **平衡回路**：排放增加→环境恶化→舆情压力→监管加强→排放减少 → 被动响应滞后
- **延迟效应**：政策出台→企业适应→效果显现，中间存在长时滞 → 督察需预判延迟
- **杠杆点**：干预成本最低、效果最大的节点 = 改变系统结构的设计（如改变激励而非加强处罚）

### 18.2 认知偏差与执法纠偏
- **锚定效应**：先听到的数字会影响后续判断 → 询问笔录中避免先报数字
- **确认偏误**：倾向收集支持已有判断的证据 → 主动搜寻"不支持"的证据
- **WYSIATI**（所见即世界）：用可得性信息代替真实概率 → 低估小概率高风险事件
- **过度自信**："我们查过没问题"的盲目自信 → 清单化检查程序强制穷尽
- **沉默的证据**：被发现的只是少数 → 不能因为"很少查到问题"就判断"问题很少"
- **强制系统2介入**：关键决策点设置冷却期，要求书面记录推理过程

### 18.3 环境伦理底座
- **施韦泽"敬畏生命"**：执业价值不只服务于人类健康，更在于人与自然的关系
- **利奥波德"土地伦理"**：土地共同体中的人类只是普通成员，生态整体性具有内在价值
- **深层环保 vs 浅层环保**：浅层=人类工具理性（治理污染为了人类健康）；深层=生态中心主义
- **对执法工作的伦理支撑**：超越"完成任务"的功利主义，找到职业的内在意义

### 18.4 大转型理论与督察的政治经济学
- **嵌入性（波兰尼）**：经济原本嵌入社会；市场扩张将经济"脱嵌"→ 社会通过运动自我保护
- **双向运动**：市场扩张（利润逻辑）vs 社会保护（监管逻辑）→ 环保督察 = 后者对前者的制度性矫正
- **督察的政治经济学逻辑**：不是简单的"政府管企业"，而是市场逻辑与生态逻辑的制度性博弈
- **启示**：督察的深层价值不是评分排名，而是维护生态逻辑对社会逻辑的侵蚀

### 18.5 反脆弱与监管韧性
- **脆弱**：压力下崩溃（如"运动式执法"依赖高压，一旦放松即反弹）
- **坚韧**：压力下不变（如标准化监管，不受外界影响但也不进化）
- **反脆弱**：压力下进化（如每次督查都产生制度改进，每起事故都成为升级契机）
- **执法应用**：不追求"不出事"的静态安全，而是建立"出了事能变得更强"的动态韧性

## 二十一、督察实战要点清单（2026-07-15新增）

### 21.1 现场异常信号识别（9种）
1. **设施运行异常**：电耗突然下降/药剂消耗为零/污泥未外运
2. **台账记录异常**：运行记录与监测数据不符/危废台账断档
3. **在线监测异常**：O₂含量恒为21%/参数恒定不变/频繁校准
4. **采样点位异常**：采样孔位置不合规/采样管漏气/稀释旁路
5. **危废贮存异常**：超期贮存/标识不规范/露天堆放
6. **排污口异常**：私设暗管/稀释排放/雨污混排
7. **监测数据异常**：监测报告与现场情况不符/监测机构资质问题
8. **环评验收异常**：未批先建/未验先投/验收造假
9. **台账证据异常**：生产记录与排污量不符/物料平衡异常

### 21.2 企业博弈应对策略
- **立场锚定破除**：企业说"一直都是这样" → 出示最新标准
- **信号甄别**：企业主动表态合规 → 核实台账/监测/现场是否一致
