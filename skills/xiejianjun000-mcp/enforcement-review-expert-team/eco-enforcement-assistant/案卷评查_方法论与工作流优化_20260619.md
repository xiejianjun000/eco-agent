# 案卷评查全过程方法论与工作流优化

## 任务目标
基于冷水江市赢湖矿产品有限公司案（91页）逐页评查实战经验，系统总结：
1. 审查流程优化方法（如何更快看完）
2. 手写签字审查加强方法
3. 最终评查报告写作模板
4. Word文档生成方案

## 输出成果

### 方法论文档（Markdown）
- **文件**：`案卷评查_审查方法论与工作流优化.md`
- **内容**：四步法、签字五维法、报告六段式模板、快速参考卡片

### Word文档
- **文件**：`案卷评查_方法论与工作流优化指南.docx`（18.9KB）
- **格式**：A4 / 封面+目录页+4章完整内容 / 页眉页脚页码 / 多表格排版
- **技术栈**：docx-js (Node.js)

### 核心结论

**优化目标**：单案评查从33分钟缩至16分钟（提速50%）
- 目录驱动：先看目录再决定看哪页，省30%
- 时间线先行：先提取日期再读内容，省20%
- 三要素抽样：只验证事实-法律-因果关系，省30%
- 扫描清单收尾：清单代替逐页查找，省20%
- 知识库复用：首次建库后后续评查免搜索，省80%

**签字审查**：五维法（存在→完整→一致→原貌→关联），1分钟快速过

**文档生成**：docx-js + NODE_PATH 支持中文排版
