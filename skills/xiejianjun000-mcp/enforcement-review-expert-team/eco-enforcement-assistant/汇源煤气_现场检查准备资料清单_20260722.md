## 二、嫌疑研判：流速造假的核心逻辑

**为什么流速 < 1m/s 是重大异常？**

```
排放量（kg/h）= 污染物浓度（mg/m³）× 流速（m/s）× 烟囱截面积（m²）× 3600 ÷ 10⁶
```

- 焦炉烟囱正常工况下流速通常 **> 3~8 m/s**，月均 < 1m/s 明显背离物理常理
- 流速是 CEMS 排放量核算的**乘数因子**，压低流速 = 缩小排放量 = 规避超标 / 逃避总量核算
- 流速由皮托管测动压换算，造假手法与火电"工况标记造假"不同，属**仪器/参数类造假**

**流速造假常见手法（重点排查方向）：**
1. **皮托管物理破坏**：堵塞、截断、拔掉、插反（全压孔背风）
2. **零点漂移未校准**：动压零点偏高 → 流速算小
3. **K 系数/量程篡改**：擅自修改皮托管系数或流速量程上限
4. **数据人为剔除**：将高流速时段标记为"无效/维护"剔除
5. **截面积造假**：烟囱截面积参数填报小于实际

- 《中华人民共和国大气污染防治法》第一百条：侵占、损毁或者擅自移动、改变大气环境质量监测设施或者大气污染物排放自动监测设备的，由生态环境主管部门责令改正，处二万元以上二十万元以下的罚款；拒不改正的，责令停产整治
- 《中华人民共和国环境保护法》第四十二条第四款：严禁通过暗管、渗井、渗坑、灌注或者篡改、伪造监测数据，或者不正常运行防治污染设施等逃避监管的方式违法排放污染物

## 五、检查重点与证据链设计（流速造假方向）

### 5.1 现场查证皮托管（第一突破口）

- [ ] 皮托管安装位置：距弯头/阀门/变径管下游 ≥ 6D、上游 ≥ 3D（不符即疑）
- [ ] 皮托管方向：全压孔是否迎风（插反 = 测不到动压 = 流速失真）
- [ ] 物理状态：探头是否堵塞、截断、拔脱、包裹
- [ ] 系数核查：皮托管 K 系数是否与企业报备一致，有无擅自修改痕迹
- [ ] 零点检查：调阅运维记录，动压零点漂移是否超差、是否按期校准

### 5.2 CEMS 数据比对（第二突破口）

- [ ] 导出焦炉烟囱流速分钟级数据，定位 < 1m/s 时段
- [ ] 同步手工监测：用便携烟气分析仪 + 皮托管现场实测流速，与 CEMS 比对
- [ ] 调取 CEMS 站房视频，核查异常时段有无人为操作
- [ ] 调取运维记录，核查是否有人为修改流速参数/量程

### 5.3 DCS / 工况交叉验证（第三突破口）

- [ ] 焦炉生产负荷曲线（结焦周期、推焦计划）
- [ ] 脱硫脱硝引风机/增压风机电流、转速、阀门开度 → 与流速逻辑比对
- [ ] 煤气产量 / 焦炭产量 → 物料平衡反算理论烟气量
- [ ] 若 DCS 显示满负荷生产但 CEMS 流速 < 1m/s → 流速数据造假实锤

### 5.4 证据链闭环（五环）

```
现场笔录（皮托管异常）        
  → 拍照录像（探头状态+时间戳）  
    → 书证调取（CEMS数据+运维记录+检定证书）  
      → 手工比对监测（实测流速印证）  
        → 询问笔录（固定主观故意/操作人）
```

## 九、法律适用预判

**定性路径（由轻到重）：**
1. **不正常运行自动监测设备**（皮托管堵塞/未校准）→ 大气法第 100 条，2~20 万 + 拒不改正停产整治
2. **篡改/伪造自动监测数据**（擅自改参数/数据造假）→ 大气法第 20 条第 2 款 + 第 99 条第（三）项，10~100 万 + 停产整治
3. **逃避监管方式排放**（数据造假 + 实际超标）→ 环保法第 63 条移送拘留（5~15 日）
4. **涉嫌犯罪**（重点排污单位 + 篡改伪造数据排放 SO₂/NOx）→ 刑法第 338 条 + 两高解释第一条第（七）项，移送公安

**处罚预判**：罚款 10~100 万 + 停产整治 + 行政拘留（若锁定故意）+ 涉嫌犯罪移送公安。
