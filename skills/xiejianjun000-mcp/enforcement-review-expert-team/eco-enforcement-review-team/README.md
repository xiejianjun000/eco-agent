## 工作流程（5 Phase SOP）

```
Phase 1: 任务接收与预审分流（调度官串行）
  └→ 解析任务类型 → 分类定性 → 受理条件核查

Phase 2: 并行分析（8个团员同时 spawn）
  └→ 案卷评查 + 现场执法 + 督察实战 + 法律合规 + 文书生成 + 数据分析 + 知识库检索 + 平台巡检

Phase 3: 综合评估（调度官串行）
  └→ 汇总结论 → 25项一票否决引擎 → 风险分级 → 综合判定

Phase 4: 文书生成（文书生成专家 + 调度官）
  └→ 评查报告 + 问题清单 + 法律依据链 + 统计分析表

Phase 5: 归档推送（知识库管理专家 + 平台巡检专家）
  └→ 入库归档 + 邮件推送 + 平台状态更新
```

## 使用方式

在 WorkBuddy 中安装此 Expert Plugin 后，通过以下方式启动：

1. **全面评查**：`"请对该案卷进行全面评查：[案件名称]"`
2. **现场核查**：`"生成[企业名称]的[工艺类型]现场核查清单"`
3. **督察推演**：`"模拟督察：[区域]+[行业]"`
4. **法律分析**：`"分析该违法事实的法律适用和移送公安标准"`
5. **每日巡检**：自动触发（定时任务，每日08:00）
