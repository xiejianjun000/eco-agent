# 湖南省生态环境行政处罚裁量权基准（2021版）

## 一、基本定位

本规定适用于湖南省行政区域内生态环境部门的行政处罚裁量。设区的市州可在此基础上参照制定适用于本辖区的裁量基准。

## 二、四大裁量原则

| 原则 | 核心要求 |
|------|----------|
| **合法** | 裁量必须在法定幅度内，不得超越法律授权 |
| **合理** | 兼顾过罚相当，避免畸轻畸重 |
| **过罚相当** | 罚款金额与违法情节、后果相匹配 |
| **公开公平公正** | 同类案件同等处理，裁量过程可追溯 |

## 三、裁量模式：多因素百分比模式

### 核心公式

**专用裁量表**：
```
罚款金额 = 裁量百分值总和 × 法定最高罚款数额（或倍数）
```

**通用裁量表**：
```
裁量起点Y = 法定最低罚款数额 / 法定最高罚款数额 × 100%
罚款金额 = [Y + (裁量百分值累加之和) × (1 - Y)] × 法定最高罚款数额
```

### 裁量步骤四步法
1. 选择适用的裁量表（有专用裁量表的必须用专用裁量表）
2. 选定裁量起点（法定最低罚款数额对应的百分值）
3. 确定各裁量因素的百分值并累加
4. 计算罚款金额，集体审议后确定

## 四、六大裁量因素

| 因素 | 说明示例 |
|------|----------|
| 污染/生态破坏程度 | 超标倍数、排污量、排放去向、环境功能区 |
| 主观过错程度 | 故意、过失、无主观过错 |
| 违法方式或手段 | 是否逃避监管、暗管偷排、弄虚作假 |
| 危害的具体对象 | 饮用水水源保护区、生态保护红线区、居民区 |
| 环境违法次数（两年内） | 首次、多次、屡教不改 |
| 改正态度和措施 | 立即改正、拒不改正、逾期不改正 |

## 五、从重/从轻/减轻/不予处罚规则

### 从重处罚（+不超过法定最高罚款20%）
- 拒不配合、干扰阻挠调查取证
- 造成重大环境污染
- 引起重大群体性事件或媒体曝光
- 重污染天气预警期间超标排放大气污染物
- 环保督察及整改期间顶风作案

### 从轻处罚（-不超过法定最高罚款20%）
- 主动消除或减轻危害后果
- 受他人胁迫或诱骗
- 主动供述尚未掌握的违法行为
- 配合查处有立功表现

### 减轻处罚（-不超过法定最低罚款50%）
- 在法定最低限值以下罚款
- 可减少处罚种类或不予并处
- 主动履行生态环境损害赔偿义务可作为从轻依据

### 不予处罚
- 违法行为轻微+及时改正+无危害后果
- 有证据证明无主观过错（法律另有规定除外）
- 初次违法+危害后果轻微+及时改正（**首违不罚**）

## 六、专用裁量表覆盖范围（12类）

1. 违反环境影响评价制度（未批先建）
2. 违反"三同时"制度（未建成/未验收/弄虚作假）
3. 违反排污许可制度（无证排污/超标排放水/气）
4. 违反现场检查规定（拒不接受检查/弄虚作假）
5. 通过逃避监管方式排放污染物
6. 违反大气污染防治（有组织/无组织超标、VOCs）
7. 违反水污染防治（直接排放/向集中处理设施排放）
8. 违反固废管理制度（危废委托/无证经营/擅自倾倒）
9. 违反土壤污染防治（风险管控/修复/向农用地排放重金属）
10. 违反辐射安全管理（无证或不按证）
11. 违反环境监测制度（未按规定自行监测）
12. 第三方机构及责任人员（机动车排放检验/土壤从业单位/责任人员）

## 七、通用裁量表

适用于专用裁量表未列出的其他所有违法情形。裁量因素包括：违法行为发生地点（生态保护红线/自然保护地/饮用水源）、环境违法次数、对周边影响等。

## 八、行业特定因子提示

- **电镀行业**：一类污染物（总铬、六价铬、总镍等）在车间口采样，超标排放适用逃避监管或超标排放裁量表
- **印染行业**：退浆、丝光废水COD数万mg/L，需独立预处理设施
- **化工行业**：危废种类多（HW06/HW08/HW49等），适用危废相关专用表
- **火电行业**：脱硫废水含重金属，适用大气污染物超标+水污染物超标组合
