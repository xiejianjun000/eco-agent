# 六大类行政处罚案卷评查框架

> 来源：《生态环境行政执法案卷评查细则（2024年修订版）》

## 一、一般行政处罚案卷（总分100分）

| 维度 | 内容 |
|------|------|
| **评查重点** | 处罚决定书要素完整性（15分）、笔录详实度（现场10分+询问10分）、证据充分性（监测5分+书证8分） |
| **独特要求** | 责令改正决定书（10分）、事先（听证）告知书（10分）、听证通知书（4分）+笔录（8分）、督促履行催告书（2分）、强制执行申请书（5分）、结案审批表（3分） |
| **必备文书** | 立案审批表（2分）→ 现场检查笔录（10分）→ 询问笔录（10分）→ 监测/检测报告（5分）→ 书证/视听资料（8分）→ 案件调查报告（8分）→ 责令改正决定书（10分）→ 事先告知书（10分）→ 听证通知/笔录（12分）→ 处罚决定书（15分）→ 执行文书 → 结案审批表（3分） |
| **常见问题** | 决定书未回应陈述申辩、裁量理由不充分、告知期限不足（3日/5日）、法律条文未引用到条款项层次 |

## 二、不予行政处罚案卷（总分100分）

| 维度 | 内容 |
|------|------|
| **评查重点** | 不予处罚条件的证据充分性、教育内容的体现（3分）、违法行为改正情况的证明（2分） |
| **独特要求** | 不予行政处罚事先告知书（10分）、不予处罚决定书（20分）中必须包含教育内容和改正情况 |
| **必备文书** | 立案审批表（4分）→ 现场检查笔录（10分）→ 询问笔录（10分）→ 监测/检测报告（5分）→ 书证（8分）→ 案件调查报告（8分）→ 责令改正决定书（10分）→ 不予处罚事先告知书（10分）→ 不予处罚决定书（20分）→ 结案审批表（3分） |
| **常见问题** | 未证明"违法行为轻微"、"及时改正"、"无危害后果"三者同时成立；首违不罚未提供初次违法的证据；未依法对当事人进行教育 |
| **三类不罚条件** | （1）轻微+及时改正+无危害后果；（2）有证据证明无主观过错；（3）首违+轻微+及时改正（首违不罚） |

## 三、按日连续处罚案卷（总分120分）

| 维度 | 内容 |
|------|------|
| **评查重点** | 责令改正→复查→拒不改正→按日计罚的程序链条完整性（按日处罚决定书15分） |
| **独特要求** | 再次责令改正违法行为决定书（5分）：必须包含拒不改正证据、再次责令改正内容、告知按日连续处罚后果、告知救济途径 |
| **必备文书** | 行政处罚全流程 + 再次责令改正决定书 + 按日连续处罚决定书（含初次检查/复查/拒不改正完整记录） |
| **常见问题** | 程序链断裂：未责令改正即按日处罚（一票否决22项）；未在规定时间内实施复查（一票否决23项）；按日处罚决定书早于原处罚决定书（一票否决24项） |
| **计时规则** | 自责令改正之日的次日起计算，至复查之日止，按日累计 |

## 四、查封/扣押案卷（总分100分）

| 维度 | 内容 |
|------|------|
| **评查重点** | 查封/扣押审批的合法性（审批表10分）、决定书的完整性（20分）、现场笔录的当场性（13分） |
| **独特要求** | 查封/扣押决定书（含清单）要素：设施/设备/物品名称+数量+型号+存放地点、期限、当事人义务、救济途径；现场笔录必须当场制作、当场告知理由和权利 |
| **必备文书** | 现场检查笔录（10分）→ 询问笔录（10分）→ 监测报告（7分）→ 书证（8分）→ 查封/扣押审批表（10分）→ 查封/扣押决定书+清单（20分）→ 查封/扣押现场笔录（13分）→ 延期决定书（11分，如适用）→ 解除决定书（11分，如适用） |
| **常见问题** | 超期未解除或未批准延长（一票否决25项）；查封扣押与违法行为无关的对象（一票否决13项）；未当场告知权利和理由（一票否决16项） |
| **期限规则** | 一般30日（含节假日），可延长不超过30日 |

## 五、移送拘留案卷（总分100分+15分加分）

| 维度 | 内容 |
|------|------|
| **评查重点** | 移送审批（10分）+移送书（10分）的完整性、行政处罚程序的同步合规性、公安机关签收的确认 |
| **独特要求** | 移送审批表须含法制机构意见和主要负责人意见；移送书须含移送材料清单和公安机关签收 |
| **必备文书** | 移送审批表（10分）→ 移送书+材料清单（10分）→ 行政处罚全流程材料 |
| **加分项** | 公安机关作出拘留决定：+15分 |
| **常见问题** | 移送材料不齐全、缺少公安机关签收记录、行政处罚程序与移送程序脱节 |
| **法典新增拘留情形** | 未批先建拒不执行（第1095条）、无证排污拒不停止（第1102条）、逃避监管排污（第1108条）、使用禁用农药（第1131条）、向农用地排重金属/有毒物质（第1160条）、未采取风险管控/修复（第1165条）、危废6种情形（第1179条） |

## 六、移送涉嫌环境污染犯罪案卷（总分100分+15分加分）

| 维度 | 内容 |
|------|------|
| **评查重点** | 移送依据的充分性：重金属超标≥3倍或危废≥3吨的量化证据（移送审批表15分+移送书15分） |
| **独特要求** | 证据标准高于一般案件：监测报告分值升至10分、书证/视听资料升至12分、笔录分值升至15分、调查报告升至12分 |
| **必备文书** | 移送审批表（15分）→ 移送书+材料清单（15分）→ 立案审批表（6分）→ 现场检查笔录（15分）→ 询问笔录（15分）→ 监测报告（10分）→ 书证/视听资料（12分）→ 案件调查报告（12分） |
| **加分项** | 公安机关作出立案决定：+15分 |
| **常见问题** | 重金属超标倍数计算错误；危废数量未累计计算；未进行危废鉴别或鉴别机构无资质；监测报告无CMA标志 |
| **不移送风险** | 应移未移 = 一票否决（第19项）；构成渎职风险 |
