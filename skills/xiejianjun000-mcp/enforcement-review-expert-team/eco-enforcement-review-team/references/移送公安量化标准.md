# 生态环境违法移送公安量化标准

## 一、重金属超标入刑标准

### 计算公式
```
超标倍数 = (实测值 - 排放标准限值) / 排放标准限值
入刑条件：超标倍数 ≥ 3
```

### 计算示例
- 排放标准限值：0.5 mg/L
- 实测浓度：2.0 mg/L
- 超标倍数：(2.0 - 0.5) / 0.5 = 3.0 → **达到入刑标准**

### 相关重金属
一类污染物重点关注：总铬、六价铬、总镍、总镉、总银、总铅、总汞、总砷

## 二、危险废物入刑标准

### 量化标准
```
入刑条件：非法排放、倾倒、处置危险废物 ≥ 3吨
```

### 关键要求
- 累计计算：多次少量倾倒累计达到3吨，同样入刑
- 鉴别依据：毒性、腐蚀性、易燃性、反应性、感染性（五性鉴定）
- 无许可证从事危废经营活动同样需评估移送

## 三、八类移送公安情形

| 类别 | 情形描述 | 关键证据要求 |
|:----:|----------|-------------|
| 1 | 非法排放、倾倒、处置危废 ≥ 3吨 | 危废鉴别报告+称重记录+联单核查 |
| 2 | 重金属排放超标 ≥ 3倍 | 监测报告+标准限值比对+采样程序合规证明 |
| 3 | 通过暗管、渗井、渗坑等逃避监管排污且含重金属/有毒物质 | 现场勘验笔录+暗管/渗坑照片+水质监测报告 |
| 4 | 两年内因同类违法行为受过两次以上行政处罚又实施 | 行政处罚决定书+时间线比对 |
| 5 | 饮用水水源保护区/自然保护地核心区排放污染物 | 保护区位置图+监测报告+现场照片 |
| 6 | 造成公私财产损失三十万元以上 | 损失评估报告+会计/审计佐证 |
| 7 | 致使乡镇集中式饮用水水源取水中断十二小时以上 | 取水中断记录+供水部门证明 |
| 8 | 无证从事危废经营活动且累犯 | 营业执照/许可核查+经营记录+处罚历史 |

## 四、危废全链条追踪（五步核实）

```
产生 → 分类 → 贮存 → 转移 → 处置
```

### 关键制度
- **五联单**：第一联产生单位 → 第二联移出地环保部门 → 第三联接受单位 → 第四联接受地环保部门 → 第五联返还产生单位
- **贮存期限**：危废贮存不得超过1年（确需延长需报批）
- **台账保存**：危废管理台账保存至少10年

### 移送前检查清单
- [ ] 危废鉴别报告是否由有资质机构出具
- [ ] 称重记录是否有当事人及见证人签字
- [ ] 五联单是否完整、是否存在断档
- [ ] 现场照片/录像是否清晰反映危废状态
- [ ] 监测报告出具的机构是否具备CMA资质
- [ ] 采样程序是否合规（点位/孔位/质控空白/见证人）

## 五、移送程序要点

- **移送时机**：发现涉嫌犯罪线索后，及时移送，不得以行政处罚代替刑事追诉
- **移送材料**：案件移送书（含清单）+ 调查报告 + 证据材料 + 监测报告 + 涉案物品清单
- **罚刑并行**：移送前已作出行政处罚的，应将处罚材料一并移送；移送不影响行政处罚决定执行
- **协作机制**：与公安机关建立案前会商、同步调查、联合办案的衔接机制
