# EcoAegis 平台管理 · 自助添加平台（前端扩展）PRD

> 文档版本：v2.0（Kimi 合规重写）｜ 作者：许清楚（产品经理）｜ 日期：2026-08-07
> 适用范围：EcoAegis「平台管理」模块的前端扩展——让执法人员自助把已备案环保执法平台接进来。
> 一句话定位：**在 Kimi 既有「平台管理」页面里，执法人员粘贴一个平台地址，系统认出它并生成 EcoAegis 风格登录界面、把验证码推到这个界面，登录一次后该平台进入「AI代管中」——全程不需写代码、不需平台方配合。**

---

## 0. 范围与基线（必遵循 Kimi 源规范）

> 本 PRD 是对 Kimi 既有「平台管理」模块的**前端扩展**，不新建后端服务。设计基线：`design.md`（全局设计系统）、`platforms.md`（既有布局与四态）、`info.md`（前端框架与数据层）。**后端 AI 基座 = Hermes agent（既有 AI 基座，对用户不可见；前端仅呈现「AI代管 / AI已识别」等人话）。**

### 0.1 平台状态机（原样沿用 platforms.md，不另造）

| 状态 | 颜色 | 说明 |
|---|---|---|
| `AI代管中` | 橄榄绿 `#7C8B5F` | 首次登录成功、心跳正常、AI 日常代管（稳态）；徽章前圆点 2s 呼吸 |
| `待人工首次登录` | 琥珀 `#C9A24B` | 模板已匹配、等待人工登录一次；卡顶琥珀提示条 +「人工登录一次」按钮 |
| `接入配置中` | 灰蓝 `#6E8299` | 模板匹配 / 配置进行中；显示配置进度条 |
| `异常` | 赤陶红 `#B0574A` | 登录失败 / 会话过期 / 探活异常；左导航「平台管理」角标显示离线平台数 |

> 注：Kimi 原设计无「未接通」态；琥珀态统一命名为 `待人工首次登录`。「已接通」仅在概览条/操作区作分类用语，其持久态即 `AI代管中`。

### 0.2 接入范围

- **白名单内「账号 + 密码 +（图形）验证码」型平台**（MVP 首批 6 个真实平台，见 §2）。
- **UKEY / 数字证书 / 人脸 / 扫码类 MFA 平台**：标记为「需人工激活 / 不支持自动接入」，不进入自动向导；若未来接入，仅支持「人工受控首次登录 → 导出会话 → AI 复用」模式（P1），不在 MVP。

### 0.3 非技术化语言铁律

界面与文案**禁用**「协议 / 接口 / 代理 / iframe / token / MCP / Hermes / API」等黑话。平台状态统一用语（四态）：`AI代管中 / 待人工首次登录 / 接入配置中 / 异常`；操作类用语：`代管范围 / 验证码协助 / 收回权限`。MCP 模块对用户称「外部工具接入」。

### 0.4 三栏布局（沿用 info.md）

左 232px / 中 flex / 右 320px；平台管理在左导航第 5 项（带「离线平台数」角标）。本扩展只落在中间工作区。

## 1. 问题陈述

**谁**：一线生态环境执法人员、平台管理员。
**痛点**：当前「平台管理」仅固定 6 平台 + 人工登录引导三步；每接入一个新业务平台都需工程师按平台单独硬编码、单独配登录流程；执法人员要在多系统间反复手动登录、跨系统查数据、重复录入。
**现在怎么解决**：① 工程师硬编码 6 平台；② 执法人员靠「人工登录一次」引导页手动填账号密码 + 验证码；③ 想扩平台就等开发排期。
**目标（本 PRD 范围）**：把「平台管理」从「固定 6 平台」升级为**支持自助添加**——白名单内，执法人员粘贴地址即走完「匹配 → 生成 EcoAegis 风格登录界面 → 验证码推到界面 → 登录一次 → 进入 AI代管中」闭环，之后 AI 代管日常操作与巡检。

## 2. 目标用户与真实平台数据

### 用户画像（沿用 §0）
- **P1 一线执法人员**（主要）：会操作电脑，不懂协议/代理/接口；粘贴地址就能接进来，之后 AI 帮日常看数据、巡检。
- **P2 管理员 / 信息科**：配模板、管代管范围、处理接入异常。
- **P3 分局领导**：看整体态势（AI代管中 X / 接入配置中 Y / 今日巡检正常）。

### 真实 6 平台（状态与数据沿用 platforms.md，自助添加在其后追加）
1. 水环境非现场执法平台 — AI代管中
2. 大气监督帮扶平台 — AI代管中（验证码自动识别）
3. 行政执法系统 — 待人工首次登录
4. 排污许可证管理端 — 接入配置中（进度 60%）
5. 在线监测系统管理端 — 待人工首次登录
6. 用电监控系统管理端 — 接入配置中（进度 35%）

## 3. 核心场景

- **场景 A · 首次自助接通（账密+图形码型）**：队员粘贴「排污许可证管理端」URL → 系统匹配白名单并生成 EcoAegis 风格登录壳 → 基座抓取验证码推到壳上 → AI 识别（或复杂弹人工）→ 队员确认提交 → 登录成功即进入「AI代管中（橄榄绿 + 呼吸点）」，提示"后续日常操作由 AI 完成，你随时可收回权限"。
- **场景 B · 验证码人工兜底**：某平台验证码扭曲，AI 识别失败 → 壳上弹出验证码图 + 说明"平台安全要求，需您协助" → 队员输入 → 提交成功。
- **场景 C · 日常 AI 代管**：平台已 AI代管中，巡检员专家每天自动登录抓数据、出巡检报告。
- **场景 D · 暂停 / 恢复代管**：年审期「暂停代管」→ 二次确认（"暂停期间预警将不会自动抓取"）→ 恢复后继续。
- **场景 E · 凭据安全与恢复（P1）**：凭据本机加密存储，不出本机；队员换设备/忘密码时由机构级恢复机制兜底（P1），避免代管中断。
- **场景 F · MFA 平台（P1，非 MVP 自动）**：若白名单平台要求 UKEY/证书/人脸/扫码，标记「需人工激活 / 不支持自动接入」，不进入自动向导。

## 4. 功能清单（MVP 前端闭环）

| 编号 | 功能 | 等级 | 是否 MVP | 说明 |
|---|---|---|---|---|
| F1 | 自助添加入口（粘贴 IP/URL + 白名单匹配） | P0 | ✅ | 虚线卡 + 向导第 0 步 |
| F2 | EcoAegis 风格登录壳渲染 | P0 | ✅ | 前端按白名单模板生成，非 iframe |
| F3 | 验证码抓取与 AI 识别兜底 | P0 | ✅ | 基座能力；图推到壳，认出预填、认不出转人工 |
| F4 | 接通状态管理 + 凭据本机加密存储 | P0 | ✅ | 四态更新；凭据加密存本机不出 |
| F5 | 代管范围权限开关 | P1 | ❌ | 只读 / 可提交 / 可下载（沿用 platforms.md） |
| F6 | 暂停 / 恢复代管 | P1 | ❌ | 二次确认（沿用 platforms.md） |
| F7 | 接入失败诊断与重试引导 | P1 | ❌ | 友好提示而非黑话 |
| F8 | 机构级凭据恢复 / 托管 | P1 | ❌ | 防单人丢失 |
| F9 | 接通后纳入巡检员专家每日巡检 | P1 | ❌ | 次日进入巡检范围 |
| F10 | MFA 平台人工受控首次登录 | P1 | ❌ | UKEY/证书/人脸/扫码，非自动 |

### 不做的（Won't Have，MVP）
- 任意网址全自动适配（仅白名单内）
- 云端托管明文凭据（一律本机加密）
- 7×24 无人首登（首次必人工一次）
- MFA 自动接入（标记不支持自动）
- SSO 对接 / 重构对方业务 / 多租户商业化 / ETL 中台

## 5. 后端 AI 基座（Hermes agent）职责边界（内部，不外露）

> 本扩展**不新建后端服务、不引入数据库、不做反向代理**。所有"智能"能力由既有 Hermes agent（AI 基座）提供，前端通过既有 agent 调用通道与之交互。

| 基座职责 | 前端呈现 |
|---|---|
| 白名单模板匹配（粘贴地址 → 命中/未命中） | "认出来了 ✓" / 温和拦截"暂不在白名单" |
| 登录壳字段生成（按模板输出账号/密码/验证码位置） | EcoAegis 风格登录界面 |
| 验证码抓取与识别 | 验证码图推到壳 + "AI 已识别 ✓" / 转人工 |
| 会话保活 / 续期 | 状态维持 AI代管中 / 异常时提示重登 |

**与前端契约**：状态四态、凭据本机加密不出本机、MFA 不自动接入。

## 6. 验收标准（AC）

- **AC1** 点击「＋添加平台」虚线卡可打开向导，步骤指示正确。
- **AC2** 粘贴白名单内地址 → 命中并展示模板卡；粘贴非白名单地址 → 温和拦截，不报错、不崩。
- **AC3** 命中后生成 EcoAegis 风格登录壳（非原站样式、非 iframe），字段与模板一致。
- **AC4** 验证码图成功推送到登录壳；AI 识别成功则预填并可改，失败则转人工输入（autofocus）。
- **AC5** 登录成功 → 登录壳淡出 + 橄榄绿 Toast"已接通，AI 开始代管" + 列表新增「AI代管中」卡（stagger 入场）+ 概览条"已接通"计数 +1。
- **AC6** 登录失败 → 赤陶红提示"账号或密码不对，请重试"，验证码区回到抓取态，不出现 401/auth fail 等黑话。
- **AC7** 四态徽章配色与文字标签严格为：AI代管中(橄榄绿)/待人工首次登录(琥珀)/接入配置中(灰蓝)/异常(赤陶红)；无"未接通"态。
- **AC8** MFA 类平台在白名单中标记为「需人工激活 / 不支持自动接入」，不进入自动向导。
- **AC9** 凭据加密存本机，不出本机；"记住账号"可在设置统一查看/清除。
- **AC10** 全模块遵守 design.md 动效与 `prefers-reduced-motion`；同屏动画元素 ≤ 8。
