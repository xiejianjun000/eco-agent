## 1. 模块定位与叙事

本扩展让一线执法人员**自己把一个已备案的环保执法平台接进「平台管理」**：

> 粘贴平台地址 → 系统认出它（匹配白名单）→ 你登录一次 → 之后 AI 帮你日常操作和巡检。

叙事与 Kimi 既有 platforms.md 完全一致（"首次人工登录一次，之后 AI 帮您日常操作与巡检"），不另造概念。

## 3. 自助添加流程（前端，挂回既有三步引导）

**入口**：点击「＋添加平台」虚线卡 → 居中向导弹窗（遮罩 30% 黑，宽 520px，白底 10px 圆角，一级阴影）。

**流程总览**（在 Kimi 三步引导**之前**插入「贴地址 + 匹配」一步）：

```
[0 粘贴地址并匹配] ——●—— [1 内嵌登录页说明] ——●—— [2 验证码协助] ——●—— [3 完成页]
   陶土橙当前步骤圆点；已完成步骤橄榄绿对勾；未完成暖灰圆点（步骤指示圆点推进 240ms）
```

> 步骤 1–3 即 Kimi `platforms.md` §4 原三步引导弹窗，文案与交互**原样不变**；本扩展仅在前置第 0 步完成「粘贴地址→匹配白名单→生成 EcoAegis 风格登录壳」，随后自然落入原三步。

### 步骤 0 · 粘贴地址并匹配白名单

```
┌──────────────────────────────────────────────┐
│  添加平台                               (✕ 关闭) │
├──────────────────────────────────────────────┤
│   把平台的地址贴进来                            │
│   我们只接入已备案的环保执法平台，粘贴后会       │
│   自动识别。                                   │
│   ┌────────────────────────────────────────┐ │
│   │  例如：10.12.34.56  或  jc.hunan-ep.com  │ │
│   └────────────────────────────────────────┘ │
│   小字提示：地址由你粘贴，系统不会主动扫描网络。 │
│                                  [ 继续 (陶土橙) ] │
└──────────────────────────────────────────────┘
```

- 命中白名单 → 展示平台模板卡（图标 + 名称 + 用途一句 + 灰蓝标签「环保执法白名单 · 已备案」），进入步骤 1
- 未命中 → 温和提示（非报错）："这个地址暂不在我们支持的白名单里。为保护账号安全，目前只接入已备案的环保执法平台。" + 次按钮「申请加入白名单」+ 文字型按钮「重新粘贴地址」
- 校验：空 / 格式不对 → 按钮禁用（opacity 降低，暖灰），下方赤陶红字"请填写一个有效的平台地址"（不出现"URL 校验失败"等黑话）

### 步骤 1–3 · 沿用 Kimi 人工登录引导弹窗（原三步）

- **步骤 1（内嵌登录页说明与注意事项）**：在 Kimi 原说明基础上补一句——"系统已为你生成 EcoAegis 风格登录界面，账号密码填在这里，验证码会直接推送到这个界面。"其余说明与注意事项不变。
- **步骤 2（验证码协助）**：登录壳内展示**从平台抓取的验证码图**（AI 基座已识别则预填 + 灰蓝芯片"AI 已识别 ✓"；认不出则灰蓝信息条"这个验证码有点绕，AI 暂时认不出，麻烦你填一下" + 输入框 autofocus）；"看不清？点此重抓"。
- **步骤 3（完成页）**："已接管，后续日常操作由 AI 完成，你随时可在本页收回权限。"（沿用 Kimi 原语气）

## 4. 登录壳组件（本扩展新增形态，其余复用 design.md）

> 登录壳 = 前端按白名单模板生成的 EcoAegis 风格登录界面（暖白卡、陶土橙主按钮），**非原站样式、非 iframe**。验证码图由后端 AI 基座抓取并推送到此界面。

### 4.1 字段形态（复用 design.md 共享组件）

| 字段 | 形态 | 状态 | 说明 |
|---|---|---|---|
| 账号 | 输入框 8px 圆角，白底，1px `#E4DDD2` 边，focus 2px 陶土橙环 | Default/Hover/Focus/Disabled/Error | 占位"请输入你的平台账号"，13px `#2E2A26` |
| 密码 | 同账号 + 右侧眼睛图标(lucide)，点击切换明文 | 同上 + 明文切换 | 默认掩码；切换 150ms |
| 验证码图 | 暖白底区块，圆角 8px，最小高 40px | AI态/人工态/Loading | 图来自平台抓取，本地渲染 |
| 验证码输入 | 输入框；AI态预填可改，人工态空且 autofocus | AI态/人工态/Error | 占位"请输入图中的字符" |
| 记住账号 | 开关 toggle（开=橄榄绿 `#7C8B5F`，关=暖灰 `#EFE9DF`） | 开/关 | 标签"记住账号（加密存在本机）" |

### 4.2 主按钮「登录并接管」

- 形态：陶土橙 `#C97C3E` 底、白字 `#FFFFFF`、13px/500、满宽、圆角 8px、高 44px（沿用 design.md 主按钮）
- 状态矩阵：Default / Hover(`#A8642F`+上移1px,150ms) / Active(scale .98) / Focus(2px 陶土橙环) / Disabled(opacity .5 暖灰) / Loading(按钮内 spinner+"正在接通，请稍候…"，禁输入) / Error(恢复 Default+上方赤陶红错误条) / Success(触发登录壳淡出+橄榄绿 Toast)

### 4.3 验证码区双态（基座能力呈现）

| 状态 | 视觉 | 交互 | 配色 |
|---|---|---|---|
| AI 已识别 | 图 + 预填输入框 + 灰蓝"AI 已识别 ✓"芯片 | 可改预填值；"看不清？点此重抓" | 灰蓝 `#6E8299` 芯片 |
| 待人工输入 | 图 + 空输入框(autofocus) + 灰蓝信息条"有点绕，麻烦你填" | 输入；"换一张"重抓 | 灰蓝 `#6E8299` 信息图标 |

## 7. 用户语言 ↔ 内部语言（非技术化对照）

| 用户看到的（人话） | 内部含义（不外露；AI 基座 = Hermes agent） |
|---|---|
| 粘贴平台地址 | 输入目标平台 IP / URL |
| 认出来了 | 匹配白名单模板（基座能力） |
| EcoAegis 风格登录界面 | 前端按模板生成的登录壳，非 iframe 原站 |
| AI 已识别 ✓ | 基座自动识别验证码并填入 |
| 有点绕，麻烦你填一下 | 复杂验证码基座识别失败，转人工 |
| 登录并接管 | 提交凭据并建立代管会话 |
| 已接通 / AI代管中 | 接入成功，进入自动操作态 |
| 记住账号（加密存在本机） | 凭据本机加密存储，不出本机 |

> 铁律：前端文案禁用"协议 / 接口 / 代理 / iframe / token / MCP / Hermes / API"等黑话。

## 8. 动效与可访问性清单

- **动效**：向导步进 240ms、登录壳淡出 280ms ease-out、新卡 stagger 入场 50ms、完成对勾 draw-in 500ms、"AI代管中"呼吸点 2s。同屏动画元素 ≤ 8，无 3D/视差/着色器（沿用 design.md §8）。
- **reduced-motion**：关闭呼吸点与计数类动画，保留即时状态切换。
- **键盘可达**：向导步骤 Tab 顺序遍历；验证码人工态输入框 autofocus；主按钮 `:focus-visible` 2px 陶土橙环。
- **对比度**：正文 `#2E2A26` on `#FFFFFF` ≥ 4.5:1；辅助 `#9A9184` 仅用于非关键说明，关键状态必带文字标签。
- **错误可感知**：错误用赤陶红 + 图标 + 文字三件套，不只靠颜色。
- **最小点击区**：按钮高 44px，开关与链接点击区 ≥ 32px。
