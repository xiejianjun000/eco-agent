# EcoAegis 平台研究资料(仓库真实资产)

## 项目
EcoAegis 生态环境执法办案评查一体化平台 — 前端已有骨架(React 18 + Vite 5 + TS strict + 纯CSS),需充实12个左侧导航模块+右侧4区。

## 用户指定布局(必须严格遵循)
- 左侧导航:执法助理、工作日历、辖区地图、企业管理、平台管理、执法办案、督察管理、案卷评查、档案管理、知识库、MCP连接、设置
- 右侧栏4区:①Office文书协同(可阅读/编辑/审阅批注,人机同步) ②GIS地图辅助(AI可标注/圈选等地图操作) ③Hermes记忆进化闭环面板 ④评查看板趋势
- 受众:一线执法人员,语言非技术化
