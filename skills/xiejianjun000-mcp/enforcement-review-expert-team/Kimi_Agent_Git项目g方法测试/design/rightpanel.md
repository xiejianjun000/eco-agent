# 右侧协作栏（rightpanel.md）— 4 个可折叠区

## 定位
贯穿全平台的协作面板（320px，`#F1EDE6` 底，左 1px `#E4DDD2` 边）。4 区顺序固定，头部 40px：图标 + 标题（13px/600）+ 状态点/角标 + 折叠箭头。默认 ①④ 展开、②③ 折叠。折叠动画 240ms ease-in-out + 箭头旋转 180°。四区总高超屏时整栏独立纵向滚动。当前模块与面板联动：如办案时 ① 自动展开并载入当前文书。

---

## ① Office 文书协同（默认展开）
**能力**：docx / xlsx / pdf 可阅读、可编辑、可审阅批注，人机同步。

- **文件头卡**：当前文书名（如"金竹山矿业案_行政处罚决定书_草稿.docx"）+ 格式徽章（docx 灰蓝/xlsx 绿/pdf 红）+ 状态（AI 草稿/人工编辑中/审阅中）。
- **三模式切换**（分段控件）：阅读 / 编辑 / 审阅（紫灰）。
  - 阅读：正文渲染，工具条仅缩放。
  - 编辑：简化工具条（字号/加粗/列表/插入引用条文）；AI 修改的内容以陶土橙下划线标识，hover 显示"文书成 修改 · 可撤销"。
  - 审阅：右侧批注列，批注卡（头像+姓名/专家名+内容+时间），支持回复与"已解决"勾；正文对应句紫灰高亮。
- **人机同步指示条**（底部）：绿点"已同步 · 文书成 与您同时在线"或"AI 正在写入第 3 段…"（写入时该段灰蓝闪烁 1 次）。
- **操作行**：「保存」「导出」「送签署」「归档」。
- **空态**："尚无打开的文书 — 从执法办案或档案管理打开一份文书"，附快捷按钮「让 AI 起草一份」（下拉 74 模板分类选择器：立案 5/调查 20/裁量 5/告知 12/决定 9/执行 18/归档 4，二级列出具体模板名）。
- **Animation**：AI 写入段灰蓝背景 600ms 渐隐；新批注滑入 240ms。

## ② GIS 地图辅助（默认折叠）
**能力**：AI 可标注、圈选、路径规划等地图编辑操作；与"辖区地图"模块共用底图样式。

- **迷你地图画布**（320×200，圆角 10px）：低饱和暖灰底图 + 当前上下文点位。
- **AI 工具行**（图标按钮）：标注点 / 圈选区域 / 画路径 / 测距 / 清除。激活工具陶土橙底。
- **AI 操作列表**：时间线式小卡——"10:24 数据芯 在金竹山矿业排口添加超标标注（红）""10:31 执法准 规划复查路线：3 个点位，全程 18 公里"。每条可「定位查看」「撤销」。
- **与大地图联动**：点击「在主图打开」跳辖区地图并携带当前标注图层。
- **折叠态摘要**：头部显示"今日 4 项地图操作"小字。
- **Animation**：新标注落点 scale 0→1 回弹 300ms + 波纹扩散一次。

## ③ Hermes 记忆进化闭环（默认折叠）
**能力**：平台从每一次办案/评查中学习，形成"经验 → 验证 → 沉淀 → 复用"闭环。语言非技术化。

- **闭环示意条**：四节点环形小图（经验积累 → 实践验证 → 规则沉淀 → 下次复用），当前活跃环节陶土橙脉动。
- **本周成长卡**：3 行数据——"新学会的经验 3 条 ｜ 修正的旧经验 1 条 ｜ 复用经验 56 次"。
- **经验条目列表**（小卡）：
  - "金竹山矿业案后：CEMS 夜间超标 + 用电骤降组合 = 旁路排放嫌疑 → 已加入检查要点"（橄榄绿"已验证"徽章）
  - "砖瓦企业听证期限易漏算 → 已加入否决扫描重点提示"（琥珀"验证中"徽章）
  - 每条附「查看来源案件」「这条不对」反馈按钮（点不对进入人工纠正弹窗：AI 会调整并说明改了什么）。
- **底部一句**："您纠正 AI 的每一次，它都会记住。"

## ④ 评查看板趋势（默认展开）
**能力**：评查数据看板，给领导与执法人员同一份直观趋势。

- **大数字行**：百卷精评 73/100（count-up）+ 合格率 93.2%（橄榄绿）/ 否决 1 卷（红）。
- **趋势迷你图**（高 64px 折线，陶土橙线 + 暖沙填充）：近 12 周评查合格率；hover 显示单周数值。
- **否决项分布**（横向条形 5 行）：程序类 10 项命中 4 / 证据类 1 / 法律适用类 1 / 移送类 0 / 其他 0——命中数红、零命中绿。
- **临期与预警行**："2 卷待人工复核 · 1 卷临期"，点击进入案卷评查。
- **Animation**：折线绘线 800ms；条形从 0 生长 500ms stagger 80ms。

## 全局交互
- 任一区可与中间工作区"钉住"联动：区头部「钉住」图标后，切换模块时该区保持展开与上下文。
- <1280px 时整栏变右抽屉，遮罩点击关闭，滑入 280ms。
