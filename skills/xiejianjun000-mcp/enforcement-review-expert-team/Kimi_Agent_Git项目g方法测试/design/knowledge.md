# 知识库（knowledge.md）— 法规与办案依据

## 定位
法规检索 + 问答。知识库专家主场。核心内容：评查细则 2024、湖南裁量权基准 2021（29 表）、生态环境法典衔接指南（2026-08-15 施行、1242 条、10 部旧法废止）、25 项否决清单、移送公安量化标准、6 类案件评查框架。

## 布局

### 1. 顶部问答大卡
- 输入框："直接问：砖厂超标该罚多少 / 法典施行后旧案子怎么引法条…"
- 回答区：答案正文 + 灰蓝引用块（条文原文 + 出处 + 施行状态标签"现行有效/2026-08-15 起施行/已废止"）+ 「加入办案笔记」。
- **Animation**：回答逐段淡入；引用块左侧 3px 灰蓝条。

### 2. 法典衔接专区（重点卡片，紫灰主题）
- 倒计时条："距生态环境法典施行还有 12 天（2026-08-15）"
- 三个子卡：
  - **新旧法对照表**：10 部旧法 → 法典对应编章，逐行对照（可搜索）。
  - **1242 条速览**：按编分类导航（总则/污染防治/生态保护/法律责任…）。
  - **8 省法典衔接报告**：报告列表（湖南/湖北/广东…），点击展开要点摘要。
- 提示卡："8 月 15 日后作出的处罚决定必须引用法典条款，平台文书模板已提前完成切换校验。"

### 3. 常用依据网格（2×3 卡）
1. 案卷评查细则（2024 版）— 全文检索入口 + 章节目录
2. 湖南省裁量权基准（2021 版）— 29 张裁量表，按违法情形索引（如"未批先建""超标排放"），表格可在线查
3. 25 项一票否决清单 — 权威版全文，四类分组，与案卷评查模块同源
4. 移送公安量化标准 — 重金属超标 3 倍 / 危废 3 吨入刑等量化条目卡
5. 6 类案件评查框架 — 大气/水/固废/噪声/辐射/其他 六类入口
6. 文书模板说明 — 74 类模板适用场景速查

### 4. 最近查阅与收藏
