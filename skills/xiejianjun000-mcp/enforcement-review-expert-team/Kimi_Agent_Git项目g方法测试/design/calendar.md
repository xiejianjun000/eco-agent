# 工作日历（calendar.md）

## 定位
执法任务、评查节点、督察复查、平台巡检的统一日程视图。非技术化：所有节点用人话命名（"送达决定书"而非"流程节点4"）。

## 布局

### 1. 顶部工具条（40px 标题条下方）
- 左：月份切换「‹ 2026年8月 ›」+「回到今天」文字按钮。
- 中：视图切换 月 / 周 / 日程（分段控件，选中陶土橙底）。
- 右：类型筛选片（多选）：执法检查(陶土橙) / 案卷评查(灰蓝) / 督察复查(橄榄绿) / 平台巡检(紫灰) / 送达节点(琥珀)。

### 2. 月视图（默认）
- 7 列网格，每格：日期数字 + 最多 3 条彩色事项条（圆角 4px，色=类型色浅底深字）+ "+2 更多"。
- 今天：陶土橙圆圈高亮日期。
- 示例事项（与全局数据一致）：
  - 8/3（今日）：金竹山矿业法制审核确认（红边，紧急）｜百卷精评第74卷复核｜每日平台巡检 09:00
  - 8/6：赢湖矿产品现场复查（督察）
  - 8/8：禾青镇页岩砖厂 处罚决定书送达截止（琥珀）
  - 8/12：鑫顺建材案 集体讨论会
  - 8/15：生态环境法典施行日（紫灰标记，全站性提示："今日起引用法典条款，旧法停用"）
  - 8/20：瑞龙木艺厂 整改期限到期
  - 8/26：每日巡检连续满月提醒
- **Animation**：月份切换时网格横向滑入 240ms；事项条 stagger 30ms 淡入；hover 事项条弹浮层（详情+「打开」）。

### 3. 周视图
- 左侧时间轴 08:00–18:00，事项块按时段纵向排列；块状卡片含标题、地点/关联案件、协同人头像。
- AI 建议行（灰蓝虚线块）：如"数据芯建议：8/7 上午安排禾青镇复查，避开周五送达高峰"。

### 4. 日程视图（列表）
- 按日期分组的纵向时间线，左侧日期竖条，右侧事项卡片，完成项橄榄绿对勾。

### 5. 右侧悬浮小面板（工作区内右侧，非右栏）
- "临期 3 日"清单：倒计时时长（"还剩 2 天"琥珀色）+ 一键「提醒承办人」。
- "AI 已帮您安排"：自动排期记录（可撤销）。

## 交互
- 点空白日期格：快速新建事项（类型/标题/关联案件下拉/时间）。
- 拖拽事项条可改期，改期后若影响法定期限（如送达期限）弹出琥珀色确认："该变更将晚于法定期限，是否继续？"
- 事项与执法办案/案卷评查/督察模块双向联动。

## 文案要点
- 期限一律写"法定截止 X月X日"，不用"DDL"。
