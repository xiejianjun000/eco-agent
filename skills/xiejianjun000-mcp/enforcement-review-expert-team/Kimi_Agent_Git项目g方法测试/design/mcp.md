# MCP 连接（mcp.md）— 外部工具接入

## 定位
面向用户的"外部工具接入中心"。对用户只讲"接通了哪些外部帮手"，技术细节（协议、端点）折叠到"高级"里，默认隐藏。

## 布局

### 1. 顶部说明卡
- "这里管理平台与外部工具的连接。接通后，AI 助理可以直接使用这些工具帮您干活，例如查地图、读文档、连打印机。"

### 2. 连接列表（卡片行）
每卡：工具名 + 用途一句 + 状态徽章（已接通 绿 / 未接通 灰 / 异常 红）+ 最近调用时间 + 开关 + 「测试」按钮。
示例连接：
1. **地图服务** — 为辖区地图与 AI 圈选提供底图 — 已接通 · 今日调用 46 次
2. **文档处理服务** — 读写 docx/xlsx/pdf，支撑文书协同 — 已接通 · 今日调用 132 次
3. **消息通知服务** — 向承办人发送临期提醒 — 已接通
4. **打印服务** — 文书直接送打印 — 未接通（「接通」按钮）
5. **数据备份服务** — 每日卷宗备份 — 异常（红，"昨晚备份失败，已自动重试 2 次"，附「重试」）
- **Animation**：测试时按钮变进度环（1.2s）→ 绿对勾/红叉提示 Toast。

### 3. 调用记录（下半部，时间线）
- 行：时间 + 谁调用（专家芯片，如"卷查清"）+ 用了哪个工具 + 干了什么（人话："读取了决定书草稿.docx 并写入批注"）+ 结果徽章。
- 目的：让执法人员知道 AI 做了什么，可审计。

### 4. 高级（默认折叠，紫灰）
- 折叠面板内含技术字段（接入地址、鉴权方式、调用配额），面板标题"高级设置（一般无需修改）"，面向管理员。

## 交互
- 「接通」向导三步：选工具 → 填地址与凭证（带"向信息中心索取"提示）→ 自动测试 → 完成。
- 异常连接红点同步左导航 MCP 项角标。
