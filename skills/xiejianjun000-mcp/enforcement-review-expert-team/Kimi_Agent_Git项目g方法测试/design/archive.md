# 档案管理（archive.md）— 电子卷宗库

## 定位
已归档案卷的检索、借阅与电子卷宗查阅；归档 4 类文书自动成套。

## 布局

### 1. 顶部数字条
- 已归档案卷 157 ｜ 本月归档 6 ｜ 借阅中 3 ｜ 临期未归档 2（琥珀）

### 2. 检索区（突出，占一行大卡）
- 大搜索框："搜案号、当事人、案件类型、文书名…"
- 高级筛选片：年份 / 案件类型（大气/水/固废/噪声…）/ 评查结论（合格/整改/否决）/ 承办人。
- AI 检索提示（灰蓝小字）："也可以直接问：'去年矿区超标被否决的那个案子'"。

### 3. 卷宗列表（表格行）
- 行：案号 + 案件名 + 归档日期 + 卷内文书数 + 评查结论徽章 + 借阅状态 + 操作「查阅」「借阅」「导出」。
- 演示数据与全局一致：娄环罚(冷)〔2026〕2号（金竹山矿业，否决卷，37 份文书）、禾青镇页岩砖厂案、赢湖矿产品案、鑫顺建材案、瑞龙木艺厂案。
- **Animation**：行 stagger 30ms 入场；hover 行底变暖沙色。

### 4. 电子卷宗查看器（点击「查阅」后工作区切换）
- 左侧目录树（按 74 模板编号顺序排列：01 指定管辖通知书 … 归档类文书）；已扫描件带页数，缺失项灰显并标注"该卷未含此文书"。
- 右侧阅读区：文书影像/PDF 预览 + 放大缩小 + 页码；顶部模式切换 阅读 / 批注（紫灰），批注与右侧 Office 区同步。
- AI 侧栏卡：卷宗摘要（"本案因听证期限不足被否决，整改要点 3 条…"）+ 「生成阅卷笔记」。

### 5. 借阅管理
- 借阅流程弹窗：借阅人/事由/期限（默认 7 天）→ 记录入册；到期前 1 天琥珀提醒。

### 6. 空态
- 检索无结果：`empty-archive.svg` / `empty-search.svg` + "没有找到对应卷宗，试试换个说法或放宽筛选"。

## 交互
- 归档入口：执法办案归档段完成后自动推送至此（"归档推送"SOP 第 5 步），显示"待确认归档"队列。
- 导出打包 docx/pdf 整卷。
