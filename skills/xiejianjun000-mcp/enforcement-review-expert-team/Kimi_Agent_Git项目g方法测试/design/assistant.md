# 执法助理（assistant.md）— 平台首页 / AI 工作台

## 定位
用户登录后的默认页。回答三个问题：今天该干什么、AI 帮我干了什么、有什么要我拍板的。

## 布局（工作区自上而下）

### 1. 问候条
- 内容："早上好，李建国 ｜ 今天是 2026年8月3日 星期一 ｜ 今日待办 6 项 · 评查进行中 2 卷 · 平台巡检正常"
- 右侧：主按钮「开始今日工作」（点击展开今日待办区并滚动定位）。

### 2. 今日待办（卡片列表，4–6 条）
每条：状态徽章（紧急=赤陶红/临期=琥珀/普通=灰蓝）+ 任务标题 + 来源模块小字 + 截止时间 + 右侧「去处理」文字按钮。
示例数据：
- 【紧急】金竹山矿业 CEMS 超标案：法制审核意见待确认（执法办案 · 今日 17:00 前）
- 【临期】娄环罚(冷)〔2026〕2号：决定书送达回证待归档（档案管理 · 明日到期）
- 【普通】百卷精评第 74 卷已就绪，待您复核 AI 初评结果（案卷评查）
- 【普通】大气监督帮扶平台：本周巡检报告已生成（平台管理）
- 【普通】赢湖矿产品现场检查复查安排（督察管理 · 8月6日）
- **Animation**：列表 stagger 40ms 依次 slide-up 10px 淡入；紧急条左侧 3px 红条微脉动（2s 循环）。

### 4. 对话助理（底部，chat 区）
- 聊天流（最多显示近 6 条，可展开历史）+ 输入框占位文字："问我：这个案子该怎么走流程 / 帮我起草一份现场检查笔录…"
- 快捷指令片（横向可滚动）：起草文书 / 核对否决项 / 查法条 / 安排复查 / 生成巡检说明。
- AI 回复带引用来源小字（如"依据：生态环境法典衔接指南 · 第 3 章"），灰蓝引用块。
- **Animation**：AI 回复逐段淡入（每段 200ms）；发送按钮按压 scale .96。

### 5. 一周小结（窄卡片条）
"本周：立案 3 · 评查通过 11 · 否决拦截 2 · 文书生成 18"，橄榄绿为主，否决数字赤陶红。点击进入评查看板。

## 交互
- 待办「去处理」跳转对应模块并携带上下文（如跳到案卷评查第 74 卷）。
- 专家卡片「指派任务」弹出抽屉：选任务类型 + 关联案件 + 备注。
- 对话中生成的文书可一键送入右侧 Office 区协同编辑。
