# 执法督察评查专家团 — 仓库内容梳理与产品布局分析

> 版本：2026-08-07 | 面向对象：一线执法人员（非技术语言）

---

## 一、一句话说明这个仓库是什么

这是一个**生态环境执法领域的 AI 专家团队系统**：9 个 AI 角色（1 个调度官 + 8 个领域专家）协同工作，帮执法人员完成从现场检查、执法办案、案卷评查到督察整改的全流程工作，目标是"案卷经得起复议、诉讼、督察，实现零败诉、零撤销、零纠错"。

---

## 二、仓库里到底有什么（按执法人员视角分类）

### 1. AI 专家团队（9 人）

| 角色 | 名字 | 能帮你干什么 |
|------|------|-------------|
| 调度官 | 法眼通 | 接收你的任务，分给合适的专家，汇总结论 |
| 案卷评查专家 | 卷查清 | 审查案卷合法性、扫描 25 项"一票否决"重大问题、逐项打分 |
| 现场执法专家 | 执法准 | 生成各行业现场核查清单、设计取证方案、提示程序合规要点 |
| 督察实战顾问 | 督察精 | 推演督察方案、分析博弈策略、识别 9 种异常信号 |
| 法律合规专家 | 法条通 | 精准查法条（含新老法典对照）、判断要不要移送公安 |
| 文书生成专家 | 文书成 | 自动生成 Word/Excel/PDF 格式的执法文书 |
| 数据分析专家 | 数据芯 | 分析在线监测（CEMS）数据、超标研判、统计报表 |
| 知识库管理专家 | 知识库 | 把经验、法规、案例入库，随时智能检索 |
| 平台巡检专家 | 巡检员 | 每天自动巡检水环境平台、大气帮扶平台并出报告 |

**工作方式**：你交办任务 → 调度官预审分流 → 8 个专家同时分析 → 汇总评估（含一票否决扫描）→ 生成文书报告 → 归档入库。

### 2. 28 项专业技能（Skill）

按业务线组织，相当于每位专家的"办案手册"：

- **案卷评查**（3 项）：25 项一票否决扫描、六类案件评查框架、评查细则逐项打分
- **现场执法**（6 项）：水、气、固废/危废、噪声执法检查 + 采样速查 + 装备清单
- **督察实战**（3 项）：方案推演、博弈策略、异常信号识别
- **法律合规**（4 项）：法条检索、法典过渡衔接、移送公安判定、**湖南省裁量权基准审查**（29 张表逐表核验）
- **文书生成**（4 项）：现场监察记录、核查清单、评查报告、**文书面板系统（74 个湖南省标准文书模板，AI 自动填充）**
- **数据分析**（2 项）：CEMS 数据研判、统计分析
- **知识库**（2 项）：知识入库、智能检索
- **平台巡检**（2 项）：水环境平台、大气帮扶平台
- **地图制图**（2 项，新增）：污染源 GIS 标注与执法路径规划、现场勘查示意图绘制

## 四、结论

**这个仓库的"大脑"已经非常完整**——专家团队、办案技能、法规知识、记忆系统、实战成果都有了，而且经过真实案卷检验。它现在缺的是"脸"：一套让执法人员点点鼠标就能用上这些能力的界面。你描述的左导航（12 模块）+ 右协作栏（Office 套件、GIS 地图、记忆闭环）正是这张脸的正确形态，而且右侧栏所需的三项核心能力（文书、地图、记忆）在仓库里已经全部有对应的后端支撑，不是从零开始。
