# 案卷评查（review.md）— 25 项一票否决扫描 · 百卷精评

## 定位
平台核心模块。评查流程：上传/选卷 → AI 五阶段 SOP → 25 项否决扫描 → 人工复核 → 出报告。

## 布局

### 1. 顶部：百卷精评进度横幅
- 大数字 **73 / 100**（橄榄绿）+ 进度条 + 小字"百卷精评行动 · 第 74 卷 AI 初评完成，待您复核"
- 右侧：通过 68 · 整改 4 · 否决 1 的迷你统计（绿/琥珀/红）。
- **Animation**：进度条从 0 充至 73% 900ms；数字 count-up。

### 2. SOP 五阶段条
预审分流 → 并行分析 → 综合评估(一票否决) → 文书生成 → 归档推送；当前卷所处阶段陶土橙高亮，步下显示负责专家（法眼通/数据芯+卷查清+法条通 并行/卷查清/文书成/知识库）。

### 3. 主体左：评查队列（列表）
- 行：卷宗名 + 案号 + 评查状态（待评/AI 初评中/待人工复核/已完成）+ 得分或否决标记 + 「开始评查/复核」。
- 演示队列：第 74 卷 鑫顺建材（待复核）、第 75 卷 瑞龙木艺厂（AI 初评中，进度 45%）、历史卷（金竹山矿业 否决卷、禾青镇页岩砖厂 整改卷 等）。

### 4. 主体右（或选中卷后整页）：25 项一票否决扫描面板
- 顶部说明条（人话）："以下 25 项任中一项，本案卷即为不合格（0 分）。"
- 四类分组折叠面板（程序类 10 / 证据类 5 / 法律适用类 3 / 移送类 2 / 其他 5）：
  - 每行：编号 + 名称 + 核心关键词小字 + 结果徽章（通过 绿 / 命中 红 / 未涉及 灰）+ 关联法条引用 + 「查看依据」（展开 AI 定位到的卷宗页码与原文摘录）。
  - 命中行整行浅红底 `#F7E9E6`，左侧 3px 红条。
- 扫描动效：点击「开始扫描」后逐行扫描——行高亮陶土橙 120ms → 落定绿/红，伴随行号计数；全站最重动效，仅此一处。
- 底部汇总卡：得分（未命中时）/ 否决结论（命中时红卡："命中第 9 项：听证期限不足 — 本案卷评查不合格"）+ 整改建议列表 + 「生成评查报告」（文书成，自动套用报告模板）。

### 5. 人工复核确认条（底部固定）
- "AI 初评结果仅供参考，请复核后确认" + 「确认通过」「退回补正」「提出异议」三按钮；异议可逐行批注（批注同步右侧 Office 区）。

## 交互
- 评查报告可导出 docx/pdf 并归档（跳档案管理携带上下文）。
- 与执法办案联动：在办案件可随时发起"随办随评"。
- 历史卷对比：同一企业历次评查分数折线小图。

## 文案
- "一票否决"首次出现带释义气泡："指触及法定底线的严重问题，案卷直接判不合格"。
