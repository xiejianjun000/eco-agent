# EcoAegis 生态环境执法办案评查一体化平台 — 全局设计文档

## 1. 产品定位

面向一线生态环境执法人员的**三栏式日常工作平台**（非营销站）。核心诉求：长时间使用不疲劳、信息密度高但不杂乱、语言非技术化、AI 能力以"助手"而非"技术"的方式呈现。平台承载真实数据资产：25 项一票否决、73+1 个文书模板、9 个 AI 专家、28 个 Skill、法规知识库（评查细则 2024、湖南裁量权 2021、生态环境法典 2026-08-15 衔接指南）、业务平台接入与实战案卷数据（金竹山矿业、赢湖矿产品、禾青镇页岩砖厂、鑫顺建材、瑞龙木艺厂、娄环罚(冷)〔2026〕2 号、百卷精评 73/100、每日巡检报告）。

## 2. 设计语言基调

- **低饱和暖色**：米白底、暖灰层次、陶土橙/橄榄绿作功能强调，红仅用于否决/告警。
- **充足留白**：卡片内边距 ≥ 16px，区块间距 ≥ 20px；信息分组靠留白而非重边框。
- **层级清晰**：三级文字层级（页面标题/区块标题/正文辅助），同一层级字号色重恒定。
- **非技术化语言**：不出现"模型""token""MCP 协议"等对用户的黑话；MCP 模块对用户命名为"MCP 连接（外部工具接入）"，内部文案用"连接外部工具""已接通/未接通"。

## 4. 字体与排版

- 字体栈：`"PingFang SC","Microsoft YaHei","Noto Sans SC",system-ui,sans-serif`。数字与编号使用 `font-variant-numeric: tabular-nums`（案件号、日期、数据表）。
- 字号阶梯：
  - 页面大标题 20px / 600 / `#2E2A26`
  - 区块标题 15px / 600
  - 卡片标题 14px / 600
  - 正文 13px / 400，行高 1.7
  - 辅助说明 12px / 400 `#9A9184`
  - 数据大字（看板数字）28–32px / 600，tabular-nums
- 徽章/标签 11px，圆角 10px，左右 padding 8px。
- 按钮文字 13px / 500，不缩字号。

## 5. 间距与圆角系统

- 间距刻度（8 基数的暖化变体）：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48。
- 卡片内边距 16–20px；工作区区块间距 20–24px；页面四周留白 24px。
- 圆角：卡片 10px，按钮/输入框 8px，徽章 10px（胶囊），头像圆形。
- 阴影：仅一级——`0 1px 2px rgba(62,56,49,.05), 0 4px 12px rgba(62,56,49,.06)`；hover 加深到 `.08/.10` 并上移 1px。不用多层阴影。

## 6. 三栏布局规范

```
┌──────────┬──────────────────────────────┬────────────┐
│ 左导航    │ 中间工作区（随模块切换）        │ 右侧协作栏  │
│ 232px    │ flex:1, min 640px            │ 320px      │
│ #3E3831  │ #FBF9F5, 可纵向滚动           │ #F1EDE6    │
└──────────┴──────────────────────────────┴────────────┘
```

- 视口 ≥ 1440px：三栏全显。1280–1439px：右栏收窄 280px。< 1280px：右栏变抽屉（右上角按钮呼出，遮罩 30% 黑）。
- **左导航 232px**：顶部平台徽标区（EcoAegis 盾形标 + "生态环境执法办案评查一体化平台"小字），下为 12 个模块项（图标 18px + 文字 13px，行高 44px，间距 2px），选中态：左侧 3px 陶土橙竖条 + 底 `#4A443C` + 文字 `#F5F1EA`。底部：当前用户（姓名/单位/头像）+ 日期。
- 12 项顺序严格固定：执法助理、工作日历、辖区地图、企业管理、平台管理、执法办案、督察管理、案卷评查、档案管理、知识库、MCP连接、设置。带角标的模块：执法助理（AI 待办数）、平台管理（离线平台数）、案卷评查（进行中数）、工作日历（今日事项数）。
- **中间工作区**：顶部 40px 模块标题条（页面标题 + 面包屑式一句说明 + 右侧常用操作按钮区），下方内容按各模块设计文件。
- **右侧栏 320px**：4 个可折叠 section，顺序固定：①Office 文书协同 ②GIS 地图辅助 ③Hermes 记忆进化 ④评查看板趋势。每区头部 40px（图标+标题+折叠箭头+状态点），折叠态仅显示头部；展开高度自适应，四区总高超屏时整栏独立滚动。默认 ①④ 展开，②③ 折叠。详见 `rightpanel.md`。

## 7. 共享组件

- **按钮**：主（陶土橙底白字）/ 次（白底暖灰边主文字）/ 文字型（陶土橙文字）。hover 加深 6%，active scale .98，过渡 150ms。
- **状态徽章**：通过(橄榄绿) / 否决(赤陶红) / 待办(琥珀) / 信息(灰蓝) / 审阅(紫灰)，浅色底 + 同色深文字。
- **AI 专家芯片**：9 专家统一样式——灰蓝圆点 + 专家名（法眼通/卷查清/执法准/督察精/法条通/文书成/数据芯/知识库/巡检员）+ 一句它正在做什么（如"卷查清 正在比对第 3 项证据"）。
- **SOP 阶段条**（5 阶段：预审分流→并行分析→综合评估→文书生成→归档推送）：横向五步圆点连线，当前步陶土橙脉动，完成步橄榄绿对勾。用于执法助理、案卷评查顶部。
- **进度条**：高 6px，暖沙底，陶土橙填充；百卷精评用橄榄绿。
- **卡片**：白底 10px 圆角 + 一级阴影 + 1px `#EFE9DF` 边；hover 上浮 1px。
- **空态**：暖沙色插画图标（SVG）+ 一句人话说明 + 主按钮，不出现英文 Empty。
- **Toast**：右上角滑入，320ms，成功橄榄绿/告警赤陶红。
- **切换开关（toggle）**：开=橄榄绿，关=暖灰。

## 8. 动效规范（克制、办公向）

- 页面切换：工作区内容 `opacity 0→1, translateY 12px→0, 280ms ease-out`；不做路由级重动画。
- 列表入场：stagger 每项 40ms，slide-up 10px。
- 折叠区：高度动画 240ms ease-in-out + 箭头旋转 180°。
- 数字看板：数字滚动计数 600ms（count-up）。
- 一票否决扫描：逐行高亮扫描动画（见 review.md / enforcement.md），是当前页面唯一允许的重动效。
- hover 微交互 150ms；全站动画元素同屏 ≤ 8 个；无 3D、无视差、无着色器——办公平台不使用 ScrollTrigger 叙事。
- 尊重 `prefers-reduced-motion`：关闭扫描与计数动画。
