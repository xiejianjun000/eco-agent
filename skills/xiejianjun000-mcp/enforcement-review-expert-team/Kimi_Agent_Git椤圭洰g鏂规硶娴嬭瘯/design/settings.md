# 设置（settings.md）

## 定位
个人偏好与 AI 协助程度设置。克制、清晰，不堆砌。

## 布局（左 Tab 导航 + 右内容，工作区内）

### Tab 1 个人与单位
- 头像（`avatar-default.png` 兜底）、姓名、单位、执法证号、联系方式；编辑走行内表单，保存按钮陶土橙。

### Tab 2 通知提醒
- 开关组（toggle，开=橄榄绿）：临期提醒（提前 3 天/1 天 两档单选）/ 否决预警即时提醒 / 平台巡检异常提醒 / 每日工作小结（下班前推送）。
- 提醒方式：站内 / 短信（勾选）。

### Tab 3 AI 协助程度（核心特色区）
- 三档单选卡（大卡片，当前档陶土橙描边）：
  1. **全面协助**（默认）：AI 自动起草、自动巡检、自动评查初评，我只做确认
  2. **关键协助**：AI 只做评查初评与法规核验，文书我来自写
  3. **仅查询**：AI 只回答问题和检索，不动我的文书
- 下方细项开关（随档位联动）：文书自动起草 / 平台自动代管 / 评查自动初评 / 日历自动排期。
- 固定声明条（暖沙底）："无论哪一档，处罚决定、销号、归档确认等关键动作始终由您本人完成。"
- **Animation**：档位切换时细项开关 240ms 依次切换状态。

### Tab 4 界面偏好
- 字号（标准/大 两档，面向长时间使用）/ 右侧栏默认展开区勾选 / 地图默认图层勾选。

### Tab 5 账号与安全
- 修改密码、登录记录列表（时间/IP 简写/设备）、「退出全部设备」。

## 交互
- 所有修改即时保存 + 右上角 Toast"已保存"；AI 协助档位切换需二次确认说明影响。
