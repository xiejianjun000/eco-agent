# 督察管理（inspection.md）

## 定位
督察任务、帮扶行动与整改闭环跟踪。督察精专家主场。

## 布局

### 1. 顶部数字条
- 进行中督察任务 4 ｜ 待整改问题 11 ｜ 逾期未完成 1（红）｜ 本月帮扶 6 次

### 2. Tab：督察任务 / 整改跟踪 / 帮扶记录

**Tab 1 督察任务（看板式，三列：待开展 / 进行中 / 已完成）**
- 任务卡：任务名 + 类型徽章（专项督察/日常督察/帮扶）+ 覆盖企业数 + 期限 + 进度条。
- 示例：① 禾青镇砖瓦行业专项督察（进行中 60%，含禾青镇页岩砖厂）② 矿区生态修复"回头看"（待开展，含金竹山矿业、赢湖矿产品）③ 大气帮扶夏季行动（进行中）。
- **Animation**：拖拽卡片换列时位移弹簧动画 300ms；列入场 stagger 60ms。

**Tab 2 整改跟踪（表格化列表）**
- 行结构：问题描述 + 责任企业 + 整改期限 + 剩余天数（≤3 天琥珀，逾期红）+ 进度（未开始/整改中/待复核/已销号 四态徽章）+ 操作「复核销号」。
- 示例行：瑞龙木艺厂 粉尘收集设施改造（剩 17 天，整改中）；鑫顺建材 堆场覆盖（逾期 2 天，红，"督察精 已生成催办函草稿"）。
- 点击行展开整改前后照片对比位 + 复核记录。

**Tab 3 帮扶记录**
- 时间线卡片：帮扶日期 + 企业 + 帮扶内容 + 后续建议；来源标注"同步自大气监督帮扶平台"。

### 3. 右侧 AI 辅助条
- "督察精 提示"卡：如"鑫顺建材整改已逾期，建议今日现场核查，路线已备好 → 查看地图"。
- 一键生成：督察通报 / 整改通知书 / 帮扶小结（文书成协同，模板编号引用 74 模板体系）。

## 交互
- 「复核销号」需上传复核材料 + 人工确认弹窗。
- 逾期行自动浮出「催办」按钮。
