## 一、项目概述

### 1.1 定位

**执法督察评查专家团**是一个面向生态环境执法领域的 AI 多智能体协作系统。它能够自动完成：

- **案卷评查**：对行政处罚案卷进行合法性审查、一票否决扫描、规范性评分，生成结构化评查报告
- **现场执法**：生成行业定制的现场核查清单、设计证据链方案、提供执法程序合规指引
- **督察实战**：推演督察方案、分析博弈策略、识别 9 种异常信号
- **法律合规**：精准检索法律条文（含生态环境法典双标注）、判定移送公安标准
- **文书生成**：生成多格式专业执法文书（docx/xlsx/pdf）
- **数据分析**：CEMS 在线监测数据研判、超标分析、统计分析
- **平台巡检**：每日自动巡检水环境平台 + 大气监督帮扶平台

### 1.2 核心使命

> 在执法办案全过程中确保合法合规，让案卷经得起复议、诉讼、督察，实现零败诉、零撤销、零纠错。

### 1.3 规模一览

| 指标 | 数值 |
|------|------|
| 团队人数 | 9 人（1 调度官 + 8 领域专家） |
| 领域 Skill | 28 个 |

## 三、团队架构

### 3.1 协作模型：Hub-Spoke（轮辐式）

```
                     ┌──────────────────────┐
                     │   法眼通 (调度官)      │
                     │   任务分发·质量仲裁    │
                     │   一票否决·综合评估    │
                     └────┬──┬──┬──┬──┬────┘
            ┌─────────────┤  │  │  │  ├─────────────┐
            ▼             ▼  ▼  ▼  ▼               ▼
     ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
     │卷查清    │  │执法准    │  │督察精    │  │法条通    │
     │案卷评查  │  │现场执法  │  │督察实战  │  │法律合规  │
     └──────────┘  └──────────┘  └──────────┘  └──────────┘
     ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
     │文书成    │  │数据芯    │  │知识库    │  │巡检员    │
     │文书生成  │  │数据分析  │  │知识管理  │  │平台巡检  │
     └──────────┘  └──────────┘  └──────────┘  └──────────┘
```

**铁律**：
1. 调度官是唯一的信息中转枢纽，所有跨成员信息流必须经调度官中转
2. 成员之间禁止直连通信
3. 成员的专业产出必须由成员亲自输出，调度官只做编排与汇编
4. 禁止调度官跳过 TeamCreate 直接模拟成员发言

## 四、工作流程

### 4.1 标准 SOP（5 Phase）

```
┌──────────────────────────────────────────────────────┐
│  Phase 1: 任务接收与预审分流（调度官串行）            │
│  ├─ 解析任务类型                                     │
│  ├─ 分类定性（六类案件判定+管辖+时效）                │
│  └─ 受理条件核查 → 分配团员                         │
├──────────────────────────────────────────────────────┤
│  Phase 2: 并行分析（团员同时 spawn）                  │
│  ├─ 案卷评查 + 现场执法 + 督察实战                   │
│  ├─ 法律合规 + 文书生成 + 数据分析                   │
│  └─ 知识库检索 + 平台巡检（按需）                    │
├──────────────────────────────────────────────────────┤
│  Phase 3: 综合评估（调度官串行）                      │
│  ├─ 汇总所有团员结论                                 │
│  ├─ 25项一票否决规则引擎                             │
│  ├─ 风险分级（高/中/低）                             │
│  └─ 综合判定                                         │
├──────────────────────────────────────────────────────┤
│  Phase 4: 文书生成                                   │
│  ├─ 评查报告（docx，含彩色分级标题+法律依据速查表）   │
│  ├─ 问题清单（xlsx，含扣分明细+法条引用+整改建议）    │
│  ├─ 统计分析（评分分布+TOP10扣分+否决命中）           │
│  └─ 法律依据链（按效力层级排列）                      │
├──────────────────────────────────────────────────────┤
│  Phase 5: 归档推送                                   │
│  ├─ 入库归档（知识库自动入库）                        │
│  ├─ 邮件推送（可选，agent-mail）                      │
│  └─ 状态更新（平台巡检状态同步）                      │
└──────────────────────────────────────────────────────┘
```

### 4.2 典型案例工作流

**案卷评查流**：
```
案情输入 → 卷查清(合法性+否决+评分) + 法条通(法条双标注+移送判定+裁量审查) + 数据芯(监测数据研判)
         └─ 法条通内部调用链：
              legal-search(法条定位) → legal-prosecution(移送判定) → legal-discretion(裁量核验)
         → 法眼通(综合评估+否决引擎+风险分级)
         → 文书成(评查报告.docx + 问题清单.xlsx) + 知识库(归档)
```

**现场执法流**：
```
企业+线索输入 → 执法准(核查清单+GIS地图标注+勘查示意图+证据链设计) + 法条通(法律依据)
              → 法眼通(综合方案审定)
              → 文书成(现场监察记录.docx + 核查清单.docx)
```

**督察实战流**：
```
区域+行业输入 → 督察精(前置分析+推演方案+博弈策略+典型案件) + 法条通(区域法规)
              → 法眼通(综合方案审定)
              → 文书成(督察方案.docx + 汇报PPT)
```

### 6.2 插件-业务线映射

```
案卷评查线：pdf(OCR) → summarize(摘要) → qmd(检索) → docx(报告) + xlsx(台账) → humanizer(润色) → agent-mail(推送)
文档处理线：pdf(拆分) → docx(模板) → xlsx(核对) → nano-pdf(修改) → excalidraw(制图)
现场执法线：tencentmap(GIS) + excalidraw(勘查图) → pdf(清单模板) → docx(监察记录)
```

## 十一、使用指南

### 11.1 安装

1. 将 `eco-enforcement-review-team/` 目录放置于 WorkBuddy 的专家插件目录
2. 确保 12 个外部插件均已安装（当前全部已就绪）
3. 配置 TMAP_WEBSERVICE_KEY 环境变量（启用腾讯地图功能）
4. 在 WorkBuddy 专家中心加载"执法督察评查专家团"

### 11.2 启动方式

| 场景 | 输入示例 |
|------|---------|
| 全面评查 | "请对该案卷进行全面评查：冷水江市赢湖矿产品有限公司超标排放案" |
| 现场核查 | "生成冷水江金富源碱业有限公司的水污染防治执法核查清单" |
| 督察推演 | "模拟督察：娄底市冷水江区域化工行业" |
| 法律分析 | "该案超标3倍是否达到移送公安标准？" |
| 文书生成 | "生成金竹山矿业现场监察记录" |
| 数据分析 | "分析金竹山矿业24次超标CEMS数据是否存在造假" |
| 案例检索 | "检索类似'在线监测不正常运行'的判例" |
| 每日巡检 | 自动触发（每日 08:00） |

### 11.3 输出物格式

| 输出 | 格式 | 特点 |
|------|------|------|
| 评查报告 | .docx | 彩色分级标题 + 法律依据速查表 + 修订痕迹 |
| 问题清单 | .xlsx | 扣分明细 + 法条引用 + 整改建议 + 图表 |
| 核查清单 | .docx | 11章专业结构 + 五色警示框 + 封面 |
| 勘查示意图 | .excalidraw + .png | 矢量可编辑 + 预览图 |
| GIS 地图 | 文字分析报告 / 交互式地图 | 空间关系 + 距离计算 |
| 巡检报告 | .md | 任务明细表 + 超期告警 + 对比结论 |

### 11.4 环境要求

| 组件 | 要求 |
|------|------|

| Python | 3.13+（脚本运行） |
