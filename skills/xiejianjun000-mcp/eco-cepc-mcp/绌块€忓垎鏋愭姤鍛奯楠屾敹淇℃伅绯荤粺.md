### 2.2 WAF 行为分析

服务器使用 **阿里云 WAF（Web Application Firewall）**，检测到 WAF 行为特征：
- **第一阶段**：返回 HTTP 412 (Precondition Failed)，下发 JS 挑战（`/2dFsELm1TcWE/BEnR5IhtWidA.dd15bf2.js` 格式，混淆代码约 200KB）
- **第二阶段**：JS 挑战执行后计算 WAF cookie（初始 `m5TEkyPGTubaO` → 计算值 `m5TEkyPGTubaP`），浏览器自动携带重定向
- **第三阶段**：所有 API 请求附带 `??GcUpVg1b=<WAF签名>` 查询参数（由前端 JS 计算）

WAF 综合判断依据：
- 浏览器指纹（`navigator.webdriver`、CDP artifacts）
- TLS 指纹（JA3）
- Canvas/WebGL 渲染指纹
- 插件、字体、屏幕分辨率等环境指纹
- 自动化框架特征（Playwright CDP 调用、Selenium chromedriver 协议）

### 2.3 ✅ WAF 绕过突破（方案14）

**关键洞察**：WAF 检测的是**自动化框架的 CDP artifacts**（Playwright/Selenium 在 Chrome 中注入的调试协议调用），而非 Chrome 本身。

**绕过方案**：
```
1. child_process.spawn 启动真 Chrome 151（非 Chromium）
   - --disable-blink-features=AutomationControlled（移除 webdriver 标记）
   - headful 模式（非 headless，WAF 检测 headless）
   - 不使用任何自动化框架包装

2. about:blank 启动 → 等待 3 秒 Chrome 就绪

3. 获取 CDP target: http://127.0.0.1:PORT/json → 找到 page 类型

4. WebSocket 连接到 target.webSocketDebuggerUrl

5. 先启用 CDP 域：Network.enable + Page.enable + Runtime.enable
   ⚠️ 关键：必须在导航之前启用，否则网络事件不会被捕获

6. Page.navigate 到目标 URL
   → Chrome 真实加载页面
   → WAF 5秒盾 JS 挑战在真实 Chrome JS 引擎中自动执行
   → WAF cookie (m5TEkyPGTubaP) 自动计算并设置
   → 页面正常加载（15秒等待）

7. 之后所有 API 调用通过 Chrome 内部 fetch() 执行
   → WAF cookie 和 GcUpVg1b 签名由 Chrome 自动携带
   → 无需手动管理 WAF 状态
```

**验证结果**：
- 页面长度：28000+ 字节（完整登录页）
- 捕获 5 个初始 API 请求（均返回 200）
- 验证码 API 响应正确（含 codeImg base64 + uuid）
- 公开项目列表 API 返回真实数据（全国项目）

#### API 技术特征

- **前缀**: 所有 API 使用 `/jeeplus-vue/` 前缀
- **WAF 签名**: 所有请求附带 `??GcUpVg1b=<computed_value>` 查询参数（由前端 JS 计算，通过 Chrome fetch 自动携带）
- **登录加密**: 用户名/密码 AES 加密后 Base64 编码
- **Token**: JWT (HS256)，存储在 Cookie 中，有效期约24小时
- **分页**: 标准分页参数（page/size），返回 {records, total, size, current, pages}
- **排序**: orders 参数支持按字段排序

## 五、MCP Server 设计方案

### 5.1 设计原则

1. **接口抽象**：定义清晰的工具接口，与 WAF 状态解耦
2. **可降级运行**：未登录模式下提供公开查询能力
3. **凭证注入**：支持外部传入已登录的 Cookie/Token
4. **数据缓存**：公开查询结果本地缓存（合规范围内）
5. **可演进化**：接口与实现分离，便于后续接入真实 API

### 5.2 工具清单

| 工具名 | 功能 | 模式 |
|--------|------|------|
| `public_project_search` | 公开项目信息查询 | 无需登录 |
| `login_session_init` | 会话初始化（注入已登录Cookie） | 需外部凭证 |
| `project_detail` | 单个项目详情 | 需登录 |
| `project_audit` | 项目填报合规性审计（25项一票否决） | 需登录 |
| `enterprise_lookup` | 企业基本信息查询 | 需登录 |
| `region_statistics` | 区域项目统计 | 需登录 |
| `attachment_download` | 附件下载 | 需登录 |
| `report_export` | 评查报告导出 | 本地生成 |

### 5.3 数据模型（核心实体）

```python
class ConstructionProject:
    project_code: str          # 项目代码（投资项目在线审批监管平台）

    pollutant_discharge: PollutantDischarge
```
