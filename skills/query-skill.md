# query-skill — 法规知识查询

## Meta

**用途**：从 FlowWiki 知识库中检索生态环境法律法规知识
**调用条件**：用户提出法规相关问题时自动触发
**依赖**：eco-knowledge-mcp / obsidian-mcp

---

## Instructions

### 1. 查询意图识别

当用户提问涉及以下内容时，激活本技能：
- 具体法规条文的内容、解释、适用
- 某一环境要素（大气/水/土壤/固废/噪声等）的法律规定
- 执法程序、处罚幅度、裁量基准
- 法规之间的关联和引用关系
- 法规的时效状态（现行/废止/修订）

### 2. 检索策略

```text
1. 识别用户问题中的环境要素标签（env/air, env/water 等）
2. 提取关键词（如 "超标排放" "处罚幅度" "行政复议"）
3. 构建检索查询（混合 BM25 + 向量检索）
4. 检索 FlowWiki 知识库（通过 MCP 工具）
5. 筛选相关度 Top 5 结果
6. 验证法规时效状态
7. 生成回答
```

### 3. 回答格式

```markdown
## 法规检索结果

**问题**：[用户原始问题]

### 相关法规

| 法规名称 | 条款 | 相关内容 | 时效 |
|:---------|:-----|:---------|:----:|
| 法规名 | 第X条 | 摘要 | ✅ 现行 |

### 分析结论

[综合分析，多法关联时说明交叉引用关系]

### 原文指针

- 法规 X 第 Y 条：`raw/法规/...`
- 法规 A 第 B 条：`raw/法规/...`

---

置信度：高 | 检索时间：xxx
```

### 4. 处理原则

- **多法综合**：当涉及多个法规时，说明各法规之间的关系和优先适用顺序
- **时效标注**：每条法规引用必须标注时效状态（现行/即将生效/已废止）
- **法典优先**：生态环境法典生效后，优先引用法典条文，同时标注对应原单行法
- **不确定处理**：无法确认的内容必须标注 `[待确认]`
